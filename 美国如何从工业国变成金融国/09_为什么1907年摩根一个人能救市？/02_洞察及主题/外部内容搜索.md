## 六、本文差异化空间

1. **问题重设**：外部多答「摩根很有钱/很有名所以能救」；本文应答「法定央行缺位时，协调权由召集、查账、接盘三类私人权力临时组装」——直接对齐核心问题与系列「协调入口」框架。

2. **主战场定位**：多数样本混写「银行恐慌」；本文可突出「信托挤兑+清算所够不着」这一制度缝隙，解释为何协调权落在摩根私人网络而非清算所官方程序。

3. **解构而非强化「一个人」**：同题内容几乎一边倒强化英雄；本文用 E0918 与协同名单，把「一个人」改写成「单一指挥中枢 + 分散出资与制度节点」，与标题形成张力而非矛盾。

4. **查账权作机制枢纽**：外部要么跳过审查，要么写「Knickerbocker 已破产」；本文以 Strong 审查与 uncertain solvency 为枢纽，呈现「谁有权在几小时内决定机构生死」——少见于中文科普。

5. **数字纪律作差异化信号**：在中文生态充斥 150%、半小时 2500 万、8 家破产时，本文严格分场景引用 2360 万/10 分钟、825 万信托贷款、2500 万信托池等，本身即专业差异。

6. **拒绝两种极端**：既不写「爱国金融侠」，也不写「阴谋食尸鬼」；以期刊体机制叙事占据中间地带，匹配 README 三红线与读者画像。

7. **轻触制度后果**：Fed 诞生仅收束，不把本篇写成「美联储前传」——与同题中文内容拉开结构差异。

## 七、对洞察编辑的约束

后续 `insight-select` 必须遵守：

1. **核心洞察须围绕「召集权、查账权、接盘网络」三类权力展开**，不得把「摩根有钱/有名/有爱国心」设为主洞察；「一个人」仅作叙事钩子，须配合 E0918 解构。

2. **制度前提写清**：无法定中央银行；清算所对成员银行与对信托公司的能力边界（E0903–E0905）；禁止「清算所=央行」「完全无人管金融」。

3. **严格遵守事实核查清单禁止写法与口径**：E0912 不写 Knickerbocker 已确认破产；E0917 纽交所筹款优先 2360 万/10 分钟；所有 2500 万须分场景；Frydman 选择性救助若出现须标学术假说；B01–B11 全部遵守。

4. **不采用中文科普谣言包**：150% 利率、8 家 4 天破产、半小时 2500 万、Barney 当场自杀等一律不进洞察。

5. **叙事比例**：场景（1907 年 10–11 月关键节点）约 40%，机制解释约 40%，判断收束约 20%；不以 Fed 诞生、Pujo 调查、2008 类比作主块。

6. **差异化检查**：每条候选洞察须能回答——与同题外部内容的差异是什么；若只能复述 Wikipedia/凤凰故事线，则淘汰。

7. **不引用同系列其他文章**；当代类比若有，仅一句回声，不作论证主钉。

## 八、风险提示

| 风险 | 说明 | 处理建议 |
|---|---|---|
| 事实风险 | 外部英文百科常写 Knickerbocker insolvent；中文样本数字混乱 | 一律以事实核查清单为准；引用机制不引用外部数字 |
| 重复风险 | 「无央行→摩根救→催生美联储」为最高频结构 | 中段锁定三类权力；Fed 仅一句收束 |
| 标题风险 | 题目含「一个人」易引英雄期待 | 导语或第一节尽早设预期：拆解「一个人」 |
| 叙事风险 | 锁门、图书馆、铜王、U.S. Steel 等场景极易写散 | 每场景只服务一种权力；禁止场景大全 |
| 立场风险 | Gotham 式批判与中文颂扬两极 | 机制中立：写「谁有权协调、附带何种利益」而不道德审判 |
| 洞察风险 | 易滑向「影子银行/信托=今天金融科技」类比 | 信托公司写「合法但监管较松」，不做当代影射主论证 |
