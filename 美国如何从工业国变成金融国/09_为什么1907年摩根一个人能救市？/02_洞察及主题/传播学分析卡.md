## 一、评估依据摘要

### 2.1 当前文章传播前提

- **平台**：今日头条信息流 + 微信公众号长文；手机端跳读，单篇 10–15 分钟（约 2800–3200 字）。
- **读者进入**：混合型——主动需求（金融史/危机救援）+ 被动唤起（「一个人能救市」「没央行怎么办」反差）。
- **传播承诺**：交付「召集权、查账权、接盘网络」三类协调权框架；拆解「一个人」简化叙事；给出可转述的机制故事链。

### 2.3 当前文章一票否决项

1. 事实未放行或突破限定口径（B01–B11、E0912/E0917 混场景、Frydman 定论式因果）。
2. 目标客户明显不匹配（仅服务专业小圈或阴谋论爱好者）。
3. 标题承诺无法兑现（「一个人包打天下」「内幕真相」「摩根独力出资」）。
4. 照搬外部常见写法（传记体、阴谋体、数字惊悚体、1913 流水账）且无机制差异。
5. 违背系列基调（个人崇拜/恶魔化、控诉腔、多入口贪多、依赖同系列他篇）。
6. 只剩情绪或故事，说不出「协调入口」与三类权力。
7. 需过多专业前置，2800–3200 字内混合型读者无法进入。
8. 把复杂制度变化压成单一坏人或单一原因。

**硬性附加规则**（审查卡第十三节）：目标客户匹配低于 3 分不得推荐为主洞察；事实支撑风险高（等同系列「事实安全」低于 4 分）不得进入方向把控。

## 三、逐条评估

### 候选洞察 1：三类协调权的临时组装

#### 1. 候选原文

> 1907 年摩根能「暂代央行」，不是因为个人更有钱，而是因为在法定央行缺位时，他临时组装了**召集权、查账权、接盘网络**三类私人协调权力。

#### 2. 阅读意图审查

| 审查项 | 判断 |
|---|---|
| 主要入口类型 | 混合型 |
| 主动需求价值 | 高——直接回答「没有央行，私人银行家凭什么协调全系统」，交付系列「协调入口」框架 |
| 被动唤起价值 | 高——可承接「一个人能救市」反差，500 字内转入具体场景（纽交所停盘、Strong 查账） |
| 点击率风险 | 低——与题面同构，但须在前 20% 拆解「一个人」防英雄期待 |
| 点赞率风险 | 低——机制获得感强，情绪克制 |
| 承诺兑现风险 | 低——P0 事实全覆盖三类权力；须避免写成并列清单而无场景 |
| 推荐策略 | 可作主洞察；开篇用单场景（M02）锚定，中段分权展开 |

#### 3. 目标客户匹配审查

| 目标客户 | 兴趣匹配 | 前置知识是否足够 | 现实处境 / 社交场景是否匹配 | 是否值得继续评估 |
|---|---|---|---|---|
| 泛财经深度读者 | 高 | 是 | 高 | 是 |
| 商业史 / 制度史爱好者 | 高 | 部分（信托/清算所需 1–2 段补齐） | 高 | 是 |
| 产业与金融化观察者 | 高 | 是 | 高 | 是 |
| 被动唤起型读者 | 中 | 部分 | 中 | 是 |

- **匹配结论**：适配
- **如果不适配，是否建议放弃**：否
- **不适配原因**：—

#### 4. 前置上下文审查

| 审查项 | 判断 |
|---|---|
| 知识上下文 | 承接「美联储/央行」「摩根救市」模糊认知，500 字内可建立无央行 + 信托挤兑背景 |
| 经历上下文 | 可轻触「系统太大不能倒」「谁有资格组织救援」当代感受，不作主钉 |
| 情绪上下文 | 承接反常识好奇（没央行却有人救场），非预设立场 |
| 问题上下文 | 直接承接核心问题「为什么私人银行家能暂代央行」 |
| 社交上下文 | 适合「推荐一篇讲清协调权的历史文」类转发 |
| 承诺匹配 | 标题「一个人」须在正文拆解为三类权力 + 多方协同（E0918） |

#### 5. 七维度评分

| 维度 | 分数 | 判断 |
|---|---:|---|
| 目标客户匹配 | 5 | 四类读者均可进入；主动读者获框架，被动读者可被场景带入 |
| 社交货币 | 5 | 可压缩为「危机里稀缺的不是钱，是谁能召集、查账、组织别人掏钱」 |
| 诱因 / 前置上下文 | 5 | 同时服务反差提问与机制需求；扩宽从「一个人」到三类权力 |
| 情绪 | 4 | 恍然大悟为主；须控三类并列导致的百科感 |
| 公共性 | 4 | 挤兑、停盘、选择性救助可感；机制段须贴人类后果 |
| 实用价值 | 5 | 读者可带走完整「协调入口」框架，与系列收获标准一致 |
| 故事 | 4 | 图书馆会聚、Strong 查账、2360 万筹款、825 万信托贷款等节点齐全；风险是平均用力变清单 |
| **总分** | **32** | **达主洞察阈值（≥31）；须用 1–2 个高可视场景锚定每类权力** |

#### 6. 转给谁及场景

- **转给谁**：读财经公众号的同事、爱聊金融史的朋友、关心 2008 救援公平性的家人
- **关系**：同事/朋友/家人，非专业金融从业者居多
- **场景**：讨论「银行危机政府会不会救、先救谁」；推荐历史机制长文；回应「摩根是不是一个人掏的钱」
- **为什么此时会转**：文章给出可复述的三类权力框架，比百科流水账多一层「原来协调权长这样」
- **对方为什么会有感触**：对方至少懂「银行、危机、摩根」模糊词；转述句不依赖 1907 全貌
- **转发后可能产生的对话**：「所以救市靠的不是钱包，是谁能把大家拉到一张桌子上」「查账决定救谁不救谁」

#### 7. 外部同质化风险

- **对应外部常见写法**：W01 英雄叙事、W06 百科全景、W02 时间线流水账
- **与外部标题/角度相似处**：同题几乎都答「有钱/有名」；少数英文样本（FR History）触及查账但未形成中文「三类权力」统一链
- **差异化空间**：高——外部内容搜索第六节第 1、4 条：中文生态几乎空白于「召集—查账—接盘」完整机制呈现
- **必须避开的套路**：A01 英雄、A08 Fed 前传主叙事、W07 数字惊悚
- **风险等级**：低

#### 8. 风险判断

- **事实支撑风险**：低——E0901、E0910–E0918、E09P1 系列 P0/P1 全覆盖；E0912/E0917 守口径即可
- **标题承诺风险**：中——题目「一个人」引英雄期待；须前 15–20% 完成解构 + 引入三类权力（外部 T01/T02）
- **外部同质化风险**：低
- **情绪失控风险**：低——机制型叙事，无阴谋/颂扬倾向
- **文风违禁风险**：低——无震惊体、无「内幕真相」

#### 9. 结论

- **是否适合作为主洞察**：是
- **更适合作为**：主洞察
- **是否因目标客户不匹配而放弃**：否
- **是否因传播潜力不足而放弃**：否
- **需要修改的地方**：避免三类权力平均用力；每类权力绑定一个硬场景（10 月 24 日纽交所=召集+接盘；Knickerbocker/Trust Company of America=查账）；收束句落「组织别人怎么用钱才是协调入口的真正权力」

### 候选洞察 2：清算所够不着的地方

#### 1. 候选原文

> 1907 年协调权落到摩根私人网络，首要原因是**恐慌主战场在信托公司**，而清算所的准央行功能只覆盖成员商业银行——制度缝隙里出现了第二层协调真空。

#### 2. 阅读意图审查

| 审查项 | 判断 |
|---|---|
| 主要入口类型 | 主动需求型为主，被动唤起型弱 |
| 主动需求价值 | 高——回答「既然有清算所，为什么还需要摩根？」制度史读者增量明确 |
| 被动唤起价值 | 中——「不是没人管，是管不到」需 1–2 段解释才能产生张力 |
| 点击率风险 | 中——单独作标题钩子偏学术，信息流吸引力不足 |
| 点赞率风险 | 低——认知增量清晰但情绪峰值不高 |
| 承诺兑现风险 | 低——E0903–E0905、E09P1-17/18 P0/P1 支撑；须定性表述准备金比例 |
| 推荐策略 | 嵌入候选 1 作制度前提（1–2 段），不单独成篇主钉 |

#### 3. 目标客户匹配审查

| 目标客户 | 兴趣匹配 | 前置知识是否足够 | 现实处境 / 社交场景是否匹配 | 是否值得继续评估 |
|---|---|---|---|---|
| 泛财经深度读者 | 高 | 部分 | 高 | 是 |
| 商业史 / 制度史爱好者 | 高 | 部分 | 高 | 是 |
| 产业与金融化观察者 | 中 | 部分 | 中 | 是 |
| 被动唤起型读者 | 低 | 否 | 低 | 否 |

- **匹配结论**：勉强适配（作辅助）；单独成主洞察时对被动读者不适配
- **如果不适配，是否建议放弃**：单独作主洞察时建议放弃；作嵌套前提时保留
- **不适配原因**：被动读者首屏需要人物/场景冲突，制度缝隙解释门槛较高

#### 4. 前置上下文审查

| 审查项 | 判断 |
|---|---|
| 知识上下文 | 需承接「银行有互助」常识，再引出信托层例外；2800 字内可 1–2 段完成 |
| 经历上下文 | 与「影子银行」仅有 distant echo，不宜当代影射主论证 |
| 情绪上下文 | 「原来如此」型，非强反差 |
| 问题上下文 | 回答「为什么是他」的前提，非全文核心问题本体 |
| 社交上下文 | 适合制度史社群讨论，泛转发力弱于候选 1/3 |
| 承诺匹配 | 若标题承诺「一个人」，本洞察不直接回应，须与候选 1/4 配合 |

#### 5. 七维度评分

| 维度 | 分数 | 判断 |
|---|---:|---|
| 目标客户匹配 | 4 | 深度读者匹配高；被动读者匹配低，拉低整体 |
| 社交货币 | 4 | 「不是没人管，是管不到信托层」可转述但不如三类权力完整 |
| 诱因 / 前置上下文 | 4 | 承接「有清算所为何还要摩根」；扩宽边界有限 |
| 情绪 | 3 | 认知型，张力弱 |

| 故事 | 3 | 缺单一高戏剧场景；易滑向教科书 |
| **总分** | **25** | **需重写或降级为辅助；单独成篇不建议进入大纲** |

#### 6. 转给谁及场景

- **转给谁**：制度史书友、研究金融监管的同事
- **关系**：同好 / 专业兴趣相近
- **场景**：讨论「1907 和 2008 影子银行通道有何历史渊源（轻度）」；解释「为什么清算所救不了信托」
- **为什么此时会转**：提供多数中文科普略过的清算所边界视角
- **对方为什么会有感触**：对方已有银行/清算所模糊概念
- **转发后可能产生的对话**：「原来 panic 主战场是信托公司，不在清算所网里」

#### 7. 外部同质化风险

- **对应外部常见写法**：W08 清算所边界（FR History、清华金融评论）；A12 清算所=央行（须反向避开）
- **与外部标题/角度相似处**：英文学术二手常写此点；中文科普多混写「银行恐慌」或跳过
- **差异化空间**：中——角度不新，但中文生态稀缺；须与候选 1 嵌套才显差异
- **必须避开的套路**：A12 把清算所写成央行；制度段过长压缩叙事
- **风险等级**：中

#### 8. 风险判断

- **事实支撑风险**：低–中——E09P1-17 准备金比例须定性表述
- **标题承诺风险**：高——若作主洞察，标题「一个人」几乎无法兑现


推荐理由：

8. **读者转述检验**：读完后应能复述「召集、查账、接盘」至少两项——作为传播成败硬标准。
9. **「一个人」须出现两次**：开篇设问 + 收束解构（E0918），中段用 Baker、Stillman、Cortelyou、Rockefeller、清算所、罗斯福等拆结构。
