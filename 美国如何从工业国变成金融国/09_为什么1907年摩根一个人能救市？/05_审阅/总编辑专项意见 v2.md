# 09 总编辑专项意见 v2

> 阶段：05_审阅（总编辑专项意见 v2，叠加于 v1 之上）
> 来源：用户 2026-06-15 22:42 直接发来的具体修订意见
> 性质：v3 修订的硬约束。**核心问题：v2 修订稿不是成稿，是带编辑指令的施工稿。**

---

## 一、v2 的硬伤（必须改）

1. **编辑标记直接出现在正文里**——这是 v2 最严重的事故。
   - 正文里出现 `> 【刺点】`、`> 【膝盖句】`、`> 【母题句·前移加重】` 等标记
   - 这些是给作者看的工作标记，不该出现在面向读者的正文里
   - 修订稿不是成稿 ≠ 修订稿里可以留编辑指令

2. **基础词解释多余**——「所谓挤兑，就是储户担心银行还不了钱，纷纷上门提现」
   - 挤兑是基础词，普通读者都懂
   - 类似的还有「拆借」之类的解释
   - 不要什么都解释

3. **人物背景介绍冗余**——
   - 「核心执行者是银行家信托公司的副总裁斯特朗——实际翻账、须在限时内出结论的人」
   - 斯特朗是谁、什么职位，没必要介绍
   - 人物出现就要推进动作或机制，不该停在"介绍他是谁"

4. **"膝盖句"等说法不该出现在成稿讨论里**——
   - "膝盖句"是工作术语，是给作者看的，v3 修订时不要在 v3 正文里复现这个词
   - 修订说明里也不要再标【膝盖句】等施工编号

5. **手机阅读节奏没卡到位**——
   - 部分句子仍偏长
   - 段落内部断行不够
   - 没有为屏幕滚动节奏做"易扫读"处理

6. **做减法不彻底**——
   - v2 还是把文字浪费在"可有可无的概念解释"上
   - 应该把字句集中到机制和结构本身
   - 多余的过渡铺垫、自我注解、术语解释一律删

## 二、v3 修订目标

### 2.1 形式层（必须做）
- 正文中**不留任何**编辑标记：【刺点】【膝盖句】【母题句·前移加重】一律不写
- 修订执行说明里也**不**复现"膝盖句""刺点"等术语，改用中性描述（如"现实体感句""收束句"）
- 句子缩短，节奏拉快，按手机阅读做
- 段落开头不出现 "本节解决…下一节要看…" 这种过场过渡

### 2.2 内容层（必须做）
- **删**挤兑、拆借等基础词解释
- **删**斯特朗职位介绍
- **删**自我注解式句子（"差别不在谁更有钱"已足够说明问题；"这是查账判定「要救」之后…"这种也可压缩）
- **保留**机制本身：三类协调权的具体动作、数字分场景、解构「一个人」、制度后果
- **保留**母题句（"危机稀缺的是组织别人怎么用钱，不是某一张个人支票"）但去掉"前移加重"这种施工标注，正文里独立成段即可
- **保留**结尾的"几万张存折"形象——但去掉"可正是"那种"作者要发力"的语气词

### 2.3 风格层（必须做）
- 期刊杂志体再降一档——更接近"说人话的机制解释"
- 不再出现"组织感很强""指挥中枢非唯一出资人"这种"作者在解释自己的句子"的话
- 减形容词、减自我注解、减术语解释

## 三、v3 硬约束

- 事实口径不变：E0912「未能确认可救」、E0917「2360 万/10 分钟」、2500 万分场景标注、E0918 解构「一个人」
- 方向主承诺不变：三类协调权 + 摩根指挥中枢非唯一出资人
- 大纲结构不变：线 B 开篇 + 四节机制链 + 收束
- 不重新引入放弃项
- 2800-3200 字区间
- 三红线：无英文字符 / 无跨篇勾稽 / 像中国人说话

## 四、可调整项

- 母题句位置可在 v3 中重定（不强制第二节末独立成段），以"自然流动"为标准
- 收束句可重写，去掉"作者发力"语气
- **删**「上一节解决…下一节要看…」过场过渡
- **保留**「三个数字、三个场景，不能混为一谈」类点题句（属机制归纳，不是解释）
- 段落切分、句子长度、节奏可重做
- 不新增人物介绍、不新增术语解释

## 五、给 v3 修订作者的话

> 你要开始做减法。
>
> 减：解释、过渡、自我注解、术语注释、人物介绍、编辑标记、作者感叹、施工编号。
>
> 留：机制动作、数字分场景、解构「一个人」、制度后果、母题句本身。
>
> 写给手机屏幕上的普通读者。
>
> 你在写文章，不是在写修订报告。
