## 二、每个文件职责

### 项目根级文件

- **README.md**：项目定位、核心问题、暂定核心判断、写作方向、文风要求、文件结构、执行原则、当前状态。
- **总计划.md**：目标读者画像、总目标、核心问题、暂定逻辑链、写作边界、证据缺口、文风原则、审稿机制、流程、最终交付标准、待补信息。
- **00_目录结构.md**：当前文件；描述目录结构、文件职责、使用规则与阶段顺序。

### 01_资料（资料研究阶段产出）

- **资料.md**：由 source-research subagent 产出；汇总可引用资料，按主题归类。
- **证据台账.md**：每条事实登记来源、口径、出版时间、引用格式、可追溯性。
- **事实核查清单.md**：逐条列出文中将用到的事实点，供 fact-check 逐条核对。

### 02_洞察及主题（主题与角度阶段产出）

- **外部内容搜索.md**：盘点同主题已有内容与差异化约束。
- **洞察及主题初选.md**：主题候选与核心判断候选。
- **传播学审查卡.md** / **传播学分析卡.md**：传播潜力审查标准与分析结果。
- **结构命题审查卡.md** / **结构命题分析卡.md**：结构命题审查标准与分析结果。
- **方向把控.md**：整合分析结果后的方向决策与事实边界。

### 03_文风与大纲（写作准备阶段产出）

- **文风卡.md**：本篇文风细则（系列基调 + 本篇特例）。
- **读者审稿卡.md**：读者审稿的固定维度。
- **大纲.md**：文章大纲。
- **自由审读_大纲.md**：零上下文大纲盲审（free-review subagent）。
- **大纲审阅.md**：正式大纲审阅记录（outline-review subagent）。

### 04_草稿（草稿阶段产出）

- **草稿.md**：文章草稿正文（draft-write subagent）。

### 05_审阅（审阅阶段产出，版本文件按需生成）

- **自由审读_草稿.md**：零上下文首版草稿盲审。
- **读者审读 vN.md** / **主编修改建议 vN.md**：阶段 A 正式审阅，N=1..5。
- **读者审读 阶段B vN.md** / **主编修改建议 阶段B vN.md**：阶段 B 正式审阅，N=1..5。
- **自由审读_修订稿 阶段B vN.md**：每版修订稿各一次零上下文盲审。
- 命名严格按版本号，不允许跳号。

### 06_修订与发布（修订与发布阶段产出）

- **修订稿 vN.md**：阶段 B 修订稿，N=1..5，按需生成。
- **发布检查.md**：发布前最终检查（三红线、字数、格式、引用、插图、标题）。
- **人工介入报告.md**：阶段 A/B 审稿达 5 轮仍未通过，或需人工接管时撰写。

### 07_传播终审与标题（传播与标题阶段产出）

- **标题生态搜索.md**：与本文主题相关的已有标题生态盘点。
- **标题方案.md**：标题候选、分析与选定方案。

### 08_插图（插图阶段产出）

- **插图方案.md**：插图数量、风格、位置、说明文字。
- **prompts.json**：插图生成 prompts。
- **插图审查卡.md**：插图合规与相关性审查。
- **images/**：最终图像存放目录。

### 09_终稿（最终发布阶段产出）

- **09_终稿.html**：最终发布的 HTML 终稿（html-build subagent）。

## 三、文件使用规则

1. **不引用同系列其他文章**：本目录下所有文件不得引用系列其他篇目的正文、标题、桥段、具体案例作论证或结构依赖；避让信息仅可在 `02_洞察及主题/外部内容搜索.md` 中以清单形式记录。
2. **不引入未核事实**：人物、年份、机构、金额、事件细节须经 `01_资料/` 三件套登记后方可进入正文。
3. **自由审读零上下文**：`自由审读_*` 文件由 free-review subagent 产出，该 subagent 只读目标文档正文，不带系列背景、审稿卡或格式说明。
4. **正式审阅须回应前置产物**：读者审读、主编审读、大纲审阅须读取并回应对应阶段的审稿卡、大纲、草稿或修订稿。
5. **版本文件按需生成**：`05_审阅/` 与 `06_修订与发布/` 中带 `vN` 的文件不在初始化阶段预建，通过审稿循环按需创建。
6. **三红线（事实 / 立场 / 隐私）必须遵守**。
7. **Windows 文件名约束**：目录与文件名已清理 `\`、`/`、`:`、`*`、`?`、`"`、`<`、`>`、`|`。
8. **不替后续审稿阶段下结论**：判断留给对应审阅 subagent。

## 四、阶段推进顺序

1. **项目初始化**（当前）：README.md / 总计划.md / 00_目录结构.md + 目录树与占位文件。
2. **资料研究**：source-research → `01_资料/资料.md`。
3. **证据台账**：evidence-ledger → `01_资料/证据台账.md`。
4. **事实核查**：fact-check → `01_资料/事实核查清单.md`（P0 放行后方可进入洞察阶段）。
5. **洞察与主题**：ecosystem-scan → insight-select → communication/structure criteria & analyze → direction-decide → `02_洞察及主题/`。
6. **文风与大纲**：style-guide → reader-criteria → outline-plan → free-review（大纲）→ outline-review → `03_文风与大纲/`。
7. **草稿**：draft-write → `04_草稿/草稿.md`。
8. **阶段 A 审阅**：free-review（草稿）→ reader-review + editor-review（最多 5 轮）→ `05_审阅/`。
9. **阶段 B 修订**：draft-revise → free-review（修订稿）→ reader-review 阶段B + editor-review 阶段B（最多 5 轮）→ `06_修订与发布/修订稿 vN.md` + `05_审阅/`。
10. **发布检查**：release-check → `06_修订与发布/发布检查.md`。
11. **标题**：title-ecosystem → title-write → `07_传播终审与标题/`。
12. **插图**：illustration-plan → `08_插图/`。
13. **终稿**：html-build → `09_终稿/09_终稿.html`。

**任一阶段未通过，不得越级进入下一阶段。** 审稿超限则输出 `人工介入报告.md` 并暂停自动流转。
