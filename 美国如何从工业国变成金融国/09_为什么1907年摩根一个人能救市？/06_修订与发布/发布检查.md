## 六、标题阶段边界

### 6.1 标题可以承诺

1. 1907 年危机中，私人银行家曾暂代系统协调；「一个人」背后有可观察的三类协调机制（查账权、召集权、接盘网络）。
2. 摩根处于指挥中枢位置，危机稀缺的是「组织别人怎么用钱」，不是某一张个人支票。
3. 无央行条件下，信托层恐慌与法定工具边界之间的协调真空，以及私人网络如何临时组装协调权。
4. 救/不救对照的张力：同样是信托公司挤兑，差别不在谁更有钱，而在谁能判定、谁能召集、谁能组织接盘。
5. 制度后果轻触：私人协调不可持续，法定协调需求由此浮现（1908 改革、1913 美联储方向）。

### 6.2 标题不能承诺

1. 摩根独力出资、个人包打天下、「一个人拿出全部救市资金」。
2. 内幕真相、华尔街阴谋、摩根故意制造/利用恐慌、选择性不救定论。
3. 1907=美联储诞生前传主叙事、Jekyll Island 密会、Pujo 调查展开。
4. 「没有摩根必大萧条」等反事实推测；Knickerbocker「已确认破产所以不救」。
5. 半小时/一夜 2500 万救纽交所、150% 拆借利率等中文谣言包数字。
6. 斯特朗个人英雄线或「斯特朗一个人查账救市」——v4 已统一为摩根审查团队叙事，标题不宜再引支线人物抢戏。

### 6.3 标题禁用或慎用表达

| 表达 | 禁用/慎用 | 原因 | 替代方向 |
|---|---|---|---|
| 一个人救市 / 摩根独力 | 慎用 | 可保留提问张力，但正文须解构；标题若写成定论则引英雄期待反噬 | 「一个人怎么救市？」提问式；或「背后不是一张支票」机制反差 |
| 内幕 / 真相 / 震惊 | 禁用 | 文风禁用清单；无阴谋论证据支撑 | 机制解释：「危机里谁有资格查账、召集、组织接盘」 |
| 半小时 2500 万 / 150% 利率 | 禁用 | B02/B03；与核查口径冲突 | 分场景数字或不写具体惊悚数字 |
| 已确认破产 / 资不抵债 | 禁用 | B06；E0912 保守口径 | 「未能确认可救」「限时条件下无法判定」 |
| 华尔街控制 / 资本阴谋 | 禁用 | 系列基调禁区；B07 | 「协调入口落在私人网络」制度解释 |
| 彻底改变 / 唯一原因 / 必然导致 | 慎用 | 过度绝对化 | 「关键机制」「开始改变」「往往会推动」 |

### 6.4 标题必须保留的限定口径

| 口径 | 标题阶段必须如何处理 | 来源 |
|---|---|---|
| E0912 Knickerbocker 弃救 | 若标题/导语触及救否对照，不得写「已确认破产」；须保留「未能确认可救」或「限时判断」语感 | 事实核查清单 D03/B06 |
| E0917 纽交所筹款 | 若写数字，优先「14 家银行约 10 分钟内承诺约 2360 万美元」；2500 万须标明财政部存款场景，不与纽交所筹款混用 | 事实核查清单 D04/B02 |
| E0918「一个人」 | 标题可保留「一个人」提问；导语/副标题须暗示或点出「媒体简化」「多方协同」 | 方向把控 / 证据台账 |
| 摩根角色定位 | 写「指挥中枢」「协调者」「暂代央行职能」，不写「唯一出资人」「个人英雄」 | E0914 / B01 |
| 制度后果 | 可轻触 1908/1913，不展开 Fed 前传；不必在标题挂斯特朗具体职务 | E09P1-21/22；v4 硬指令 |
| 系列入口 | 本篇服务「协调入口」；标题不必同时承诺融资、治理、定价等其他入口 | 系列基调配置 |
