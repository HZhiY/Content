## 一、审查依据

本文件使用 `传播学审查卡.md` 的六个维度：

1. 社交货币；
2. 诱因 / 前置上下文；
3. 情绪；
4. 公共性；
5. 实用价值；
6. 故事。

每项 1-5 分。

总分参考：

- 26 分以上：可作为主洞察候选；
- 22-25 分：可作为辅助洞察或传播素材；
- 18-21 分：需要重写；
- 18 分以下：不建议进入大纲。

## 二、阅读意图总判断

06 最适合采用 **混合型阅读策略**。

也就是说，本篇不能只服务一种读者：

- 如果只服务主动需求型读者，文章会很扎实，但题材入口偏窄，点击率可能不高；
- 如果只服务被动唤起型读者，文章会更容易被点开，但如果正文不能快速兑现现实承诺，点赞率和信任感会下降；
- 最稳的方式，是用被动唤起型入口打开阅读，再用主动需求型深度兑现收获。

因此，06 的传播策略应当是：

**用 B 的现实痛感唤起普通读者，用 A 的“买得起”概念承接阅读，用 C 的结构命题完成深度兑现。**

对应关系如下：

| 候选 | 阅读意图类型 | 主要作用 | 主要风险 |
|---|---|---|---|
| A：“买得起”被重新定义 | 混合型 | 同时连接历史故事和现实经验，最适合承接全文阅读。 | 如果写得太金句化，会削弱历史机制。 |
| B：未来收入被组织进今天 | 被动唤起型 | 现实痛感强，容易带来点击和共鸣。 | 如果历史故事接入太慢，读者会觉得正文偏题。 |
| C：成熟行业竞争转向购买能力组织 | 主动需求型 | 深度强，适合兑现收获、形成谈资和收藏价值。 | 入口偏抽象，单独承担传播入口会压低点击。 |

后续所有标题、开头和大纲，都应围绕这条路径设计：

**被动唤起入口 → 混合型概念承接 → 主动需求型深度兑现。**

## 三、候选洞察 A｜“买得起”被重新定义

### 候选表述

**福特让汽车变便宜，通用重新定义了“买得起”：过去是攒够钱才买，现在是月供还得起就买。**

### 阅读意图审查

| 审查项 | 判断 |
|---|---|
| 主要入口类型 | 混合型。既能接住主动想看福特、通用、汽车金融的读者，也能接住被“买得起”“月供”唤起的普通读者。 |
| 主动需求价值 | 对商业史、汽车史、金融史读者来说，福特与通用的竞争提供明确题材入口。 |
| 被动唤起价值 | “买得起”的标准变化和月供经验，能让原本不想看汽车史的读者觉得与自己有关。 |
| 点击率风险 | 中等。若标题或开头太偏福特通用，普通读者可能划走；若太偏月供，历史读者可能觉得浅。 |
| 点赞率风险 | 较低。只要正文兑现机制解释，主动需求型和被动唤起型读者都容易觉得有收获。 |
| 承诺兑现风险 | 可控。正文需要同时兑现“福特通用故事”和“买得起被改写”两条承诺。 |
| 推荐策略 | 作为全文传播承接概念：既负责把读者带入历史故事，也负责把历史机制翻译成现实经验。 |

### 前置上下文审查

| 审查项 | 判断 |
|---|---|
| 知识上下文 | 读者只需要知道福特、通用、汽车分期这些基本概念，不需要懂汽车史细节。 |
| 经历上下文 | 买车、还车贷、看首付和月供、家庭讨论大件消费，都是常见经历。 |
| 情绪上下文 | 击中“收入不低但大件消费仍要靠贷款”的现实刺痛。 |
| 问题上下文 | 读者心里已有疑问：为什么东西更丰富、更便宜了，人反而更离不开月供？ |
| 社交上下文 | 身边常有人讨论买车、房贷、车贷、现金流和家庭预算，容易进入对话。 |
| 承诺匹配 | 洞察承诺解释“买得起”的变化，正文可用福特和通用机制兑现。 |

### 六维度评分

| 维度 | 分数 | 判断 |
|---|---:|---|
| 社交货币 | 5 | 读者转发时能展示自己不是只看汽车史，而是看懂“买得起”被改写的机制。 |
| 诱因 / 前置上下文 | 5 | 读者原本知道福特流水线、分期付款、月供，本洞察是在扩宽已有认知边界。 |
| 情绪 | 4 | 有现实刺痛，但不靠控诉；能让读者产生“原来如此”的感受。 |
| 公共性 | 5 | “买得起”“月供”“首付”“贷款”都是公共生活经验。 |
| 实用价值 | 5 | 可解释汽车、房产、大件消费，也可转述为谈资。 |
| 故事 | 5 | 福特降价、普通人仍难一次付清、通用分期、雪佛兰反超，故事链完整。 |
| 总分 | 29 | 可作为主洞察。 |

### 转给谁及场景

- 转给谁：正在买车或准备贷款买车的妻子、丈夫、朋友、同事。
- 关系：家庭成员、朋友、同事。
- 场景：买车前讨论首付和月供；家庭预算讨论；朋友聊车贷；同事午饭聊消费压力。
- 为什么此时会转：这句话能解释“月供还得起就算买得起”的心理变化。
- 对方为什么会有感触：对方正在经历或见过类似消费决策。

### 结论

- 是否适合作为主洞察：是。
- 更适合作为：主洞察 + 大纲主线。
- 需要修改的地方：正文中要避免把它写成简单金融批判，必须保留福特和通用的历史机制。

## 四、候选洞察 B｜未来收入被组织进今天

### 候选表述

**现代人的困境，不是东西买不起，而是越来越多东西只能靠未来收入来买。**

### 阅读意图审查

| 审查项 | 判断 |
|---|---|
| 主要入口类型 | 被动唤起型。读者未必想看汽车史，但容易被“未来收入”“月供”“现金流紧”这类现实处境吸引。 |
| 主动需求价值 | 较弱。它不直接指向福特、通用或汽车金融，主动寻找历史题材的读者可能觉得入口偏现实。 |
| 被动唤起价值 | 很强。它击中中年读者熟悉的贷款、账单、家庭预算和未来收入被提前安排的感受。 |
| 点击率风险 | 较低。现实痛感强，容易让普通读者点进来。 |
| 点赞率风险 | 较高。若正文很快转入汽车史材料，读者可能觉得标题吸引自己，但正文没有继续解释自己的处境。 |
| 承诺兑现风险 | 高。必须在开头明确：现实月供生活不是另起一篇，而是由福特与通用的汽车金融机制引出。 |
| 推荐策略 | 适合作为引言钩子或结尾回声，不宜单独作为全文传播主轴。 |

### 前置上下文审查

| 审查项 | 判断 |
|---|---|
| 知识上下文 | 几乎不需要历史知识，主要依赖现实生活经验。 |
| 经历上下文 | 房贷、车贷、信用卡、分期、大件消费和工资到账后还账单，都是强经历入口。 |
| 情绪上下文 | 击中“明明收入不低，却总觉得现金流紧”的中年压力。 |
| 问题上下文 | 读者已有疑问：为什么生活水平提高了，反而感觉未来几年收入都被安排好了？ |
| 社交上下文 | 很适合转给正在还贷、讨论预算、感叹钱不够用的朋友、配偶或同事。 |
| 承诺匹配 | 洞察偏现实，正文必须迅速接回汽车史，否则会出现标题现实化、正文历史化的错位。 |

### 六维度评分

| 维度 | 分数 | 判断 |
|---|---:|---|
| 社交货币 | 4 | 读者能借此表达自己看懂现代消费压力，但历史识别度弱于 A。 |
| 诱因 / 前置上下文 | 5 | 与房贷、车贷、信用卡、月供高度相关，点击入口强。 |
| 情绪 | 5 | 中年读者共鸣强，容易产生“说的是我”的感受。 |
| 公共性 | 5 | 未来收入被提前占用，是高度公共的生活经验。 |
| 实用价值 | 4 | 可解释现实处境，但作为文章主轴容易过于现实化。 |
| 故事 | 3 | 需要福特与通用故事外接，否则容易离开历史主线。 |
| 总分 | 26 | 可作为主洞察候选，但更适合作为现实刺痛句。 |

### 转给谁及场景

- 转给谁：正在还房贷车贷的朋友、家庭成员、同事。
- 关系：同龄朋友、夫妻、同事。
- 场景：工资到账后讨论账单；朋友说“钱不知道花哪去了”；家庭讨论是否添置大件。
- 为什么此时会转：能解释“收入不低但现金流紧”的现实感受。
- 对方为什么会有感触：对方能立刻想到自己的月供、账单和未来收入安排。

### 结论

- 是否适合作为主洞察：谨慎。
- 更适合作为：引言钩子 / 结尾金句 / 现实刺痛句。
- 需要修改的地方：必须由历史案例托住，不能单独写成现实焦虑文。

| 审查项 | 判断 |

## 八、传播层最终建议

### 阅读意图策略

06 的传播策略应当明确为：

**用被动唤起型入口打开阅读，用主动需求型深度兑现收获。**

更具体地说：

1. **B 负责唤起**  
   用“未来收入”“月供”“现金流紧”这类现实痛感，把原本不知道自己想看汽车史的读者带进来。

2. **A 负责承接**  
   用“买得起被重新定义”把现实痛感接到福特与通用的历史机制上，避免正文突然变成汽车史。

3. **C 负责兑现**  
   用“成熟行业竞争转向购买能力组织”提供深层收获，让读者读完之后有新的谈资和解释框架。

这条路径可以概括为：

**B 唤起点击，A 承接阅读，C 兑现点赞和收藏。**

### 最适合传播的主线表达

**福特让汽车变便宜，通用重新定义了“买得起”：过去是攒够钱才买，现在是月供还得起就买。**

这个表达最适合承担传播层主线，因为它同时具备：

- 历史人物；
- 现实经验；
- 概念反差；
- 可转述金句；
- 具体转发场景。

### 最适合传播的现实刺痛句

**现代人的困境，不是东西买不起，而是越来越多东西只能靠未来收入来买。**

它适合放在引言或结尾，但不宜单独承担全文主命题。

### 最适合传播的金句候选

**所谓买得起，过去看存款，现在看月供。**

它适合作为传播触发素材，但正式标题设计应放到 `03_文风与大纲` 阶段处理。

### 传播层对结构层的提醒

传播层最强的表达，不一定就是结构上最深的命题。

本篇在结构上更深的判断是：

**成熟行业的竞争，不只是生产效率竞赛，也是购买能力组织竞赛。**

但这个判断直接作为传播入口偏硬，需要在 `03_文风与大纲` 阶段结合大纲和开头方式再设计标题。

因此，传播层建议采用：

**用 A 做读者入口，用 B 制造现实刺痛，用 C 支撑文章深度。**

## 九、标题设计移交说明

本文件不正式设计标题。

标题设计属于 `03_文风与大纲` 阶段，应在大纲链条、开头方式、正文承诺和结尾回收确定之后处理。

本阶段只保留对标题设计有用的传播输入：

- 哪些概念有传播触发力；
- 哪些现实经验容易被击中；
- 哪些表达适合成为开头钩子或便携句；
- 哪些承诺风险需要后续标题设计避免。

后续设计标题时，应重点检查：

- 标题击中的前置上下文，正文是否能兑现；
- 标题是否过度现实化，导致历史故事显得来得太晚；
- 标题是否过度历史化，导致现实共鸣不足；
- 标题是否过度锋利，导致文章被误读为简单金融批判。

## 十、对后续大纲的传播约束

后续大纲必须同时满足：

1. 后续标题击中的前置上下文，正文必须兑现；
2. 开头可以从现实痛感进入，但必须尽快交代福特与通用；
3. 开头必须完成从 B 的现实痛感到 A 的“买得起”概念的转换；
4. 正文必须完成从 A 的主线表达到 C 的结构命题的兑现；
5. 每一节都要有一句可转述判断；
6. 现实回声不能喧宾夺主，必须服务历史机制；
7. 文章最后要留下一个便携句，方便读者转述。

从传播角度看，最稳的推进方式是：

**现实痛感 → 福特故事 → 通用机制 → “买得起”被改写 → 成熟行业竞争规律 → 现代月供生活回声。**
