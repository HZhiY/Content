# 主编修改建议 v2

## 0. 本轮总判断

修订稿 v1 已经解决第 1 轮的大部分硬伤，可以从“大改”转入“小修”。

当前稿件的主线、事实钉子、B/A/C 分工都基本成立：

- B 线：月供和家庭账本能带读者进入；
- A 线：“买得起”从存款变月供，已经成为文章主线；
- C 线：购买能力被重新组织，已经出现并有解释。

但作为主编，第 2 轮仍不建议直接放行。剩余问题主要集中在 C 层兑现：文章已经说出了“购买能力被重新组织”，但还没有把它打磨成足够稳的结尾认知。

本轮修订不需要改结构，只需局部压低概念腔、补强“组织购买能力”的定义、让结尾回扣现实家庭账本。

## 2. 本轮必改意见

### 【必改】M0611
位置：导语第4段
原文：“它是怎么变成现代消费社会的基本动作的？”
问题：“现代消费社会的基本动作”偏作者语言，略像概念先行。
改法：改为“这种习惯是怎么来的？”或“这种买东西的算法，是怎么来的？”
理由：开头应该更口语，降低入口门槛。

### 【必改】M0612
位置：第四节第2段
原文：“这个数字背后，是行业竞争逻辑的变化。”
问题：过渡句偏报告腔。
改法：改为“这说明，卖车已经不只是看谁价格低，也要看谁能让消费者先开上车、以后慢慢还钱。”
理由：用读者语言解释数据含义。

### 【必改】M0613
位置：第四节末段
原文：“钱什么时候付，风险谁先扛，车什么时候到手，这些安排一起变了，购买能力也就被重新组织了。”
问题：C 层核心句仍然落得过快。
改法：补一句解释“组织”的含义：消费者有未来工资，经销商有库存压力，厂家有销量目标，通用用金融把这三件事接在一起。
理由：结构命题审查卡要求读者能获得可复述框架。

### 【必改】M0614
位置：第五节第3段
原文：“这套算法，在 1920 年代美国汽车销售里已经成型。”
问题：“算法”略现代商业腔。
改法：改为“这种计算方式，在 1920 年代美国汽车销售里已经成型。”
理由：更自然。

### 【必改】M0615
位置：第五节第5段
原文：“它不只是汽车史上的一个销售办法，也是一条可以迁移的商业规律：当一个行业逐渐成熟，单靠生产效率已经很难继续拉开差距，竞争就会从‘谁更会造’，扩展到‘谁更会让人买’。”
问题：“可以迁移的商业规律”概念腔较重。
改法：改为：“这件事放到别的行业里也说得通：当东西已经便宜到一定程度，下一步比的就不只是造得便宜，而是谁能把付款这件事安排好。”
理由：保留结构收获，但改成人话。

### 【必改】M0616
位置：第五节结尾
原文：“现代消费社会的一部分，就是从这个变化里长出来的：不是每个人突然更有钱了，而是未来的收入，被提前搬到了今天。”
问题：结尾有力，但还可以更贴近导语里的家庭账本和月供场景。
改法：补一个回扣：“所以今天一家人坐下来算月供时，其实算的不是车价本身，而是未来几年收入能不能被今天提前使用。”
理由：增强转发给家人朋友的现实场景。

## 3. 可选意见

### 【可选】M0617
位置：第五节第8段
原文：“福特改变了汽车的价格。通用改变了买车的算法。”
问题：“算法”略有包装感，但有传播力。
建议：如果第五节前文已把“算法”改掉，这里可以保留；如果想更口语，可改为“福特改变了汽车的价格。通用改变了买车的办法。”

## 4. 放行判断

修订稿 v1 不建议直接定稿，但只需小修。

修订稿 v2 只要完成以下三项，即可进入最终验收：

1. 去掉第四、第五节的商业分析腔；
2. 明确解释“购买能力组织”；
3. 结尾回扣月供、家庭账本和未来收入提前使用。
