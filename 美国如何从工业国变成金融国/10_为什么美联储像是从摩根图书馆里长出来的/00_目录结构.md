## 三、文件使用规则

1. 所有资料、证据、稿件、审读、修订都留在本目录内。
2. 不迁移旧系列「美联储 / 杰基尔岛」相关稿件；旧文只作历史背景参考，不作正文事实来源。
3. 证据先入台账，再进入正文。
4. 文风卡 + 读者审稿卡 + 方向把控先成形，再写大纲。
5. 大纲先审阅，再写草稿。
6. 每轮审读和主编意见必须按审稿卡格式输出（位置、原文、问题、改法、严重度、理由），不合格式的意见视为无效。
7. 每版稿件开头标注版本号、所采纳的审读/主编意见编号。
8. 阶段 A 审稿 4 读制（free-review → reader-review → density-edit → editor-review），每轮顺序不得打乱。
9. 阶段 B 审稿同样 4 读制，文件名中的 vN 必须与被审的 `修订稿 vN.md` 严格对齐。
10. 第 3 轮若仍有必改项，按手册允许延长；第 5 轮仍不通过则写 `人工介入报告.md` 停止。

## 四、阶段推进顺序

```text
project-setup → source-research → evidence-ledger → fact-check
→ ecosystem-scan → insight-select → communication/structure 链 → direction-decide
→ style-guide → reader-criteria → outline-plan → free-review → outline-review
→ draft-write
→ [每轮审稿] free-review + reader-review + density-edit → editor-review → draft-revise
→ release-check（内容闭环，须主编「内容冻结」）
→ title-ecosystem → title-write → illustration-plan
→ format-final-check（成稿终审）→ html-build
```

### 4.1 阶段 A 审稿循环（审 `04_草稿/草稿.md`）

- 轮次：v1..v5。
- 顺序：free-review → reader-review → density-edit → editor-review。
- 主编结论 = 「内容冻结，可进 release-check」→ 进入阶段 B。

### 4.2 阶段 B 审稿循环（审 `06_修订与发布/修订稿 vN.md`）

- 轮次：v1..v5，vN 与修订稿版本号强绑定。
- 顺序：free-review → reader-review → density-edit → editor-review。
- 主编结论 = 「内容冻结，可进 release-check」→ 进入 release-check。

### 4.3 发布闸门

- release-check 通过 → 进入 07 标题阶段。
- format-final-check 通过 → 进入 09 html-build。
