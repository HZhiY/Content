- 二元论腔：「私有 vs 国有 / 反对 vs 继承 / 阴谋 vs 公开」
- 升维腔：「文明兴衰 / 世界秩序 / 金融霸权 / 制度史长链」
- 100% 绝对化：「100% / 彻底 / 完全 / 永远是」

### 8.4 标题可以放大哪些判断

- 「为什么 X 像是从 Y 长出来的」反常识句式（已给定，不改）
- 「私人图书馆 → 公共建筑」视觉对照
- 「12 储备区 vs 纽约联储」制度内部张力
- 「协调权 / 协调能力」概念
- 「私人救市的局限 / 临时机制 / 不可持续 / 不可跨周期」
- 「不是继承也不是反对」第三种位置
- 「制度不天然中立 / 仍会决定它服务谁」
