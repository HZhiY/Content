## 一、本文结构命题前提

### 3.1 当前文章表面题材

美联储的建立史——一个国家央行如何诞生的制度故事。

### 3.2 当前文章真正要解释的问题

美联储不是"反对华尔街的公共机构"，而是"把华尔街私人协调危机的功能接管并制度化"。换言之：国家接手了私人金融协调无法长期承担的功能，金融资本的协调能力因此被国家放大，也因此被国家重塑。

### 3.3 当前文章读者已有认知

读者大概率知道：
- 美联储是美国的中央银行；
- 1907年有过一次金融危机（可能知道"银行家摩根"）；
- 华尔街与美联储之间存在某种张力；
- 美联储和"华尔街"有时被描述为对立关系。

读者不一定知道：
- 1907年恐慌之前，美国没有央行，私人清算所和摩根网络实际承担了全系统流动性协调；
- 这些私人机制有哪些结构性局限，为什么无法长期维持；
- 美联储建立不是"收编华尔街权力"，而是"制度化了一种协调逻辑"；
- 区域联邦储备银行在法律形式上与私人银行股东的关系。

### 3.4 当前文章应提供的新启发

读者应获得：
- 对"国家接手私人协调功能"这一机制的新理解；
- 对"制度化"不是消灭而是放大+重塑私人权力逻辑的新解释；
- 对"为什么是美联储而不是其他方案"背后制度逻辑的新框架；
- 对"协调入口"这一系列核心概念在美联储案例中的具体展现。

### 3.5 当前文章不能越界解释的内容

- 不解释美联储的货币政策机制（利率、通胀、就业）；
- 不解释美联储与政府其他机构（财政部、SEC）的日常关系；
- 不详细展开融资入口、定价入口、消费入口（留给其他篇）；
- 不把美联储写成"华尔街阴谋的产物"或"战胜华尔街的公共胜利"；
- 不写大萧条或美联储在其中的角色（超出本文边界）；
- 不讨论美联储的当代争议（QT、加息等）。

### 3.2 匹配判断问题

1. **这个候选命题是否落在目标客户已有兴趣或已有问题中？**

2. **目标客户是否具备理解命题所需的历史、商业、金融或制度前置知识？**

   - 这个框架是否能帮助读者理解其他"国家接手私人功能"的案例（政府救市、国企改革等）。

5. **如果目标客户明显不匹配，后续分析卡是否应该允许放弃，而不是强行证明它有价值？**
   - 如果候选洞察主要服务专业金融史学者，而非泛财经读者，说明目标客户定位偏差；

## 四、结构命题层

### 5.1 核心问题

**美联储是反对华尔街，还是把华尔街的协调机制制度化？**

子问题链：
1. 1907年恐慌之前，美国私人金融系统靠什么机制维持流动性协调？
2. 这些私人机制（清算所、摩根网络）为什么无法长期承担全系统的协调功能？
3. 国家建立美联储之后，保留了哪些私人协调的逻辑？改变了哪些结构？
4. 金融资本的协调入口因此获得了什么，又失去了什么？
5. 这个案例如何印证"工业国到金融国"系列暗线——协调入口如何在金融化中变得更重要？

### 5.2 当前文章审查问题

1. **主承诺是否单一、可证、不过度抽象？**
   - 候选洞察能否压成一句完整的主承诺（如："美联储不是在消灭华尔街的协调权，而是在接管并制度化它"）；
   - 这句承诺是否能在正文范围内被证明；
   - 是否不超过本文事实边界（不得写"阴谋"、"美联储是私人银行"等）。

2. **骨架命题是否能贯穿全文？**
   - 候选洞察是否能在每个小节都找到落脚点；
   - 是否不会出现"某段内容与骨架命题无关"的情况；
   - 是否不会出现"大段历史叙事压过机制解释"的情况。

3. **入口洞察和骨架命题是否一致？**
   - 开头进入的角度是否与主承诺方向匹配；
   - 不会出现"开头从X角度进入，正文从Y机制证明，结尾谈Z结论"的断裂。

4. **反差是否有效且可兑现？**
   - 候选洞察中的反差（如"表面是央行建立，实际是协调权制度化"）是否能在正文找到支撑；
   - 是否不会出现"反差很大，但正文无法兑现"的情况。

### 5.3 不合格信号

1. 主承诺无法被事实核查清单支撑（如：把美联储写成"华尔街阴谋产物"）；
2. 试图同时证明多个主命题（如：既讲协调入口，又讲融资入口）；
3. 主承诺过于抽象，正文只能靠类比和感叹完成，无法给出机制；
4. 入口洞察和骨架命题方向不一致（如：开头谈"美联储的独立性"，正文证明"协调机制制度化"）；
5. 反差洞察正文无法兑现（如：标题承诺"美联储如何管住华尔街"，正文却无法证明）；
6. 骨架命题空洞，需要不断用"这说明"来强行连接；
7. 把"协调入口制度化"写成"国家胜利"或"私人资本失败"，而非揭示真实的权力重塑机制。

### 5.4 合格标准

- 主承诺能压成一句完整、可证、不超过事实边界的机制判断；
- 每个小节都服务于同一个骨架命题；
- 没有"资料节"——每节都在证明或铺垫主承诺；
- 骨架命题能贯穿"1907年前私人协调→1907年危机暴露缺陷→国家建立美联储→协调逻辑被制度化"的全流程；
- 不会在中间滑向"美联储的货币政策"或"金融监管"等其他话题。

- 读者知道这个机制的边界——它不是万能的，它在什么条件下成立，在什么条件下失效。

## 六、故事证据层

### 7.1 Claim / Grounds / Warrant 要求

| 项目 | 当前文章必须回答的问题 | 不合格表现 |
|---|---|---|
| Claim（要证明什么） | 美联储不是在消灭华尔街的协调权，而是在接管并制度化它——协调逻辑被国家放大，也被国家重塑 | 写成"美联储是华尔街阴谋"或"美联储战胜了华尔街"——两者都是对本文核心判断的扭曲 |
| Grounds（拿什么证明） | 1907年恐慌暴露私人协调局限 → 摩根图书馆/清算所的临时协调 → 国家建立美联储 → 区域银行的私人股东结构/利润上缴机制/双重复合结构 | 只有1907年故事，缺乏美联储制度设计的证明；或只有制度描述，缺乏从私人协调到制度化的演化脉络 |
| Warrant（为什么这些证据能证明） | 1907年私人协调危机 + 美联储制度设计保留了私人协调逻辑（区域银行股东结构、利润分配机制）+ 国家接手后协调能力更强——这三者共同证明"制度化"命题 | 证据与命题之间缺乏逻辑链；把"美联储建立了"当成对"协调逻辑被制度化"的证明 |

### 7.2 当前文章机制链要求

```text
起点问题 → 旧办法解决了什么 → 旧办法解决不了什么 → 新办法如何出现 → 新办法带来什么结果 → 这个结果揭示什么规律
```

本文可以如何改写这条机制链：

```text
起点问题：1907年恐慌爆发，美国没有央行，谁来组织全系统流动性？
旧办法：私人清算所和摩根网络实际承担了协调功能（临时性、无法律授权）
旧办法局限：私人协调无法长期、无上限地提供流动性；没有法律授权就没有持续性
新办法出现：国家建立美联储，接管最后贷款人功能
新办法结果：协调入口从私人网络转移到国家制度；同时保留了私人银行的股东结构和参与机制
规律揭示：当私人协调无法长期维持某个关键社会功能，国家接手的同时，往往会保留并放大原有的协调逻辑——制度化不是消灭，而是重塑
```

### 7.3 不合格信号

- **Claim和Grounds不匹配**：说"美联储是华尔街阴谋"，但证据只能证明"1907年恐慌后私人协调失败"；
- **证据链断裂**：只讲1907年故事，不讲美联储制度设计如何体现了"制度化"；
- ** Warrant 缺失**：把历史事实（1907年恐慌→1913年美联储建立）当成因果证明，但没有解释为什么前者导致后者；
- **故事压过机制**：大段叙事，但读者在每个故事节点不知道它在证明什么；
- **使用未核事实**：引入E1002的"锁门"细节、E1012的"摩根亲自审核账本"作为核心证据；
- **引入禁止框架**：把1907年写成"银行家蓄意制造恐慌"（B01）或把美联储写成"银行家阴谋产物"（B06）。

### 7.4 合格标准

- Claim能压成一句完整、单一、可证的机制判断；
- Grounds中每个证据都能在事实核查清单中找到对应项，且核查状态为"通过"或"按口径通过"；
- 证据链中不存在被标注为"待补资料"的关键节点（可以作为背景提及，但不能作为主要证明）；
- Warrant说清楚"为什么这些证据共同指向这个结论"；
- 机制链每个环节都有正文对应——起点问题在开头，演化在中段，规律揭示在结尾；
- 没有一个证据是用来"填充篇幅"的，每个证据都在服务骨架命题。

## 七、承诺兑现层

### 8.1 标题承诺审查

**标题已定：** 为什么美联储像是从摩根图书馆里长出来的？

- 承诺方向：美联储与摩根图书馆（私人协调网络）之间存在某种"生长"关系——不是对立，而是延续和演变；
- 检验问题：正文是否解释了"美联储如何在结构上继承了摩根图书馆的协调逻辑"，而非只讲"历史上有摩根这个人"；
- 兑现风险：如果正文只讲1907年摩根救市的故事，然后跳到1913年美联储建立，两者之间缺乏机制连接，标题的"像是从……长出来的"这个隐喻就无法兑现。

### 8.2 开头承诺审查

- 开头应提出的问题：1907年恐慌时美国没有央行，谁来救？私人协调为什么不能长期维持？为什么后来建立了美联储，它是在消灭还是在继承协调逻辑？
- 检验问题：开头是否让读者知道"本文要回答美联储与华尔街协调逻辑的关系"；
- 兑现风险：开头如果只讲1907年恐慌的戏剧性，不点出"私人协调→制度化"这条主线，读者会以为文章是讲1907年危机故事。

### 8.3 正文证明审查

- 每个小节是否都在证明或铺垫"协调逻辑被制度化"这个主承诺；
- 是否不会出现"某节只讲美联储货币政策效果"或"某节只讲威尔逊总统的功绩"这类偏离主线的段落；
- 机制链是否完整：起点（1907年前私人协调）→ 危机暴露（私人协调局限）→ 国家回应（建立美联储）→ 制度设计（保留协调逻辑）→ 机制揭示（制度化不是消灭，是重塑）。

### 8.4 结尾兑现审查

- 结尾是否回收了开头和正文对"协调逻辑制度化"的承诺；
- 结尾是否点出这一机制在系列暗线（金融资本掌握协调入口）中的位置；
- 结尾是否克制，不写成"宏大控诉"或"历史终局"；
- 推荐落点：这个案例说明，当某个协调功能对系统运转不可或缺，而私人机制无法长期维持续存在，国家接手往往会以制度化来实现——但制度化的不只是功能，还有功能背后的权力逻辑。

### 8.5 不合格信号

- 标题承诺（美联储与摩根图书馆的"生长"关系）在正文中找不到机制支撑；
- 开头提出的问题在结尾没有得到回答；
- 正文出现"某节与主承诺无关"的情况；
- 结尾突然拔高到"美国金融史就是一部阴谋史"或"美联储是拯救美国的英雄机构"；
- 标题是问句（"为什么美联储像是从摩根图书馆里长出来的？"），但正文最后没有给出一个机制性的回答，只给出一个描述性结论（"因为它确实是这样来的"）。

### 8.6 合格标准

- 标题承诺 → 开头问题 → 中段证明 → 结尾回收形成完整闭环；
- 每个环节都在回答同一个问题：美联储是在消灭还是在制度化华尔街的协调逻辑；
- 结尾能帮助读者形成一个可复述的机制判断；
- 没有任何一个环节（标题、开头、小标题、结尾）单独跑题。

## 八、当前文章一票否决项

1. **主承诺无法被事实核查清单支撑**
   - 如果候选洞察把美联储写成"华尔街阴谋"（B06）或"银行家故意制造1907年恐慌"（B01），直接否决；
   - 如果候选洞察使用"美联储是私人银行/公司"（B02）等误导性表述，直接否决。

2. **目标客户明显不匹配**
   - 如果候选洞察的目标读者是专业金融史学者，而非泛财经读者，且无法用低迁移成本适配泛财经读者，直接否决；
   - 如果候选洞察要求读者具备清算所、货币银行学等专业知识，而文章无法在低篇幅内补齐这些前置知识，直接否决。

3. **Claim无法被 Grounds 证明**
   - 如果候选洞察的结论（Claim）与可用证据（Grounds）之间缺乏逻辑链（Warrant），直接否决；
   - 如果关键证据引用了事实核查清单中标注为"待补资料"的内容，且该内容是核心证明节点，直接否决。

4. **命题无法被压成单一机制句**
   - 如果候选洞察需要用三句以上才能说清楚本文要证明什么，说明命题不够清晰，直接否决；
   - 如果候选洞察可以压成金句，但正文无法在3000字范围内证明，说明命题过大，直接否决。

5. **命题过大，超出单篇文章容量**
   - 如果候选洞察试图同时解释"协调入口制度化"和"美联储货币政策影响"（或其他多个主题），直接否决；
   - 本文只能打一颗主钉：协调入口的制度化。

6. **只有态度，没有机制**
   - 如果候选洞察是"美联储应该更独立"或"美联储被政治绑架了"这类价值判断，而非"美联储如何把私人协调逻辑制度化"这类机制解释，直接否决；
   - 本系列不写态度判断，只写机制分析。

7. **承诺错位**
   - 如果标题承诺"为什么美联储像是从摩根图书馆里长出来的"，但正文主要讲"1907年危机史"或"美联储建立史"，承诺与正文不一致，直接否决；
   - 标题的隐喻（"长出来"）必须在正文中找到机制解释。

8. **反差无法兑现**
   - 如果候选洞察使用"表面是央行，实际是……"这类反差结构，但正文无法证明这个"实际是"，直接否决。

9. **入口洞察和骨架命题不一致**
   - 如果开头从"美联储的独立性"进入，但主承诺是"协调逻辑制度化"，两者方向不一致，直接否决。

10. **使用未放行事实作为核心支点**
    - E1002（"锁门"细节）、E1012（"摩根亲自审核账本"）等限制使用项，不得作为核心证明节点；
    - E1002必须用"在限定空间内组织协商"的限定写法，不得渲染戏剧细节。

## 九、评分方式

| 维度 | 评分问题 | 分值 |
|---|---|---|
| 目标客户匹配 | 是否匹配泛财经读者的兴趣入口、前置知识水平、认知收获期待和可迁移场景 | 1-5 |
| 命题清晰度 | 是否能压成一句单一、可证明、不超过事实边界的机制句 | 1-5 |
| 解释深度 | 是否解释了"为什么"（因果）、"是什么背景下"（背景）、"谁获得什么"（利害）、"代价是什么"（代价）和"边界在哪里"（边界） | 1-5 |
| 认知收获 | 是否让读者获得新概念（新框架）、新理解（机制解释）或新边界（条件限制） | 1-5 |
| 证据承载 | 故事材料（1907年、清算所、摩根图书馆）是否能证明"协调逻辑制度化"这个主承诺；是否有证据链断裂 | 1-5 |
| 迁移价值 | "制度化不是消灭，而是重塑"这个框架是否能解释其他案例（政府救市、国企改革等）；读者是否能带走可复述的判断 | 1-5 |
| 承诺兑现 | 标题承诺（"像是从摩根图书馆里长出来的"）、开头问题、正文证明、结尾回收是否形成闭环 | 1-5 |

**评分标准：**

- **32分以上**：可作为全文结构命题；
- **28-31分**：可作为主线候选，但需修补；
- **23-27分**：适合作为辅助命题或段落命题；
- **23分以下**：不建议作为文章主命题。

**重要提示：**
如果"目标客户匹配"维度低于3分，即使命题本身有知识深度，后续分析卡也必须谨慎推荐，必要时建议调整目标客户定位或降低命题野心，而非强行证明它对泛财经读者有价值。

## 十、结构命题分析卡输出模板

说明后续 `结构命题分析卡.md` 应如何逐条评估候选洞察。

`结构命题分析卡.md` 的任务是：**在结构命题审查卡定义的评估标准下，逐条评估候选洞察，给出具体分数和判断理由**。

分析卡必须：
1. 读取并引用结构命题审查卡的相关维度；
2. 对每个候选洞察逐一评分；
3. 说明每项得分的具体依据（为什么得4分或2分）；
4. 指出每个候选洞察的优势和主要缺陷；
5. 不做预选——只提供评分结果，由后续 `方向把控.md` 做最终选择；
6. 不写正文、不写大纲、不写标题。

分析卡**不得**：
1. 跳过审查卡，直接从候选洞察中选出"最优命题"；
2. 对候选洞察做"推荐/不推荐"的结论性判断；
3. 修改审查卡定义的评分标准；
4. 使用未在事实核查清单中放行的事实。

## 十一、最终提醒

1. **本文的主线是"协调入口的制度化"，不是"1907年危机史"，也不是"美联储建立史"。** 任何候选洞察，如果无法落到这个主线上，都需要重新审视。

2. **"像是从摩根图书馆里长出来的"这个标题隐喻，必须在正文中找到机制解释。** 读者读完应该理解"协调逻辑如何在制度化过程中被放大，也被重塑"，而不只是"历史先有摩根图书馆，后有美联储"。

3. **本文的事实边界比大多数文章更严格。** E1002（"锁门"细节）和E1012（"摩根亲自审核账本"）只能作为背景提及，不得作为核心证明节点；E1006（"沃伯格是罗斯柴尔德代理人"）严禁使用。

4. **"半熟悉半启发"的关键是：让读者从"1907年恐慌"和"摩根"这两个相对熟悉的点进入，然后揭示一个他们不曾想透的机制——私人协调如何被国家制度化，而这个制度化既放大了协调能力，也保留了私人逻辑。**

5. **本文的核心反差不是"华尔街vs美联储"，而是"私人协调的临时性vs国家制度化的持续性"。** 如果候选洞察把反差落在"英雄摩根vs英雄威尔逊"或"阴谋vs光明"上，机制就不成立。

6. **承诺兑现是本文最核心的风险。** 标题是问句（"为什么美联储像是从摩根图书馆里长出来的？"），结尾必须有机制性的回答，不能只是描述性的"因为历史就是这样演变的"。
