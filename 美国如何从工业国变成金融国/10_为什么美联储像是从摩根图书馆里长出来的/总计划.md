# 总计划：为什么美联储像是从摩根图书馆里长出来的？

> 系列：美国如何从工业国变成金融国
> 文章编号：10
> 状态：初始化阶段

---

## 1. 目标读者画像

本系列核心目标读者：

```
对美国、资本、产业、金融、制度演化有兴趣的成熟中文读者；
不满足于"华尔街贪婪"这种简单解释的人；
想理解今天美国经济为什么资产价格强、制造业弱、金融权力大的读者。
```

**本篇额外定位：**
对"国家与市场关系"、"私人协调如何变成公共制度"有兴趣的读者。

---

## 2. 总目标

写出一篇3000字左右的制度解释型财经历史长文，交付一个核心机制：

```
美联储不是在消灭华尔街的协调权，而是在接管并制度化它。
私人协调无法长期承担的功能，被国家接手；
金融资本的协调能力因此被放大，也因此被重塑。
```

读者读完能复述：这个协调入口原本由谁掌握，后来如何转移，金融资本为什么因此变得更重要。

---

## 3. 核心问题

**美联储是反对华尔街，还是把华尔街的协调机制制度化？**

子问题：
1. 1907年恐慌之前，私人协调机制（摩根图书馆、清算所）是如何组织全系统流动性的？
2. 为什么这些私人机制无法长期维持？
3. 美联储建立后，保留了哪些协调逻辑？改变了哪些结构？
4. 国家接手协调功能后，金融资本的协调入口获得了什么，又失去了什么？

---

## 4. 暂定逻辑链

```
1907年恐慌 → 摩根私人协调 → 清算所俱乐部的局限 →
国家出手建立美联储 → 私人协调被制度化吸收 →
金融资本的协调能力被国家放大 + 被重塑 →
结论：美联储不是摩根模式的反面，而是它的制度化版本
```

**注意：** 暂定逻辑链，待资料研究后补全和修正。

---

## 5. 写作边界

**本篇聚焦：**
- 协调入口（清算所 → 摩根 → 美联储的制度演变）
- 私人协调与国家制度的张力
- 金融资本的协调权如何被国家放大

**本篇不涉及：**
- 融资入口（详细讨论留给其他篇）

- 定价入口
