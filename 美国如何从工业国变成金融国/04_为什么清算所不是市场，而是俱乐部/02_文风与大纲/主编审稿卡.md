# 04 主编审稿卡

> 用途：规定主编每一轮审稿（共 6 轮 + 大纲审阅）的固定职责、意见格式与验收标准。
> 背景：沿用 03 严审稿卡；用户对前几篇主编的批评是"点评太泛泛"。本卡把主编职责钉死为三项，并规定不合格式的意见无效。
> 创建：2026-06-10

---

## 一、主编的三项固定职责

每轮审稿，主编**只做这三件事，但每件都要做穿**：

### 职责一：行文结构

- 整体结构对不对：节与节的顺序是否服务于主判断？有没有哪一节放错了位置？
- 通顺不通顺：逐节检查上一节末尾与下一节开头的衔接，是内容性衔接还是口号性衔接？
- **详略是否得当**：逐节登记"字数 vs 信息量"，明确指出哪一节该展开（信息密度过高、读者跟不上）、哪一节该压缩（字数多于信息）。
- **文风是否跑回 03 期刊杂志体**：段长是否突破 100 字、节奏是否放缓、每 200 字是否还有"小满足"。

### 职责二：体系合理性

- 有没有多余的东西：逐节、逐段问"删掉它，主判断受损吗？"
- 输出**删除清单**：每条写明位置、原文、删除理由、删除后如何缝合。
- 若本轮无可删项，必须逐节写一句"为什么必要"，不允许空着。
- **专项：抢题检查**——是否有 09（摩根救市全过程）/ 10（杰基尔岛+美联储）/ 11（贝尔斯登/雷曼）/ 03（1865 年 10% 税）的内容被拉进来；如有，强制删除或挪到留白。

### 职责三：架构真实性

- 文中每一处"矛盾/冲突/反差"逐个登记，检验：**它是史料里自然存在的，还是为了戏剧性强行拧出来的？**
- 检验标准：去掉修辞后，这个矛盾还成立吗？台账里有没有支撑它的钉子？
- 凡判定为"硬造张力"，必须给替代写法（通常是：如实陈述 + 让真实的复杂性自己产生张力）。
- **金句检验**：砸地金句是否"够狠"？3-4 句短句连击是否真正砸在地上？金句是否承担了机制翻译，还是只做漂亮表达？

## 二、意见格式（硬性要求）

每条意见必须包含四要素，缺一即无效：

```
【必改/可选】M4xx
位置：第几节第几段
原文：「……」（直接引用）
问题：具体说出违反了哪条职责/文风卡哪条规范
改法：给出可直接采用的改写或操作（删/移/并/扩）
```

**禁止出现的无效意见**（出现即重写本轮审稿）：

- "建议增强可读性""节奏可以更好""这段略显冗长"——无位置、无原文、无改法
- "整体不错，个别地方可以打磨"——既无整体结论的依据，也无个别地方的定位
- 只提问题不给改法
- "金句还不够狠"——无原文、无具体怎么改
- "跑回 03 期刊杂志体了"——无具体段落、无段长数据

## 三、每轮输出的固定结构

```
# 主编修改建议 vN

## 0. 本轮总判断（3 句内：能不能进入下一版/下一阶段，最大的问题是什么）
## 1. 行文结构（逐节详略登记表 + 结构意见 + 文风跑偏检查）
## 2. 体系合理性（删除清单 / 抢题检查清单，或逐节必要性说明）
## 3. 架构真实性（矛盾登记表：每处冲突 → 史料支撑 → 判定 + 金句够狠检查）
## 4. 必改清单汇总（编号 M4xx）
## 5. 可选清单汇总
## 6. 收敛度（与上轮对比：上轮必改 N 条 → 本轮 N 条；新引入问题单列）
```

## 四、各轮侧重

| 轮次 | 对象 | 侧重 |
|---|---|---|
| 大纲审阅 | 大纲 | 职责一 + 三：结构次序、矛盾是否有史料支撑、与 03/05/06/09/10/11 的边界、金句是否"够狠" |
| v1 | 草稿 v1 | 三项全开，火力最大的一轮；重点砸金句 |
| v2 | 草稿 v2 | 验证 v1 必改项是否改净 + 新引入问题；重点砸节奏（段长、每 200 字小满足） |
| v3 | 草稿 v3 | 结构定稿判定：放行进入修订稿，或退回；重点砸抢题检查 |
| v4 | 修订稿 v1 | 不再动大结构；详略微调 + 体系残余 + 抢题最终检查 |
| v5 | 修订稿 v2 | 验证 v4 改净；逐节通读流畅度；金句最后一遍砸 |
| v6 | 修订稿 v3 | **验收轮**：只允许"零必改"或延长循环，不允许带必改放行 |

---

## 五、验收标准（v6 轮）

1. 逐节详略登记表全部为"得当"。
2. 删除清单为空，且逐节必要性说明成立。
3. 矛盾登记表全部判定为"史料自然支撑"。
4. 全文与文风卡硬指标核对通过（段长 ≤100 字 / 每 200 字小满足 / 砸地金句 ≥2/节 / 粗体 2-3/节 / 感叹号 0 / 黑名单句式 0）。
5. 抢题检查通过：与 03、05、06、09、10、11 的边界零越界。
6. 金句够狠检查通过：每节砸地金句能独立成立，不只是"漂亮表达"。
