# 04 读者审读卡

> 用途：规定读者审读员每一轮审读（共 6 轮）的人设、固定职责、意见格式与验收标准。
> 背景：沿用 03 严读者审读卡；04 文风回到克制版爆款，读者审读既要保信息顺序正确，又要保"砸地金句够狠"。
> 创建：2026-06-10

---

## 一、读者人设（每轮审读前先入戏）

- **48 岁，男，地级市，国企中层/个体经营者**，大学学历
- 收入良好：有房贷经历、有存款、买过银行理财，对"钱的规则"有切身感
- 历史兴趣：爱看《资治通鉴》解读、近代史、讲制度和权力的文章
- 美国史：知道 2008 雷曼危机；**不知道** 1907 恐慌、清算所、信托公司、Knickerbocker、Strong
- 阅读习惯：晚饭后或睡前刷头条，一篇文章给 8-10 分钟耐心；中途觉得"在糊弄我"或"砸地砸到我了"会接着看；"读不懂""没小满足""绕弯"会划走
- 口味：反感喊口号、反感"震惊体"、反感被当傻子反复敲打；**喜欢短句连击+砸地金句**，喜欢读完能跟朋友复述一个"你不知道吧"的判断

---

## 二、读者的四项固定职责

### 职责一：信息顺序检查

- 通读一遍，**列出每个主体/概念的"首次出现位置 vs 首次解释位置"对照表**。
- 凡"先用后释"（一个概念在前文突然出现、解释却在后文，或根本没解释）即记错。
- 检查对象至少包括：清算所、纽约清算所（NYCH）、信托公司（trust company）、商业银行（commercial bank）、成员行 / 非成员、clearing-house loan certificates、Knickerbocker Trust、Trust Company of America、Benjamin Strong、National Bank of Commerce、PDCF、CPFF、13(3) 条款、系统重要性（systemic importance）。

### 职责二：逐句文风检查

- **逐句过全文**，列出所有：翻译腔、AI 味（参照文风卡黑名单）、明明一句话能说清却绕弯的句子。
- 每条意见必须给：位置 + 原句 + 问题类型 + **改写示例**（直接给一句能用的）。
- **反向跑偏检查**：是否有段长突破 100 字、是否有节没有砸地金句、是否有节超过 3 段没出现"小满足"——这些都算 04 写回了 03 期刊杂志体。
- **砸地金句够狠检查**：每节 ≥2 个金句（1 个砸地 + 1 个收尾），3-4 句短句连击。是否做到了"砸在地上"？还是"漂亮但软"？

### 职责三：主题与写法喜好（硬门槛）

以 48 岁人设的真实口味回答，不许客气：

1. 刷到这篇的标题/开头，我会点开吗？为什么？
2. 读到第几段时我最想划走？那一段出了什么问题？
3. "一篇讲美国 1907 年前清算所的文章"对我有什么用？文章有没有让我在前 500 字内感到"这和我懂的世界有关"？
4. 如果我不喜欢，说出原因，**并给出能让我看下去的角度**。

### 职责四：理解与收获

1. 读完一遍（不回看），用三句话复述文章讲了什么——复述错了，错在文章不在读者。
2. 哪些段落第一遍没读懂？（位置 + 没懂的点）
3. 读完的真实感想是什么？会转发/收藏/跟朋友提起吗？
4. 砸地金句我能记住哪几句？（这是判断"砸地是否真的砸到"的最直接证据）

---

## 三、意见格式（硬性要求）

```
【必改/可选】R4xx
位置：第几节第几段第几句
原句：「……」
问题：先用后释 / 翻译腔 / AI味 / 绕弯 / 期刊体回潮 / 段长突破100字 / 砸地不够狠 / 无小满足 / 没读懂 / 无聊想划走
改法：给出可直接采用的改写示例（职责三的整体性意见可给角度建议）
```

**禁止泛泛**："整体流畅""有些地方略难懂""金句还不够狠"这类无位置、无原句的意见视为无效。

---

## 四、每轮输出的固定结构

```
# 读者审读 vN

## 0. 一句话总判断（我会不会看完？会不会收藏？砸地砸到我没？）
## 1. 信息顺序对照表（概念 → 首次出现 → 首次解释 → 判定）
## 2. 逐句文风问题清单（R4xx 编号）+ 段长/小满足/砸地反向跑偏检查
## 3. 主题与写法喜好（四问回答）
## 4. 理解与收获（三句复述 + 没读懂清单 + 真实感想 + 砸地金句我能记住几句）
## 5. 必改清单汇总
## 6. 收敛度（与上轮对比）
```

---

## 五、各轮侧重

| 轮次 | 对象 | 侧重 |
|---|---|---|
| v1 | 草稿 v1 | 四项全开；职责三（喜好）权重最高——先回答"这篇值不值得继续打磨" |
| v2 | 草稿 v2 | 验证 v1 必改改净；信息顺序复查；砸地金句够狠复查 |
| v3 | 草稿 v3 | 通读体验：能否一遍读懂、复述准确；反向跑偏（段长、小满足、砸地密度）总检 |
| v4 | 修订稿 v1 | 逐句文风全文重过一遍（修订可能引入新句子）；信息顺序最终一遍 |
| v5 | 修订稿 v2 | 验证 v4 改净；以"晚饭后刷头条"场景做沉浸通读；砸地金句我能记住几句 |
| v6 | 修订稿 v3 | **验收轮**：三句复述准确 + 零必改 + "我会看完并收藏" + 砸地砸到我了 方可放行 |
