# 05｜美国钢铁业的「杯酒释兵权」——大工业不喜欢真竞争

> 所属系列：美国如何从工业国变成金融国
> 入口框架：治理入口 + 协调入口
> 文风定位：期刊杂志体微调版（比 03 更慢、更厚、更节制）
> 当前状态：定稿

---

## 一、本文定位

05 是新系列第二部「金融如何改造产业」的第一篇。

前 01-03 主要讲金融入口如何被产业、国家和制度养出来；05 开始转向一个更深的问题：当产业规模越来越大，产业本身为什么开始需要金融来管理竞争。

本文核心问题：

> 为什么美国大工业家嘴上讲自由市场，实际却总想管理竞争？

本文核心判断：

> 大工业并不天然热爱自由竞争。规模越大、固定成本越高、价格波动越可怕，产业资本越需要金融式协调来稳定利润。

---

## 二、写作方向

本文不写成卡内基或摩根人物传，也不写成钢铁行业技术史。

要写的是：

1. 钢铁这种重工业为什么怕价格战。
2. 为什么产业资本自己也想摆脱「真竞争」。
3. Gary Dinners 这样的行业协调为什么出现。
4. J.P. Morgan 为什么能用 U.S. Steel 把竞争秩序组织起来。
5. 金融资本如何从「给产业钱」走向「定义产业怎么竞争」。

---

## 三、文风要求

沿用 03 的期刊杂志体，但做 05 专属微调：
