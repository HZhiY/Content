# 03｜为什么一场 10% 的税，重塑了美国银行？

> 所属系列：美国如何从工业国变成金融国（第一部·产业如何养大金融）
> 主入口：制度入口（谁有资格发行信用）
> 状态：生产中
> 创建：2026-06-10

---

## 本篇定位

1865 年 3 月 3 日，国会对州立银行票据征收 10% 流通税。没有禁令，两年内 97% 的州立银行票据消失。本篇讲的不是"税收的威力"，而是**资格清洗**：规则如何替市场先把玩家选了一遍，让"发行信用"的资格从地方自发，变成国家授权。

02 讲国家把信用入口建起来；03 讲国家用规则把这个入口关上门——从此想发信用，先得有联邦的执照。
