# 03 文风卡：期刊杂志体

> 文章：03｜为什么一场 10% 的税，重塑了美国银行？
> 文风定位：**期刊杂志体**——冷静、从容、有耐心的深度叙述；判断锋利，但靠材料推出来
> 替换对象：01/02 的"克制版爆款"（短句轰炸 + 每 200 字小满足 + 粗体密集）
> 起因：用户反馈前几篇"太紧太急，从头到尾都是高潮"；45-55 岁读者要的是一篇值得慢慢看完的文章
> 创建：2026-06-10

---

## 一、一句话定义

> **像一本好杂志的特稿：开头给你一个画面，中间不催你，每一节把一件事讲清楚，判断在材料里自己长出来。**

读者读完的感受应该是"这文章写得稳，作者知道自己在说什么"——而不是"作者一直在敲我肩膀让我惊讶"。

---

## 二、与 01/02 文风的对照表（写每段前看一眼）

| 维度 | 01/02 克制版爆款 | 03 期刊杂志体 |
|---|---|---|
| 节奏 | 每 200 字一个"小满足" | **取消该指标**；每节只保证"讲清楚一件事" |
| 金句 | 高密度，节节有、段段有 | **每节至多 1 处**，放在该节收尾或转折处 |
| 段落 | 一段一句、≤100 字 | **允许 100-200 字完整叙述段**；短段保留，但作为变奏不作为常态 |
| 粗体 | 关键判断密集加粗 | **每节 ≤ 2 处** |
| 开头 | 数据炸弹 + 反常识钩子 | **场景或细节进入（lede）**，第一节末才收出问题 |
| 排比 | "不是A，是B"连击 | 全文 ≤ 2 组；判断用平实陈述句给出 |
| 设问 | "问题来了？""怎么办？"频繁 | 全文 ≤ 3 处，只在真正的转折处用 |
| 感叹号 | 偶用 | **全文 0 个** |
| 破折号 | 高频 | 明显降频，优先用句号和逗号 |

## 三、期刊杂志体的 6 条正面规范

1. **场景先于论点**：每节尽量从一个具体的人、物、日期或文件进入，再过渡到机制。例：从商人收银台上那本《银行票据通报》进入战前货币乱象，而不是从"货币体系混乱"进入。
2. **让数字自己说话**：给出数字后，用一句平实的话点意义即可，不堆叠惊叹。例："1.43 亿变成 400 万，中间只隔了两年。"——到此为止，不再追加三句排比。
3. **耐心交代因果**：允许用一整段把"为什么州立银行不愿转换执照"讲完，不急着切下一个高潮。
4. **判断后置**：每节的判断句出现在材料铺完之后；全文最重的一句话留给结语。
5. **承认复杂**：该让步就让步（"州立银行后来回来了""立法者想的是战争融资"），让步恰恰让主判断更可信。
6. **过渡用内容不用口号**：节与节之间靠"上一节留下的未解问题"衔接，不靠"更可怕的还在后面"这类悬念口号。

---

## 四、保留不变的底线（与 01/02 一致）

- **直白**：不写"由此可见""综上所述""在某种意义上"等学者腔；不写翻译腔（"作为一个……的存在""值得注意的是"）。
- **注脚**：人名/法案/机构/术语首次出现给一句话人话解释（"货币监理署，财政部下面管银行执照的机构"）。
- **称呼**：可以用"你"，但降频——杂志体里"你"只在真正需要把读者拉进场景时用。
- **红线**：不写阴谋论；正文不出现"中国""国内""我们"等明示词；不举国内案例。
- **事实精度**：数字、日期、主语必须可回台账；不为节奏牺牲精度。

---

## 五、AI 味与翻译腔黑名单（读者逐句检查的依据）

以下句式出现即记错：

| 类型 | 黑名单示例 | 改法 |
|---|---|---|
| AI 排比腔 | "这不是X，这是Y。这不是A，这是B。"连用 | 全文此结构 ≤ 2 组 |
| AI 总结腔 | "换句话说""更重要的是""值得注意的是"高频出现 | 每个连接词全文 ≤ 2 次 |
| 翻译腔 | "作为一名银行家，他……""这使得……成为可能" | "他是银行家""这样一来……才办得成" |
| 空转折 | "然而，事情并没有那么简单" | 直接写不简单在哪 |
| 悬念口号 | "真正可怕的还在后面" | 删除，用内容本身衔接 |
| 绕弯 | "在某种程度上可以说，这一政策在客观上起到了……的作用" | "这条税实际做到的是……" |
| 万能形容 | "深刻地改变了""产生了深远影响" | 写出具体改变了什么 |

## 六、节奏与配比（目标 ~3900 字）

| 部分 | 字数 | 任务 |
|---|---|---|
| 开场 lede | 350 | 一个具体场景 + 收出问题 |
| 一、八千种钞票的国家 | 600 | 战前货币面貌（画面 + 两次央行失败一笔带过） |
| 二、战争给了联邦一个理由 | 650 | 国民银行体系的设计与遇冷 |
| 三、一条税率，替市场做了选择 | 700 | 10% 税的通过、算账、换执照潮 |
| 四、数字给出的答案 | 600 | 票据蒸发 + Veazie 案 + 蔡斯双重角色 |
| 五、银行回来了，资格没有回来 | 650 | 州立银行回流；资格清洗的真正含义 |
| 结语 | 350 | 收束到"规则先于市场"；扣 02 不预告 04 |

- 单段上限 200 字；全文感叹号 0 个；每节金句 ≤ 1、粗体 ≤ 2。
- 阅读时长目标 10-13 分钟，符合"值得慢慢看完"的定位。

---

## 七、写完每节的自检（作者用）

1. 这一节从画面进入还是从论点进入？（应为画面/细节）
2. 这一节讲清楚了哪**一件**事？
3. 金句超过 1 处了吗？粗体超过 2 处了吗？感叹号出现了吗？
4. 有没有黑名单句式？
5. 数字的主语准确吗？可回台账吗？
6. 节末留下的是"内容性的未解问题"还是"悬念口号"？
