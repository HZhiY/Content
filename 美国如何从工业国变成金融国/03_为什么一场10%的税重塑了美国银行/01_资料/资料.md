## 一、旧素材迁移要点（旧系列 02 草稿/大纲）

可直接继承的事实骨架：

1. 1865 年前后美国约 1600 家银行各自发钞，无统一货币。
2. 美国两次建立中央银行均失败（第一合众国银行 1791-1811、第二合众国银行 1816-1836），货币发行权留在各州。
3. 内战爆发后联邦需要统一货币与稳定融资。
4. 1865 年 3 月国会对州立银行票据征收 10% 流通税；未禁止、未强制。
5. 州立银行票据流通量：约 1.43 亿美元（1865）→ 约 400 万美元（1867），降幅超 97%。
6. 后果分层：银行收入、地方权力、普通持票人、州财政、地方金融自治。

**旧文已用过的写法（新 03 必须避开）**：
- "杀死州立银行""制度设计不靠禁止"的角度与金句；
- 短句轰炸式的"五层代价"清单；
- "重新定义正常"的结尾论式。

## 二、规模与数据

### 2.1 内战前的货币面貌（自由银行时代，1837-1863）

- 1860 年前后，全美州立银行约 1500-1600 家，各自发行票据。
- 市面流通的各种银行票据**种类以千计**（常见估计为数千种至八千种以上，需在台账标注口径）。
- 票据异地流通要打折：离发行银行越远、银行信用越差，折扣越大。商人靠《银行票据通报》（Bank Note Reporter，定期出版的票据行情与假币名录）查每张票据的折价和真伪。
- 假币泛滥；"野猫银行"（wildcat bank，把兑付点设在偏远地区故意逃避兑付的银行）是这个时代的产物。

### 2.2 国民银行体系的建立与遇冷

- 1863 年 2 月 25 日《国民货币法》（National Currency Act），1864 年 6 月 3 日修订为《国民银行法》（National Bank Act）。
- 机制：想成为"国民银行"，须向财政部下设的货币监理署（Comptroller of the Currency）申请特许；**用资本金购买联邦国债存入监理署，按存入国债面值的 90% 上限领取统一印制的国民银行券**。
- 这套设计一举三得：统一货币 + 为战争国债制造买家 + 联邦获得对银行的特许权。
- 但州立银行**不愿主动转换**：1864 年底国民银行约数百家，州立银行仍上千家。发自家钞票有利可图，何必去买国债换执照。

### 2.3 10% 税与结果

- 1865 年 3 月 3 日，国会在岁入法案中加入条款：**对任何银行支付出去的州立银行票据征收 10% 的税**，自 1866 年（7 月 1 日后支付的票据）起执行。
- 州立银行数量：约 1000 余家（1864）→ 数百家（1865-1866 大批转换为国民银行执照）→ 约 247-300 家（1866-1868 低点）。
- 国民银行数量：66 家（1863）→ 467 家（1864）→ 1294 家（1865）→ 1634 家（1866）。
- 州立银行票据流通量：约 1.43 亿美元（1865）→ 约 2000 万美元（1866）→ 约 400 万美元（1867）。
- 1869 年最高法院 Veazie Bank v. Fenno 案裁定 10% 税合宪。**执笔人是首席大法官萨蒙·蔡斯（Salmon P. Chase）——他正是当年设计国民银行体系的财政部长。**

### 2.4 关键的"但是"：州立银行没有死

- 10% 税杀死的是**州立银行的发钞业务**，不是州立银行本身。
- 州立银行随后转向**存款与支票业务**：支票不是"票据"，不交 10% 税。
- 州立银行数量回升：约 631 家（1877）→ 约 2700 家（1887）→ 1890 年代重新超过国民银行数量。
- **这正是"资格清洗"角度的核心证据**：被收归国家的不是"开银行的资格"，而是"发行货币的资格"。银行可以继续开，但凡是像货币一样流通的信用凭证，从此只能由联邦授权发行。

## 三、机制拆解（写作主线）

```
[战前] 发行信用的资格 = 各州特许，地方自发
   ↓ 内战：联邦要钱、要统一货币
[1863-64] 联邦自建一套带国债抵押的"国家授权信用"（国民银行券）
   ↓ 但旧玩家不愿搬家——两套体系并行
[1865] 10% 税：不禁止旧资格，只让旧资格无利可图
   ↓ 市场完成清场：换执照的换执照，退出的退出
[1866-69] 数字落定 + 最高法院背书：资格转移完成
   ↓
[之后] 州立银行靠存款业务回流——但"发钞资格"再也没有回来
```

一句话主旨：**这条税替市场先选了一遍玩家——它改变的不是税负，而是"谁有资格发行信用"。**

## 四、时间线

| 时间 | 事件 |
|---|---|
| 1791 / 1816 | 第一、第二合众国银行先后成立，又先后失去特许 |
| 1837-1863 | 自由银行时代：州立银行各自发钞 |
| 1861 | 内战爆发；联邦融资压力骤增 |
| 1862-02-25 | 《法定货币法》：联邦发行"绿钞"（greenback，不可兑金银的法定纸币） |
| 1863-02-25 | 《国民货币法》：国民银行体系 + 货币监理署设立 |
| 1864-06-03 | 《国民银行法》修订完善 |
| 1865-03-03 | 岁入法案加入 10% 州立银行票据流通税 |
| 1866-07-01 | 10% 税开始适用 |
| 1865-1867 | 州立银行大批换领国民银行执照；票据流通量蒸发 97% |
| 1869 | Veazie Bank v. Fenno：最高法院裁定 10% 税合宪 |
| 1870s-1890s | 州立银行靠存款/支票业务回流，数量反超 |

## 五、案例与画面素材

1. **缅因州 Veazie 银行**：拒不退场、状告联邦税务官 Fenno 的那家州立银行——给"资格清洗"提供了一个有名有姓的反抗者，及其败诉结局。
2. **《银行票据通报》**：战前商人收银台上的必备出版物，按银行逐家列出折价与假币特征——"收一张钞票前先查册子"是战前美国的日常画面。
3. **蔡斯的双重角色**：1861-1864 年任财政部长，设计国民银行体系；1869 年以首席大法官身份裁定 10% 税合宪。同一个人，先造了新资格，又亲手给旧资格的死亡盖了章。
4. **国债抵押机制的画面**：国民银行的钞票背后压着的是联邦国债——想印钱，先借钱给华盛顿。

## 六、风险点与口径说明

| 风险点 | 说明 | 处理 |
|---|---|---|
| 银行总数 1600 家 | 不同年份、不同口径（是否含未发钞银行）数字不同 | 正文用"约 1600 家"模糊化，台账标口径 |
| 票据种类"八千种" | 常见估计，无权威单一来源 | 正文用"以千计"，避免精确数 |
| 10% 税生效日期 | 法案 1865-03-03 通过，适用于 1866-07-01 后支付的票据；1866-07-13 又有扩展条款 | 正文写"1865 年通过、次年生效"，台账存细节 |
| 州立银行数量序列 | 各来源（货币监理署年报 / Friedman & Schwartz）口径略异 | 正文用趋势性表述 + 区间，台账标来源 |
| "杀死州立银行"的夸张 | 州立银行 1870-90 年代靠存款业务回流 | **必须如实写**，这是新角度的支点，不是要遮掩的瑕疵 |
| 阴谋论风险 | 把财政政策写成"华盛顿密谋" | 写"战争融资 + 货币统一的意图、超出意图的效果" |
