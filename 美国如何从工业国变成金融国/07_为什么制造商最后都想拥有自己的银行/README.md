# 07｜为什么制造商最后都想拥有自己的银行？

## 项目定位

本篇是《美国如何从工业国变成金融国》系列第 07 篇。

表面问题：为什么很多制造企业，最后都长出了自己的金融部门？

核心命题：**产业自建金融，起初是为了摆脱外部金融约束、把产品卖出去；但金融一旦做大，就会从销售工具变成利润中心，最后反过来定义企业。**

## 写作边界

- 主案例：福特信贷、约翰迪尔金融、通用电气资本。
- 轻触案例：通用汽车金融只作背景一笔带过，避免与第 06 篇重复。
- 正文目标：2500–3100 个中文字符，不含标题和章节号。
- 三条红线：不用英文字符，不写跨篇引用，不写翻译腔。
- 读者对象：四十岁左右，受过教育，有收入与资产压力，希望获得谈资、认同和结构解释的男性读者。
