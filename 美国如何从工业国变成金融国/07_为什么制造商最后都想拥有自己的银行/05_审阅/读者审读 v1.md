# 读者审读 v1

## 总体判断

稿子基本可读，逻辑清楚，选题有认知增量。它能把“制造商为什么搞金融”讲成一条从销售工具到金融反噬的曲线，适合受过教育、关心资产和经济结构的中年男性读者。

主要问题：开头还不够狠，现实共鸣还停在“买车月供”层面，通用电气资本段略偏财经解释，最后的转发理由还可以更具体。

## 必须修改

1. 强化开头钩子。更早点出“买车不是买价格，而是在安排未来现金流”。
2. 把三段递进关系写得更明显：福特组织家庭购买力，约翰迪尔组织产业周期，通用电气资本则是金融反过来组织企业。
3. 通用电气资本段降低财经术语密度，把“资产期限长、融资期限短”等说法转成口语解释。
4. 增加现实映射，不要让它只是美国企业史。
5. 结尾增加更适合转发的金句，强化“主业赚钱慢，金融赚钱快”的现实刺痛。
