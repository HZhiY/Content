# 08 事实核查清单｜为什么杜邦要救通用汽车？

## 一、已核事实

- [x] 杜邦公司在 1917—1919 年购买通用汽车约 23% 股份。
  - 采用口径：最高法院案和地区法院事实材料中的 23% / 23.96%。
  - 正文写法：到 1920 年底，杜邦持有通用汽车约 23.96% 的流通股。

- [x] 1920 年杜兰特辞任通用汽车总裁，皮埃尔·杜邦接任。
  - 来源：纽约时报 1920 年 12 月 1 日报道；法院材料。
  - 正文写法：1920 年 11 月底，杜兰特辞去总裁职务，皮埃尔·杜邦接任。

- [x] 皮埃尔·杜邦任通用汽车总裁至 1923 年 5 月，随后斯隆接任。
  - 来源：法院材料。
  - 正文写法：皮埃尔·杜邦更像过渡性治理者，1923 年把总裁位置交给斯隆。

- [x] 唐纳森·布朗 1921 年进入通用汽车任财务副总裁。
  - 来源：杜邦历史网页存档；管理会计研究资料。
  - 正文写法：杜邦不只派来资本，也派来了财务控制语言。

- [x] 布朗在杜邦体系中发展投资回报率和统一会计程序，后在通用汽车发挥作用。
  - 来源：杜邦历史网页存档；会计史论文。
  - 正文写法：不要说“一个公式拯救通用”，要说“总部从此能看见各部门如何占用资本”。

- [x] 斯隆与布朗共同形成“分散经营、集中控制”的管理体系。
  - 来源：会计史论文、管理会计材料。
  - 正文写法：各事业部自己经营，总部用预算、财务指标和资本配置掌握方向。

- [x] 杜邦快干漆在 1924 年被通用汽车大范围采用，缩短涂装时间。
  - 来源：美国涂料协会。
  - 正文写法：作为供应关系的侧证，最多一小段。

- [x] 1957 年美国最高法院在美国诉杜邦案中认定杜邦购买通用汽车股份违反《克莱顿法》第 7 条。
  - 来源：Cornell LII、Justia Supreme Court。
  - 正文写法：股权关系不是普通投资，一旦带来供应偏好和排他可能，就成为市场结构问题。

## 二、待核或谨慎事实

- [ ] 杜邦一战利润和资本积累的具体数字。
  - 暂不写具体数字，保守写“一战期间快速扩张，战后需要寻找新出口”。

- [ ] 杜邦家族或杜邦公司在 1919 年是否“控制超过 26% / 37% / 38%”的不同口径。
  - 正文不采用媒体高口径，统一使用法院材料的 23.96%。

- [ ] 杜邦对通用汽车供应额占比。
  - 不写具体占比，除非后续找到权威数字。

- [ ] 杜邦被迫剥离通用汽车股份的最终完成时间线。
  - 如正文不需要，不展开。

## 三、禁用或限制写法

- 不写“杜邦完全控制通用汽车”。
- 不写“杜邦发明了事业部制”。
- 不写“皮埃尔·杜邦一个人拯救了通用汽车”。
- 不写“杜邦卖油漆才救了通用汽车”。
- 不写“1957 年杜邦犯罪”。
- 不写当代公司类比。
- 不写跨篇勾稽话术。

## 四、正文证据优先级

### P0 必用

1. 1917—1919 年杜邦购买通用汽车 23% 股份。
2. 1920 年杜兰特出局，皮埃尔·杜邦接任。
3. 1921 年唐纳森·布朗进入通用汽车。
4. 斯隆与布朗形成财务控制和事业部治理。
5. 1957 年反垄断案。

### P1 可用

1. 拉斯科布推动投资。
2. 杜邦一战后资本出口。
3. 杜邦快干漆。
4. 通用汽车承兑公司。

### P2 慎用

1. 杜邦持股超过 37% 或 38% 的媒体说法。
2. 杜邦与通用具体供应额比例。
3. 过度神化杜邦分析法的中文管理学文章。
