## 三、事实检查

- [x] 杜邦公司在 1917—1919 年购买通用汽车约 23% 股份；到 1920 年约 23.96%。
- [x] 1920 年 11 月底 / 12 月 1 日，杜兰特辞任，皮埃尔·杜邦接任。
- [x] 皮埃尔·杜邦任总裁至 1923 年，斯隆接任。
- [x] 唐纳森·布朗 1921 年进入通用汽车。
- [x] 布朗在杜邦体系中发展投资回报率，后在通用汽车完善财务控制。
- [x] 杜邦快干漆 1924 年被通用汽车大范围采用。
- [x] 1957 年最高法院在“美国诉杜邦公司案”中认定杜邦取得通用汽车 23% 股份违反《克莱顿法》第 7 条。
- [x] 持股 23% 写法采用法院口径，未使用媒体口径。
