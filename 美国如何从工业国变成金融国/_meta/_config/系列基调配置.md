# 系列基调配置

> 适用系列：美国如何从工业国变成金融国  
> 用途：供方向、文风、大纲、审稿、修订、发布检查等 agent 读取，统一系列气质、解释边界和表达原则。  
> 核心母题：美国不是突然变成金融国的。它是工业扩张先养大金融工具，后来金融工具反过来接管工业命运。

---

## 一、系列定位

本系列是**制度解释型财经历史长文**，不是单纯金融史、企业史、美国史，也不是华尔街阴谋故事。

它要回答：

```text
美国是怎么从工业国变成金融国的？
产业资本为什么一步步输给金融资本？
```

核心叙述不是“金融天然邪恶”，而是：

```text
金融最初是产业扩张的工具。
铁路、钢铁、汽车、制造业需要钱、债券、银行、资本市场。
产业亲手把金融养大。
当金融掌握融资、制度、消费、治理、协调和定价入口之后，
它就不再只是服务产业，而开始决定产业怎么活、为谁活、危机时谁有资格活下去。
```

---

## 二、系列总气质

| 维度 | 要求 |
|---|---|
| 总体气质 | 克制、清楚、有机制感、有历史纵深 |
| 解释方式 | 用故事承载机制，用机制解释现实 |
| 叙述视角 | 看制度、资本、产业和组织激励如何相互塑造 |
| 情绪强度 | 有 tension，但不煽动；有判断，但不控诉 |
| 现实连接 | 可以点出现实回声，但不能把历史材料粗暴套到现实 |
| 读者收获 | 读完获得一套判断现实的框架 |

一句话原则：

```text
不写“谁坏”，写“什么机制让结果一步步变成这样”。
```

---

## 三、六个入口框架

全系列围绕金融资本逐步掌握产业生存入口展开。

| 入口 | 核心问题 | 典型材料 |
|---|---|---|
| 融资入口 | 谁能拿到钱 | 铁路、国债、证券市场、投资银行 |
| 制度入口 | 谁有资格发行信用 | 国民银行制度、银行税、清算所、监管资格 |
| 消费入口 | 谁能把未来收入变成今天购买力 | 汽车分期、GMAC、消费信贷、信用卡 |
| 治理入口 | 谁能控制公司决策 | 大股东、董事会、并购、控股公司 |
| 协调入口 | 谁能在危机中组织全系统 | 清算所、摩根、美联储、财政部、大型银行 |
| 定价入口 | 谁决定一家企业值多少钱 | 股市估值、债券评级、回购、杠杆、资产价格 |

每篇文章必须明确自己主要服务哪个入口，不要一篇文章同时吃下多个入口。

---

## 四、写作总原则

### 4.1 单篇独立

每篇文章都必须独立成立。

读者不看前文，也能理解：

1. 本篇在问什么；
2. 本篇讲哪个机制；
3. 本篇结论是什么；
4. 本篇如何放回“工业国到金融国”的暗线。

### 4.2 暗线统一

每篇文章都从不同角度回答：

```text
金融资本怎样获得一个入口？
产业资本怎样让出这个入口？
```

但正文中不要机械重复“金融资本赢了”这句话，要让读者从机制里自己看到这个结论。

### 4.3 每篇只打一颗主钉

一篇文章只解决一个核心问题，交付一个核心机制。

禁止：

- 同时讲融资、治理、消费、定价多个大问题；
- 在结尾突然升到全系列总论；
- 为了宏大感牺牲单篇清晰度。

### 4.4 不写阴谋论

禁止把金融资本写成神秘操盘者。

推荐写法：

```text
金融资本的胜利，很多时候不是靠阴谋，
而是靠产业自己需要它、制度不断放大它、危机反复强化它。
```

### 4.5 不写教科书

不要按年代平铺，不做术语介绍大全。

每篇必须从一个反常识问题进入，用故事承载机制，用机制解释现实。

---

## 五、优先内容类型

根据复盘，本系列优先采用：

| 类型 | 用法 |
|---|---|
| 机制型 | 解释融资、制度、消费、治理、协调、定价入口如何运转 |
| 逻辑型 | 解释产业资本为什么会接受、依赖，最后被反向支配 |
| 分析型 | 提炼框架，帮助读者获得判断工具 |
| 对比型 | 用于福特 vs 通用、贝尔斯登 vs 雷曼等天然反差题 |
| 叙事型 | 只作为入口，不作为默认结构；故事必须服务机制 |
| 规律型 | 只用于多案例归纳或收束篇，避免空泛 |

最优先组合：

```text
机制型 × 分析型
```

---

## 六、表达口径

### 6.1 推荐表达

- “入口”
- “机制”
- “信用”
- “融资能力”
- “购买能力”
- “协调权”
- “定价权”
- “治理入口”
- “制度筛选”
- “产业需要金融，金融反过来塑造产业”

### 6.2 慎用表达

- “金融收割产业”
- “华尔街控制一切”
- “资本阴谋”
- “美国骗局”
- “历史真相”
- “彻底改变”
- “唯一原因”

慎用词只有在事实和正文充分支撑时才能使用，并必须降级为机制解释。

### 6.3 禁止表达

- 阴谋论口吻；
- 民粹控诉腔；
- 没有证据的道德审判；
- 把复杂制度变化归因给单个坏人或单次阴谋；
- 把美国历史直接套成当代中国判断；
- 用“金融资本天然邪恶”替代机制分析。

---

## 七、结尾基调

结尾应该完成三件事：

1. 回收本篇机制；
2. 点出本篇在全系列暗线中的位置；
3. 给读者一个可带走的判断框架。

结尾不应：

- 突然拔高成宏大控诉；
- 强行预测未来；
- 写成金句堆叠；
- 把历史案例直接变成现实立场。

推荐结尾力度：

```text
克制地指出：当产业越来越依赖某个金融入口，它就会逐渐按那个入口的规则重塑自己。
```
