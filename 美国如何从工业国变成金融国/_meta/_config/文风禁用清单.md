# 文风禁用清单

> 适用系列：美国如何从工业国变成金融国  
> 用途：供文风、大纲、草稿、审稿、修订、发布检查和标题阶段识别禁用表达、风险语气和不合系列气质的写法。  
> 核心原则：写机制，不写情绪；写结构，不写阴谋；写清楚，不写玄乎。

---

## 一、总禁区

本系列禁止以下总体风格：

1. 标题党；
2. 短视频腔；
3. 阴谋论腔；
4. 金融控诉腔；
5. 论文腔；
6. AI 腔；
7. 过度鸡汤或金句腔；
8. 过度宏大叙事腔。

---

## 二、标题党与短视频腔

### 2.1 禁用词

禁止使用：

```text
震惊
炸裂
彻底
终于
刚刚
重磅
惊人
内幕
真相大白
看完沉默
不看后悔
所有人都错了
```

### 2.2 禁用句式

禁止：

- “你绝对想不到……”；
- “背后真相令人……”；
- “美国不装了……”；
- “华尔街摊牌了……”；
- “这一切早有预谋……”；
- “看懂这个，你就看懂了全部……”；
- “所有制造业的结局都一样……”；
- “一文讲透美国金融化全部真相”。

### 2.3 替代表达

| 不推荐 | 推荐 |
|---|---|
| 真相令人震惊 | 机制比表面更关键 |
| 华尔街摊牌 | 金融资本获得了新的入口 |
| 美国彻底变了 | 美国经济结构开始发生转向 |
| 一切都因为金融 | 金融在其中获得了更强的定价和协调权 |

---

## 三、阴谋论腔

### 3.1 禁止方向

禁止把复杂结构写成少数人密谋：

- “华尔街设计了一切”；
- “金融资本早就计划好”；
- “银行家操控国家”；
- “资本集团秘密接管产业”；
- “美国制度从一开始就是骗局”。

### 3.2 推荐改法

改写为：

```text
产业扩张制造了金融需求。
制度安排放大了金融权力。
危机反复强化了金融协调者的位置。
资本市场逐渐把企业改写成可定价资产。
```

---

## 四、金融控诉腔

禁止只用道德批判替代机制分析。

### 4.1 慎用词

```text
收割
吸血
绑架
掠夺
资本的獠牙
金融怪兽
产业奴役
韭菜
赌场
```

这些词除非正文有非常明确的历史语境和证据，否则不得使用。

### 4.2 推荐表达

| 控诉腔 | 机制表达 |
|---|---|
| 金融收割产业 | 金融掌握了产业融资和定价入口 |
| 华尔街绑架公司 | 资本市场指标开始改变公司治理目标 |
| 银行吸血消费者 | 信贷安排把未来收入提前转化为购买力 |
| 资本操纵危机 | 危机中具备协调权的人可以决定救援顺序 |

---

## 五、论文腔与术语堆叠

### 5.1 禁止写法

禁止连续堆叠抽象概念：

```text
金融资本通过制度化权力结构完成对产业资本主体性的再编码。
```

禁止用学术概念替代解释：

- 主体性；
- 现代性；
- 结构性张力；
- 资本逻辑；
- 制度性安排；
- 历史必然性。

不是完全不能用，而是不能不解释就用。

### 5.2 推荐写法

```text
当企业越来越依赖外部融资，能不能拿到钱就比能不能造出东西更重要。
这时，金融不再只是服务者，而开始变成筛选者。
```

## 六、AI 腔

禁止出现：

- “本文将从三个维度展开分析”；
- “综上所述”；
- “值得注意的是”；
- “不可否认的是”；
- “从某种意义上说”；
- “这不仅是……更是……”连续套用；
- “它深刻揭示了……”；
- “具有重要启示意义”。

推荐改为具体判断：

```text
问题不在于企业有没有钱，而在于谁能决定钱的入口。
```

---

## 七、过度绝对化

禁止或慎用：

```text
唯一原因
全部原因
彻底改变
完全控制
必然导致
从此以后再也没有
所有企业都
没有任何例外
```

推荐降级：

| 绝对表达 | 降级表达 |
|---|---|
| 唯一原因 | 关键原因之一 |
| 彻底改变 | 开始改变 / 逐渐改变 |
| 完全控制 | 获得更强影响力 |
| 必然导致 | 往往会推动 / 容易造成 |
| 所有企业 | 越来越多企业 / 一类企业 |

---

## 八、过度升维

禁止每篇结尾都升到：

- 文明兴衰；
- 人性真相；
- 历史终局；
- 时代答案；
- 国家命运；
- 世界秩序大变局。

本系列允许升维，但必须从正文机制自然推出。

推荐结尾落点：

```text
这一步让金融掌握了某个入口。
当产业越来越依赖这个入口，它就会逐渐按金融的规则调整自己。
```

---

## 九、代词悬空

慎用：

```text
它
这件事
他们
这一切
那个东西
你
```

尤其在标题、小标题和开头中，优先使用具体对象。

不推荐：

```text
它为什么改变了一切？
```

推荐：

```text
分期付款为什么改写了汽车竞争？
```

---

## 十、英文与翻译腔

发布版本中应避免英文字符和英文式表达。

如果必须出现英文缩写或机构名，应在事实核查或发布检查阶段确认是否允许。

禁止翻译腔：

- “进行一个决定”；
- “扮演了重要角色”；
- “产生了深远影响”；
- “在某某方面发挥作用”；
- “对于某某而言是重要的”。

推荐改为具体动作：

```text
它改变了谁能拿到钱。
它决定了谁能进入清算网络。
它让企业开始按月供而不是售价设计竞争。
```
