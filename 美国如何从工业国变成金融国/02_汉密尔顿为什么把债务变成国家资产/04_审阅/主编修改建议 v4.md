## 二、必须改（3 项）

### 必须改 1：第一节 61 行 病句

**位置**：第一节 60-61 行

**原版**：
```
杰斐逊怕的是"金融资本控制国家"。
但，汉密尔顿想的是"美国靠什么站立起来，资本"。
```

**问题**：
- "美国靠什么站立起来，资本"——"美国靠什么站立起来"是完整疑问句，加"，资本"是**断尾**
- "但"是转折，但前一句"怕的是金融资本控制国家"和后一句"想的是美国靠什么站立起来"**不需要转折**——都是"想法"

**改法**：
```
杰斐逊怕的是"金融资本控制国家"。
汉密尔顿想的是"美国靠什么站立起来"。
```

**理由**：
- 删"但"——前一句是"怕"，后一句是"想"，**两者是平行的，不需要转折**
- 删"，资本"——"美国靠什么站立起来"已经是完整表达
- 删"，资本"也对应"**用资本的力量**"那句——前文已经讲过"用资本的力量"了——这里再加"资本"是重复

---

### 必须改 2：第三节 191 行 错断句

**位置**：第三节 191 行

**原版**：
```
汉密尔顿做了政治交易：把国都从纽约南迁到弗吉尼亚，杰斐逊的票仓。，换杰斐逊点头。
```

**问题**："票仓。"多了个"。"——把句子**切断**了——读起来"票仓。"是独立段，但"票仓"应该是"弗吉尼亚"的同位语。

**改法**：
```
汉密尔顿做了政治交易：把国都从纽约南迁到弗吉尼亚（杰斐逊的票仓），换杰斐逊点头。
```

**理由**：
- 用括号把"杰斐逊的票仓"作为"弗吉尼亚"的同位语
- 删那个"。"断句
- 整句连贯："把国都从纽约南迁到弗吉尼亚（杰斐逊的票仓），换杰斐逊点头。"

---

### 必须改 3：第三节 202 行 2 个"还"字

**位置**：第三节 202 行

**原版**：
```
这可把债还清还厉害 100 倍——还清只解决一次，变成利益共同体了，资本就永远不走了。
```

**问题**："这可把债**还**清**还**厉害 100 倍"——2 个"还"字连在一起。

**改法**：
```
这可比把债还清还厉害 100 倍——还清只解决一次，变成利益共同体了，资本就永远不走了。
```

**理由**：加"比"字——"这**比**把债还清**还**厉害 100 倍"——前后对比结构更清楚。

## 三、可选优化（1 项）

### 可选 1：第三节 153-154 行 删"按平均算 4%"段

**读者审读 v4 提的**——但**主编判断不修**。

**理由**：
- 用户删了"按平均算 4%"，但加了"反正已经这样了，不如试试呢"——**用口语化盖过算账**

**结论**：**不修**——保留用户的删版。
