这七个洞察共同服务同一个主承诺——"显影 → 改写 → 穿透 → 拆除"四段机制链。**入口洞察 O2**（Raskob 报告）让读者在前 1/3 段就明白"为什么救"——杜邦 1917 年自己已经写明"我们的持股无疑将确保 Fabrikoid、Pyralin、油漆与清漆业务"，这是产业资本用治理通道绑定客户的"动机主钉"，不是慈善。**骨架命题 T01 显影**承接 O2，把 1914 Pierre 个人投资 → 1915 入董事会 → 1917 Raskob 报告 → 1920-11 联合接盘串成"治理网络前置完成的显影瞬间"——这是文章主承诺的"显影"侧。**副洞察 CJ1-2** 把"显影"具体落到 1920-11-30 的危机显影（老式治理失灵 + 新式治理网络补位），避免抽象。**副洞察 CJ2-1 + CJ2-2** 把"显影"展开为 1921-1929 的"改写"过程：Brown 双重身份 + 1923 分工 + 1928 边界测试，证明资本逻辑被嵌入产业治理的实体通道。**新意洞察 CJ3-1** 把"穿透"具体落到 1954 地区法院"产品竞争力" vs 1957 最高法院 "commanding position" + "reasonable probability" 的双口径对照——这是 1954 地区法院"产品竞争力"判断被推翻的瞬间，也是治理网络第一次被反垄断法律看见的瞬间。**结尾升维 CJ3-2 + E1** 把"穿透"展开为 1957 → 1961 → 1965 → 1977 的拆除时差——8 年拆除时差 + 51 年建拆跨度，证明治理网络一旦建立就会比单点控股更稳，留下"治理入口的真正可怕不在建立，而在被看见之前就已经稳态化"的可迁移判断。所有保留洞察共同回答"为什么杜邦要救通用汽车？"——答案不是"慈善"也不是"控股"，而是"治理网络前置完成后的显影 + 改写 + 穿透 + 拆除时差"四段机制；产业在让出危机处置入口的同时，也把日常决策入口一并交了出去。

### 6.1 方向判断

当前文章主要服务 A / B / C / D 四类目标客户，E 类作为辅助匹配。**A 类（成熟历史读者）**是问句式"为什么"的最大潜在点击群，T01 显影差异化角度比"救援 / 控股"标题腔更吸引人；**B 类（治理与控制权职业读者）**对"治理入口"有现成认知，T01 + CJ2 + CJ3 三段机制链给出可迁移框架；**C 类（财经 / 政策读者）**关心"产业资本输给金融资本"，T01 显影是"治理网络显影 = 金融化先行案例"的位置感对应；**D 类（反垄断 / 法律读者）**由 CJ3-1 双口径 + CJ3-2 拆除时差共同满足；**E 类（制造 / 化工 / 汽车从业者）**作为辅助匹配——"Fabrikoid / 油漆与清漆业务"是化工产业熟悉的语汇，"上下游持股"是制造业读者熟悉的公共经验，O2 报告原文是天然入口。
