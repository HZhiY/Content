## 三、发布检查边界摘要

### 3.1 标题可以承诺

1. "为什么杜邦要救通用汽车？"——问"为什么"而非"如何救"；不预判答案，留出显影差异化空间
2. 1920 年 11 月作为时间锚——NYT 1920-12-01 头版 + Cornell LII 双源可证
3. 杜邦+摩根两个接盘主体——F04/E10 可证
4. 从"一次接盘"放大到"治理网络显影"机制——F01–F04 + F19 主钉全链路可证
5. "治理通道早已搭好"的反常识角度——1914–1917 三条通道前置完成的事实链可证
6. "8 年拆除时差"——1957→1961→约1965→1977 时间链可证

### 3.2 标题不能承诺

1. "杜邦控股 GM"——K01 三口径未合并；1954 地区法院认定非控股
2. "杜邦垄断了 GM 供应链"——1957 用"合理可能性"，非"必然"
3. "1957 杜邦立即被强制退出"——B13；8 年拆除时差是文章核心证据
4. "反垄断第一案 / 沉睡巨人"——T05 噱头；与 T01 显影主承诺错位
5. "斯隆打败资本方 / 斯隆模式"——W04 饱和
6. "RFC 救 GM"——B01；K05 否定
7. "杜邦把 GM 变成子公司"——B06；GM 始终为独立上市公司
8. "Reford 失败"——G01 无一手来源

### 3.3 标题禁用或慎用表达

| 表达 | 禁用/慎用 | 原因 | 替代方向 |
|---|---|---|---|
| 拯救 / 救援 | 禁用 | W01 商业传奇饱和区；与 T01 显影主承诺错位 | 用"接盘""介入""显影"方向 |
| 控股 / 控制 | 禁用 | K01 三口径未合并 | 用"治理通道""治理入口"方向 |
| 垄断 | 禁用 | 1957 用"合理可能性" | 用"治理位置"方向 |
| 反垄断第一案 | 禁用 | T05 噱头；承诺漂移 | 用"两份判决说两套话"方向 |
| 管理天才 / 斯隆模式 | 禁用 | W04 饱和 | 用"钱开始决定事情"方向 |
| 真正原因不是……而是…… | 禁用 | 爆款腔 | 用问句式或机制判断句 |
| 震惊 / 炸裂 / 颠覆 | 禁用 | 标题党 | 用事实推进代替情绪推进 |

### 3.4 必须保留的事实限定口径

| 口径 | 标题中如何保留 | 来源 |
|---|---|---|
| K01 持股三口径 | 不合并为单一"控股"表述；如标题涉及持股，必须暗示"不是简单控股" | 事实核查清单 K01 |
| K04 双口径 | 不只引 1957 不引 1954；标题不预判"垄断"结论 | 事实核查清单 K04 |

## 四、标题策略方向

### 4.1 推荐主策略

```text
本文标题应从"反常识问题入口"进入：读者通常认为1920年杜邦接盘通用汽车是一次"救援"，但正文证明这是1914-1917年治理通道前置完成后的"显影"。标题应保留"为什么杜邦要救通用汽车"的问句框架，因为它自带反常识感——读者会想"化工公司为什么要救汽车公司"，而正文给出的答案不是"慈善"也不是"控股"，而是"治理网络早已搭好"。标题应避免承诺"控股""垄断""拯救"等已被正文否定或限定的表达，应聚焦于"为什么介入""治理入口""钱开始决定事情"等机制入口。
```

### 4.2 读者入口设计

| 入口 | 是否采用 | 理由 | 标题表达方向 |
|---|---|---|---|
| 问题入口 | 是 | "为什么杜邦要救通用汽车"问句自带问题感；适合40+头条读者 | "为什么一家化工资本要介入一家汽车公司" |
| 人物入口 | 部分 | 1920年时间节点可作副标题锚点，但不作主标题主入口 | "1920年，杜邦做了一个决定"方向 |
| 反差入口 | 是 | "不是救援而是显影"是核心反差；"建公司的人输给管钱的人"也是反差 | "看起来是救援，其实是显影"方向 |
| 机制入口 | 是 | 本文卖点是"治理网络显影"机制 | "治理通道早已搭好"方向 |
| 后果入口 | 部分 | "8年拆除时差"可作信息流标题的钩子 | "确认违法后，为什么还要8年才能拆"方向 |
| 误解纠偏入口 | 是 | "1920年不是救援"是纠偏 | "不是为了救，而是为了别的"方向 |

```text
为什么杜邦要介入通用汽车：1920年不是救援，是治理通道的显影
```

### 7.2 可选副标题

```text
不建议使用副标题。主标题已包含问句+解释承诺双段式结构，信息密度足够；加副标题会使标题过长（超过32字），影响手机端识别。
```

### 7.3 不建议采用的标题方向

1. "杜邦控股/控制通用汽车"——K01三口径未合并；1954年地区法院认定非控股
2. "杜邦垄断通用汽车供应链"——1957年用"reasonable probability"，非"必然"
3. "反垄断第一案/沉睡巨人"——T05噱头；与T01显影主承诺错位
4. "斯隆模式/管理天才"——W04饱和区
5. "RFC救通用汽车"——K05否定
6. "震惊/炸裂/颠覆"等爆款腔——文风禁用清单
7. "真正原因不是……而是……"——爆款腔；文风禁用清单
