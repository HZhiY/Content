## 一、整体阅读感受

> 这一节先写整体体感，再进入分项评分。不要只罗列问题，要模拟目标读者读完后的真实第一反应。

### 1.1 一句话体感

```text
像在读一份把"救援故事"拆成"治理通道显影"的机制稿——骨架清楚、材料硬，但中间几处编辑痕迹和英文块会让手机读者顿一下。
```

### 1.2 整体判断

| 项目 | 判断 | 说明 |
|---|---|---|
| 第一反应 | 想继续读 | 标题问句 + 引言双钉（1920 头版 / 1917 报告）有反差，愿意往下翻 |
| 最大优点 | 1917 年 Raskob 报告动机 + "1920 不是临时起意而是显影" | 把"为什么救"从慈善传说拉回股权与订单绑定，和读者审稿卡的主承诺一致 |
| 最大阻碍 | 正文里冒出的 K01/K03/F02/F10 等内部编号 + 结尾"真正可怕的是" | 前者像审稿备注闯进正文，后者触发读者审稿卡爆款腔警戒 |
| 最容易掉线的位置 | 第一节末三口径持股段 + 第三节法律双口径段 | 数字、来源、英文原句叠在一起，竖屏阅读负担陡增 |
| 最有获得感的位置 | 第二节"换的不是 CEO，是公司按什么目标运行" + 第四节 8 年拆除时差 | 机制句可带走，且能联想到今天的股权/董事会场景 |
| 读完后的残留印象 | 清楚 | 记得"建立慢、拆更慢"和"治理通道前置完成"，暗线"资本逻辑改写目标函数"在第二节有落地 |

### 1.3 读者复述测试

读完后，目标读者能否用一句话复述这篇文章？

```text
能。示例："杜邦 1917 年就写明持股是为了拿通用汽车的化工订单，1920 年接盘只是早就搭好的股权/董事会/财务委员会显形；后来法院 1957 年才穿透这套网络，真正拆完还要再等 8 年——治理权一旦嵌进去，比单点控股还难拆。"
```

### 1.4 整体建议

```text
这篇草稿的方向主承诺兑现度高：没有漂成"杜邦慈善救命"或"斯隆管理神话"，K01 三口径、K04 双口径、B13 八年拆除时差都在正文里找得到。修订时优先做两件事：一是把正文里的 K/F 编号和"事实红线"式编辑语句全部改写成读者能读的自然句；二是删掉或改写结尾"真正可怕的是"，换成机制判断口吻。保留引言双钉、第二节目标函数改写、第四节时间链和结尾"产业让出危机入口同时让出日常决策入口"——这些是读者最愿意转述的部分。英文原句可保留但宜压缩，首次出现的人名（Durant、Raskob）建议在引言各补半句身份。
```

## 四、读者侧必改项

> 必改项是：不改会导致目标读者读不下去、看不懂、不信、误解或无收获的问题。

| 编号 | 位置 | 问题 | 为什么影响读者 | 修改方向 | 是否需主编判断 |
|---|---|---|---|---|---|
| R1 | 结尾段（"治理入口的真正可怕不在建立……真正可怕的是治理网络……"） | 使用读者审稿卡与文风卡黑名单表达"真正可怕的是" | 成熟读者对头条深度文中的爆款腔敏感，会瞬间把机制文读成惊悚标题党，损害系列"稳、克制"预期 | 改为机制判断句，如"难点不在建立而在拆除""拆除成本体现在 8 年时差"等事实后置表述，不用"真正可怕"结构 | 否 |
| R2 | 第一节末持股三口径段末句（"K01 三口径分写是事实红线"） | 内部核查编号闯入正文 | 读者不知道 K01 是什么，会误以为文章未完成或误读为学术论文脚注，直接出戏 | 删编号，用自然语言交代"三口径并存的原因"（如地区法院曾据此认定非控股），保留数字与来源即可 | 否 |
| R3 | 第二节 Pierre 三时点段（"K03 三时点必须分写"） | 同上，编辑指令式语句 | 打断"1923 分工"叙事，读者刚理解 Sloan 接任，突然被拉回审稿模式 | 删"K03 必须分写"，保留三时点事实本身；必要时用一句"三个职务节点不能混为一谈"作读者向过渡 | 否 |
| R4 | 第三节 F02/F10 对照段（"F02 1917 年……F10 1957 年……不可混用"） | 事实编号 + 重复已在前文出现过的对照 | 法律读者或许能忍，A/B 类读者会觉得同一段信息说了两遍且带编辑标签 | 合并为一句读者向对照："1917 年杜邦自写'无疑将确保'，1957 年法院只写到'合理可能性'——强度不同，不能互替" | 否 |
| R5 | 引言第 1 段 / 第 2 段 | Durant、Raskob 首次出现无身份 | 读者画像要求首次出现的人要一句话说明是谁；否则第一屏只剩日期和人名，和"堆人名"不合格信号擦边 | 各补半句：如"创始人 Durant""杜邦财务委员会主席 Raskob"，不展开传记 | 否 |

## 八、给修订阶段的读者侧提醒

1. 修订时先全局搜索正文中的 K/F/E 编号和"事实红线""必须分写"等编辑语——读者不应看见任何审稿内部标签。
2. 暗线"产业资本如何被资本逻辑改写"已在第二节落地，修订勿为删编号而削弱"目标函数""资本配置写在生产管理之前"等白话机制句。
3. 持股三口径、1954/1957 双口径、8 年拆除时差是读者愿意转述的硬货，压缩篇幅时优先删英文重复和选举细节，不删这三块核心信息。
