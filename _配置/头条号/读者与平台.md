## 为什么是账号级的

**一个账号只有一批读者。** 平台推给你的人，是被你已发内容训练出来的，不会因为这一篇换了题材就换一批人。

旧配置里，中国历代政治得失写的读者是"四十岁以上、中高收入、对社会运行有天然兴趣的成熟男性"，巴基斯坦系列写的是"泛国际时政读者、对一带一路感兴趣的商业读者"——但它们发在同一个号上。四份读者画像各自漂移，等于四个系列在对四个想象中的人写作，而真实读者只有一批。

题材可以换，读者不换。所以这份文件只有一份。

## 一、核心读者

```text
四十岁以上、受过较完整教育、有稳定职业与中高收入、
对社会运行和制度问题有天然兴趣的成熟男性读者。
```

他们不是为了考试读历史，也不是为了听八卦，而是在工作和生活之外寻找一种有质量的精神放松。

愿意读严肃内容，但不愿意读教材、论文、讲义和原著摘录。

### 1.1 读者要的不是知识点

| 他不想看 | 他想看 |
|---|---|
| 某朝某代发生了什么 | 这种结构为什么会这样运行 |
| 谁英明谁昏庸 | 一个好设计为什么在执行中变形 |
| 原书哪一章讲了什么 | 一个位置为什么会逼出某种行为 |
| 有什么知识点 | 这个问题为什么今天仍然让人熟悉 |

读完能带走的应该是**一种更稳的现实判断力**，不是几个史实。

### 1.2 阅读动机

| 动机 | 内容如何回应 |
|---|---|
| 想获得高质量放松 | 文字要轻，判断要重，不写成课堂讲义 |
| 想看懂复杂现实 | 用具体案例解释权责、信息、考核、资源如何运转 |
| 想获得可信解释 | 不煽动、不影射，用材料和机制支撑判断 |
| 想读有判断的文章 | 前三段内亮出问题和核心判断 |
| 不想读通史 | 每篇只讲一个具体问题 |

## 二、读者最有效的入口

| 入口 | 适用场景 | 示例 |
|---|---|---|
| 制度悖论 | 改革、考核、监察、选拔 | 越认真的改革，最后越容易变形 |
| 现实切片 | 组织层级、考核、流程、责任错位 | 上级要结果，基层掌握真实信息 |
| 反差 | 初衷与运行结果相反 | 科举扩大公平，却制造趋同 |
| 常识纠偏 | 纠正"都是人坏了"式解释 | 不是执行者坏了，是位置逼他这样做 |
| 机制问题 | 权力、财政、信息、监督 | 谁有权，谁负责，谁承担成本 |

## 三、读者在哪掉线

1. 开头太像课堂；
2. 背景铺太久；
3. 人物太多，问题反而不清；
4. 引文太密；
5. 概念连续出现但没有翻译；
6. 现实暗示太重；
7. 全文没有一句能被带走的判断；
8. 标题提出问题，正文却变成经过叙述。

对应处理：

- 开头三段内进入问题；
- 每篇只解释一个机制；
- 复杂概念第一次出现时用短句解释；
- 每节结尾用一句判断拉回主线；
- 现实感只做入口或余味，不做正文主轴。

### 3.1 降低门槛的标准动作

专业概念第一次出现时，优先用这套话翻译：

```text
谁发命令。
谁执行。
谁掌握真实信息。
谁承担风险。
谁被考核。
谁有动力改变制度目标。
```

## 四、平台阅读路径

发布环境是今日头条。读者路径：

```text
随机刷到标题
↓ 看标题判断值不值得点开
↓ 前三段判断作者有没有观点
↓ 小标题判断文章清不清楚
↓ 结尾判断值不值得收藏或转发
```

**每篇必须独立成立。** 禁止依赖"前文已经讲过""下一篇再展开""本系列前几篇的概念""读者已经读过原书"。

### 4.1 各环节的硬要求

| 环节 | 要求 |
|---|---|
| 标题 | 问题清楚、对象具体、判断有限、无震惊体、与正文承诺一致 |
| 开头 | 150 字内出现反差，300 字内出现核心判断 |
| 小标题 | 像路标，不像目录标签 |
| 结尾 | 留下一句可转述判断 |

### 4.2 实测数据（截至 2026-08，n=30）

点击率是平台分发的总阀门：点击率 ≥10% 的篇目展现量中位 11.6 万，<2% 的 3,594，相差 32 倍。

同时——发文密度对展现量的影响量级超过任何文本因素。同一篇文章隔月重发，密度从 3.3 天/篇变成 1.9 天/篇后，展现量差 14 倍。**发文维持 3-7 天/篇，不连日双发。**

详见 `_工作流/_反馈/已验证规律.md`。

## 五、传播资产

每篇尽量形成四个：

| 资产 | 要求 |
|---|---|
| 清楚问题 | 读者一眼知道文章解释什么 |
| 悖论/反差 | 表面目标与运行结果之间有张力 |
| 可转述判断 | 读者能复述一句核心判断 |
| 现实余味 | 不影射，但让读者自然联想到组织和社会运行 |

### 5.1 可转述判断的标准

不超过 40 字；有反差或机制；不是空泛金句；能独立成立；和正文论证一致。

样例：

```text
好制度最大的敌人，不是坏执行，而是执行者所处的结构位置。
中央越想看见基层，基层越会学会制造上级想看的数字。
一个制度的成功，常常也是它未来问题的起点。
```

### 5.2 现实余味 vs 现实影射

合格：

```text
大组织里，只要考核只能看指标，指标就可能替代目标。
```

不合格：

```text
这放到今天也一样，懂的人都懂。
```

判断方法：**删掉现实联想，文章是否仍然成立？** 不成立就说明过度依赖现实暗示。

## 六、基调红线

**这一节高于数据。** 任何来自表现反馈的优化都不得放宽以下红线——打开率永远可以靠震惊体提升，不设红线，反馈闭环会稳定地把内容推向标题党。

1. **不写"谁好谁坏"，写"什么结构让事情一步步变成这样"。**
2. 有判断，但不表演；有现实感，但不影射。
3. 人物只能作为入口，落点必须在机制。
4. 不把一个案例泛化为"从古至今""所有人"。
5. 不用今天的标准简单审判过去。
6. 不把复杂变化归因于某个坏人。

### 6.1 禁止的整体走向

历史课 / 原著摘抄 / 帝王故事会 / 权谋厚黑 / 借古讽今 / 现实影射 / 历史鸡汤 / 论文式制度史 / 短视频式揭秘。

### 6.2 特别禁止的句子

```text
这不就是今天的某某吗？
古代如此，现在也是如此。
看懂这个，就看懂了今天的一切。
老祖宗早就看透了。
中国人从古至今都是这样。
懂的人自然懂。
不能说得太明白。
```

## 七、读者收获标准

读完后目标读者至少应该能复述：

```text
这篇讲的是哪个问题。
它原本想解决什么。
它在运行中为什么变形。
谁获得权力，谁承担成本。
这件事为什么今天仍然让人熟悉。
```

**只能记住故事、不能复述机制，文章未达标。**

这一条也是发布后复盘的判据：`retro-analyze` 会把评论区里读者的复述和这个标准对照。
