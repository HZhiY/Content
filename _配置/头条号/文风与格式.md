## 二、文章结构

```text
标题
引言：快速抛出悖论
正文 4-6 节
结尾：收束成一句稳判断
```

推进结构：

```text
悖论开头 → 历史切片 → 机制拆解 → 制度代价 → 现实余味 → 稳判断结尾
```

### 2.1 引言

任务是把读者迅速带进问题。**不先讲背景，不先讲原书，不先讲朝代。**

推荐公式：

```text
反常识判断 → 1-2 个案例或现实切片 → 否定简单归因 → 提出真正机制 → 进入正文
```

样例：

```text
历史上最讽刺的一件事是：

越是认真的改革，最后越容易变形。

王安石想帮农民，结果变成强制放贷。
张居正想让官员干活，结果变成数字游戏。

两个人都没做错。
制度也没错。

但结果，一模一样。
```

前 300 字内必须让读者知道：本文解释什么问题、为什么这不是普通故事、准备给出什么判断。

禁止的开头：

```text
钱穆先生在《中国历代政治得失》中说……
在中国古代政治制度中……
自古以来……
某朝某代是中国历史上的重要时期……
本文将从三个方面分析……
```

铺垫超过 500 字还没进入主问题 = 不合格。

### 2.2 正文

默认 4-6 节。少于 4 节容易论证不足，多于 6 节容易散。

每节必须承担一个明确功能：纠正常见理解 / 补足最小背景 / 展开切片 / 拆解机制 / 说明收益与代价 / 抽象成结构判断 / 回收现实余味。

**不允许出现只负责堆材料的小节。**

承诺链：

```text
标题承诺 → 引言问题 → 小节推进 → 结尾回收
```

每节都要能回答：这一节如何帮助证明本文主判断？

### 2.3 小标题

像路标，不像目录标签。用二级标题，一般不用三级。

推荐：

```text
一、好制度最大的敌人不是坏执行
二、这条裂缝是中国皇权的结构问题
三、王安石：目标被 KPI 替换了
```

不推荐：

```text
一、历史背景
二、制度介绍
三、原因分析
四、现实启示
```

### 2.4 结尾

回收本文，不写成系列总论。完成三件事：回收本篇机制、说明收益与代价、给一句可带走的判断。

结尾不应：突然升到文明兴衰 / 写"历史启示"四个字 / 强行映射现实 / 情绪控诉 / 复述全文摘要 / 用"综上所述"开头。

## 三、字数与节奏

| 项目 | 标准 |
|---|---|
| 正文字数 | 2500-4500 字 |
| 小节数量 | 4-6 节 |
| 引言长度 | 150-350 字 |
| 单段长度 | 1-3 行为主 |
| 长段限制 | 不超过 6 行 |
| 现实切片 | 全文不超过 2 处 |
| 历史材料 | 1-3 组，必须服务主机制 |

允许单句成段，尤其是判断句、转折句、概念定义句。关键判断应单独成段。

一条句子只推进一个判断。禁止连续多重从句和论文式长定语。

推荐节奏：

```text
两个人都没做错。
制度也没错。
但结果，一模一样。
```

## 四、禁用表达

### 4.1 标题党与短视频腔

禁用词：

```text
震惊  炸裂  终于  刚刚  重磅  惊人  内幕  真相  真相大白
看完沉默  不看后悔  所有人都错了  一文读懂  十分钟看懂
老祖宗早就看透  千古谜团  历史证明了一切
```

禁用句式："你绝对想不到……""背后真相令人……""看懂这个，你就看懂了今天……""中国人从古至今……""终于明白为什么……""历史早就给出答案"。

替代：

| 不推荐 | 推荐 |
|---|---|
| 千古真相 | 一个长期存在的问题 |
| 终于看懂 | 重新理解 |
| 历史证明 | 从这个案例可以看到 |
| 所有人都错了 | 常见解释漏掉了一层机制 |
| 老祖宗早就看透 | 这个问题在历史中反复出现 |

### 4.2 权谋厚黑腔

禁止把制度问题写成心术和人性黑暗：

```text
皇帝都在算计。
宰相不过是权力斗争牺牲品。
真正高手都懂得制衡。
权力场没有好人。
```

改为：

```text
皇权需要集中决策，但行政系统又需要有人承担责任。
相权被压缩后，事务不会消失，只会换一种形式回到系统里。
制度不是取消矛盾，而是重新分配矛盾。
```

### 4.3 论文腔与教材腔

禁止连续堆叠抽象概念。禁止用学术词替代解释：主体性、现代性、结构性张力、制度性安排、历史必然性、治理范式、政治生态、底层逻辑。

不是完全不能用，是**不能不解释就用**。

改为：

```text
中央想管得更细，就必须让更多层级参与执行。
层级一多，信息就会变形。
上面看到的是数字，下面面对的是具体的人和事。
```

### 4.4 AI 腔

禁止：「本文将从三个维度展开分析」「综上所述」「值得注意的是」「不可否认的是」「从某种意义上说」「这不仅是……更是……」连续套用、「深刻揭示了」「具有重要启示意义」「通过以上分析我们可以发现」。

### 4.5 历史鸡汤腔

禁止把分析写成励志或人生感悟：

```text
历史告诉我们，做人要懂得……
成败得失，最终还是人心。
真正聪明的人，都懂得顺势而为。
```

改为：

```text
这不是个人修养问题，而是组织位置问题。
当考核指标替代制度目标，认真执行也可能制造变形。
```

### 4.6 过度绝对化

慎用：所有、必然、唯一、彻底、从来、永远、完全、本质上就是、归根到底只有。

优先降级为：往往、常常、在很多情况下、更容易、更接近于、可以理解为。

## 五、推荐文风

优先使用：短句、短段、判断先行、问题先行、案例服务机制、概念出现后立刻翻译。

推荐句式：

```text
不是 A，而是 B
表面看是 A，实际是 B
问题不在于 A，而在于 B
历史上最讽刺的一件事是：
问题不在这里。
真正难的是另一件事。
关键词不是"私心"，而是——替换。
不是人坏了，是位置在逼他这样做。
```

推荐词库：

```text
制度运行  结构位置  权力分工  责任链条  信息上行  信息失真
考核替代目标  数字替代真实  执行层自保  治理成本  制度成本
治理半径  制度变形  运行逻辑  现实余味
```

### 5.1 修订时优先删除

1. 不能推进主机制的背景；
2. 不能证明判断的人物细节；
3. 空泛的现实感慨；
4. 学术化定义；
5. 过度拔高的结尾；
6. 重复解释同一概念的段落；
7. 看似漂亮但不承担论证功能的金句。

## 六、标题方法

### 6.1 总原则

标题的任务不是制造震惊，而是让读者感觉：

```text
这篇文章会帮我看懂一个我也熟悉的运行问题。
```

同时满足：问题清楚、对象具体、判断有限、有悖论、不标题党、不影射、与正文承诺一致。

### 6.2 五条硬约束

来自两处证据：自有 30 篇（`_工作流/_反馈/表现台账.md`）和对标账号的**账号内部**落差（`_看板/对标研究/数据/`）。

对标数据只用同一账号内部的高低对照——同账号即同读者同分发，落差只能来自标题本身。跨账号比较一律不作数（`_看板/对标研究/标题起法方法论 v1-v3` 犯的就是这个错，那三份已降级为参考资料）。

**T1｜主语必须是读者认得的角色，不能是需要背景知识的专名。**

用皇帝、宰相、县官、朝廷、国家、地方；不用张居正、考成法、开中法、杜邦、摩根。

> 自有数据：「——杜邦与通用汽车」0.4%，「摩根图书馆」0.3%。
> 对标（文化纵横内部）：泛称主语「美智库」18 万、「波兰媒体」17 万、「美《外交事务》」16 万；具名主语「皮凯蒂」1,840、「米尔斯海默」1,585、「克里·布朗」180、「施密特」95。
> 例外：专名作为**被评判的对象**而非借来的权威时可用（「亨廷顿的预言对了，但理论错了」3.7 万）。

**T2｜主体要做一个具体动作，不能只描述状态或关系。**

> 自有数据：「国家终于**看见了**地方，地方却只**看见了**上级」11.4%、「美国是如何**杀死**州立银行的」12.7%、「当王朝开始**用监察替代治理**」14.2%；对照「宰相，这个岗位为何永远'废'不掉？」4.3%、「为什么集权的皇帝，永远**需要**一个'影子宰相'」4.3%。
> 对标（思想史万有引力内部）：无人称知识陈述全部垫底——「中世纪并非黄金时代」423、「美国的两院是如何制衡的」658、「什么样的自由不应被保护？」628。

**T3｜「不是 A，而是 B」的 B 位放具体机制，不放抽象名词。**

结构本身不产生效果，B 位的具体度才产生效果。

> 对标（文化纵横内部，同一骨架）：B = 「我们中国人也没看清」21 万、「盲目复制'美式大农场'」12 万、「两会要打破的经济恶性循环」8.9 万；B = 「一场蔓延全球的'粮食博弈'」520、「一种认知错觉」92、「'空心美国'」19。
> 自有数据同向：「巴基斯坦外交，不是谁拍板：军方管红线……」0.5%——B 位是三个并列的抽象职能。

**T4｜标题必须给出一句判断，不能只抛一个题目。**

> 对标（思想史万有引力内部）：「亨廷顿的预言对了，但理论错了」3.7 万、「雷蒙阿隆：法国知识分子其实有病」2.2 万；对照「霍布斯与极权主义的关系」821、「西方对权力的驯化史」2,917。
> 自有数据：「巴基斯坦为什么永远先安全、后发展？」0.7%、「为什么美联储像是从摩根图书馆里长出来的？」0.3%，都是抛题目。

**T5｜标题里不出现任何连载暗示：编号、「上/下篇」、「续」、「系列之N」。**

> 对标（思想史万有引力内部）：「人文主义的诞生」（一）1128 →（二）443 →（三）425 →（四）415；「最重要的论战」（一）3182 →（二）1014 →（三）665；「中世纪最重要的一场思想革命」（一）2093 →（二）1254。每加一个编号腰斩一次，无例外。

### 6.2.1 这五条的证据等级

T1、T5 有两处独立数据同向，可当规律用。T2、T3、T4 目前主要靠对标账号的内部落差，自有数据样本还不够——**每篇发布前按 `_工作流/_反馈/标题预测.md` 登记预测，靠对账来验证或推翻**。

### 6.3 五种标题类型

| 类型 | 公式 | 示例 |
|---|---|---|
| 制度悖论型 | 为什么越想 A，越容易 B | 为什么越想管住地方，地方越容易失真 |
| 真问题型 | X 真正的问题，不是 A，而是 B | 御史真正的作用，不是纠错 |
| 反直觉型 | 常见判断 A，其实关键是 B | 好制度最大的敌人，不是坏执行 |
| 重新理解型 | 重新看 X：它解决的是 A，不是 B | 重新看郡县制：它解决的是控制问题，不是治理问题 |
| 结构位置型 | X 为什么会变成 Y，关键在它的位置 | 为什么县官最难做：他站在中央命令和基层现实中间 |

八个候选必须覆盖至少 4 种类型。

### 6.4 标题评分

| 维度 | 满分 | 标准 |
|---|---:|---|
| 问题清楚 | 20 | 一眼知道文章讨论什么 |
| 机制感 | 20 | 落在运行机制，不是人物八卦 |
| 反差感 | 20 | 有"表面 A / 实际 B"的张力 |
| 克制程度 | 15 | 没有夸张、猎奇、影射 |
| 点击理由 | 15 | 成熟读者是否愿意点开 |
| 正文一致 | 10 | 不超出正文承诺 |

低于 80 分不作为主推。

### 6.5 标题禁区

绝对禁用词：震惊、炸裂、内幕、真相、千古谜团、终于明白、一文读懂、看完沉默、所有人都错了、老祖宗早就看透、从古至今、彻底、唯一答案。

禁止方向：帝王秘史、权谋真相、历史阴谋、现实影射、民族性格判断、人性鸡汤、以名人名气替代问题、以朝代总论替代具体问题。

**禁止先写一个漂亮标题再反向硬凑正文。**

## 七、事实与引用

正文不用学术脚注体。

1. 年份、制度名称、人物职务必须准确；
2. 不在正文堆来源；
3. 不用长引文替代解释；
4. 有争议时降低口径。

推荐表达：「更准确地说……」「在这个意义上……」「可以理解为……」「它更接近于……」

禁止：把一个朝代的情况泛化成整个中国古代；把后世结果倒推为设计初衷；把某位学者的判断直接当唯一事实；为显得专业堆砌原文史料。
