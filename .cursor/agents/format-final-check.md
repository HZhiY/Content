## 检查项（仅格式与卫生）

| 编号 | 检查项 | 标准 |
|---|---|---|
| F1 | 编辑标记 | 正文无 `【…】`、`> 【刺点】` 等施工块；无 K/F/E 内部编号 |
| F2 | 编辑指令入正文 | 无「事实红线」「必须分写」「不可混用」等 |
| F3 | 执行说明污染 | `修订稿 vN.md` 正文区**不含**「写作执行说明」「修订执行说明」或任何审稿处理表；流程记录须在独立文件 `修订执行说明 vN.md` 中（**若修订稿末尾仍残留执行说明段，须先退回 draft-revise 拆分**） |
| F4 | 施工术语 | 正文无「刺点」「膝盖句」等审稿术语 |
| F5 | 元数据污染 | 正文无「本标题非最终标题」等工作注释（标题方案已定后应已清除，或仅允许 html-build 层处理） |
| F6 | 三红线 | 正文无英文字符；无同系列跨篇勾稽 |
| F7 | 字数 | 含标点总字数在系列/文风目标区间内 |
| F8 | 加粗 | 无整段滥用；关键机制句加粗合理（对照密度/主编建议，如有） |
| F9 | HTML 就绪 | 标题方案已定；插图路径与方案一致；修订稿为 html-build 唯一正文源 |

## 结论类型

只能从以下选择：

```text
通过，可进 html-build
退回修订（格式/卫生）
```

- **退回修订**：仅因 F1–F9 格式/卫生问题；不涉及退回方向或事实上游
- **通过**：允许 `09-html-build`
