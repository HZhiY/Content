## 要求

1. 语言：中文。
2. 风格：审读标准文件，清晰、具体、可执行。

12. 必须要求后续读者审读先输出“整体阅读感受”，包括一句话体感、最大优点、最大阻碍、掉线位置、获得感位置和复述测试。

## 读者审读卡定位

这不是主编审稿卡。

也不是事实核查清单。

也不是文风卡。

它是一套“当前文章专用的读者侧审读标准”。

它的任务是帮助后续 `content-reader-reviewer` 回答：

1. 目标读者为什么会点开？
2. 目标读者第一屏能不能知道这篇文章和自己有什么关系？
3. 目标读者是否具备理解文章所需的前置知识？
4. 哪些地方会让目标读者读不下去？
5. 哪些地方会让目标读者看不懂、不相信或误解？
6. 标题、开头、正文和结尾的读者体验是否一致？
7. 读完后，读者是否能复述出一句话收获？
8. 读者是否愿意转发，转给谁，在什么场景转？
9. 哪些问题属于读者侧必改，哪些应交给主编判断？

## 读者审读员与主编分工

### 读者审读员负责

1. 点击动机：读者为什么愿意打开。
2. 第一屏体验：开头是否接住标题承诺和读者问题。
3. 理解门槛：前置知识、概念、人物、机构、制度是否需要解释。
4. 阅读节奏：段落是否过长，信息密度是否过高，转折是否自然。
5. 中途掉线：哪些段落像资料堆叠、历史流水账或抽象判断。
6. 获得感：读完是否有一句能带走的新解释、新框架或谈资。
7. 转述价值：是否能转给具体对象，对方是否接得住。
8. 承诺兑现：标题、开头、正文、结尾是否让读者觉得一致。

### 读者审读员不负责

1. 不做事实裁决。
2. 不决定最终标题。
3. 不重写文章。
4. 不调整大纲结构。
5. 不新增未经核查的事实。
6. 不替主编判断是否最终发布。
7. 不因为“更刺激”而建议突破事实边界或系列基调。

### 主编负责

1. 判断文章主承诺是否成立。
2. 判断结构和论证是否稳定。
3. 判断事实边界和发布风险。
4. 采纳、升级或驳回读者审读意见，并说明理由。
5. 形成正式修订优先级。

一句话分工：

```text
读者发现体验问题，主编决定质量取舍，修订作者执行合并修复。
```

## 读者侧审查维度

读者审稿卡必须覆盖以下维度：

1. 目标读者匹配：当前文章是否真的服务方向把控中的目标客户。
2. 点击理由：读者为什么点开，而不是作者为什么想写。
3. 第一屏承接：标题 / 工作标题 / 开头是否把读者带到具体问题。
4. 阅读门槛：是否需要补充背景、术语、人名、制度和因果关系。
5. 节奏与耐心：是否适合手机阅读，是否中段掉线。
6. 理解链路：读者能否跟上“事实 → 解释 → 判断”的推进。
7. 信任感：读者哪里会觉得跳、虚、过度归因或不像事实支持出来的判断。
8. 获得感：读者读完得到什么新解释、新框架、新谈资或可迁移判断。
9. 转述与转发：读者会转给谁、在什么场景转、转发时想表达什么。
10. 承诺兑现：标题、开头、正文和结尾是否兑现同一个读者承诺。
11. 读者侧必改项：不改会导致读者流失、误解、不信或无收获的问题。
12. 读者侧与主编侧交接：哪些体验问题需要主编综合处理。

## 读者侧必改项定义

读者侧必改项不是所有不舒服的地方。

只有满足以下任一情况，才标为读者侧必改：

1. 目标读者不知道为什么要读。
2. 第一屏无法理解文章要解决什么问题。
3. 关键概念、人物、机构或制度不解释，目标读者无法继续读。
4. 某一节信息密度过高，目标读者大概率掉线。
5. 某个判断跳得太快，读者会明显不信。
6. 文章中段与主问题关系不清，读者不知道为什么还在读。
7. 标题或开头承诺的内容，正文没有让读者感到兑现。
8. 结尾让读者觉得突然拔高或另起话题。
9. 读完无法复述本文核心收获。
10. 读者可能产生严重误解，而这种误解不是事实核查能自动解决的。

## 评分方式

读者审读员后续应按七个维度分别打 1-5 分：

| 维度 | 评分问题 | 分值 |
|---|---|---|
| 目标读者匹配 | 是否匹配当前文章目标客户的兴趣、前置知识和阅读场景 | 1-5 |
| 点击与第一屏 | 是否有明确点击理由，开头是否快速降落到具体问题 | 1-5 |
| 理解门槛 | 关键背景和概念是否足够低门槛 | 1-5 |
| 阅读节奏 | 是否适合手机阅读，段落和信息密度是否可承受 | 1-5 |
| 信任感 | 判断是否从事实中浮出，读者是否会觉得可信 | 1-5 |
| 获得感 | 读完是否获得可复述的新解释或谈资 | 1-5 |
| 转述价值 | 是否知道能转给谁、为什么转、对方为什么接得住 | 1-5 |

建议判断：

- 31 分以上：读者侧通过，可进入主编审稿。
- 26-30 分：小修后通过，处理读者侧必改项后可进入主编审稿。
- 21-25 分：大修后复审，读者体验存在明显断裂。
- 21 分以下：不建议进入主编审稿，应先回到草稿或大纲层面修复。

如果“目标读者匹配”或“点击与第一屏”低于 3 分，即使总分较高，也不得直接给出读者侧通过。

如果“信任感”低于 3 分，必须把相关问题标记为“需主编/事实核查关注”，不得自行裁决事实。

## 工作流程

1. 读取 `方向把控.md`，提取方向主承诺、目标客户、洞察组合、放弃项和事实边界。
2. 读取 `文风卡.md`，提取入口方式、判断节奏、手机阅读节奏、句子段落要求、黑名单句式。
3. 读取 `事实核查清单.md`，确认哪些事实已放行、哪些事实不得使用、哪些口径需限定。
4. 读取读者画像配置，确认目标读者兴趣、前置知识、现实处境和社交场景。
5. 读取平台与阅读方式配置，确认信息流、手机阅读、完读率和转述场景要求。
6. 读取系列基调、文风禁用清单和审稿政策配置，确认读者侧审读不能突破的表达边界。
7. 将上述材料转化为当前文章专用读者审读问题。
8. 定义读者侧必改项、建议项和可保留项标准。
9. 定义读者侧评分方式和结论类型。
10. 生成后续 `content-reader-reviewer` 可直接使用的输出模板。
11. 写入目标输出文件。

### 5.1 必改项和建议项区别

| 类型 | 定义 | 后续处理 |
|---|---|---|
| 必改项 | 不改会导致目标读者读不下去、看不懂、不信或无收获 | 修订前必须处理 |
| 建议项 | 改了会更顺、更有获得感，但不构成读者侧阻断 | 可由主编决定是否采纳 |
| 可保留项 | 对读者体验有效，应尽量保留 | 修订时避免误删 |

## 六、读者侧评分方式

| 维度 | 评分问题 | 分值 |
|---|---|---|
| 目标读者匹配 | 是否匹配当前文章目标客户的兴趣、前置知识和阅读场景 | 1-5 |
| 点击与第一屏 | 是否有明确点击理由，开头是否快速降落到具体问题 | 1-5 |
| 理解门槛 | 关键背景和概念是否足够低门槛 | 1-5 |
| 阅读节奏 | 是否适合手机阅读，段落和信息密度是否可承受 | 1-5 |
| 信任感 | 判断是否从事实中浮出，读者是否会觉得可信 | 1-5 |
| 获得感 | 读完是否获得可复述的新解释或谈资 | 1-5 |
| 转述价值 | 是否知道能转给谁、为什么转、对方为什么接得住 | 1-5 |

### 6.1 结论类型

| 分数 / 条件 | 读者侧结论 | 后续处理 |
|---|---|---|
| 31 分以上，且无关键低分项 | 读者侧通过 | 可进入主编审稿 |
| 26-30 分，必改项可局部处理 | 小修后通过 | 处理后进入主编审稿 |
| 21-25 分，存在明显体验断裂 | 大修后复审 | 修改后重新读者审读 |
| 21 分以下，或目标读者匹配/第一屏低于 3 分 | 不建议进入主编审稿 | 先回到草稿或大纲层面修复 |

## 八、读者审读红线

后续读者审读员不得：

1. 不得做事实裁决。
2. 不得新增事实。
3. 不得重写正文。
4. 不得改写文章方向主承诺。
5. 不得建议使用方向把控已放弃的洞察。
6. 不得为了吸引读者建议使用夸张、阴谋化、短视频化表达。
7. 不得把主编侧结构问题伪装成读者感受。
8. 不得只写“好读 / 不好读”，必须说明具体位置和原因。

---

## 九、给主编的交接说明

主编审稿时应重点查看读者审读中的：

1. 读者侧必改项；
2. 信任感低分项；
3. 标题 / 开头 / 正文承诺不一致问题；
4. 读者无法理解或无法复述的问题；
5. 读者侧标记“需主编判断”的事实、结构或发布风险问题。

主编可以采纳、升级或驳回读者意见，但必须说明理由。

## 禁止事项

你不得：

- 审读当前草稿；
- 写正文；
- 写标题候选；
- 写主编审稿意见；
- 写修订方案；
- 做事实裁决；
- 新增未经核查的事实；
- 引用其他文章具体内容；
- 把读者审稿卡写成泛泛读者画像；
- 把读者侧标准写成主编侧发布标准。
