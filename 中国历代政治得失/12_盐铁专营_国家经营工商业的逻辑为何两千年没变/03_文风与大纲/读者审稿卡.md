## 二、读者审读定位

### 2.1 本文目标读者

基于方向把控 §六 与读者画像配置 §一-§四，**本篇不写给一般历史爱好者或学生读者**。它面向四类 40+ 头条成熟男性读者，每一类对本文主承诺的代入感、风险点都不同。

| 目标读者 | 可能关心的问题 | 前置知识 | 阅读场景 | 转述场景 |
|---|---|---|---|---|
| **A. 40+ 体制内 / 国企中层管理者** | "国家为什么不能轻易退出某个行业""考核指标与真实目标为什么会脱节""机构改组后为什么目标被替换" | 足够——听过桑弘羊、盐铁会议；"国家经营""国企"为已有语词；具体朝代制度（就场专卖/开中法/纲法/引岸）需白话翻译 | 头条信息流晚间刷到；手机单手阅读；前 3 段判断"作者有没有观点"；通勤场景为主 | 饭局上跟同事/下属聊"为什么这事改不动"；机关支部学习会引用；微信工作群分享 |
| **B. 40+ 民营中小企业主 / 投资者** | "国家直接经营与民间资本的关系""为什么有些行业始终由国家控制""为什么有些事换了一种走法但结果类似" | 部分——存在"政府管得宽"直觉；具体朝代制度需白话翻译 | 头条信息流午休刷到；与 A 类场景类似，但更容易被"国家爱管闲事"情绪吸引 | 朋友圈转给同行；饭局上反驳"国家爱管" |
| **C. 40+ 高校背景 / 阅读型读者** | "为什么'国家经营工商业'这件事跨两千年反复出现""制度为什么会自我强化""结构判断与道德判断的边界" | 部分——具体朝代制度需白话翻译；但"皇权""相权""中央地方"为已有语词；钱穆是"听说但未必读过的学者" | 头条收藏型阅读；常点收藏夹回看；愿意读长文（5-10 分钟） | 书评群 / 微信读书群转给同好；豆瓣/知乎长文转评；公众号转载 |

### 2.2 读者审读只回答的问题

1. 目标读者刷到标题后，会不会点开（点击理由是否成立）？
2. 第一屏（开头 3 段）是否让四类读者知道"这篇文章和我有什么关系"？
3. 四类读者是否具备理解"普通税基 / 治理延伸 / 形态可换、底层不变 / 批发权不让 / 退出比进入更难"所需的前置知识？哪些概念需白话翻译？
4. 中段四段切片（汉/唐/明/清）和公元前 81 年盐铁会议、副轴票盐改革——哪些地方四类读者会掉线？哪一类先掉线？
5. 文章是否在某一处滑向"政府爱管闲事"或"国企效率差"的情绪判断，从而触发 B 类读者情绪共鸣但损失 A/C/D 类的信任？
6. 文章是否在某一处出现"今天也是这样""这不就是国企吗"等触发句式，触发三红线？
7. 四类读者读完后，能否分别用一句话复述主承诺（"形态可换、批发权不让" + "退出比进入更难"）？
8. 结尾"治理与财政一旦被绑在一起，退出就比进入更难"是否独立成立——不联想到现实也能读懂？
9. 哪些问题属于读者侧必改（体验问题），哪些应交给主编/事实核查（结构/事实/发布风险）？

### 2.3 读者审读不回答的问题

1. 不做事实裁决——例如"桑弘羊是否真是商人子弟""票盐改革是否真的失败"不在读者审读范围，应交给事实核查与主编。
2. 不决定最终标题——只检视"标题是否兑现了承诺"，不替标题 agent 选词。
3. 不重写文章——只标记"读者在哪一段读不下去"，不提供替换段落。
4. 不调整大纲结构——只检视"当前大纲对四类读者是否成立"，不替大纲 agent 改章节。
5. 不新增未经核查的事实。
6. 不替主编判断是否最终发布。

## 三、本文读者侧主承诺

### 3.1 读者看到标题或开头时，以为本文会回答什么

```text
国家直接经营工商业这件事，从汉到清形态换了七八种，但有些东西始终没换——批发权这种核心控制点一直在国家手里；而且这种"政府之手一旦伸进去就收不回来"的现象，背后是治理结构的选择，不是哪一任皇帝或哪个朝代的偶然。
```

预期读者反应：四类读者在刷到反差钩（"形态换了七八种，做的却是同一件事"）后，会带着一个具体的"我懂这件事"的代入感往下读——

- A 类代入："机构改组后换了考核指标，但目标还是没变"；
- B 类代入："换了营业执照、换了监管，但行业还是那批人在做"；
- C 类代入："一个制度解决了一个问题，就会制造下一个问题"；
- D 类代入："改革推下去，3 年后还得回头重新捋一遍"。

### 3.2 正文必须让读者获得什么

```text
一句可复述的稳判断——"治理与财政一旦被绑在一起，退出就比进入更难"；
一组可迁移的结构判断——"形态可换、底层不变""批发权不让""退出比进入更难"；
一个可作为谈资的历史切片——公元前 81 年盐铁会议"60 多人吵了 5 个月，最后只撤了一小部分"。
```

### 3.3 不能向读者承诺什么

1. **不能承诺"今天也是这样"**——按文风卡 §6.3 与审稿政策 §6，结尾不引申到今天；现实切片只作结尾余味的引导，不作结论。
2. **不能承诺"看懂这篇就看懂了今天"**——按读者画像 §五，三年后的文章价值应来自历史解释本身，而非现实暗示。
3. **不能承诺"提供改革建议"**——按方向把控 §一.1 与 §一.2，本文不写"国家应该怎样""政府应该怎样"；不替现实做政策表态。
4. **不能承诺"评价人物对错"**——按方向把控 §七 与文风卡 §7.7，桑弘羊与贤良文学只写成"两种治理逻辑"，不站好恶。
5. **不能承诺"逐句讲解《盐铁论》"**——按方向把控 §一.2 与总计划 §五，《盐铁论》只作机制证据的引用背景，不作逐句导读。
6. **不能承诺"覆盖所有专卖商品"**——按方向把控 §三与放弃项，候选 5（酒酤/茶兴废）只作一段铺垫，不独立成节；候选 7（罗马/日本/法国比较）只作余味，不进入主线。
7. **不能承诺"提供钱穆对每一朝代的原话"**——按方向把控 §一.2 与文风卡 §6.1，钱穆原话 3-4 句、不超过全文 5%，不写具体页码。

| 对方是否接得住 | 转述后对方能用一句话接住——"国家直接经营工商业不是财政手段，是治理延伸；形态换了七八种，批发权不让；退出比进入更难" | 转述后对方以为你在讽刺现实；或对方以为你在讲汉代故事 |
| 转发后对话价值 | 转发能引出"我工作里也有类似的事"的结构判断对话；不引出"汉武帝是不是昏君"的人物评价对话 | 转发后变成"汉武帝对不对"的站队；或"今天国企应该怎么办"的政策讨论 |

## 五、读者侧必改项定义

后续读者审读中，如出现以下问题，应列为必改项：

1. **目标读者不知道为什么要读**——开头 3 段没有建立"这篇和我有什么关系"的代入感，四类读者任一类读完后仍觉得"这是写给历史爱好者的"。
2. **第一屏无法理解文章要解决什么问题**——前 500 字内没有出现主承诺前半句（"国家从未真正放弃对关键商品核心环节的控制"），反差钩被埋到第二段以后。
3. **关键概念不解释，读者无法继续读**——"治理延伸""形态可换、底层不变""批发权不让""就场专卖/开中法/纲法/折色/引岸/票盐/窝本"等术语第一次出现时无一句普通话翻译。
4. **某一节信息密度过高，读者大概率掉线**——中段四段切片某一段超过 5 段；会议过程展开超过 1 段；票盐改革五件事未收束。
5. **某个判断跳得太快，读者会明显不信**——出现"国家爱管闲事""国企效率差""与民争利""国家能力胜利"等粗糙解释；或现实切片出现在中间主体而非开头钩子/结尾余味。
6. **中段与主问题关系不清，读者不知道为什么还在读**——会议戏剧张力（60 余人 5 个月）抢戏；票盐改革被写成成功学/悲剧论；桑弘羊被写成"汉代财政奇才"。
7. **标题或开头承诺的内容，正文没有让读者感到兑现**——标题说"两千年没变"，正文却只讲汉代/唐代两段；标题说"国家经营"逻辑，正文却只讲桑弘羊个人。
8. **结尾让读者觉得突然拔高或另起话题**——结尾升到文明/民族/人性；"历史给我们的启示是""中华民族几千年的智慧""这放到今天也一样""懂的人自然懂"。
9. **读完无法复述本文核心收获**——读者复述测试只能复述汉武帝/桑弘羊/盐铁会议故事，不能复述"形态可换、批发权不让"或"退出比进入更难"。
10. **可能产生严重误解**——读者把文章读成"汉武帝错了/桑弘羊是坏人/贤良文学是书呆"；或读成"盐铁会议是协商民主起源"；或读成"今天国企就是这样"。这些不是事实核查能自动解决的，需要读者审读员标"需主编判断"。

### 5.1 必改项和建议项区别

| 类型 | 定义 | 后续处理 |
|---|---|---|
| 必改项 | 不改会导致四类目标读者任一类读不下去、看不懂、不信或无收获 | 修订前必须处理 |
| 建议项 | 改了会更顺、更有获得感，但不构成读者侧阻断 | 可由主编决定是否采纳 |
| 可保留项 | 对读者体验有效，应尽量保留 | 修订时避免误删 |

**特别说明**：
- 凡触发**三红线**（借古讽今=0、现实影射=0、个人好恶=0）的，必为读者侧必改项——一旦出现，事实核查与读者审读都不能"放行"。
- 凡触发**事实核查 B01—B09**（管仲发明专卖/2014 取消食盐专营/8.22%/罗马长期专营/钱穆页码/汉代盐官具体数字/票盐改革成功学/国家社会主义标签）的，标"事实风险"交主编/事实核查，不在读者侧必改中裁决。

## 八、读者审读红线

后续读者审读员不得：

1. 不得做事实裁决——所有"数字对不对""人物关系对不对""年份对不对"应交给事实核查或主编。

3. 不得重写正文——只标"读者在哪一段读不下去"，不提供替换段落。
4. 不得改写文章方向主承诺——主承诺由方向把控锁定（"国家直接经营工商业……形态可换、批发权不让；治理与财政一旦被绑在一起，退出比进入更难"），读者审读不得质疑或改写。

2. **信任感低分项**——若读者审读中"信任感"低于 3 分，必须由主编综合事实核查与方向把控共同裁决。
3. **标题 / 开头 / 正文承诺不一致问题**——若读者审读标"读者复述不出主承诺"或"读者以为在讲汉代故事"，主编应判断是大纲承诺链问题还是草稿执行问题。
4. **读者无法理解或无法复述的问题**——若四类读者中任两类以上复述测试失败，主编应判断是术语未翻译还是机制未显形。
5. **读者侧标记"需主编判断"的事实、结构或发布风险问题**——读者审读员不裁决，主编必须裁决。

主编可以采纳、升级或驳回读者意见，但必须说明理由。
