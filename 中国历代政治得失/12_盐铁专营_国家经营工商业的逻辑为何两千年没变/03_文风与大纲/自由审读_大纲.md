# 自由审读｜大纲 v2

> 性质：零上下文盲审，自由文本，不设必改项。
> 下游：由 03-outline-review 读取。

读完这份大纲 v2，作为第一次接触这个题目的人，我把我脑子里真实跑过的东西写下来。

---

## 整体感觉

这份大纲的"工程化"程度在 v1 → v2 的修订里又加深了一档。它已经不只是大纲，而是一份接近"半施工图 + 自我审计清单 + 闸门自检"的三合一文档：每个小节都有功能 / 核心问题 / 使用事实 / 使用洞察 / 写法策略 / 与上下节承接 / 禁止越界 / 内部顺序八个固定字段，最后还跟着一份长长的自检表和质量自检清单。我读完的感受是——**这份大纲读起来像一份"驾驶员手册"，而不像一份"路书"**。这是文档组织层面的观感，不影响我对内容的判断，但确实会让一个普通读者在大纲阶段就被"约束密度"压住。

作为读者，我更想要的是"这一节要做什么 → 怎么推进 → 落到哪里"这条路书，而不是"这条路上哪里有坑、哪里不能踩、踩到红线怎么办"。两者结构感很不一样。

不过这只是表达形式上的问题。

---

## 我真正想知道、真正感到的东西

**方向主承诺**："形态从汉到清换了七八种，底层却几乎没变；治理与财政一旦被绑在一起，退出就比进入更难"——这句话我是真的想读。骨架命题（P2）+ 收束稳判断（P4）这条主轴我觉得成立。"机制判断"式写作比"汉代故事会"或"古代专卖史"有吸引力得多。这一点大纲 v2 立得稳。

**承接链**。标题 → 引言 → 第一节 → 第二节 → 第三节 → 第四节 → 第五节 → 第六节（结尾）的链条 v2 给得很完整，每个节点都有"承接什么 + 推进什么"的设计。我作为读者读完 3.1 的"承接链一句话"后，脑子里确实能形成一条推进路径。这点 v2 比 v1 更成熟。

---

## 关于票盐改革"五件事"——v2 显式化（M1 必改项）

这是 v2 最关键的修订项。我读完第五节"本节内部顺序"后，对照感受如下：

**好的部分**：五件事终于被显式列出来了——取消总商 / 开放运销 / 降低运盐成本 / 大商多次试图重新垄断 / 改革并不彻底。每件事都有功能标注（1+2+3 = 制度层面退出 / 4 = 阻力 / 5 = 结果）。"读者数着等，不允许承诺空头"这个提醒非常到位。这件事 v2 落地是清楚的。

**让我犹豫的部分**：五件事里第 4 件（大商多次试图重新垄断）和第 5 件（改革并不彻底）在大纲里的实际"字数"和"信息密度"显著低于前 3 件。前 3 件每件都对应一段制度变化（有动作、有对象、有机制），第 4、5 件则更像是"运行时发生了什么"的总体描述。如果草稿作者按 v2 大纲落地，会出现"前三件丰满、后两件扁塌"的不对称感——读者读到第 4、5 件时会感觉"是不是少写了什么"。这未必是大纲的问题，但落地时需要在"阻力"和"结果"两项里再补几句具体材料（比如"大商具体怎么反扑"、"为什么改革最终不彻底"），否则五件事的"承诺重量"和"实际重量"会不一致。

---

## 关于第三节压缩到 800 字（S1 建议项）

v2 把第三节从 900 字压缩到 800 字，做法是：清代引岸 + 窝本细节压缩为机制判断（30—40 字）、候选 5（酒酤反复 + 茶兴废）由独立段铺垫压为一句过渡（30—40 字）。

**作为读者我的真实反应**：我读完压缩后的步骤 4 后，反而比 v1 读起来更顺。v1 把候选 5 写成独立段，对我这种"非历史专业"的读者来说，反而像是"插队"的旁注——和主轴（明代三步 → 清代）的节奏不搭。压成一句过渡之后，主轴感更强。压缩方向我赞同。

**但有一个我犹豫的点**：压缩后步骤 4 实际上变成了"清代 + 候选 5"两件事混在一段里，30—40 字给清代机制判断（"销区切成块、引岸；朝廷发的引和窝本代代相传"），30—40 字给候选 5（"酒酤反复、茶兴废"）。这两件事在密度上是平摊的，但在"重要性"上不对等——清代的"引岸 + 窝本"是主轴的最后一段切片，候选 5 是辅助观察。我作为读者读完会下意识感到"清代这部分是不是太短了"——主轴最后一刀的篇幅被压缩得有点狠。这是 v2 落地时作者需要小心的地方：要在 30—40 字内把"清代特许垄断的固化"这件事说清楚，不容易。

---

## 关于钱穆出场四功能句式差异化（S2 建议项）

v2 把钱穆出场拆成四种功能：识别工具（第一节，长句）/ 直接出现（第二节，短引）/ 方法论（第四节，方法论提示句）/ 回扣（第五节 + 第六节，不留痕）。

**作为读者**我读完这套设计后脑子里浮出的最大疑问是：**作者真的能在 450—500 字的章节里同时承担"机制判断 + 钱穆 + 历史切片"三件事，且让钱穆每次出场都"句式不一样"吗？**

具体说几个让我犹豫的点：

1. **第一节 500 字**：要承担"历史切片 + 钱穆识别工具（长句）+ 普通税基补齐 + 贤良文学反驳对冲 + 小结推进"五件事。钱穆长句还要嵌在"建立机制识别框架"任务里。我读完步骤 3 步骤 4 后觉得这里会非常挤——500 字要塞这么多任务，长句很可能被挤压成"短句 + 引号"。
2. **第二节 450 字**：要承担"758 第五琦 + 762 刘晏就场专卖 + 钱穆短引 + 财政依赖证据 + 小结推进"。钱穆短引在步骤 3，但步骤 3 之前要先把"就场专卖"这个机制判断写完，450 字里其实留给钱穆的空间很窄。
3. **第四节 450 字**：三件事（步骤 1—3）已经写满了 5 个多月 + 60 余人 + 罢了一小部分，步骤 4 方法论接续还要"显式承接 P1+P2"——这要求作者既要把钱穆方法论写出来，又要承接前两节已建立的机制。450 字里这段很容易写成"提示句 + 概括"两层叠加，每层都被压缩。
4. **第五节 450 字**：五件事显式化已经占了不少字，步骤 5 还要"钱穆回扣 = 不留痕"——"不留痕"的设计本身是对的，但要做到"不引新原话、只把方法论隐性回扣"，其实需要一段相当精密的措辞。

我作为读者，**最担心的是钱穆出场次数和大纲规定的字数之间存在张力**。大纲规定钱穆在 P1—P3 段配比（P1 1 句 + P2 1 句 + P3 1 句 + P4 0 句回扣），原话 3—4 句、不超过全文 5%——这是数量控制；但落地到 450—500 字的章节里，"长句、短引、方法论提示句、不留痕"四种句式的差异化需要足够的语境空间。如果作者为了差异化而硬凹句式，反而会落入"为了不同而不同"的造作。

这是 v2 落地时真正的高难度点，不是大纲的问题。

---

## 关于副轴三步式重组（S3 建议项）

v2 把第四节"本节内部顺序"重组为三阶段：三件事（步骤 1—3）→ 方法论接续（步骤 4）→ 结构判断（步骤 5）。

**作为读者**我读完这套设计后有两层反应：

1. **结构感更清晰了**：v1 步骤 4 是"小结 + 推进"，v2 改为"结构判断 + 推进"——把"小结"提升到"结构判断"层级，这个提升是对的。一节如果只是"小结"，对读者来说容易显得平；"结构判断"则把这一节的功能从"总结"提升到"提升抽象层级"，对全文的承接有意义。

2. **但步骤 4 的"方法论接续"任务特别重**：v2 在步骤 4 里要求"显式承接 P1+P2 已建立的'国家嵌入经营网络'机制——会后保留大部分专营不是会议胜负问题，而是 P1+P2 机制的副产品"。这句话作为"作者指令"非常清晰，但作为读者我读完步骤 4 之后，感受到的是：**作者必须把"会期长 + 人数多 + 会后结果只撤一小部分"三件事的"机制解释"用一句话串起来，并且这句话还要承接 P1+P2**——这其实是要求作者在 100—150 字里同时完成"机制解释 + P1+P2 承接 + 钱穆方法论呈现"三件事。我读 v1 大纲时觉得副轴只要写"三件事 + 钱穆方法论"就够了；v2 把任务加重了，落地时的文字密度会比表面看起来更高。

## 关于标题候选

四个候选里，作为读者我最喜欢的是备选 C——"从汉到清，盐换了七八种管法：但批发权一直没让"。钩子最强，"批发权"作为机制判断词也最锐利。但 C 字数 23 字最长，且"管法"偏口语化（大纲自己也警示过）。

备选 A"国家为什么一直不肯撒手：盐铁专营两千年没变"——"不肯"这个词略有意志色彩，我作为读者读到会有一种"国家有主观选择"的暗示，与全文要表达的"结构已经在运转"形成微妙张力。

推荐版"盐铁专营：国家经营工商业的逻辑，为何两千年没变"——稳但钩子稍温。"两千年没变"作为反差钩没问题，但和"国家经营工商业的逻辑"放一起，主承诺的承担略分散。

备选 B"同一件事，国家管了两千年：盐铁专营的形态与底层"——"同一件事"直接对位"形态 vs 底层"框架，但"管了"这个词偏动作化，把结构性问题拉回了动作层面。

如果让我推荐，我会选 C 作为基础精修，或者把 C 的前半句和 A 的后半句做组合。但这是标题阶段的事，不在大纲审读范围内。

## 关于"零上下文读到的几件让我犹豫的事"

读完大纲后我脑子里浮现过几件"好像不太对"的事，写下来：

1. **副轴引言措辞**：v2 第一节步骤 4 写"桑弘羊说'放开盐铁，肥的是豪强，亏的是国家'——这是他的自我陈述；贤良文学的话反过来提醒一件事：国家延伸出去未必能管好"。这段作为读者我读完感到——把"桑弘羊"和"贤良文学"放对冲位是合理的，但"这是他的自我陈述"这一句作为读者会读出"作者在标注史料立场"的味道，有点像论文注释体。大纲前文说"严控桑弘羊笔墨（不展开评传）"，但"自我陈述"这种元话语写出来反而会暴露作者对史料的判断。如果作者是想"让读者知道这是桑弘羊自己说的，不一定是事实"，其实可以用更隐性的措辞。

2. **第三节步骤 5 末尾的"小结 + 推进"**：v2 步骤 5 末尾写"形态从开中到折色到纲法到引岸，名字换了四五种，朝廷的入口却越来越深。下一步要问的是：既然入口这么深，一场激烈的政治辩论能不能撤得掉？"——作为读者我读到"名字换了四五种"时脑子里闪过一个轻微的不适感：标题承诺是"形态换了七八种"，但这里写"四五种"。这是不是数字承诺不一致？查了一下，其实是合理的——"七八种"是更宽泛的说法，"四五种"是主轴四段切片范围内的计数。但如果作为读者第一次读到这里，会感到"数字飘了"。作者在落地时可能需要把"四五种"统一为"七八种"或者反过来。

3. **结尾收束链**："当治理能力被织进专营网络，国家就没法'撒手'——它不是因为某个人不肯放，是因为结构已经在运转"——这句作为读者我读完感到它和主承诺后半句"退出就比进入更难"是同一个意思的不同表达。两句同时出现会不会显得重复？大纲说"结尾 200 字 + ≤40 字稳判断"，但收束链里又给了一句更长的版本。作者落地时需要决定：到底是 40 字稳判断独立成段，还是用这句更长的句子来收束。如果是后者，40 字稳判断可能就显得多余。

4. **现实余味引导**："现实切片只作结尾余味引导"——大纲反复强调这一点，但主承诺本身"治理与财政一旦被绑在一起，退出就比进入更难"已经是一个普适判断，任何读者读到都会自动往今天映射。"余味引导"这个说法在大纲里出现多次，但落地时很难界定"余味"和"影射"的边界。这不是大纲的问题，是这类文章的内禀难题。

---

## 总体感觉

v2 在 v1 基础上做了三件事：把票盐五件事显式化（必要）、把第三节压缩（合理）、把钱穆句式差异化（方向对但落地难）、把副轴改成三步式（结构更清）。作为读者我读完 v2 后的总体判断是：

- **方向稳**：主承诺、骨架、收束都成立。
- **结构清晰**：承接链、四段切片、副轴、稳判断的链条 v2 给得很完整。
- **密度仍在临界**：第三节 800 字要塞明代三步 + 清代一段 + 候选 5 一句过渡 + 钱穆回扣，密度仍在。落地时作者需要非常克制。
- **钱穆句式差异化是方向对但落地难**：450—500 字的章节里同时承担"机制判断 + 历史切片 + 钱穆差异化"，对作者笔力的要求比表面看起来更高。
- **副轴三步式的"方法论接续"任务加重**：v2 把步骤 4 的承接任务显式化之后，落地密度反而比 v1 高。
- **稳判断的"机制 vs 现实"边界是真正的高难度处**：大纲反复强调"不引申到今天"，但主承诺本身是普适判断，落地时需要"机制感压过现实感"——这是写作者要解决的最微妙的问题。
