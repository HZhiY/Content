### 3.1 承接链一句话

```text
[标题]"国家经营工商业为何两千年没变"
    → [引言]"形态换了七八种，做的却是同一件事"（反差钩 + 主承诺前半句）
    → [第一节 P1]普通税基不够用，国家升级为经营（机制第一层 + 钱穆识别工具 = 长句）
    → [第二节 P2 上]唐代就场专卖——形态换了一种，批发权不让（主轴第一段切片 + 钱穆直接出现 = 短引）
    → [第三节 P2 下]明代开中 → 折色 → 纲法 → 清代引岸 + 窝本——名字换得越多，朝廷的入口越深（主轴第二/三/四段切片 + 钱穆回扣 = 不留痕）
    → [第四节 P3]公元前 81 年：三件事（会期长 + 人数多 + 会后结果）→ 方法论接续 → 结构判断（副轴机制证据 + 钱穆方法论 = 方法论提示句）
    → [第五节 P4 + 收束]道光年间的"松绑"试了一次——v2 五件事显式化 = 制度层面退出 + 退出阻力 + 退出结果（退出成本支点）
    → [结尾稳判断]治理与财政一旦被绑在一起，退出就比进入更难（回收主承诺后半句）
```

### 3.2 承接风险

1. **引言过快进入"两千年"承诺，正文 P2 四段切片在第二节—第三节中段过于密集**——必须严控唐代/明代/清代每段切片只服务一个机制判断，避免滑入朝代通史。**v2 应对**：第三节压缩清代引岸+窝本为机制判断（S1 落地）。
2. **第四节副轴会议戏剧张力抢戏**——60 余人、5 个多月、第一手文献记录这些元素容易让副轴变成"会议纪要"；必须严控只取三件事。**v2 应对**：三步式重组——三件事 → 方法论接续 → 结构判断（S3 落地），让结构判断替代"小结 + 推进"。
3. **第五节票盐改革易写成"改革成功/失败"评价**——必须只取"五件事"作退出成本支点，不写评价。**v2 应对**：五件事显式化为独立清单 + 三层结构标注（M1 落地），避免"五件事"承诺空头。
4. **结尾稳判断被读者误读为"今天也是这样"**——必须严守"回收机制不回收对错"原则，不引申到今天；现实切片只作余味引导。
5. **钱穆支点错位**——必须 P1 段建立机制识别工具 + "历史意见"方法论；P2 段直接出现"直到清代……大体上总还遵循这一政策"；P3 段方法论显式呈现；P4 段回扣方法论而不引新原话；不独立成段，不挂名。**v2 应对**：四功能句式差异化（S2 落地）——识别工具 = 长句 / 直接出现 = 短引 / 方法论 = 方法论提示句 / 回扣 = 不留痕。
6. **第三节密度塌缩为朝代通史**——明代三步（1370 → 1492 → 1617）+ 清代一段 + 候选 5 一段铺垫，原 v1 配 900 字接近结构配置"信息密度控制"边界。**v2 应对**：候选 5 由独立段铺垫压为一句过渡（约 30—40 字），清代引岸+窝本细节压缩为机制判断（§六 第三节 步骤 4），第三节总字数 900 → 800（S1 落地）。

### 4.2 引言功能

引言必须完成：

#### 本节内部顺序

1. 步骤 1（历史切片 + 反常识判断）：公元前 120 年（元狩三年），汉武帝下了一道命令：把盐和铁收归国家经营。盐，民间生产、官府收购运销；铁，官府从生产到销售全部管起来。在数十个产盐郡国设盐官，严禁私煮私铸。
2. 步骤 2（机制解释）：这套制度表面上是补财政。桑弘羊自己说过一句话：边用度不足，故兴盐铁。——对外战争打钱，光靠税收顶不住。但深层其实是补治理。
3. 步骤 3（钱穆识别工具 = **长句** + "普通税基"补齐）：钱穆在《中国历代政治得失》里说，汉武帝这一套制度，"近似于近代之所谓国家社会主义的路线"。他提醒我们，评价古制，要把"当时人怎么想"和"我们现在怎么想"分开。——普通税基，就是人头税、田租、关税这些。盐铁专卖之前，国家主要靠这几样收钱。
4. 步骤 4（贤良文学反驳对冲）：贤良文学的反驳也直白：你不加税就让国用富足，可结果是国家衰耗、城郭空虚。桑弘羊说"放开盐铁，肥的是豪强，亏的是国家"——这是他的自我陈述；贤良文学的话反过来提醒一件事：国家延伸出去未必能管好。
5. 步骤 5（小结 + 推进）：从这一段开始，我们看到的不是"该不该国家管"的问题，而是"普通税基不够用时，国家会本能地把手伸进利润最大、最容易征税的行业"。但一旦伸手进去，国家就嵌进了经营网络——批发权、特许权、缉私网络、地方就业。下一步的问题是：到了唐代，这条路被怎么改写了？

### 第二节：唐代：换了一种走法，批发权还在国家手里

#### 本节内部顺序

1. 步骤 1（历史切片）：公元 758 年，第五琦把盐全收归国家，每斗在时价上加一百钱出售——这就是唐代的"榷盐法"。四年后，762 年，刘晏把制度改了。
2. 步骤 2（机制判断）：改在哪里？盐还是国家统购，但运输和销售交给了商人。批发权没让。这就是"就场专卖"——盐在产地就由国家统一收购，不在销售地管。
3. 步骤 3（钱穆直接出现 = **短引**）：钱穆说，"直到清代……大体上总还遵循这一政策"——名字从"榷盐"换成"就场专卖"，但国家不放弃对批发权的控制这件事，没换。
4. 步骤 4（财政依赖证据）：到唐代宗大历末年，盐税从四十万缗涨到约 600 万缗，约占国家正税收入一半。——专营给国家带来的是"看得见的钱"，国家自然就更不愿意撒手。
5. 步骤 5（小结 + 推进）：唐代换了一种走法，批发权还在国家手里；而且财政对专营形成了深度依赖。这一步迈出去之后，下一步就是"朝廷把盐引变成自己发的特许"。

#### 本节内部顺序

1. 步骤 1（明代切片 — 开中法）：明初洪武三年（1370），朝廷开始用盐做招商筹码——"召商输粮而与之盐"，谁把粮草运到边疆，谁就拿到一张"盐引"，凭引到指定地方领盐去卖。这就是"开中法"。

3. 步骤 3（明代切片 — 纲法世袭）：到了明代末年（万历四十五年，1617），袁世振创"纲运法"——把盐的运销权编成纲册、固定下来，可以世代继承、可以转卖，叫"窝本"。盐的运销权变成了朝廷特许的"私产"——"留与众商永永百年，据为窝本"。

> 五件事 = 前三件"做了什么"（制度层面退出） + 后两件"运行中发生什么"（退出阻力 + 退出结果）。这三层对应"退出成本"的三层结构：1+2+3 = 制度层面退出；4 = 退出阻力（利益集团反扑）；5 = 退出结果（财政依赖未解除）。

1. 步骤 1（历史切片）：清代道光年间（约 1831—1832），两江总督陶澍在淮北推行票盐改革。
2. 步骤 2（**五件事之 1—3 / 制度层面退出**）：
   - **五件事之 1：取消总商**——打破原有大盐商对销区的垄断。
   - **五件事之 2：开放运销**——允许普通商人参与运盐（任何商民纳税后都能领票运盐）。
   - **五件事之 3：降低运盐成本**——通过裁减浮费、整顿吏治减少中间环节。
3. 步骤 3（**五件事之 4—5 / 退出阻力与结果**）：
   - **五件事之 4：大商多次试图重新垄断（阻力）**——退出过程中利益集团反扑。
   - **五件事之 5：改革并不彻底（结果）**——退出最终未完成，国家财政仍依赖盐利。
4. 步骤 4（机制判断）：看上去是一次"市场化松绑"。但运行中，大商仍多次试图重新垄断，改革并不彻底。——这不是谁对谁错的问题。明代以来"窝本"已经变成世袭的"私产"——朝廷授的引、世代传的窝本、销区切成的岸，每一个都已经"长"在盐的运转里。改一次就要在已经形成的利益网络里持续博弈。
5. 步骤 5（**钱穆回扣 = 不留痕** + 推进）：钱穆的提醒再一次有效：制度运行是连续的，退出比进入更难——财政缺口怎么补、地方就业怎么安排、已经形成的利益网络怎么处理，每一项都是真问题。
