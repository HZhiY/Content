## 一、整体阅读感受

> 这一节先写整体体感，再进入分项评分。不要只罗列问题，要模拟目标读者（A 体制内/国企中层、B 民营中小企业主、C 高校阅读型、D 公务员/政策研究者）读完后的真实第一反应。

### 1.1 一句话体感

```text
读完像被人用一句话把一件模糊的事情说清楚了——"形态换了七八种，批发权不让"+"退出比进入更难"——这两句话记住了，但中间走过的那些朝代和制度名字，心里有点模糊。
```

### 1.2 整体判断

| 项目 | 判断 | 说明 |
|---|---|---|
| 第一反应 | 想继续读 | 开头第一句"从汉到清，盐这件事怎么管，名字换了七八种"有反差感，但没有震惊体那种压迫感，愿意往下看 |
| 最大优点 | 机制判断清晰 | "进入是一步，退出是一网"这句话作为结尾收束，有效；读完后能记住"形态可换、批发权不让"和"退出比进入更难"两个核心判断 |
| 最大阻碍 | 第三节节奏问题仍在 | 第三节第三节标题虽已拆段，但每段内部仍有"判断句+史实句"两连发的结构，扫读时第二句容易飘过去 |
| 最容易掉线的位置 | 第三节中段（开中法→折色→纲运法→引岸四段连读时） | 四段连下来，每段都是"入口加深"开头，判断句很像，读到第三段就有点累了 |
| 最有获得感的位置 | 第四节结尾"不是辩论不够激烈，是结构已经在运转" | 这一句让读者感到"原来是这样"，有被说服的感觉 |
| 读完后的残留印象 | 清楚但有点累 | 记住了结论，但读的过程中有几段要来回看；第三节是主要累点 |

### 1.3 读者复述测试

读完后，四类目标读者能否分别用一句话复述这篇文章？

```text
- A 类（体制内/国企中层）：【能】"国家直接经营工商业这件事，形态换了七八种，但批发权始终没松手——而且一旦进去，再退出来就难了。"
- B 类（民营中小企业主）：【能】"换了多少种名字不重要，重要的是批发的口子一直在国家手里，想松都松不开。"
- C 类（高校阅读型）：【能】"从汉到清，国家经营盐铁的形态换了七八种，但'批发权不让'这个底层结构一直没变；退出成本比进入成本高，这是一个制度问题不是人的问题。"
- D 类（公务员/政策研究者）：【能】"盐铁专营表面是财政问题，实质是治理延伸——形态可换，批发权不让，退出比进入更难。"
- 共性收获：四类都能复述出"形态可换、批发权不让"或"退出比进入更难"至少一个核心判断。
```

### 1.4 整体建议

```text
最应该保留的：引言反差钩（"名字换了七八种"/"批发权始终是朝廷管的"）+ 第四节"不是辩论不够激烈，是结构已经在运转"+ 第五节五件事清单骨架（按时间顺序列）+ 第六节"进入是一步，退出是一网"对仗收束。
优先修的：第三节四段切片节奏——每段"判断句+史实句"结构相同，四段连读会疲劳，建议四段中至少留出一段只用纯判断短句，减少重复感。
不要修坏的：钱穆出场方式和位置；"治理延伸"作为第一个框架性判断的定位；第五节五件事清单的清晰度。
```

## 八、给修订阶段的读者侧提醒

1. **引言反差钩是全文最强点击资产**——"名字换了七八种"/"批发权始终是朝廷管的"这两句必须在；修订时严防被替换为情绪性表达。

2. **第四节"结构已经在运转"是全文获得感最强的一句**——四类读者读到这里都有"被说服"的感觉；不得删，不得弱化，不得展开成会议纪要。

3. **第五节五件事清单是"退出比进入更难"的证据支撑**——清单形式清晰；五件事顺序（取消总商→开放运销→降低运盐成本→大商反扑→改革不彻底）对应"退出成本一点点浮现→利益网络反扑→退出失败"的逻辑链，不得打乱。

4. **第六节"进入是一步，退出是一网"与引言首句形成首尾对称**——这是全文结构美感最强的地方；不得改成散句。

5. **钱穆方法论"历史意见 vs 时代意见"在第一节、第二节、第四节三次出现，比例合适**——钱穆支点不作独立候选、不挂名、不超过全文5%，当前位置合适。

6. **三红线检查通过**——全文无"今天也是这样""这不就是国企吗""懂的人自然懂"等触发句式；无借古讽今、无现实影射、无个人好恶。
