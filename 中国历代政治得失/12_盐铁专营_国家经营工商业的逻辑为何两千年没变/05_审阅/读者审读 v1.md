## 一、整体阅读感受

> 这一节先写整体体感，再进入分项评分。模拟四类目标读者（A 体制内/国企中层、B 民营中小企业主、C 高校阅读型、D 公务员/政策研究者）读完后的真实第一反应。

### 1.1 一句话体感

```text
像一位克制的老朋友在手机上讲清楚一件事：名字换了七八种，批发权一直没松；读完后能带走"退出比进入更难"，而不是"国家爱管闲事"。
```

### 1.2 整体判断

| 项目 | 判断 | 说明 |
|---|---|---|
| 第一反应 | 想继续读 | A/C/D 类被反差钩和"批发权不让"快速拉住；B 类也会被"国家爱管闲事"两句否定式写法勾住，但需读到第一节才落到具体史实 |
| 最大优点 | 引言反差钩 + 结尾"进入是一步，退出是一网" | 反差钩让四类读者立刻知道"不是朝代通史"；结尾把 P1—P4 收成一句可转述的稳判断，D 类尤其愿意收藏 |
| 最大阻碍 | 引言前三段缺汉代锚点；第三节明代术语连续出场 | 文风卡要求前三段完成汉代锚点，目前汉武帝、桑弘羊延至第一节才出现，部分读者第一屏会觉得"有判断但略飘"；开中法/折色/纲法/窝本在同一节内连续切换，C 类非专业读者可能在此略顿 |
| 最容易掉线的位置 | 第三节「朝廷把盐引变成自己发的特许」中段 | B 类若在此失去"批发权"主线，容易把文章读成"制度名词串"；A/D 类通常能靠后文会议段拉回 |
| 最有获得感的位置 | 第四节盐铁会议 + 第六节收束段 | "60 多人吵了 5 个月，只撤一小部分"对 A/D 是强机制证据；结尾四步链 + "治理与财政一旦被绑在一起，退出就比进入更难"四类读者都能复述 |
| 读完后的残留印象 | 清楚 | A/D 留"退出比进入更难"；C 留"形态可换、批发权不让"；B 若读完全文留结构判断，若中途退出可能只留"国家一直管盐" |

### 1.3 读者复述测试

读完后，四类目标读者能否分别用一句话复述这篇文章？

```text
- A 类（体制内/国企中层）：能——"国家一握住批发权，就不只是收钱，而是一整套治理网络长进去了；形态可以换，控制点换不掉，所以退出比进入难得多。"
- B 类（民营中小企业主）：部分能——能复述"换了几种管法，批发权一直在国家手里"，但若只读到第三节，容易退化成"国家一直管盐铁"的情绪印象，带不走"退出成本"框架。
- C 类（高校阅读型）：能——"从汉到清专卖形态换了七八种，国家始终不放弃批发环节；公元前 81 年辩论撤不掉，清代票盐改革也撤不彻底，因为财政和治理已经绑在一起。"
- D 类（公务员/政策研究者）：能——"治理与财政一旦被绑在一起，退出就比进入更难；盐铁会议和票盐改革都是同一结构的两次验证。"
- 共性收获：四类读者读完全文后，都应能复述"形态可换、批发权不让"或"治理与财政一旦被绑在一起，退出就比进入更难"至少一个核心判断。
```

### 1.4 整体建议

```text
最应该保留：引言"名字换了七八种/批发权始终朝廷管"的反差钩；第一节"治理延伸"判断段；唐代"表面放权、深层换控制点"；会议"只撤一小部分"三件事；票盐五件事清单；结尾四步链与"进入是一步，退出是一网"。

优先修：引言前三段补上汉代锚点（元狩三年盐铁官营 + 桑弘羊一句），让第一屏完成文风卡三件事；第三节"引岸"首次出现时补一句白话，与后文票盐段的"岸"接上；明代切片段落后各加一句机制收束，防止术语堆叠掉线。

不要修坏：不要把"国家爱管闲事"从"被否定的浅解释"改成正文主解释；不要把会议段展开成路线斗争或戏剧化辩论；不要把票盐改革写成成功/失败评仪；结尾不要加"启示""今天也是这样"或现实影射。
```

## 八、给修订阶段的读者侧提醒

1. 反差钩（"名字换了七八种/批发权始终朝廷管"）是本文最强点击资产，补汉代锚点时严禁换成"国家爱管闲事"或通史开头。
2. 公元前 81 年盐铁会议只保留"会期 + 人数 + 会后结果"三件事——"挑战够激烈了吧"可留，勿再扩写辩论过程或站人物好恶。
3. 票盐改革五件事清单是退出成本支点，勿简化为"陶澍改革成功/失败"。
4. 术语首现翻译清单里还差"引岸"——补上即可显著降低第三节到第五节的理解断层。
5. 结尾只回收"治理与财政一旦被绑在一起，退出就比进入更难"——不加"启示""反思""这放到今天也一样"。
6. 三红线自检：全文未出现借古讽今/现实影射/个人好恶触发句；修订时勿为增强"共鸣"而加"这不就是国企吗"类写法。
