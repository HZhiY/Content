# 结构反审

## 一、反方压缩

打仗缺钱，田租已经钉死加不成，卖爵、铸钱、向盐铁富人伸手也拿不到能锁住的现金，朝廷才改去卖盐铁。卖法不是把商人灭掉，是把煮盐的盆和私铸收进官里，旧商人改坐吏位。报表可以写没加赋，是因为铁器的价钱、成色和摊派把账接走了；这本账撤过，缺钱的冬天还会开回来。

整篇不是三个朝代确认「国家天生要垄断」，而是一条选择链加上锁法和账单。后两节如果只拿来反复证明「所以才下场」，这篇会立刻变薄；按现骨架，它们回答的是另外两问：锁住的是什么、人还在不在；谁在付钱、抽得走吗。

## 二、六项测试

| 测试 | 结论 | 证据 |
|---|---|---|
| 首屏耗尽 | 通过 | 骨架前两句和读者路径前约 200 字只立住别扭：打仗缺钱，最直是加田赋，却去卖盐铁；抢商人解释得了下场，解释不了田赋为什么按着不动。第一节才摊选择链。路径本身把后文留给两个新问题：「锁住的又是什么，商人被赶走了吗」（第 2 节）；不益赋与苦恶能否同时为真、罢了会不会回来（第 3 节）。后文不是换三朝确认「缺钱所以做生意」。 |
| 章节合并 | 通过 | 第 1 节＝其他管道锁不住才下场；第 2 节＝锁的是官器与私铸，人改座不消失；第 3 节＝田赋账与价质摊派是同一本账，且抽走过还会被用度拉回。对调 1 与 2，读者会先看见怎么锁、却不知道为什么下场。对调 2 与 3，账单和回潮会压在换座之前，商人还在不在的问题会被谁付钱吞掉。合并 1+2，会丢掉「后上场」和「没赶尽」两层纠偏。合并 2+3，会把锁法与账单收成一句「下场了所以民付钱」，看不见换座本身。 |
| 新增信息 | 通过 | 第 1 节相对引言新增选择链：三十税一定额、买爵赎罪与武功爵已先行、万金不佐急、赡用与摧并兼同句、山海属大农佐赋。第 2 节新增锁法与人事：募民自给费、官器牢盆、私铸釱左趾、故盐铁家除为吏。第 3 节新增代价与后果：卜式所见苦恶价贵强买对照「民不益赋而天下用饶」，接着真罢过、冬天因用度不足而复、三年而复。不是换例子再证「所以才下场」。 |
| 具体载体 | 通过 | 至少两个可复述现场：募民用官器、官与牢盆，敢私铸者釱左趾、没入器物；故盐铁家富者除为吏，吏道多贾人。另外还有能改理解的数字与反常结果：孝景二年三十税一；卜式见铁器苦恶、价贵、强买，对照报表「民不益赋」；罢盐铁官后冬天复开。不是只靠术语分类。 |
| 读者利害 | 通过 | 读完不是只会把「专营」和「消灭商人」分开说。判断改在三处：缺钱时国家为什么不走加田赋、改当卖家；田上那笔不动时，谁在用铁器上付钱；这本账为什么撤了还会被缺口拉回来。改变的是对谁承担成本、制度为何继续存在的判断，不是用词更准确。 |
| 作者防守 | 通过 | 准备进正文的口径边界只有两处、且合计最多一次：F13 是钱穆对「不便再加」的解释不是诏书；F9「用度不足」并非唯一社会原因。摧并兼只在 F19 同句出场，第 1 节收束和第 3 节末段禁止再念「所以不是仅仅补财政」。结尾主轴是除吏换座、苦恶铁器、冬天复开三个现场，不是「本文不是来……」。「不做什么」写在给写作者的提醒里，不构成一节或收束主轴。 |

## 三、阻塞项

无。现骨架里，第 2 节若写成第 1 节的生产附录，或第 3 节若写成再证「缺钱所以做生意」，会把角度写坏；那是草稿阶段的走形风险，不是现在这份大纲已经摊开的结构失败。

## 四、结论

```text
结论：可进草稿
```

三节分别回答为什么下场、锁住的是什么、账单在谁身上且抽不走，首屏只立别扭，没有把后文收成同一句话的三次证明。
