## 一、整体阅读感受

> 这一节先写整体体感，再进入分项评分。模拟四类目标读者（A 体制内/国企中层、B 民营中小企业主、C 高校阅读型、D 公务员/政策研究者）读完修订稿后的真实第一反应。

### 1.1 一句话体感

```text
比草稿更"落地"了：开头就把汉代锚点和批发权问题钉住，中段一路用汉唐宋明清切片证明"换走法不换控制点"，读完后能带走"进入是一步、退出是一网"，而不是停在"国家爱管闲事"。
```

### 1.2 整体判断

| 项目 | 判断 | 说明 |
|---|---|---|

### 1.3 读者复述测试

读完后，四类目标读者能否分别用一句话复述这篇文章？

```text
- A 类（体制内/国企中层）：能——"国家一握住批发权，就不只是收钱，而是一整套治理网络长进去了；形态可以换，控制点换不掉，所以退出比进入难得多。"
- B 类（民营中小企业主）：部分能——能复述"换了几种管法，批发权一直在国家手里"；读完全文能带走"退出成本"，若只读到第三节仍可能退化成"国家一直管盐"的浅印象。
- C 类（高校阅读型）：能——"从汉到清专卖形态换了七八种，国家始终不放弃批发环节；公元前 81 年辩论撤不掉，清代票盐改革也撤不彻底，因为财政和治理已经绑在一起。"
- D 类（公务员/政策研究者）：能——"治理与财政一旦被绑在一起，退出就比进入更难；盐铁会议和票盐改革都是同一结构的两次验证。"
- 共性收获：四类读者读完全文后，都应能复述"形态可换、批发权不让"或"治理与财政一旦被绑在一起，退出就比进入更难"至少一个核心判断。
```

### 1.4 整体建议

```text
最应该保留：引言"名字换了七八种/生产者到商人这一关始终朝廷管"的反差钩；引言内汉代锚点（元狩三年 + 桑弘羊一句）和"国家爱管闲事太浅"的否定式处理；第二节"表面放权、深层换控制点"；第三节引岸首现白话；会议"只撤一小部分"三件事；票盐五件事清单；结尾四步链与"进入是一步，退出是一网"。

优先修（建议级，非阻断）：第三节明代切片段落之间可加一句"同一机制、入口越来越深"的过渡信号，帮 B/C 类不把四名词读成并列科普；P1 段可在"国家不只收税"处轻点"治理延伸"四字（配已有白话），强化 D/C 类复述抓手；引言主承诺句可酌情把"生产者到商人手里这一关"与"批发权"二字并提，与第二节钥匙句更快对齐。

不要修坏：不要把"国家爱管闲事"从"被否定的浅解释"改成正文主解释；不要把会议段展开成路线斗争或戏剧化辩论；不要把票盐改革写成成功/失败评仪；结尾不要加"启示""今天也是这样"或现实影射；钱穆方法论不能删成单句标签。
```

## 八、给修订阶段的读者侧提醒

1. 反差钩（"形态换了七八种，做的却是同一件事"）和引言汉代锚点是本文最强点击资产，后续微调不要把它后移或替换成人物/会议入口。
2. 第三节是 B/C 类唯一仍可能掉线的位置——加过渡句比重写制度细节更安全；每加一个名词，段末"批发权/朝廷入口没换"的收束不能删。
3. 会议只取"会期 + 人数 + 会后结果"三件事，票盐只取五件事——这两段是 A/D 类获得感来源，修订时严防戏剧化或成功学化。
4. 结尾"治理与财政一旦被绑在一起，退出就比进入更难"已独立成立，不要再加现实切片或"启示"句式帮读者"联想当下"。
5. 三红线自检：全文未出现"今天也是这样""这不就是国企吗""懂的人自然懂""汉武帝错了"等触发句——后续轮次修订保持这一状态。
