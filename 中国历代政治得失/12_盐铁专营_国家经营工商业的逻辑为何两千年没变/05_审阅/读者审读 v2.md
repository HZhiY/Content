### 1.3 读者复述测试

读完后，四类目标读者能否分别用一句话复述这篇文章？

```text
- A 类（体制内/国企中层）：能——"国家一握住批发权，就不只是收钱，而是一整套治理网络长进去了；形态可以换，控制点换不掉，所以退出比进入难得多。"
- B 类（民营中小企业主）：能——"换了几种管法，批发权一直在国家手里；不是爱管闲事，是财政和治理绑在一起后，想撤也撤不干净。"
- C 类（高校阅读型）：能——"从汉到清专卖形态换了七八种，国家始终不放弃批发环节；公元前 81 年辩论撤不掉，清代票盐改革也撤不彻底，因为财政和治理已经绑在一起。"
- D 类（公务员/政策研究者）：能——"治理与财政一旦被绑在一起，退出就比进入更难；盐铁会议和票盐改革都是同一结构的两次验证。"
- 共性收获：四类读者读完全文后，均能复述"形态可换、批发权不让"或"治理与财政一旦被绑在一起，退出就比进入更难"至少一个核心判断。
```

### 1.4 整体建议

```text
最应该保留：引言"名字换了七八种/元狩三年盐铁官营/批发权始终朝廷管"三件套；第一节"治理延伸"判断段；第二节"表面放权、深层换控制点"；会议"只撤一小部分"三件事；票盐五件事清单；结尾四步链与"进入是一步，退出是一网"。

优先修（非阻断）：第三节每换一种制度名，可紧跟半句"批发权/入口没换"机制收束，降低术语接力时的微掉线；折色首现可再压半句白话，帮 B 类读者与开中法区分。

不要修坏：不要把"国家爱管闲事"从"被否定的浅解释"改成正文主解释；不要把会议段展开成路线斗争；不要把票盐改革写成成功/失败评仪；结尾不要加"启示""今天也是这样"或现实影射。
```

## 八、给修订阶段的读者侧提醒

1. 反差钩 + 汉代锚点 + 批发权主承诺是 v2 最强改进，修订时严禁换回"国家爱管闲事"或通史式开头。
2. 公元前 81 年盐铁会议只保留"会期 + 人数 + 会后结果"三件事——"挑战够激烈了吧"可留，勿再扩写辩论过程或站人物好恶。
3. 票盐改革五件事清单是退出成本支点，勿简化为"陶澍改革成功/失败"。
4. 第三节术语接力处可加半句机制收束，但勿为此扩写成朝代制度科普。
5. 结尾只回收"治理与财政一旦被绑在一起，退出就比进入更难"——不加"启示""反思""这放到今天也一样"。
6. 三红线自检：全文未出现借古讽今/现实影射/个人好恶触发句；修订时勿为增强"共鸣"而加"这不就是国企吗"类写法。
