## 七、读者侧建议项（不阻断，但建议进入 v5）

按用户 5 层抽象意见，v5 需要做以下升级：

### R1：主承诺从"批发权不变"升级为"重复最优解"

- v4 主承诺："批发权始终是朝廷管的" → "形态可以换，批发权不换" → "退出一网"
- v5 主承诺：把"批发权不变"显性化为**"为什么国家持续选这条路"**——
  > "盐铁专营反复出现的，不是'制度惯性'，而是'财政约束下的重复最优解'——只要国家需要稳定现金流、而直接征税成本高于控制流通节点，类似结构就会反复出现。"

### R2：v5 引言或第一节加"为什么是盐"作为机制第一环

- 盐的特殊属性：需求刚性 / 产地集中 / 不易替代 / 价格空间大 / 不影响农业基本生产结构。
- **v4 缺这一层**——直接进入"国家缺钱→盐被挑出来"，没解释"为什么是盐"。
- v5 应在引言段 3 后或第一节前段加一句"为什么是盐"的**最简翻译**。

### R3：v5 第二节加"国家要的从来不是'卖盐'，而是'征税入口 / 流通链 / 现金流'"

- 把"批发权"显性化为"可定位的征税入口 / 可追踪的流通链 / 可稳定抽取的现金流"——这是用户的"二层抽象"。
- v4 第二节"形态可以换，批发权不换"后面**加一句**"国家要的从来不是'卖盐'，而是'在最不容易逃税的节点收钱'"。

### R4：v5 第四节后段或第五节前段加"为什么'放开'总是失败"

- v4 第四节"结构已经在运转"回答了"为什么松不开"——但没回答"为什么放开失败"。
- 用户指出："财政系统已依赖 / 官僚体系已建立 / 地方网络已嵌入"——这是 v4 缺的。
- v5 第五节前段加一段"三套网络已嵌入"——作为"退出一网"的前置。

### R5：v5 第六节收束升级为"重复最优解"

- v4 收束："进入一步 / 退出一网" + "退出比进入更难"。
- v5 收束升级为：
  > "问题没变、约束没变、结果就不断收敛到类似方案。"
- 但保留 v4 的"进入一步 / 退出一网"对仗作为短收束句。
