### 1.1 如果继续推进

文风卡和大纲必须围绕以下主承诺展开：

```text
[标题/开头承诺] 国家直接经营工商业不是单纯的财政手段，而是治理能力的延伸；形态从汉到清换了七八种，但底层结构几乎没变
    → [正文必须证明的机制] 治理延伸(P1)→ 形态可换、批发权不让(P2)→ 一场激烈辩论撤不掉(P3)→ 退出比进入更难(P4)
    → [结尾留下的认知收获] 治理与财政一旦被绑在一起，退出就比进入更难——这是结构问题，不是个人选择；删除现实联想后仍能独立成立
```

### 1.2 如果暂不推进

不适用——本卡闸门结论为"进入文风卡和大纲"。

## 二、方向主承诺

### 2.1 一句话主承诺

```text
国家直接经营工商业这件事，形态从汉到清换了七八种，底层却几乎没变——国家从未真正放弃对关键商品核心环节（尤其是批发权）的控制；而治理与财政一旦被绑在一起，退出就比进入更难。
```

### 2.2 主承诺拆解

| 位置 | 可以承诺什么 | 必须避免什么 |
|---|---|---|
| 标题 | "两千年没变"的反差钩；机制判断（不是讲汉代故事）；"形态 vs 底层"的反差框架 | 标题套路 T01 循环史观（"一直没变"）、T02"两千年前的 X 辩论"、T03"X 是 Y 的源头"、T04"重读《盐铁论》"、T06"被忽视的 X"、T10"X 谢幕/终结"、T11"古代治理智慧"、T12"数字+朝代史+现代类比" |
| 开头 | 第一段出现"反常识钩"（普通税基扛不动→国家升级为经营 / 会后保留大部分专营的反差判断）；前 300 字内出现核心问题，前 500 字内出现主承诺 | 论文腔入口；超过 500 字还在铺背景；落入"国家爱管闲事"或"国家能力论"道德标签 |
| 正文 | 用汉/唐/明/清四段切片证明"形态可换、批发权不让"；用公元前 81 年盐铁会议作机制证据；用清代票盐改革作"退出成本"支点 | 通史复述（盐业史/专卖制度史）；桑弘羊/贤良文学个人评传；W01 路线斗争叙事；A02 协商民主起源；A08 票盐改革成功学/悲剧论 |
| 结尾 | 回收本篇机制（"治理与财政一旦绑在一起，退出比进入更难"）；可在结构判断层做一句抽象升华 | 突然升到文明兴衰/民族性；"历史给我们的启示是""中华民族几千年的智慧""这放到今天也一样""懂的人自然懂"等系列明令禁止的表达 |

### 2.3 主承诺成立条件

1. **四段切片(汉/唐/明/清)必须落实**——主轴 P2"形态可换、批发权不让"必须被四段切片证明，每段切片只服务于一个机制判断（汉代 → 治理延伸；唐代 → 形态可换但批发权不变；明代 → 退出成本出现；清代 → 改革反被改革反噬）
2. **公元前 81 年盐铁会议必须作机制证据使用**——副轴 P3 取"会期长(5 个多月)+人数多(60 余人)+会后结果(只撤一小部分)"三件事，不展开会议过程、不站人物好恶
3. **清代票盐改革必须作退出成本支点使用**——P4 取"取消总商+开放运销+降低运盐成本+运行中大商仍多次试图重新垄断+改革并不彻底"五件事，不评价成功/失败
4. **钱穆支点必须引原话+方法论同时出现**——按事实核查 B07，引"近似于近代之所谓国家社会主义的路线"原话 + "历史意见 vs 时代意见"方法论同时出现；不简化为"国家资本主义"或"国家社会主义"标签；不写具体页码（不同版本页码不一）
5. **稳判断不超过 40 字、可被三句话转述**——"治理与财政一旦绑在一起，退出就比进入更难"必须独立成立，删除现实联想后仍能用

### 3.1 洞察组合逻辑

入口洞察 P1 用"普通税基不够用→国家升级为经营"做反常识钩，让读者在熟悉的"汉武帝打匈奴+桑弘羊"符号上接住陌生机制；骨架命题 P2 用汉/唐/明/清四段切片证明"形态可换、批发权不让"，把"两千年没变"从循环史观改写为"治理结构选择的稳定性"——这是文章最强差异化抓手；副轴 P3 用公元前 81 年盐铁会议作机制证据（一场激烈辩论撤不掉已运转的专营），为 P4 退出成本埋伏笔；稳判断 P4 用清代票盐改革作"退出比进入更难"的纵向证据，把全文收束在"治理与财政一旦绑在一起，退出就比进入更难"这句可被三句话转述的稳判断上。四命题共同服务"国家经营工商业 → 治理延伸 → 市场受压 → 财政依赖 → 强化专营"主机制——P1 解释"为什么进入"，P2 解释"为什么形态可换但底层不变"，P3 解释"为什么政治论辩撤不掉"，P4 收束"退出比进入更难"。钱穆支点作为机制识别工具和方法论贯穿 P1—P3（不独立），与历史切片形成"钱穆识别 + 史实验证 + 作者延伸"三层配比（钱穆原话 3—4 句，不超过全文 5%）。

## 四、组合合法性检查

| 检查项 | 结论 | 说明 |
|---|---|---|
| 是否服务同一个主承诺 | **是** | 四命题(P1+P2+P3+P4)按"进入→运转→论辩→退出"逻辑链共同支撑"国家经营工商业 → 治理延伸 → 形态可换批发权不让 → 一场辩论撤不掉 → 退出比进入更难"主机制 |

## 十一、给大纲编辑的指令

### 11.1 大纲必须围绕

```text
P2 制度形态可换，批发权不让(主轴)
+ P1 财政表象下的治理延伸(机制第一层 / 引言钩子)

+ P4 治理与财政一旦被绑在一起，退出就比进入更难(收束层稳判断)
```

### 11.2 大纲必须体现的洞察分工

1. 入口洞察(P1)只负责进入（引言第一段或第二节），不得直接替代骨架命题
2. 骨架命题(P2)必须成为正文主线（中段，四段切片汉/唐/明/清全部承担）
3. 副洞察(P3/P4)只能服务主线（中段副轴 + 收束稳判断），不得开新主题
4. 新意洞察（钱穆支点+方法论）必须在 P1 段先建立、P2 段直接出现、P3 段作方法论显式呈现、P4 段回扣
5. 结尾升维(P4)必须由正文证明（P1+P2+P3）自然推出
6. 放弃项（候选 5/6/7 独立成节、W01/W03/W05 影射叙事、A02/A08 评议、个人评传）不得进入大纲

### 11.3 大纲必须避免

1. 把汉/唐/明/清四段切片写成朝代知识科普或通史复述（每段切片必须只服务于一个机制判断）
2. 把公元前 81 年盐铁会议写成会议纪要或路线斗争（只取会期+人数+会后结果三件事）
3. 把清代票盐改革写成改革成功学或改革悲剧论（只取五件事作退出成本支点，不评价成功/失败）
4. 把罗马/日本/法国比较作为正文主线（只作"现实余味"使用，不进入主线）
5. 把候选 5（专营范围可伸缩性）写成独立小节（只作"跨朝代纵深"节一段铺垫）

### 11.4 大纲失败信号

如果大纲出现以下情况，应判定失败：

1. 标题入口和正文证明方向不一致（如标题"重读《盐铁论》"，正文却写制度机制；或标题"汉武帝的财政智慧"，正文却写退出成本）
2. 入口洞察(P1)替代了骨架命题(P2)（如开篇花大量笔墨讲"国家为什么要这么做"，中段只简单提一下"形态换了七八种"）
3. 副洞察(P3/P4)抢主线（如中段主轴变成"盐铁会议纪要"或"票盐改革史"）
4. 多个洞察被并列堆放，没有共同服务主承诺（如把 P1、P2、P3、P4 并列写成四个独立小节，没有"进入→运转→论辩→退出"逻辑链）
5. 结构命题无法被已放行事实证明（如写"管仲发明专卖""罗马长期专营""2014 取消食盐专营""清盐利占财政 8.22%"等禁用事实）
6. 目标客户读不懂或不关心（如大量堆砌制度细节而无机制解释；或大量堆砌人物细节而无制度判断）
7. 只是复述材料，没有形成机制解释（如把"汉→唐→宋→明→清"纵向时间线写成制度通史，没有"形态可换、底层不变"机制判断）
8. 过度照搬外部常见写法（如落入 W01 路线斗争、W03 借古喻今、W05 当代经济学解读、A02 协商民主起源、A08 票盐改革成功学/悲剧论）
9. 违反系列基调、审稿政策或已提供的禁用表达（如"今天也是这样""懂的人自然懂""中华民族几千年的智慧""国家从来都是这样"等触发句式）
10. 超出事实核查清单放行范围（如写钱穆页码、汉代盐官具体数字、"占 GDP 一半"误用、罗马"长期专营"等）

## 十二、最终提醒

用 6 条提醒约束后续文风卡和大纲阶段：

1. **四段切片每段只服务一个机制判断**——汉代 → 治理延伸（用 E12-02 一句话补齐"汉代形态"）；唐代 → 形态可换但批发权不变；明代 → 退出成本出现；清代 → 改革反被改革反噬。不堆制度细节，不写完整朝代制度图。
2. **钱穆支点贯穿 P1—P3，不独立**——引"近似于近代之所谓国家社会主义的路线"原话 + "历史意见 vs 时代意见"方法论同时出现；不写具体页码；不简化为"国家资本主义"或"国家社会主义"标签；作者延伸不能冒充钱穆原意；钱穆原话 3—4 句，不超过全文 5%。
3. **会议过程只取三件事**——会期长(5 个多月)+人数多(60 余人)+会后结果(只撤一小部分)；不展开会议过程；不站人物好恶；把双方写成"两种治理逻辑"。
4. **结尾只回收本篇机制**——"治理与财政一旦绑在一起，退出就比进入更难"；不引申到今天；不写"可悲""讽刺""值得反思"等情绪判断词；不写"历史给我们的启示是""中华民族几千年的智慧""这放到今天也一样"等被系列明令禁止的表达。
5. **三红线不破**——借古讽今=0、现实影射=0、个人好恶=0；全文不出现"今天也是这样""这不就是国企吗""汉武帝错了""懂的人自然懂"等触发句式。
6. **平台节奏与读者门槛**——今日头条移动端优先；段落 1—3 行，最长不超过 5 行；前 300 字出现核心问题，前 500 字出现主承诺；术语首现必须普通话翻译（就场专卖/开中法/纲法/引岸/票盐）；"普通税基"（人头税/田租/关税）的具体含义必须用一句话补齐。
