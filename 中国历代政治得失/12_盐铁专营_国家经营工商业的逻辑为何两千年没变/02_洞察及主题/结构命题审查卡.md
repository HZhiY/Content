> 用途：在写洞察、定主题、写大纲之前，评估候选洞察是否具备结构深度、认知收获和证据承载能力。

## 一、本文结构命题前提

### 3.1 当前文章表面题材

"盐铁专营"在公共讨论里被反复提起，常被默认成三个粗糙解释之一：

```text
1. 国家爱管闲事，所以插手赚钱的买卖；
2. 国企效率差，所以专营至今没被取消；
3. 古代政府与民争利的政治遗产。
```

这三个解释都活在读者已有认知里；它们既不需要补课，也能被"挺国家"或"骂政府"两种情绪分别激活。在头条信息流的随机进入场景中，这三类解释是读者最容易滑向的现成答案。

### 3.2 当前文章真正要解释的问题

本篇文章要解释的，不是"盐铁专营好不好"或"该不该由国家经营"，而是一个被默认解释遮住的机制问题：

```text
为什么国家直接经营工商业这件事，从汉代到今天一直存在？
它解决的是财政问题，还是治理问题？
```

围绕这一核心问题，本篇文章必须把三件事讲透：

1. 为什么普通税基扛不动时，国家会本能地从"只收税"升级为"自己经营"；
2. 为什么从汉到清的制度形态换了七八种，国家不放弃的关键环节（尤其是批发权）几乎没变；
3. 为什么公元前 81 年那场延续数月的辩论，最后只罢了一小部分——退出为何比进入更难。

### 3.3 当前文章读者已有认知

读者大概率已经具备：

- "汉武帝时有过盐铁官营和一场著名辩论"这件事听过；
- 桑弘羊、贤良文学的名字作为符号存在，不一定有具体印象；
- "古代国家会控制盐、铁等关键物资"这一长期印象；
- "今天还存在国企和行业准入"作为现实参照。

读者大概率不具备：

- 唐代榷盐、明清盐政的具体制度安排；
- 桑弘羊与贤良文学的真实分歧所在（不是"谁对谁错"而是"两套治理逻辑"）；
- 跨朝代"形态可换、底层结构不变"这一判断框架；
- "退出比进入更难"作为结构性判断的解释力。

### 3.4 当前文章应提供的新启发

合格文章应在读者离场时，留下三层启发：

1. 一个反常识判断：国家直接经营工商业，表面是补财政，深层是补治理；
2. 一个反差框架：从汉到清，制度形态换了七八种，做的却是同一件事；
3. 一个稳判断：治理与财政一旦被绑在一起，退出就比进入更难。

这三层不是装饰，而是文章"为什么不是别人写过的角度"的核心差异化空间。

### 3.5 当前文章不能越界解释的内容

本篇文章不能进入的解释边界：

- 不解释"国家应不应该经营工商业"的价值判断；
- 不解释"国企效率高还是低"的效率评价；
- 不解释"中国政治为什么失败或成功"的文明论；
- 不写"今天也是这样""这不就是某某吗"的现实映射；
- 不写"古代政府与民争利"的道德化叙事；
- 不写"古代财政智慧对今天的启示"的应用型评论；
- 不写《盐铁论》六十篇的逐章解读；
- 不写盐业通史或专卖制度史；
- 不写汉武帝评传、桑弘羊评传、贤良文学评传；
- 不下"改革成功 / 失败"的二元结论。

## 三、目标客户匹配审查

### 3.1 预测目标客户列表

| 目标客户 | 兴趣入口 | 已有前置知识 | 需要补齐的前置知识 | 期待获得的新东西 | 匹配风险 |
|---|---|---|---|---|---|
| 40+ 体制内或国企中层管理者 | 国家为什么不能轻易退出某个行业；考核指标与真实目标之间为何会脱节 | 听过桑弘羊、盐铁会议，熟悉"国家经营"和"国企"两套语词 | 唐代榷盐、明清盐政的具体演变；桑弘羊与贤良文学的真实分歧 | 一句不超过 40 字的稳判断；一个可解释自己工作处境的机制框架 | 候选命题如果只讲汉代故事、不解释机制，匹配度低 |
| 40+ 民营中小企业主或投资者 | 国家直接经营与民间资本的关系；为什么有些行业始终由国家控制 | 知道存在"国家专营"现象，直觉上感到"政府管得宽" | 盐铁官营不是单纯财政手段；退出成本比进入成本更高 | 一套可替代"政府爱管闲事"情绪解释的结构判断 | 候选命题如果落向"政府爱管闲事"的共鸣，匹配度反升但违反系列基调 |
| 40+ 高校背景、阅读型读者 | 为什么"国家经营工商业"这件事跨两千年反复出现；制度为什么会自我强化 | 读过钱穆或其他制度史通俗读物，熟悉"皇权""相权""中央地方"等概念 | 跨朝代专营的纵向线索；市场被压弱与财政依赖之间的闭环 | 一个能解释"形态可换、底层结构不变"的反差框架 | 候选命题如果太浅、太"故事化"匹配度低；太学院化完成率低 |
| 40+ 公务员或政策研究者 | 财政、治理与市场之间的真实关系；为什么改革往往"按下葫芦浮起瓢" | 熟悉"治理能力""财政可持续"等现代话语；对"改革难"有切身感受 | 古代财政与国家经营之间的结构性逻辑；钱穆视角的启发 | 一个"退出比进入更难"的判断框架，可迁移到今天的改革讨论中而不做现实影射 | 候选命题如果被现实影射带偏，匹配度反升但违规；如果只讲汉代不延伸，匹配度低 |

### 3.2 匹配判断问题

1. 候选结构命题是否落在目标客户已经关心、正在经历或容易被唤起的问题上，而不是落在只有制度史专家才会追问的问题上？
2. 目标客户是否具备理解候选命题所需的前置知识？如果不具备，文章能否用较低成本补齐（术语首现翻译、概念白话化）？
3. 目标客户读完后是否能获得可转述、可讨论、可迁移的东西（一句稳判断 + 一个机制框架）？
4. 如果候选命题明显与四类目标客户中的多数不匹配，后续分析卡是否应该允许放弃，而不是强行证明它有价值？

### 3.3 不合格信号

- 候选命题本身有知识深度，但目标客户没有兴趣入口；
- 目标客户缺少关键前置知识，且文章需要大篇幅补课才能读懂；
- 读者已有认知与候选命题之间没有桥，既不熟悉，也不启发；
- 候选命题能解释作者关心的问题，但无法给目标客户带来新解释、新谈资或新迁移；
- 候选命题的主要传播力来自现实影射（"这就是今天""懂的人自然懂"），删除现实联想后命题无法成立。

## 四、结构命题层

### 5.1 核心问题

```text
为什么国家直接经营工商业这件事，从汉代到今天一直存在？
它解决的是财政问题，还是治理问题？
```

### 5.2 当前文章结构命题清单（必须由这些命题共同支撑一篇文章）

主轴：**制度形态可换，批发权不让**（承接方向 B，文章最强差异化抓手）

配套副轴与隐含命题：

```text
P1【机制第一层 · 因果性 · 强】
   为什么普通税基扛不动，国家必须升级为经营？
   （承接方向 A：财政表象下的治理延伸）
   位置：开头 / 引言钩子
   配套历史切片：汉武帝元狩三年（公元前 120 年）起推行盐铁官营；
                 桑弘羊"边用度不足，故兴盐铁"的自我陈述
   配套钱穆支点："这个制度，很像近代西方德国人之所首先创始的
                 所谓国家社会主义的政策"——作为机制识别工具
                 （不作为机制定义工具）

P2【机制第二层 · 描述性 + 因果性 · 强】
   从汉代盐铁到 2016 盐改，制度形态换了七八种，
   底层结构为什么不变？
   （主轴：制度形态可换，批发权不让）
   位置：中段 / 主轴
   配套历史切片：四段切片——
                 唐代宝应元年（762）刘晏改革"民制、官收、商运、商销"
                            的就场专卖制；
                 明代洪武三年（1370）开中法"召商输粮而与之盐"；
                 万历四十五年（1617）纲运法"留与众商永永百年，
                                  据为窝本"；
                 清代引岸制度 + 窝本制
   配套钱穆支点："直到清代……大体上总还遵循这一政策，
                  总还不离于近代之所谓国家社会主义的路线"

P3【机制第三层 · 因果性 · 强】
   公元前 81 年那场会议，为什么最后保留了大部分专营？
   （承接方向 C：会后保留了大部分专营）
   位置：中段 / 副轴
   配套历史切片：汉昭帝始元六年（公元前 81 年）二月下诏召开盐铁会议，
                 持续到秋七月；
                 桑弘羊（御史大夫）vs 贤良文学 60 余人；
                 会后"罢榷酤官、关内铁官，盐铁犹如故"
   配套钱穆支点："历史意见 vs 时代意见"方法论
                  ——评价古制要把"当时人怎么想"和
                    "我们现在怎么想"分开

P4【隐含的稳判断 · 评价性 · 中】
   治理与财政一旦被绑在一起，退出就比进入更难。
   位置：收束 / 结尾稳判断
   配套历史切片：清代道光年间（约 1831—1832）陶澍在淮北推行
                 票盐改革——取消总商、开放运销；
                 但运行中大商仍多次试图重新垄断，改革并不彻底
   配套钱穆支点：与 P3 同——"历史意见"方法论
```

四命题的相互关系：

```text
P1（为什么进入）  →  P2（为什么形态可换但批发权不让）
                              ↓
                P3（为什么一场辩论撤不掉）  →  P4（为什么退出更难）
```

四命题共同支撑主机制：

```text
国家经营工商业 → 治理延伸 → 市场受压 → 财政依赖 → 强化专营
```

### 5.3 当前文章审查问题

1. P1—P4 是否共同支撑"治理延伸—市场受压—财政依赖—强化专营"主机制，缺一不可？
2. P2（主轴）是否能在四段切片中清晰证明"形态可换、批发权不让"，而不是堆朝代知识或盐业通史？
3. P3 是否只把盐铁会议结果作为"机制证据"使用，不展开会议过程、不站人物好恶？
4. P4 是否能作为可带走的稳判断独立成立，删除现实联想后仍能用？
5. 四命题是否都在"治理结构选择"而非"个人选择"或"民族性"的解释框架内？

### 5.4 不合格信号

- 四命题中任意一个被替换为"国家爱管闲事""国企效率差""与民争利"等情绪化或道德化判断；
- 主轴 P2 退化为朝代通史、盐业史或制度图谱；
- P3 把会议写成"桑弘羊务实/贤良文学为民请命"的路线斗争，或写成"协商民主起源"；
- P4 滑入"改革无用论""国家从来都是这样"等情绪判断或绝对化判断；
- 四命题之间的因果链断裂（P2 不能解释 P3，P3 不能收束为 P4）；
- 命题数量过载（一篇文章同时吃下皇权、地方、财政、科举、监察多个问题）；
- 命题过浅（"讲讲盐铁""分析盐铁会议"等），无法成为结构命题。

### 5.5 合格标准

```text
1. 主轴 P2 必须能被压成一句单一可证明的机制句
   （"形态换了七八种，做的却是同一件事"或"国家不放弃对关键
   商品核心环节的控制"）；
2. P1—P3 三层必须形成完整因果链：进入 → 运转形态不变 → 退出难；
3. P4 必须能作为结尾稳判断独立成立（不超过 40 字），
   删除现实联想后仍能用；
4. 四命题必须能用 P0 事实钉子（E12-01—E12-15）支撑，
   不依赖事实核查清单标为"不通过""待补资料""不采用"的事实；
5. 四命题必须避开"国进民退""古代财政智慧对今天的启示"
   等被外部 W01—W12、A01—A12 写烂的角度。
```

## 五、认知收获层

### 6.1 当前文章应提供的收获类型

| 收获类型 | 当前文章判断方式 | 不合格信号 |
|---|---|---|
| 解释收获 | 候选命题是否能让读者获得"国家经营工商业不只是财政手段，而是治理延伸"这一新解释 | 候选命题只能解释"汉武帝时搞了盐铁"，不能解释"为什么一直存在" |
| 机制收获 | 候选命题是否能让读者获得"形态可换、批发权不让"这一可迁移的机制判断 | 候选命题只能解释"中国古代怎样怎样"，无法对应到其他场景 |
| 概念收获 | 候选命题是否能让读者带走"治理—市场—财政"闭环或"退出比进入更难"这类可转述概念 | 候选命题只在汉代语境下成立，读者带不走可复述的概念 |
| 迁移收获 | 候选命题是否能让读者把"形态可换、底层结构不变"或"退出比进入更难"对应到工作中的某种体验（公司改组、机构改革、政策调整） | 候选命题的判断只能在历史里成立，读者无法把任何工作或组织经验带入 |
| 代价收获 | 候选命题是否讲出了"专营在解决财政问题的同时，制造了市场被压弱、新增依赖等代价"——而非只讲收益或只讲代价 | 候选命题只讲国家"做得对"或只讲国家"做得错"，没有机制层的代价分析 |
| 边界收获 | 候选命题是否明确告诉读者"这一判断的适用范围是什么、不适用于什么"，避免被读者泛化使用 | 候选命题让读者把"国家直接经营"泛化为"中国人从古至今都是这样"或"今天也是这样" |

### 6.2 合格标准

```text
1. 候选命题至少同时提供"解释收获 + 机制收获 + 迁移收获"三层；
2. 必须明确讲出"制度收益与制度代价"——不是只讲成功，也不是只讲失败；
3. 必须留下可被读者用三句话转述的稳判断，不超过 40 字；
4. 必须明确判断的适用边界，避免被泛化为"从古至今"或"今天也一样"；
5. 候选命题的稳判断在删除现实联想后仍能独立成立。
```

## 六、故事证据层

### 7.1 Claim / Grounds / Warrant 要求

| 项目 | 当前文章必须回答的问题 | 不合格表现 |
|---|---|---|
| Claim | 候选结构命题要让读者相信的核心判断是什么？这个判断能否被压成一句不超过 40 字、可独立成立的机制句？ | Claim 无法压成单一句；或 Claim 是价值判断（"应该""不应"）而非机制判断 |
| Grounds | 候选命题要调用哪些 P0 事实钉子（E12-01—E12-15）来证明 Claim？这些事实是否都在事实核查清单放行范围内？ | Grounds 依赖"清盐利占财政 8.22%""管仲发明专卖""2014 取消食盐专营"等已预警不采用的事实；或 Grounds 堆史料却没有为机制服务 |
| Warrant | 为什么这些事实能证明 Claim？候选命题有没有给出从"事实"到"机制"的推理桥梁，而不是只把事实摆在一起？ | Warrant 缺失，读者看到事实后无法自己推出 Claim；或 Warrant 跳到现代事件，触发现实影射红线 |

### 7.2 当前文章机制链要求

合格候选命题应能改写为如下机制链（任一环节缺失即不合格）：

```text
起点问题（普通税基扛不动战争/赈灾/转运压力）
    ↓
旧办法解决了什么（"只收税"覆盖不了大宗刚需商品的财政需求）
    ↓
旧办法解决不了什么（看不见具体经营、压不住地方、覆盖不了边防）
    ↓
新办法如何出现（国家从"收税"升级为"经营"——
                 桑弘羊自陈"边用度不足，故兴盐铁"）
    ↓
新办法带来什么结果（财政暂时稳住，但国家嵌入了
                     经营网络——批发权、特许权、缉私网络、地方就业）
    ↓
为什么形态换了七八种（唐代就场专卖、明代开中/折色/纲法、
                       清代引岸/票盐）批发权依然没让
    ↓
为什么一场延续数月、有 60 余人正面挑战的辩论（公元前 81 年
    盐铁会议）最后只罢了一小部分
    ↓
这个结果揭示什么规律（治理与财政一旦被绑在一起，
                       退出就比进入更难）
```

### 7.3 不合格信号

- 候选命题只有 Claim（"国家很厉害"或"国家不好"），没有 Grounds；
- 候选命题只有故事（"汉武帝时怎样怎样"），没有机制抽象；
- 候选命题的 Grounds 来自未通过事实核查清单的待补资料或不采用事实；
- 候选命题的 Warrant 跳到"今天也是这样"或"这不就是某某吗"，触发现实影射红线；
- 候选命题把"桑弘羊务实 / 贤良文学为民请命"作为机制推动力，违反不站人物好恶；
- 候选命题的故事材料（汉→唐→明→清四段切片）抢戏，变成朝代通史或盐业通史。

### 7.4 合格标准

```text
1. Claim 必须可压成一句不超过 40 字、可独立成立的机制句；
2. Grounds 必须来自事实核查清单放行范围内的 P0 事实
   （E12-01—E12-15，按保守口径使用）；
3. Warrant 必须能从事实自然推到机制，不依赖现实事件触发；
4. 故事材料必须服务机制，每段历史切片只服务于一个机制判断；
5. 不能借故事戏剧化推进（如盐铁会议戏剧张力、会后悬念感），
   只能借故事作为机制证据。
```

## 七、承诺兑现层

### 8.1 标题承诺审查

| 审查项 | 判断方式 | 不合格信号 |
|---|---|---|
| 标题是否提出一个清楚的制度问题 | 候选标题是否能让读者识别出"这篇在解释一个制度运行问题"而不是"这是历史故事" | 标题像朝代故事（"汉武帝的一场豪赌"）、像人物评传（"桑弘羊的铁血一生"）、像揭秘体（"被掩盖 2000 年的真相"） |
| 标题是否承接"两千年没变"的主承诺 | 候选标题是否能让读者预判"我会看到跨朝代的纵向解释"，而不是"我会看到汉代一个朝代的故事" | 标题只承诺汉代或盐铁官营本身，不承诺"两千年"或"反复出现"的纵向解释 |
| 标题判断是否有限 | 候选标题是否在问题感、对象具体、判断有限三点上同时合格 | 标题空泛（"古代制度的智慧"）；或过度绝对（"中国两千年的真相"）；或与正文承诺不一致 |
| 标题是否避开禁用表达 | 候选标题是否避开了"真相""内幕""看透""从古至今""永远""彻底""老祖宗早就看透"等传播禁用词 | 标题使用禁用词或触发震惊体、循环史观、民族性叙事 |

### 8.2 开头承诺审查

| 审查项 | 判断方式 | 不合格信号 |
|---|---|---|
| 前三段是否进入主问题 | 候选开头是否在 300 字内让读者看到"本文在解释什么问题" | 开头从"钱穆先生在《中国历代政治得失》中说"开始；或开头先讲汉武帝生平；或铺垫超过 500 字还没进入主问题 |
| 前三段是否亮出核心判断 | 候选开头是否在第二、三段内出现"形态可换、批发权不让"或"治理与财政一旦被绑在一起，退出就比进入更难"等核心判断 | 开头只有反常识钩（"汉武帝做了一件 2000 年没被取消的事"），但没有亮出机制判断 |
| 开头是否使用推荐类型 | 候选开头是否使用悖论开头 / 反差开头 / 现实切片开头 / 历史并列开头 / 常识纠偏开头中的一种 | 开头使用"自古以来""中国古代政治制度……""本文将从三个方面分析……"等被禁用开头 |
| 开头是否避开现实影射 | 候选开头是否避开"今天也是这样""这不就是某某吗"等触发影射红线的句式 | 开头借古讽今；或开头把读者引向"对号入座"而不是"机制识别" |

### 8.3 正文证明审查

| 审查项 | 判断方式 | 不合格信号 |
|---|---|---|
| 每个小节是否承担不同功能 | 正文每节是否分别承担"反常识切入 / 历史切片 / 机制拆解 / 跨朝代纵深 / 制度代价 / 现实余味"中的一种 | 出现只堆材料、不服务机制的小节；或两节功能重复 |
| 历史切片是否服务主机制 | 四段切片（汉、唐、明、清）每段是否只服务于一个机制判断 | 切片变成朝代知识科普；或切片堆制度细节、汉代盐官数字、年份、机构名称 |
| 钱穆支点是否清晰 | 钱穆原话（"近似于近代之所谓国家社会主义的路线"）+ "历史意见 vs 时代意见"方法论是否同时出现 | 钱穆只挂名不引用；或简化为"国家资本主义""国家社会主义"标签；或引具体页码（不同版本页码不一） |
| 是否守住事实边界 | 是否按事实核查清单的保守口径处理——钱穆不写页码、汉代盐官不写具体数字、折色后开中并行、清盐利不写 8.22%、2014 不写"取消食盐专营"、"占 GDP 一半"误用不写、罗马不写"长期专营"、《管子》不归功管仲一人 | 出现违反 B01—B09 红线的事实处理 |

### 8.4 结尾兑现审查

| 审查项 | 判断方式 | 不合格信号 |
|---|---|---|
| 结尾是否回收本文机制 | 结尾是否收束在"治理与财政一旦被绑在一起，退出就比进入更难"或"形态可换，批发权不让"这一本篇机制上 | 结尾突然升到文明兴衰（"中华民族两千年的智慧"）；或用"历史启示"四个字硬总结 |
| 结尾是否留一句稳判断 | 结尾是否给读者一句不超过 40 字、可独立成立、可被转述的判断 | 结尾复述全文摘要；或用"综上所述""可见""总而言之"开头 |
| 结尾是否不写情绪词 | 结尾是否避开了"可悲""讽刺""值得反思""令人深思"等情绪判断词 | 结尾情绪拔高；或用抒情代替机制收束 |
| 结尾是否不映射现实 | 结尾是否避开了"今天也是这样""这不就是国企吗""我们身边到处都是"等影射句式 | 结尾强行映射到今天；或结尾把本文结论外包给"下一篇再讲" |

### 8.5 不合格信号

- 标题承诺"两千年没变"，正文只讲汉代一个朝代；
- 标题提出制度问题，正文变成历史经过；
- 引言抛出判断，结尾没有回收；
- 每个小节都在服务不同主题，承诺链断裂；
- 历史材料只为"显得博学"，不为机制服务；
- 结尾换了一个更大的主题（从"盐铁专营"换成"中国古代政治"或"国家治理"）；
- 结尾现实余味超过历史解释，触发现实影射红线。

### 8.6 合格标准

```text
1. 标题 → 引言 → 正文 → 结尾必须围绕同一结构承诺
   （"为什么这件事两千年没变 / 它的机制是什么 / 退出为什么更难"）；
2. 标题承诺的每一个判断，正文必须有相应小节证明；
3. 引言抛出的判断，结尾必须回收；
4. 历史材料只承担三种功能：证明、对比、纠偏；
5. 结尾收在本篇之内，不外溢到全系列总论或今天事件。
```

## 八、当前文章一票否决项

1. **命题主体跨越多个制度问题**：候选结构命题同时吃下皇权、地方、财政、科举、监察、军政等多个大问题；本篇只能打"国家经营工商业"这一颗主钉；
2. **触犯通史复述风险**：候选命题把文章变成汉武帝评传、盐业通史、专卖制度史或《盐铁论》逐章解读；
3. **触犯个人时评风险**：候选命题把桑弘羊或贤良文学写成"好人 / 坏人""务实 / 民粹""书呆 / 狠人"等人物好恶；
4. **触犯教材腔风险**：候选命题引入连续抽象概念堆叠（"制度内卷化""治理范式""结构性张力"等学术词）却不解释；
5. **触犯评论腔风险**：候选命题的稳判断或结尾出现"今天也是这样""这不就是某某吗""懂的人自然懂""中国人从古至今都是这样""历史早就给出答案"；
6. **触犯借古讽今风险**：候选命题把"国家经营工商业"泛化为对今天的影射（"国进民退""现代国企就是当年的盐铁官营"），删除现实联想后命题无法成立；
7. **命题依赖未放行事实**：候选命题的核心支点依赖事实核查清单标为"不通过""待补资料""不采用"的事实（包括"清盐利占财政 8.22%""管仲发明专卖""2014 取消食盐专营""罗马帝国长期专营盐业""盐利占唐代 GDP 一半""汉代 35 处盐官"等具体数字钩子，以及"国家社会主义"作为现代意识形态标签）；
8. **钱穆支点失真**：候选命题只挂"钱穆"名字不引原话；或简化为"国家资本主义""国家社会主义"标签；或借钱穆直接下价值判断（"钱穆早就说过……所以……"）；
9. **只有观点没有史实 / 只有材料没有机制抽象**：候选命题的所有判断都依赖现实联想才能被理解（没有事实支撑）；或候选命题只摆史料不抽象机制；
10. **命题因果链断裂**：P1（为什么进入）→ P2（形态可换但批发权不让）→ P3（为什么一场辩论撤不掉）→ P4（退出更难）四者之间出现逻辑跳跃；或主轴 P2 无法被四段切片（汉/唐/明/清）证明；
11. **承诺错位**：标题承诺"两千年没变"，正文只解释汉代一次；或标题承诺"机制判断"，正文变成历史经过。

## 九、评分方式

| 维度 | 评分问题 | 分值 |
|---|---|---|
| 目标客户匹配 | 是否匹配目标客户的兴趣入口、前置知识、现实处境和社交场景 | 1-5 |
| 命题清晰度 | 能否压成一句不超过 40 字、可独立成立、可被证伪的机制句 | 1-5 |
| 解释深度 | 是否解释了因果（为什么进入）、背景（普通税基为何扛不动）、利害（治理延伸的双面）、代价（市场被压弱、财政依赖）、边界（适用与不适用） | 1-5 |
| 认知收获 | 是否让读者获得新概念（治理延伸 / 批发权不让 / 退出比进入更难）、新框架（治理—市场—财政闭环）、新理解（形态可换底层不变） | 1-5 |
| 证据承载 | P0 事实钉子（E12-01—E12-15）是否能证明主命题；故事链是否服务机制 | 1-5 |
| 迁移价值 | 是否能解释不止一个案例（汉 / 唐 / 明 / 清四段切片），并能在删除现实联想后仍可用于解释其他场景 | 1-5 |
| 承诺兑现 | 标题 → 引言 → 正文 → 结尾是否围绕同一结构承诺；结尾是否回收机制 | 1-5 |

建议：

```text
32 分以上：可作为全文结构命题；
28-31 分：可作为主线候选，但需修补；
23-27 分：适合作为辅助命题或段落命题；
23 分以下：不建议作为文章主命题。
```

如果目标客户匹配低于 3 分，即使命题本身有知识深度，后续分析卡也必须谨慎推荐，必要时建议放弃。

## 十、结构命题分析卡输出模板

后续 `结构命题分析卡.md` 应按以下流程处理候选命题：

1. 逐条复述候选命题的核心判断句；
2. 用本文第四节结构命题层 §5.3 审查问题逐项核对候选命题是否符合；
3. 用本文第八节一票否决项 11 条逐条核对是否触发；
4. 用本文第九节评分方式七维度逐项打分（1-5），记录依据；
5. 用本文第三节目标客户列表逐条检查"匹配判断问题"4 个问题；
6. 用本文第六节 Claim / Grounds / Warrant 要求逐项检查证据承载；
7. 用本文第五节六类收获类型检查认知收获是否齐备；
8. 用本文第七节承诺兑现要求检查标题—引言—正文—结尾的承诺链是否闭合；
9. 给出该候选命题的总分、是否进入主命题候选、是否需要重写或建议放弃；
10. 不做主命题选择，只把每个候选命题的得分和合格 / 不合格判定交回给方向决策环节。

分析卡不得：

- 替方向决策环节选择主命题；
- 用"看起来更稳"这类无依据表达打合格；
- 跳过任一一票否决项的核对；
- 引入不在事实核查清单 P0 放行范围内的事实；
- 用"现实影射得分高"为由推荐不合格命题。

## 十一、最终提醒

1. 审查卡只制定评估标准，不预选、不暗示、不决定具体命题；是否合格，按本卡第四节 §5.3、第八节 11 条、第九节七维度逐项核对，不得跳过。
2. 凡是"主轴 P2 退化为朝代通史"的命题，无论总分多高，必须判为不合格——这是头条读者三段内感到"被骗"的最大风险。
3. 凡是依赖"清盐利占财政 8.22%""管仲发明专卖""2014 取消食盐专营""罗马帝国长期专营盐业""国家社会主义作为现代意识形态标签"等事实核查清单明令禁用写法的命题，即使机制讲得对，也必须判为不合格——事实边界不能被机制判断覆盖。
4. 凡是让读者必须借"今天也是这样""这不就是某某吗"才能理解机制的命题，删除现实联想后命题无法成立，必须判为不合格——这是"借古讽今=0、现实影射=0"红线的最直接体现。
5. 凡是结尾必须拔到"中华民族""中国两千年""历史启示""现实就是……"等大词的命题，会同时触犯系列基调、审稿政策、文风禁用清单——结尾只能收在本篇的机制上。
6. 凡是四命题（P1—P4）之间因果链断裂、无法形成"进入 → 运转形态不变 → 退出难"完整链条的命题，必须在分析卡中标记为"主轴候选但不闭合"——可在 direction-decide 阶段由方向决策决定是否降级为辅助命题。
