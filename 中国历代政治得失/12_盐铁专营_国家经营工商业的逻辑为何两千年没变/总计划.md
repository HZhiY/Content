## 一、目标读者画像

来源于系列配置 `中国历代政治得失/_meta/_config/读者画像配置.md`，本篇直接锁定的目标读者：

```text
四十岁以上、受过较完整教育、有稳定职业与中高收入、
对社会运行、组织秩序、权力结构、制度成本有天然兴趣的成熟男性读者。
```

本篇尤其适合以下读者：

- 听过"盐铁会议"或"桑弘羊"但不记得细节；
- 习惯用"政府管太多"或"国企效率差"解释一切，但隐约觉得解释力不够；
- 对"国家为什么反复做某件事"有兴趣，不只是想知道某朝某代发生了什么；
- 愿意读长文，但要求读起来不累、落下去有分量。

读者大概率已经知道：

- 汉武帝时有过盐铁官营与一场著名辩论；
- 桑弘羊主张专营，贤良文学反对；
- 古代中国长期由国家控制盐、铁等关键物资；
- 今天依然存在国有企业与行业准入。

读者大概率不知道：

- 盐铁官营为什么不是单纯的"为财政"；
- 唐代榷盐、明清盐政是不是在做同一件事；
- 为什么"让国家退出工商业"在历史上极难做到；
- 这种困难来自治理结构本身，而不是来自任何个人。

## 二、总目标

本篇作为「中国历代政治得失」系列第二批的开篇主菜，不追求面面俱到，而是要把"国家直接经营工商业为什么长期存在"这个机制讲透：

```text
表面是财政，深层是治理；
治理越深，市场越弱；
市场越弱，财政越依赖专营；
两边互相强化，形成闭环。
```

具体目标：

1. 交付一组主机制：**国家经营工商业 → 治理延伸 → 市场受压 → 财政依赖 → 强化专营**；
2. 让读者读完后能复述："国家直接经营工商业，不只是为了收钱，而是为了控制"；
3. 让读者明白"为什么这件事从汉到清都换形态不换结构"；
4. 让读者在结尾自然意识到：今天仍能感受到这条逻辑的余波，但不出现"这就是今天"这种影射句式。

不在本篇目标之内：

- 不写成《盐铁论》导读；
- 不写成盐业史或专卖制度通史；
- 不写成汉武帝评传、桑弘羊评传或贤良文学评传；
- 不写成国企改革评论；
- 不写成"借古讽今"的时评；
- 不做现实政策建议。

## 三、核心问题

本篇核心问题：

```text
为什么国家直接经营工商业这件事，从汉代到今天一直存在？
它解决的是财政问题，还是治理问题？
```

围绕这一核心问题，本篇需在正文中显式拆出三个子问题：

1. **历史问题**：为什么汉武帝时期会推出盐铁官营？桑弘羊与贤良文学到底在争什么？
2. **机制问题**：表面上是补财政，为什么深层其实是补治理？治理如何反过头来重塑财政？
3. **结构问题**：为什么这一逻辑在唐、明、清反复出现？退出为什么比进入更难？

## 四、暂定逻辑链

```text
[1] 反常识切入：
     国家经营工商业这件事，看起来像"管得宽"，
     实际却非常顽固——它从汉代到今天都没真正取消。

[2] 盐铁会议的真实分歧：
     桑弘羊 vs 贤良文学，表面是路线之争，
     实质是两种治理逻辑的冲突：
     一边相信"国家必须直接经营"才能稳住财政与秩序，
     一边相信"让利于民"才能让经济自己长出秩序。

[3] 为什么专营在汉武帝时能推下去：
     战争、边疆、赈灾、转运——这些是普通税基扛不动的。
     当国家发现"只收税"不够用时，
     它会本能地把手伸进利润最大、最容易征税的行业。

[4] 表面是财政，深层是治理：
     国家之所以选择直接经营，
     不只是为了多一笔钱，
     而是为了掌握信息、压住地方、维持运转。
     专营提供的不只是收入，还有控制感。

[5] 治理越深，市场越弱：
     一旦国家长期经营关键行业，
     民间资本就被挤进低利润空间，
     技术与组织迭代的土壤也就被压住。
     市场不活，国家就得更深地依赖专营。

[6] 闭环是怎么形成的：
     专营压住市场，市场变弱，财政缺口扩大，
     国家就要专营更广、更深、更细，
     直到整个经济都被卷进这条轨道。
     这条轨道一旦形成，退出成本极高。

[7] 为什么两千年没变：
     不是因为古人不懂市场，
     而是因为每一代国家在面对类似压力时，
     都会重新走到这条路上。
     这是治理结构的选择，不是个人的选择。

[8] 结尾回收：
     盐铁专营留下的不是"对错",
     而是一种机制:
     一旦治理和财政被绑在一起,
     退出就比进入更难。
```

> 说明：本逻辑链仅为方向占位；如资料不足以支撑某一环节，写"待资料研究后补全"，不要补造判断。

## 五、写作边界

本篇严格遵守以下边界：

1. **不影射现实**：不写"今天也是这样""这不就是某某吗"等句子。
2. **不替现实做政策建议**：不写"国家应该怎样""政府应该怎样"。
3. **不站人物好恶**：桑弘羊与贤良文学都不被写成"对"或"错"。
4. **不把专营绝对道德化**：既不写成"与民争利"的恶政，也不写成"国家能力"的善政。
5. **不写《盐铁论》逐句解读**：只引用支撑机制判断的关键段落。
6. **不堆朝代知识**：朝代切片必须服务于"机制"，不为"显得博学"。
7. **不拔高到文明论**：结尾不上升到"中华民族"或"中国两千年"。
8. **不下道德评价**：不写"可悲""讽刺""值得反思"等情绪判断词。
9. **不引入未核史料**：所有年份、机构、人物、数据须经证据台账登记。

## 六、证据缺口

当前为 0.1 项目初始化阶段，未进入资料研究。以下资料缺口在进入 `01-source-research` 后处理：

1. **汉代盐铁官营的第一手与权威二手材料**
   - 待补资料：《盐铁论》原文与权威校注本的关键章节；
   - 待补资料：桑弘羊与贤良文学主要观点的原文出处；
   - 待补资料：汉武帝时期盐铁官营的推行节点与机构设置（如盐官、铁官的设立）。

2. **唐代榷盐制度**
   - 待补资料：唐代榷盐（特别是刘晏改革）的关键事实与制度安排；
   - 待补资料：唐代盐政与汉代盐铁官营在机制上的同与异。

3. **明清盐政**
   - 待补资料：开中法 → 纲盐法 → 票盐法的演变；
   - 待补资料：明清盐政在国家财政中的占比与作用。

4. **跨朝代纵向材料**
   - 待补资料：除盐之外，被纳入专营的工商业（酒、茶、矿、铸币等）；
   - 待补资料：可说明"专营-依赖"逻辑反复出现的简化案例。

5. **钱穆的判断支点**
   - 待补资料：《中国历代政治得失》中与盐铁、财政、国家经营相关的原书判断。

6. **现实余味材料**
   - 待补资料：可用于类比、不影射、不对号入座的现代组织与产业案例；
   - 待补资料：现代经济史中"专营-依赖"逻辑的简化解释（仅作为余味使用，不进入正文主线）。

资料处理原则：

- 先找一手史料，再找权威二手；
- 不引用未核年份、机构、数据；
- 跨朝代材料须能服务于机制判断，不为铺陈；
- 现实余味材料只用于"让读者意识到结构相似"，不进入正文论证。

## 七、文风原则

本篇文风口径严格遵守系列配置，仅提炼要点：

1. **系列基调**：成熟、克制、清醒、耐读；读起来轻，落下去重。
2. **读者画像**：40 岁以上成熟男性读者，不站队，不表演，不影射。
3. **文章结构**：反常识切入 → 第一手历史切片 → 制度机制 → 跨朝代纵深 → 机制收束。
4. **平台节奏**：今日头条移动端优先；段落 1-3 行，最长不超过 5 行；前 300 字出现核心问题，前 500 字出现主承诺。
5. **术语解释**：盐铁官营、榷盐、纲盐、票盐等专有名词首现必须普通话翻译。
6. **结尾基调**：回收机制，不拔高，不影射；让读者带走一句稳定判断。

本篇三红线自检：

```text
借古讽今 = 0
现实影射 = 0
个人好恶 = 0
```

## 八、审稿机制

本篇按标准内容工作流推进：

1. **大纲审阅**：通过 03-outline-review 校验方向、标题-引言-正文-结尾承诺链、事实边界、文风合规性。
2. **草稿阶段**：完成 04-draft-write 草稿后，并行触发：
   - 05-free-review（零上下文自由审读）
   - 05-reader-review（按读者画像审读）
   - 05-density-edit（内容密度审读）
3. **主编阶段**：由 05-editor-review 整合上述三方意见，输出主编修改建议。
4. **修订阶段**：由 draft-revise 完成修订稿，必要时进入下一轮审读。
5. **发布检查**：06-release-check 在主编明确内容冻结后执行内容闭环检查。
6. **成稿终审**：06-format-final-check 在 HTML 构建前完成格式与卫生检查。
7. **HTML 阶段**：09-html-build 仅做排版与格式实现，不重写正文。

每轮审稿必须满足：

```text
单篇只打一颗主钉
不影射现实
不做政策建议
不站人物好恶
结尾有可带走判断
```

## 十、最终交付标准

本篇完成（HTML 终稿阶段）的判定标准：

1. **结构**：标题、引言、正文 4-6 节、结尾，承诺链闭合；
2. **机制**：读者读完后能复述"国家经营工商业 → 治理延伸 → 市场受压 → 财政依赖 → 强化专营"；
3. **历史切片**：汉代盐铁会议、唐代榷盐、明清盐政三类材料均能服务于机制判断；
4. **事实安全**：所有年份、机构、人物、数据来自资料与证据台账，不夸大、不类比过界；
5. **合规安全**：不影射现实、不替现实做政策建议、不站人物好恶；
6. **读者友好**：术语首现有解释，段落短，语气不端着；
7. **可带走判断**：明确给出"治理与财政一旦被绑在一起，退出就比进入更难"；
8. **审稿链路完整**：审稿记录、修订记录、发布检查、成稿终审完整；
9. **HTML 排版规范**：标题层级清楚，小标题像路标，样式不盖过正文机制。
