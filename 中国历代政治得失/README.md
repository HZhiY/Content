# 中国历代政治得失

> 借钱穆的眼光，解释中国古代政治制度为什么那样设计、为什么曾经有效、为什么后来失灵。

---

## 系列定位

**面向头条成熟男性读者的一组制度型历史解读文章**，以钱穆《中国历代政治得失》为原点。

它要做的不是替原著逐章翻译，也不是把原书拆成通俗版，而是借钱穆提出的问题意识，重新解释中国古代政治制度。

**核心价值**：

1. 提供制度视角（谁有权、谁负责、谁监督、谁承担成本）
2. 提供历史尺度（不简单评判先进/落后）
3. 提供现实回声（让读者意识到结构性问题今天仍然熟悉）

**目标读者**：40+ 男性，受过完整教育，中高收入，对社会运行、组织秩序、权力结构有天然兴趣。

**关键气质**：成熟、克制、清醒、耐读。**读起来轻，落下去重。**

详细定位见 [_meta/定位简报.md](./_meta/定位简报.md)（14 节），执行策略见 [_meta/执行策略.md](./_meta/执行策略.md)（15 节）。

## 写作流程

每篇文章按 **五轮打磨** 执行（见 [_meta/执行策略.md](./_meta/执行策略.md) 第三节）：

1. 收缩到真正的问题
2. 确认钱穆能否提供支点
3. 确认能否做成头条单篇
4. 确认现实连接是否自然
5. 确认能否留下稳定判断

每篇文章按 **六步结构** 写（见 [_meta/执行策略.md](./_meta/执行策略.md) 第六节）：

1. 问题开门
2. 尽早亮判断
3. 补最小背景
4. 展开制度机制
5. 讲出代价和变形
6. 收束成一句稳判断

## 钱穆使用边界

✅ 钱穆提供观察坐标，文章负责完成当代再解释
✅ 区分三层：钱穆原始判断 / 历史事实补充 / 作者延伸
❌ 不照搬原书结构
❌ 不写成"原文说了什么我来解释"的读书笔记

## 标题与禁区

**推荐标题句式**：为什么型 / 真问题型 / 反差型 / 重估型

**标题禁区**：震惊体、看完沉默、终于明白了、一针见血看透、十分钟读懂

**写法禁区**：帝王八卦化、课堂讲义化、情绪时评化、系列依赖化、观点夸张化

## 立项与验收

每篇开写前过 [立项检查表](./_meta/执行策略.md#十三立项检查表)（7 条），满足 5 条以上再动笔。

每篇写完后过 [成稿自检表](./_meta/执行策略.md#十四成稿自检表)（10 条），逐条检查。
