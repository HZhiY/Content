# 结构反审

## 一、反方压缩

这篇实际上只有一件事：安史危机把原属边防的军镇扩张并推入内地，军镇随后成为常用军事框架，于是统军、筹取供军收入和地方控制更容易捆在一起；这不是唐亡的唯一解释。

## 二、六项测试

| 测试 | 结论 | 证据 |
|---|---|---|
| 首屏耗尽 | 失败 | 「全文骨架」已依次公布边防起点、十至四十多个且内移、成为军事基本框架、征收供军、功能捆绑及“不等于唐亡”的结论；「读者路径」前段又先给十、九、四十多个与内地的反差。此后第1—4节只是把这些环节逐项背书，第5节只划论证边界，剩下没有两个不只是证明“应急组织常态化会捆绑功能”的新问题。 |
| 章节合并 | 失败 | 第1节到第4节有起点—扩张—常态化—财政连接的顺序，交换会削弱推进；但第5节把前四节再画成三列关系图，并说明“不足以解释唐亡、不能写五代总论”。并入结尾的升维边界后，读者对军镇机制的理解几乎无损。 |
| 新增信息 | 失败 | 第1节新增边防起点，第2节新增覆盖空间，第3节新增基本框架，第4节新增征收供军的功能连接。第5节新增的是三条“不能写成什么”的口径，既无新的因果步骤、选择、冲突、代价、反例，也无新的后果。 |
| 具体载体 | 通过 | 引言和第2节的“十个边防军区、九个由节度使统领，危机中增至四十多个且多数在内地”是能改变组织空间理解的具体数字；第4节的辖民重税、收入主要供军则给出军镇如何把资源转成军队维持的具体行为与成本。 |
| 读者利害 | 通过 | 读者会把“将领坐大”改判为组织位置改变：谁能从辖区汲取资源、资源为何被用于维持军队、地方控制为何随之靠近。这改变了对财政成本由谁承担及军镇何以持续的判断，并非只纠正词义。 |
| 作者防守 | 失败 | 第5节题目直接是“组织捆绑的代价，不等于把它写成唐亡总论”；其证明、信息增量、删节测试和读者反应都在防止作者过度归因。再加「给写作者的提醒」第3—5条，读者被要求理解的主要内容变成材料不能支持什么，防守已构成正文主线。 |

## 三、阻塞项

1. 从骨架到读者路径，开头已经把“边防扩张内移—常态框架—征收供军—功能捆绑”的答案及其结论给完；应退回角度，寻找后文能持续开启新问题的长文命题。
2. 第3节以“成为军事组织基本框架”直接完成了从扩张到常态化的关键跳跃，第4节再以重税供军确认结果，缺乏一个具体组织如何完成这一转变的过程；应退回角度，而非以更多概述性结论延长链条。
3. 第5节只是边界校正，删除或并入结尾并不损伤对象说明；应修改大纲，将防守撤回结尾或写作纪律，不能保留为正文长节。
4. 现有具体载体仅能说明数量、空间与供军关系，没有第二个能让读者看到军镇内部选择、地方反应或控制后果的过程性场景；应修改大纲，补入能推进机制而非重述结论的具体载体。

结论：退回角度
