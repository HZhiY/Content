## 候选 A：朝廷把边防交给军镇，为什么军镇会变成新的秩序中心

### 第一性链条

| 环节 | 推导 |
|---|---|
| 制度要解决的原始问题 | 面对边防压力，朝廷需要能在远方持续调兵、供军和处置突发情况的组织，不能每一件事都等待中央逐项发令。 |
| 掌握／缺失的信息 | 中央掌握总体资源与名义授权，却难以及时取得边地威胁、兵员和供给的细部信息；前线组织掌握这些即时信息。 |
| 各方激励 | 朝廷有动力授予足够的指挥与供给能力，以换取快速响应；军镇则有动力把可支配的兵、财和辖区资源留在自己的组织内，保证自身可调度。 |
| 执行成本与约束 | 若把指挥、征取和供给拆得过开，战时协调成本高；若把它们收进同一军镇，组织效率提高，但中央重新拆分的成本也随之上升。 |
| 纠偏机制 | 名义上的中央授命与军镇编制本可限制地方军事组织的边界；一旦军镇数量扩展、且进入内地，这种以“边防例外”为前提的纠偏便会变弱。 |
| 代价 | 应急的军事授权会从解决边防问题，转成重新分配地方资源和指挥权的常态安排；秩序所依赖的武力组织也更可能改写秩序。 |

- **读者已知**："藩镇坐大，就是安史之乱后皇帝压不住有野心的将领。"
- **本文新增**：问题不先是“谁野心大”，而是远方军事组织一旦必须同时拥有即时信息、指挥和供给能力，中央为了应急而作的授权会产生难以逆转的组织黏性。
- **需要的事实**：F1、F2、F3、F17；均为 P0/P1、核查=已核实。
- **验证节点（最多两组）**：
  1. **例外如何扩张**：唐前半期形成十个大型边防军区，其中九个由节度使统领（F1）；安史之乱中军镇增至四十多个，且多数位于内地（F2）。这检验“边防例外转为广泛组织框架”。
  2. **组织如何自我维持**：唐后期自治或可能自治军镇成为军事组织的基本框架（F3）；相关研究称其统治者向辖民重税、收入多供养军队（F17）。这检验“指挥与供给被同一组织吸收”的后果，不能推成唐亡唯一原因。
- **如果错了，错在**：若军镇的内移与增多没有使其获得更稳定的供给和组织位置，或 F3 所称“基本框架”不能承受这一解释，第一性链条中“应急授权形成组织黏性”的关键环节就不成立。
- **工作标题**：朝廷为了守边把权交给军镇，军镇后来却成了秩序中心
- **标题化难度**：容易 —— 朝廷、守边、交权、军镇四个要素具体，且“守边—秩序中心”有可兑现的反差。
- **文章发动机**：远方军事危机要求中央授权一个能自行调度兵与粮的组织；这种授权一旦从边防例外扩成内地常态，中央为什么很难再把它拆回去？
- **三个独立收获**：
  1. 知道唐前期军镇首先是边防军事组织，不能把“节度使”直接等同于地方割据。
  2. 看懂十个军区变四十多个、且多在内地，真正改变的是军镇所处的组织位置，不只是数量。
  3. 能复述：一个组织若同时掌握即时信息、指挥和供给，原本临时的授权就会变得难以收回。
- **最强现场**：战乱中军镇由十个增至四十多个，且多数由边地进入内地；读者先看到的不是一位将领，而是一套应急组织在改变覆盖范围。
- **首屏耗尽测试**：首屏只抛出“中央为什么要在危机时把兵、粮和指挥交给同一组织”，再用“十镇变四十多镇”作压力证据；不得先说“军镇终将坐大”或解释唐亡，答案留给中段的组织黏性推导。

**结构命题**：

| 六项 | 内容 |
|---|---|
| 表面问题 | 藩镇失控，是将领野心和中央软弱造成的。 |
| 真实机制 | 中央为解决远方军事的即时调度问题而把指挥与供给授予军镇；当该组织从边防例外扩成基本框架，授权本身形成难以拆回的权力与资源结构。 |
| 钱穆支点 | 制度的效果不能只看设立时的名称和本意，要看它在具体环境中承担了哪些实际功能。 |
| 历史材料 | 节度使统领的边防军区；安史之乱中军镇内移并扩张；唐后期军镇成为军事框架及其供军链条。 |
| 制度代价 | 军镇提高了应急调度能力，也让军政与资源组织化地绑定在地方。 |
| 现实余味 | 当组织为了快速响应而获得一揽子资源，真正难的不是授权，而是危机过去后谁还能把这套能力重新拆开。 |

## 候选 B：国家用账册分配赋役，为什么账册反而难以记录真实

### 第一性链条

| 环节 | 推导 |
|---|---|
| 制度要解决的原始问题 | 国家需要把人口、户别与应承担的赋役对应起来，才能把有限的征发任务分派到具体家庭，而非凭临时摊派。 |
| 掌握／缺失的信息 | 家庭最清楚丁口、田产和实际负担；中央只看得到经地方汇集的账册。账册必须向上标准化，才可作为征役依据。 |
| 各方激励 | 国家希望登记越准确，赋役分派越稳定；一旦登记直接影响负担，家庭就有动力改变自己在账册中的位置，基层经手者也面对核实与征发的双重压力。 |
| 执行成本与约束 | 逐户核实最接近真实，却耗费人力且会拖慢征役；依赖既有账册则成本较低，却把信息误差和规避激励一起固化。 |
| 纠偏机制 | 逐级上送、里正催驱、对瞒隐与改籍的惩罚，以及多层责任追溯，都是为了把账册拉回可征用状态；它们能提高规避成本，不能消除账册决定负担这一根源。 |
| 代价 | 国家得到可计算、可分派的统一表格，也把“如实登记”变成涉及利益的博弈；核验与处罚会成为制度长期运行的一部分。 |

- **读者已知**："黄册就是古代人口普查；账册不准，是有人造假或官府没有认真查。"
- **本文新增**：账册的困难不在于古人不会登记，而在于它同时承担“记录事实”和“决定谁出多少役”两件事；只要这两件事合一，信息就会带着负担激励上行。
- **需要的事实**：F9、F10、F11、F12、F13、F14；均为 P0/P1、核查=已核实。
- **验证节点（最多两组）**：
  1. **账册如何成为征役链条**：《唐六典》规定户籍由县上送州、省、户部总领（F9），里正兼负督察、催驱赋役之责（F10）；《明史》称黄册以户为主、赋役据此确定（F11）。这检验“登记不是孤立记录”。
  2. **纠偏为何持续出现**：两浙富民为避徭役寄田于他户（F12）；《大明律》惩治瞒丁、逃役、改籍（F13）；清律又规定家长、里长、县官对脱漏户口的责任（F14）。这检验“规避—核验—追责”是运行链的一部分，不能据此断言全国失真规模。
- **如果错了，错在**：若黄册并不决定赋役，或寄户、瞒隐、改籍与逃避差徭不能构成同一条激励链，那么“账册因决定负担而承压”的核心推导就不成立；现有材料同样不能证明所有地区或所有时期都如此。
- **工作标题**：国家用账册分配赋役，账册为什么难记下真实
- **标题化难度**：容易 —— 国家、账册、分配赋役都是具体动作，“难记下真实”承诺的是可验证机制而非泛泛的造假故事。
- **文章发动机**：国家需要账册才能公平、持续地分派赋役；但为什么恰恰是“账册决定负担”这件事，让它很难再只记录事实？
- **三个独立收获**：
  1. 知道黄册的关键不是“登记了多少人”，而是登记如何接到赋役分派。
  2. 看懂寄户、瞒隐、改籍和催驱、惩罚并非两段逸事，而是一条制度运行链的两端。
  3. 能复述：一张表只要同时记录事实和决定负担，填表就会变成利益调整，而不仅是信息传递。
- **最强现场**：黄册“以户为主，赋役据此确定”之后，两浙富民为避徭役把田产寄到他户名下；一张登记表立刻变成负担可以被移动的入口。
- **首屏耗尽测试**：首屏只提出“国家为什么非得靠一本账来分役”并亮出黄册—赋役的反差，不讲寄户、法律惩罚和清律责任链；读者应在首屏后继续追问“既然人人想改账，国家如何维持它”。

**结构命题**：

| 六项 | 内容 |
|---|---|
| 表面问题 | 黄册不准，是基层有人造假、官府核查不严。 |
| 真实机制 | 当账册同时是人口信息和赋役分派依据，它便把真实信息与负担激励绑在一起；规避和纠偏都是这一绑定的产物。 |
| 钱穆支点 | 制度要连同执行位置、信息来源与成本一起看，条文上的统一不等于运行中的真实。 |
| 历史材料 | 唐代户籍上行与里正职责；明代黄册定赋役、寄户及惩罚；清律的多层责任。 |
| 制度代价 | 统一账册降低了分派成本，却增加核验、惩罚和责任追溯，并使信息成为利益争夺点。 |
| 现实余味 | 任何既记录事实又配置负担的表格，都会让“填对”与“对谁有利”同时出现。 |

**评分**（账号级标题评分 + 系列四维，共 140 分）：

| 维度 | 分 | 理由 |
|---|---:|---|
| 问题清楚 | 19/20 | 对象、动作与困惑明确。 |
| 机制感 | 20/20 | 信息、激励、核验成本与纠偏闭环清楚。 |
| 反差感 | 19/20 | 为记录真实设账册，账册却因负担分派承压。 |
| 克制程度 | 15/15 | 不把规避道德化，也不夸大失真范围。 |
| 点击理由 | 15/15 | “账册难写真”有具体而克制的张力。 |
| 正文一致 | 10/10 | 两组节点足以承受标题。 |
| 母题单一性 | 10/10 | 落在人口治理，不扩成中央—地方总论。 |
| 命题反差强度 | 10/10 | 统一分派与信息失真构成直接反差。 |
| 材料可证性 | 10/10 | 设计、执行、规避与纠偏均有已核实材料。 |

| **合计** | **136/140** | 可选。 |

**代价**：必须放弃户籍制度通史，也不能用“基层总会造假”替代具体的赋役激励；若把唐、明、清按年代轮流讲，第一性链条会再次被史料骨架取代。

## 候选 C：国家把继嗣写进法律，为什么还要留下族长的位置

### 第一性链条

| 环节 | 推导 |
|---|---|
| 制度要解决的原始问题 | 无子家庭的继嗣会牵动家庭延续、亲属资格与相关权利；国家需要让这类身份转换有可预期的规则，而不能每次都从零裁量。 |
| 掌握／缺失的信息 | 国家可以规定可继嗣者的资格排序，却不掌握每个家庭的具体亲属关系、昭穆与实际情形；同宗网络掌握这些近距离信息。 |
| 各方激励 | 国家有动力预先写出资格边界，以减少争议处理的直接投入；宗族成员则关心谁被承认为合格继嗣，因而有动力参与并影响程序。 |
| 执行成本与约束 | 由官府逐案核查亲属关系，成本高且信息不对称；完全放任家族自行决定，则国家难以维持统一资格标准。 |
| 纠偏机制 | 同宗、昭穆、服制的法定排序，以及“依例议立”的要求，构成对族长裁量的规则约束；现有材料不能证明这些规则在实际争议中如何被复核。 |
| 代价 | 国家用宗族的近距离信息降低处理成本，却让宗族程序获得影响家庭资格的中介位置；这种中介是否损害其他治理功能，现有材料只能作为研究性待检验命题。 |

- **读者已知**："继承本来就是宗族私事，国家管不到基层，只能让族长说了算。"
- **本文新增**：清律不是简单退出，而是先用法律把继嗣资格排出顺序，再在特定情形让族长依例议立；国家需要的不是替代宗族，而是把宗族掌握的信息纳入可预期的程序。
- **需要的事实**：F5、F6、F7、F8、F15、F16；均为 P0/P1、核查=已核实。
- **验证节点（最多两组）**：
  1. **国家先规定什么**：清代规则要求无子者优先由同宗、昭穆相当的侄辈承继，再依服制亲疏选择（F5）；招婿养老未立继而死者，由族长依例议立（F6）。这检验“法律资格排序 + 特定程序中介”，不等于族长有独立司法权。
  2. **为何会需要中介**：研究所引清末全国约一千三百名知县（F7），并概述地方行政依靠乡村长老提供基层解题能力（F8）；同一研究把宗族中介的行政成本收益与治理副作用列为解释性判断（F15、F16）。这只验证问题背景与待检验机制，不能推出全部基层事务均由宗族办理。
- **如果错了，错在**：若 F5、F6 的规定只是在确认习俗、并未形成国家规则与族长程序的配合，或宗族的近距离信息并非降低行政处理成本的必要条件，这一链条就只是漂亮推测；尤其不能由此推出清代基层治理的一般因果。
- **工作标题**：国家把继嗣写进法律，为什么还要让族长参与议立
- **标题化难度**：一般 —— 国家和族长的动作明确，但“继嗣／议立”需在首屏译为“无子家庭由谁接续”。
- **文章发动机**：国家既已给继嗣排定资格，为什么不由官府逐案裁决，而要在特定情形使用族长掌握的亲属信息？
- **三个独立收获**：
  1. 知道清律对无子继嗣规定了同宗、昭穆与服制的排序，不是笼统地让家族“自己商量”。
  2. 看懂族长“依例议立”是一个被规则限定的程序位置，不能夸大成独立司法权。
  3. 能复述：国家能力有限时可以借中介的信息降低逐案处理成本，但中介也会取得影响规则落地的空间。
- **最强现场**：一个招婿养老而未立继的家庭死亡后，并非官府直接指定继承人，也不是族长任意决定，而是“从族长依例议立”。
- **首屏耗尽测试**：首屏只能展开这个无子家庭的具体难题，并追问“既有法律，为何还要族长”；不得马上说“国家借宗族降低成本”或抛出清末知县数量，否则中段的“规则与信息如何配合”会失去展开空间。

**结构命题**：

| 六项 | 内容 |
