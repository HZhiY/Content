# 传播评估配置

> 适用系列：中国历代政治得失  
> 用途：供传播分析、方向选择、标题、开头、结尾、发布检查等 agent 判断文章是否具备平台传播力。  
> 核心原则：传播力来自清楚的制度悖论、可转述的稳判断和克制的现实余味，而不是标题党和影射快感。

---

## 一、传播目标

本系列追求的传播不是短期刺激，而是成熟读者的稳定点击、读完、收藏和转发。

最理想的读后反应是：

```text
这篇说的不是一个古代故事，而是把一个我熟悉但说不清的制度问题讲明白了。
```

---

## 二、传播核心资产

每篇文章必须尽量形成四个可传播资产：

| 资产 | 要求 |
|---|---|
| 清楚问题 | 读者一眼知道文章解释什么 |
| 制度悖论 | 表面目标和运行结果之间有反差 |
| 可转述判断 | 读者能复述一句核心判断 |
| 现实余味 | 不影射，但让读者自然联想到组织和社会运行 |

---

## 三、最适合传播的内容类型

### 3.1 制度悖论型

适合本系列优先使用。

公式：

```text
越想解决 A，越容易制造 B。
```

例：

```text
越认真的改革，越容易在执行中变形。
越严密的监督，越说明常规机制不足。
越公平的选拔，越可能制造同质化。
```

### 3.2 常识纠偏型

公式：

```text
读者以为问题是 A，文章说明真正问题是 B。
```

例：

```text
很多人以为改革失败，是执行的人不行。
但更深的问题，是执行者所处的位置。
```

### 3.3 机制解释型

公式：

```text
谁有权，谁负责，谁掌握信息，谁承担成本。
```

适合皇权相权、中央地方、财政税制、监察制度等题。

### 3.4 重估人物型

人物只能作为入口，传播点必须落到机制。

例：

```text
重新看王安石，真正难的不是有没有改革决心，而是制度目标如何被执行指标替换。
```

## 四、标题传播标准

标题必须满足：

1. 有问题感；
2. 有反差；
3. 对象具体；
4. 判断有限；
5. 不夸张；
6. 不影射。

合格标题更像：

```text
为什么好制度最后会坏在运行里
为什么中央越想管住地方，信息越容易失真
御史真正的作用，不是纠错，而是证明系统开始失灵
```

不合格标题更像：

```text
中国古代政治的千古真相
看懂这个，你就看懂了中国
老祖宗早就看透了权力的本质
```

---

## 五、开头传播标准

开头必须尽快制造阅读理由。

优先使用：

```text
历史上最讽刺的一件事是：
越是认真的改革，最后越容易变形。
```

开头不应：

- 长篇介绍钱穆；
- 长篇介绍朝代背景；
- 把文章写成论文导言；
- 一开始就抛太多抽象概念；
- 靠现实暗示吸引读者。

开头最好在 150 字内出现一个反差，在 300 字内出现核心判断。

---

## 六、结尾传播标准

结尾是收藏和转发的关键。

合格结尾应做到：

1. 回收本文主机制；
2. 留下一句稳判断；
3. 有现实余味；
4. 不借古讽今；
5. 不鸡汤。

推荐结尾方向：

```text
知道这一点，不是让你变得更聪明，而是让你知道：这个问题，从来不是靠“找个好人”就能解决的。
```

结尾禁止：

```text
历史给我们的启示是……
所以今天我们更应该……
这就是中华文明几千年的智慧……
```

---

## 七、可转述判断标准

每篇文章应提炼一句可转述判断。

判断句应满足：

- 不超过 40 字；
- 有反差或机制；
- 不是空泛金句；
- 能独立成立；
- 和正文论证一致。

推荐句式：

```text
好制度最大的敌人，不是坏执行，而是执行者所处的结构位置。
```

```text
中央越想看见基层，基层越会学会制造上级想看的数字。
```

```text
一个制度的成功，常常也是它未来问题的起点。
```

---

## 八、现实余味标准

现实余味不是现实影射。

合格余味：

```text
大组织里，只要考核只能看指标，指标就可能替代目标。
```

不合格余味：

```text
这放到今天也一样，懂的人都懂。
```

判断标准：

```text
如果删掉现实联想，文章是否仍然成立？
```

如果不成立，说明文章过度依赖现实暗示。

---

## 九、传播风险词

避免在标题、开头和结尾使用：

```text
真相
内幕
千古
看透
一针见血
终于明白
所有人都错了
从古至今
彻底
唯一答案
```

可替换为：

```text
真正难的是
更关键的是
容易被忽略的是
重新理解
常见解释漏掉了
```

## 十、传播评分表

| 项目 | 满分 | 判断 |
|---|---:|---|
| 标题问题感 | 20 | 是否清楚提出制度问题 |
| 开头进入速度 | 15 | 前 300 字是否进入主判断 |
| 制度悖论强度 | 20 | 是否有清楚反差 |
| 机制解释清晰度 | 20 | 是否能复述机制 |
| 现实余味克制 | 10 | 是否有代入但不影射 |
| 结尾可转述性 | 15 | 是否留下稳判断 |

低于 75 分，不建议进入发布阶段。
