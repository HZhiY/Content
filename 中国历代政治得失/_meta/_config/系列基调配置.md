# 系列基调配置

> 适用系列：中国历代政治得失  
> 用途：供方向、文风、大纲、审稿、修订、发布检查、标题等 agent 读取，统一系列定位、解释边界和文章气质。  
> 核心母题：制度不是只看设计，而是看它到了运行层会被怎样改写。

---

## 一、系列定位

本系列是**制度型历史解释长文**，不是历史课、原著导读、帝王故事、权谋评论，也不是借古讽今。

它以钱穆《中国历代政治得失》为问题源头，面向今日头条成熟男性读者，重新解释中国古代政治制度为什么会那样设计、为什么曾经有效、为什么后来失灵，以及这些制度逻辑为什么今天仍值得理解。

一句话定位：

```text
借钱穆的问题意识，解释制度在真实运行中如何生效、变形和失灵。
```

文章最终交付的不是知识点，而是一种更稳的现实判断力。

---

## 二、系列总气质

| 维度 | 要求 |
|---|---|
| 总体气质 | 成熟、克制、清醒、耐读 |
| 解释方式 | 用历史切片承载制度机制，用制度机制解释现实感 |
| 叙述视角 | 看权力、责任、信息、财政、监督和执行位置如何相互塑造 |
| 情绪强度 | 有判断，但不表演；有现实感，但不影射 |
| 读者收获 | 读完能带走一句稳定判断 |

一句话原则：

```text
不写“谁好谁坏”，写“什么结构让事情一步步变成这样”。
```

---

## 三、与钱穆原著的关系

本系列是对钱穆的再解释，不是对钱穆的注释。

钱穆在本系列中承担三种作用：

1. 提供问题意识；
2. 提供制度比较视角；
3. 提醒文章不要离开历史环境裁判制度。

但文章不能写成：

```text
原书说了什么，我来解释一下。
```

而应该写成：

```text
钱穆在这个问题上给了一个重要视角，我们借这个视角重新理解一个制度困境。
```

必须区分三层内容：

| 层级 | 内容 | 使用方式 |
|---|---|---|
| 钱穆原始判断 | 原书中的问题意识、制度观察、比较框架 | 作为支点，不作为全文框架束缚 |
| 史实补充 | 年份、人物、制度名称、后续研究材料 | 用来补足和校正论证 |
| 作者延伸 | 面向今天读者的解释框架和现实余味 | 可以表达，但不能冒充钱穆原意 |

禁止：

- 把钱穆判断直接当作未经核查的史实；
- 把作者延伸写成钱穆原意；
- 为了服务钱穆原书结构而牺牲单篇可读性；
- 把文章写成读书笔记。

---

## 四、核心母题词典

每篇文章应优先落在一个核心母题上，不要一篇文章同时吃下多个大问题。

| 母题 | 实质问题 | 常见文章方向 |
|---|---|---|
| 皇权与相权 | 权力集中与行政效率之间的矛盾 | 皇帝为什么需要宰相，又为什么总想削弱宰相 |
| 中央与地方 | 统一控制与地方活力之间的矛盾 | 中央越想管到基层，运行链条越长，信息越容易失真 |
| 科举选官 | 公平入口与人才趋同之间的矛盾 | 科举解决了资格问题，也制造了系统同质化 |
| 财政税制 | 国家资源能力与地方承受能力之间的矛盾 | 财政从来不只是收钱，而是重新安排权力与责任 |
| 监察制度 | 正常机制不足与外部纠偏之间的矛盾 | 御史越活跃，越说明系统常规纠错能力不足 |
| 改革制度 | 设计目标与执行自保之间的矛盾 | 改革越认真，执行层越要先保证自己不出事 |
| 郡县制度 | 中央意志下沉与地方自主不足之间的矛盾 | 郡县解决控制问题，不等于解决治理问题 |
| 军政关系 | 秩序依赖武力与武力威胁秩序之间的矛盾 | 军事力量既保护王朝，也可能改写王朝 |
| 地方治理 | 国家能力落地与基层真实复杂性之间的矛盾 | 政令到县以下，常常要被乡绅、宗族、胥吏重写 |

## 五、写作总原则

### 5.1 以问题为单位，不以朝代为单位

朝代只是材料来源，问题才是文章单位。

合格问题：

```text
为什么越想集中权力，执行链条越容易失真？
为什么科举扩大了政治吸纳，却没有自动提升治理质量？
为什么财政问题最后总会变成政治问题？
```

不合格问题：

```text
讲讲宋代政治。
谈谈古代制度智慧。
中国古代政治为什么失败？
```

### 5.2 以制度为中心，不以人物为中心

人物可以出现，但只能作为制度入口。

王安石、张居正、司马光、皇帝、宰相、御史，都不能被写成单纯人物评传。文章要回答的是：他们所处的位置、制度、责任和激励如何限制了他们。

### 5.3 以再解释为主，不以复述为主

文章不是把钱穆讲浅，而是借钱穆把一个问题讲透。

### 5.4 一篇只打一颗主钉

每篇只交付一个核心机制。

禁止：

- 同时讲皇权、地方、财政、科举、监察多个问题；
- 为了显得宏大，把一个题写成制度总论；
- 在结尾突然拔高到全部中国政治史。

## 六、推荐表达口径

推荐长期使用：

```text
制度运行
结构位置
权力分工
责任链条
信息上行
信息失真
考核替代目标
数字替代真实
执行层自保
中央与地方
皇权与相权
治理成本
制度成本
治理半径
制度变形
运行逻辑
现实余味
结构呼应
```

推荐判断句：

```text
问题不在于某个人，而在于他所处的位置。
制度的难处，不在纸面设计，而在运行过程。
一个制度解决了一个问题，往往也会制造下一个问题。
越想把规则做严密，执行层越容易把规则变成自保工具。
中央想提高控制力，往往会同步提高运行成本。
```

---

## 七、禁止方向

禁止把系列写成：

1. 历史课；
2. 原著摘抄；
3. 帝王故事会；
4. 权谋厚黑；
5. 借古讽今；
6. 现实影射；
7. 历史鸡汤；
8. 论文式制度史；
9. 短视频式历史真相。

特别禁止：

```text
这不就是今天的某某吗？
古代如此，现在也是如此。
看懂这个，就看懂了今天的一切。
老祖宗早就看透了。
中国人从古至今都是这样。
```

---

## 八、结尾基调

结尾应收束成本篇机制，不写成全系列总论。

合格结尾应该让读者带走一句判断，例如：

```text
好制度最大的敌人，不是坏执行，而是执行者所处的结构位置。
```

结尾不应：

- 突然升到文明兴衰；
- 用“历史启示”四个字硬总结；
- 强行影射现实事件；
- 把本文结论外包给下一篇；
- 用空泛抒情代替机制收束。
