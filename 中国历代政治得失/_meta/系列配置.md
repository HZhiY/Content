## 一、系列定位

**制度型历史解释长文。** 不是历史课、原著导读、帝王故事、权谋评论，也不是借古讽今。

```text
借钱穆的问题意识，解释制度在真实运行中如何生效、变形和失灵。
```

核心母题：

```text
制度不是只看设计，而是看它到了运行层会被怎样改写。
```

交付的不是知识点，是一种更稳的现实判断力。

---

## 二、与钱穆的关系

本系列是对钱穆的**再解释**，不是注释。

钱穆承担三种作用：提供问题意识、提供制度比较视角、提醒不要离开历史环境裁判制度。

不能写成：

```text
原书说了什么，我来解释一下。
```

应写成：

```text
钱穆在这个问题上给了一个重要视角，我们借这个视角重新理解一个制度困境。
```

### 2.1 三层内容必须分清

| 层级 | 内容 | 使用方式 |
|---|---|---|
| 钱穆原始判断 | 原书的问题意识、制度观察、比较框架 | 作为支点，不作为全文框架束缚 |
| 史实补充 | 年份、人物、制度名称、后续研究材料 | 补足和校正论证 |
| 作者延伸 | 面向今天读者的解释框架和现实余味 | 可以表达，但不能冒充钱穆原意 |

**这一条是 `fact-collect` 和 `fact-audit` 的硬约束：** 事实包里每条来自钱穆的主张必须标注为"钱穆判断"而非"史实"，核查时不得以"钱穆这么说"作为唯一来源。

禁止：把钱穆判断当未经核查的史实；把作者延伸写成钱穆原意；为服务原书结构牺牲单篇可读性；写成读书笔记。

## 三、母题词典

**每篇优先落在一个母题上，不要一篇同时吃下多个大问题。**

| 母题 | 实质问题 | 常见方向 |
|---|---|---|
| 皇权与相权 | 权力集中与行政效率的矛盾 | 皇帝为什么需要宰相，又总想削弱宰相 |
| 中央与地方 | 统一控制与地方活力的矛盾 | 中央越想管到基层，链条越长，信息越易失真 |
| 科举选官 | 公平入口与人才趋同的矛盾 | 科举解决了资格问题，也制造了系统同质化 |
| 财政税制 | 国家资源能力与地方承受能力的矛盾 | 财政从来不只是收钱，而是重新安排权力与责任 |
| 监察制度 | 常规机制不足与外部纠偏的矛盾 | 御史越活跃，越说明常规纠错能力不足 |
| 改革制度 | 设计目标与执行自保的矛盾 | 改革越认真，执行层越要先保证自己不出事 |
| 郡县制度 | 中央意志下沉与地方自主不足的矛盾 | 郡县解决控制问题，不等于解决治理问题 |
| 军政关系 | 秩序依赖武力与武力威胁秩序的矛盾 | 军事力量既保护王朝，也可能改写王朝 |
| 地方治理 | 国家能力落地与基层真实复杂性的矛盾 | 政令到县以下，常被乡绅、宗族、胥吏重写 |
| 国家经营 | 财政汲取与市场活力的矛盾 | 国家下场做生意，解决的是财政问题，代价落在别处 |

> 「国家经营」为 12_盐铁专营 新增。新增母题需在此登记。

## 四、题材边界

### 4.1 以问题为单位，不以朝代为单位

朝代只是材料来源，问题才是文章单位。

合格：

```text
为什么越想集中权力，执行链条越容易失真？
为什么科举扩大了政治吸纳，却没有自动提升治理质量？
为什么财政问题最后总会变成政治问题？
```

不合格：

```text
讲讲宋代政治。
谈谈古代制度智慧。
中国古代政治为什么失败？
```

### 4.2 以制度为中心，不以人物为中心

人物可以出现，但只能作为入口。王安石、张居正、司马光、皇帝、宰相、御史，都不能写成人物评传。要回答的是：**他们所处的位置、制度、责任和激励如何限制了他们。**

### 4.3 一篇只打一颗主钉

每篇只交付一个核心机制。禁止同时讲皇权、地方、财政、科举、监察；禁止为了显得宏大把一个题写成制度总论；禁止在结尾突然拔高到全部中国政治史。

## 五、结构命题标准

**每篇必须先有结构命题，再组织材料。** 这是 `angle-propose` 输出每个候选角度时的必填格式，也是 `outline-plan` 的输入。

结构命题不是标题，也不是金句，是文章的内部发动机：

```text
读者通常以为问题是 A，但文章要证明真正起作用的是 B。
```

### 5.1 六项必填

```text
表面问题：读者通常以为这是 A。
真实机制：实际起作用的是 B。
钱穆支点：钱穆提供了什么问题意识或制度观察。
历史材料：用 1-3 个历史切片证明 B。
制度代价：B 解决了什么，同时制造了什么。
现实余味：这种结构为什么今天仍然熟悉，但不做具体影射。
```

### 5.2 合格示例

以「为什么制度坏在运行而不是设计」为例：

```text
表面问题：王安石和张居正改革失败，是因为执行者不行。
真实机制：执行者所处的结构位置，会把制度目标替换成自保目标。
钱穆支点：制度不能只看条文，要看它和人事、环境如何配合。
历史材料：青苗法、考成法。
制度代价：严密考核提升了执行压力，也放大了指标替代目标的问题。
现实余味：大组织里，指标一旦替代目标，认真执行反而会制造变形。
```

### 5.3 五种命题类型

| 类型 | 公式 | 适合母题 |
|---|---|---|
| 制度悖论型 | 制度越想解决 A，越容易制造 B | 改革、考核、监察、科举、中央集权 |
| 权责错位型 | 谁有责任谁没权，谁有权谁不承担真实成本 | 皇权相权、地方治理、财政税制 |
| 信息失真型 | 上级要结果，基层握真实信息，数字替代真实 | 考核、财政、地方治理、监察 |
| 成功反噬型 | 一个制度最初解决的问题，后来变成它自己的限制 | 科举、郡县、中央集权、监察 |
| 外部纠偏型 | 纠偏机制越活跃，越说明常规机制不足 | 御史、监察、谏官、巡按 |

### 5.4 命题质量判断

合格命题必须：能一句话说清、有反差、能被历史材料证明、能讲出收益与代价、不依赖现实影射、结尾能收束成稳判断。

不合格命题长这样（太大、太泛、太像课堂题）：

```text
讲讲宋代政治制度。
分析中国古代政治为什么失败。
王安石到底是好人还是坏人。
科举制度有什么影响。
古代监察制度对今天有什么启示。
```

### 5.5 材料只承担三种功能

证明、对比、纠偏。不承担这三种功能的材料，原则上不放。

**先确定结构命题，再选择材料。** 不要先堆材料再临时找观点。

## 六、角度评分的题材维度

`angle-propose` 给每个候选角度打分时，在账号级标题评分之外，额外加这四项（各 10 分，共 40）：

| 维度 | 判断 |
|---|---|
| 母题单一性 | 是否只落在一个母题上，没有同时吃多个 |
| 命题反差强度 | 表面问题 A 与真实机制 B 的距离够不够远 |
| 材料可证性 | 1-3 个历史切片是否真能证明 B，而不是只能佐证 |
| 与已发篇目的距离 | 对照 `_meta/已用论点.md`，主机制是否和已发 11 篇重复 |

**最后一项是硬否决项。** 与已用论点撞车的角度直接淘汰，不进入人工选择。中国政治题材已发 11 篇，是全账号重复风险最高的系列。

## 七、结尾基调

结尾收束成本篇机制，不写成系列总论。

合格结尾让读者带走一句判断：

```text
好制度最大的敌人，不是坏执行，而是执行者所处的结构位置。
```

不应：突然升到文明兴衰 / 用"历史启示"四个字硬总结 / 强行影射现实事件 / 把本文结论外包给下一篇 / 用空泛抒情代替机制收束。
