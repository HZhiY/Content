## 一、总览

本篇插图追求"少而准"，不追求多：

1. **封面图｜散户面对三块屏幕**——给文章一个工具横评气质，承接标题里的"聚宽、米筐、优矿"；
2. **正文图一｜回测 ≠ 实盘**——把"功能存在 ≠ 用得上"压成一张一眼可记的画面；
3. **正文图二｜三平台 → 三条策略路径**——把"选平台 = 选流程"可视化，为第五节判断公式做承接。

手机端原则：

- 每张图只表达一个核心意思；
- 主体要大；
- 文字要少且大；
- 走当代工作场景，避免金融广告大片感；
- 让读者不放大也能看懂。

## 2. 画面描述

主体是当代工作场景：

- 一个人（散户，背对或侧身，避免精确面部）坐在桌前；
- 桌上有三块并排的电脑显示器，屏幕里模糊显示三类不同界面（不要画成真实平台 UI）；
- 桌上有咖啡杯、笔记本、半杯水、行情小窗；
- 屏幕中间浮一行粗体中文：`聚宽、米筐、优矿`；
- 屏幕之间用细虚线连接，暗示"同名字、不同门槛"。

主体必须大：

- 三块屏幕 + 桌子占画面中下部 60%；
- 顶 20% 留给中文标题区；
- 底 20% 留给桌沿与留白。

### 必须出现的元素

**散户面对三块屏幕，但屏幕上呈现的内容不一样，工具理性气质。**

## 3. 手机端注意事项

- 屏幕内容要模糊化，不要把三个平台画得跟真实界面一样；
- 中文 `聚宽、米筐、优矿` 必须是画面最大、最清楚的字；
- 不要画排行榜 / 评分 / 红色 logo；
- 桌面不要堆元素（避免像广告静物）；
- 主体色调用冷蓝灰 + 一两处暖光（屏幕 / 咖啡）。

## 4. 风险与避坑

- 不要现代互联网广告摄影；
- 不要赛博风；
- 不要漫画；
- 不要 logo / 真实品牌色精确还原；
- 不要把中文画成英文或拼音；
- 不要画爆款"小红书桌面"风格；
- 不要堆元素（K 线、代码、咖啡、笔记本、人、屏幕、窗户、绿植全上）。

## 5. Prompt

一张适合手机阅读的工具横评类文章封面图，当代写实风格，表现一个散户（背对或侧身、面部模糊）坐在一张极简工作桌前，桌上有三块并排的电脑显示器，三块屏幕里分别显示模糊但不同的代码、回测曲线和文档界面，桌面只有一杯咖啡和一本翻开的笔记本，不要堆元素。画面顶部加入清晰大号中文「聚宽、米筐、优矿」，字体大、清楚、居中或偏上，作为整张图的主标题。冷蓝灰主调 + 一两处暖光（屏幕 / 咖啡），写实理性，无水印，无英文文字，无品牌 logo，无广告海报感，不要赛博风，不要漫画。

## 4. 风险与避坑

- 不要阴谋论黑手；
- 不要把平台画成压迫消费者；
