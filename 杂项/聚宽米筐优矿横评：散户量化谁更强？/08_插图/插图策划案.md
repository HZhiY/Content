## 一、整体视觉判断

本文是工具横评类文章，正文约 2400 字，六节结构：

1. 开头：散户面对三个名字时的卡顿；
2. 平台到底在帮散户做什么：共同点与模块化；
3. 为什么横评不能只看功能表：功能存在 ≠ 用得上；
4. 三个平台的真实差异：数据 / 回测 / 学习 / 执行四维；
5. 散户真正的选择标准：卡在哪，就先用哪个；
6. 结尾：工具不是替散户赚钱，是替散户组织流程。

整篇文章没有 1920 年代历史氛围，是当代工具与方法论叙述。

因此，插图不需要历史复古色调，应当走"现代写实 + 极简示意"路线：

- 主体：量化平台界面、策略代码、笔记本、咖啡桌、行情屏幕；
- 色调：偏冷的中性色（深蓝、灰、淡橙、暖白），避免金融广告大片感；
- 工具元素：屏幕、代码、笔记本、回测曲线、文档、流程箭头。

本文插图主要承担三种信息：

- 为手机阅读形成停顿；
- 把"功能存在 ≠ 用得上"可视化；
- 把"选平台就是选策略流程"可视化。

结论：**推荐 3 张图**。

## 四、三张图的策划

## 1. 封面图｜散户面对三块屏幕

### 推荐位置

引言和第一节之间。

### 阅读功能

- 给文章一个第一眼的"工具横评"气质；
- 让读者知道这不是历史财经，而是当代工具比较；
- 完成从"标题暗示"到"正文主题"的视觉转场。

### 内容承接

视觉母题：

**一个人（散户）坐在桌前，面前是三块并排的屏幕，分别显示聚宽、米筐、优矿的界面。桌上有咖啡、笔记本、行情小窗、正在闪烁的回测曲线。**

### 手机端要求

- 主体要大：人和三块屏幕必须一眼可见；
- 屏幕里的内容可以模糊化（避免把品牌名画得太像真平台）；
- 不要画功能对比表；
- 顶部用大字中文点题："聚宽、米筐、优矿"；
- 屏幕之间可以加一条细虚线，暗示"同名字、不同门槛"。

### 风险

- 容易画成产品广告海报；
- 屏幕界面如果太真，会显得在给某一平台打广告；
- 容易堆元素（K 线、代码、咖啡、笔记本、人、屏幕），手机上看不清。

### 判断

值得做，但要控制元素数量。

## 2. 正文图一｜回测好 ≠ 实盘跑得动

### 推荐位置

第三节后、第四节前。

也就是读者读完"功能存在 ≠ 用得上"之后。

### 阅读功能

- 作为正文分割图，缓解文字密度；
- 把"回测 / 实盘落差"这一最常见散户经历压缩成画面；
- 为第四节"四类门槛"做承接。

### 内容承接

视觉母题：

**一张被对折的纸，左半边是漂亮的回测曲线（绿、平稳、向上），右半边是实盘曲线（红、震荡、向下）。纸的两边写着"回测"和"实盘"。纸下面是一双散户的手，纸被对折，让两边并列。**

这是文章里最容易被"一眼记住"的画面。

### 手机端要求

- 构图要极简，只有一张对折的纸 + 一句话；
- 主体必须居中且大；
- 中文点题："回测 ≠ 实盘"；
- 不要画人物、不要画电脑、不要画交易所屏。

### 风险

- 如果用真屏幕截图会带 LOGO；
- 如果把曲线画得太花会像基金广告；
- 容易把"回测 vs 实盘"画成吐槽漫画。

### 判断

值得做，但要走极简风。

## 3. 正文图二｜三平台 → 三条策略路径

### 推荐位置

第四节后、第五节前。

也就是读者读完三平台四维差异之后，进入"选平台 = 选流程"判断之前。

### 阅读功能

- 解释"工具不是中性的"；
- 把"聚宽 / 米筐 / 优矿 + 四类门槛"压缩成"三条策略路径"；
- 为第五节的判断公式做承接。

### 内容承接

视觉母题：

**画面是三条并排的简化路径图。**

- 路径 A：聚宽。起点画一个笔记本（"从 0 到 1"），中间是社区策略广场，终点是一辆车的钥匙（"挂单看一看"）。
- 路径 B：米筐。起点是 VS Code / 文档，中间是 RQAlpha Plus 工程化框，终点是接入实盘的"工程闭环"。
- 路径 C：优矿。起点是一本厚书 / Notebook，中间是因子与 PIT 严谨研究，终点是研究复现（不强调实盘）。

三条路径上方横向是"数据 / 回测 / 学习 / 执行"四个轻标签，让读者看到：四类门槛在三条路径上的着力点不一样。

### 手机端要求

- 路径要简洁，最多 3 条，每条 3-4 个节点；
- 节点用统一形状（圆 / 方块），不要混用 5 种图标；
- 中心放一个轻写实元素：账本 / 笔记本 / 终端，让画面不显得像 PPT；
- 中文点题："选平台，就是选流程"。

### 风险

- 路径图容易画成 PPT 截图；
- 节点太多会糊；
- 三个平台如果画得太像品牌广告会引来比价读者。

### 判断

值得做，但要走"半写实 + 极简示意"风格。

## 六、中文使用

因为图片模型支持中文，建议每张图都配一个短中文点题。

推荐中文：

| 图片 | 推荐中文 | 理由 |
|---|---|---|
| 封面图 | `聚宽、米筐、优矿` | 直接点出主体，不放标题，避免和文章标题重复 |

| 正文图二 | `选平台，就是选流程` | 全文结构命题 |

可放备选中文（仅在生成效果不佳时切换）：

- 封面图备选："不是比功能"；
- 正文图一备选："功能 ≠ 用得上"；
- 正文图二备选："看你卡在哪"。

原则上：

- 中文短：每张图不超过 10 个字；
- 中文大：手机屏一眼可见；
- 中文少：只点题，不解释。
