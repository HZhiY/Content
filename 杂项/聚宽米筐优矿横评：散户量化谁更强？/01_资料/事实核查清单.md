## 三、必核类别

### 1. 平台定位

- [x] 聚宽偏研究/社区 + 教学体系
- [x] 米筐偏研究/工程 + 因子与组合优化
- [x] 优矿偏研究 + 数据严谨
- [x] 三者不构成绝对优劣，只构成“门槛不同”

### 2. 数据能力

- [x] 行情覆盖范围已核对
- [x] 财务数据范围已核对
- [x] 因子数据范围已核对
- [x] 写入正文时应避免“更全”这种绝对表述

### 3. 回测能力

- [x] 回测不应被误写为实盘
- [x] 滑点、成本、撮合假设需在正文弱化（不展开）
- [x] 回测结果应限于“研究阶段表现”

### 4. 社区与学习路径

- [x] 社区热度不直接代表质量
- [x] 策略分享不直接代表“可用”
- [x] 学习路径应写为“较完整”而非“最完善”

### 5. 执行与实盘

- [x] “支持实盘”应区分平台与版本
- [x] 应写为“实盘接入的难易度”
- [x] 涉及米筐的实盘应区分基础版/企业版

### 6. 散户适配性

- [x] “功能存在”不等于“散户易用”
- [x] “适合学习”不等于“适合交易”
- [x] “适合回测”不等于“适合实盘”

## 四、高风险表述清单

以下表述必须谨慎核查：

- “更适合散户” → 改写为“在某方面对散户更友好”；
- “门槛更低” → 改写为“在某个环节门槛更低”；
- “数据更全” → 改写为“研究型数据维度更丰富”；
- “社区更好” → 改写为“学习路径更完整”；
- “更接近实盘” → 改写为“实盘接入路径相对清晰”；
- “最容易上手” → 改写为“对新手较友好（第三方评测口径）”；
- “更像专业平台” → 改写为“研究属性更强”；
- “更适合长期使用” → 改写为“更匹配长期研究习惯”。

---

## 五、核查流程

1. 先把可疑事实记入本清单；
2. 再交叉比对 `证据台账.md`；
3. 若仍不确定，正文里降级表述；
4. 若关键结论无法验证，该结论不进入正文主判断。
