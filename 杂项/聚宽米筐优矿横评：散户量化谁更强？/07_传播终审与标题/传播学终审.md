# 传播学终审

> 文章：聚宽米筐优矿横评：散户量化谁更强？
> 审查对象：`06_修订与发布/修订稿 v3.md`
> 审查依据：`02_洞察及主题/传播学审查卡.md`、`03_文风与大纲/大纲.md`、第 3 轮读者与主编验收
> 审查范围：只从传播学角度判断文章能不能行、需不需要改正文、标题应承担什么筛选任务

---

## 一、总判断

**这篇文章从传播学角度可以成立，正文暂不需要再改。**

但它的传播成败高度依赖标题。

原因是：正文已经完成了一组稳定的三层结构：

1. **现实入口**：散户总卡在“回测看起来不错，实盘总跑不起来”；
2. **历史/机制承接**：聚宽、米筐、优矿三个平台真正降低的门槛不一样；
3. **结构收获**：选平台不是比谁功能多，而是选一种策略组织方式。

正文的问题不在于“讲不清”，而在于标题如果起错，会把错误读者吸进来。

- 如果标题只写“量化新手用哪个平台最好”，可能吸来大量只想看“选平台教程”的被动读者。回到四维差异与“选流程”主线后，部分读者会觉得偏慢，完读和收藏不一定好。
- 如果标题只写“聚宽、米筐、优矿横评”，主动需求型读者更精准，但信息流里点击门槛偏高，冷启动可能弱。
- 如果标题只写抽象结构，比如“选平台就是选策略组织方式”，深度有了，但普通读者很难在一秒内判断与自己有关。

所以，本篇标题的任务不是单纯提高点击率，而是完成筛选：

**用“散户 / 量化 / 平台”这些明确主体接住主动需求型读者，用“回测 / 实盘 / 卡住 / 跑不起来”这些现实经验唤起被动读者，再用一个认知缺口告诉读者：这篇不是平台教程，而是在解释散户量化的真实门槛。**

---

## 二、阅读意图分层审查

### 1. 主动需求型读者

主动需求型读者包括：

- 本来就在纠结选哪个量化平台的散户；
- 对量化平台、回测、模拟盘、JQData / RQSDK / PIT 感兴趣的人；
- 对“散户为什么总是跑不通”这类机制问题感兴趣的人。

正文对这类读者的承接是合格的。

原因：

- 文章保留了明确主体：聚宽、米筐、优矿；
- 保留了关键事实钉：JQData、RQSDK、RQAlpha Plus、PIT、基础版/企业版资源差、回测 + 实盘衔接等；
- 没有把三者简单写成“谁功能多”，而是按“数据 / 回测 / 学习 / 执行”四维差异拆开；
- 最后提炼出“选平台是选一种策略组织方式”。

主动需求型读者的主要收益是：

**他原本以为这是一篇平台横评，读完后能带走一个更高层的判断：工具选择决定的是策略流程，不只是功能多寡。**

风险：如果标题不出现“散户、量化、平台、回测”等主体，这类读者可能不知道文章在讲自己感兴趣的题材。

### 2. 被动唤起型读者

被动唤起型读者包括：

- 听过聚宽、米筐、优矿，但不知道三者差别的人；
- 回测看起来挺好，但实盘总跑不起来的人；
- 在朋友群问“学量化用哪个平台”还没拿到清晰答案的人。

正文对这类读者也基本合格。

原因：

- 开头直接从“散户真正卡住的地方”进入，门槛低；
- 第一屏没有堆平台功能表，也没有先讲抽象组织理论；
- 中段把“卡住”讲成“数据 / 回测 / 学习 / 执行”四类门槛；
- 结尾回扣“看你卡在哪，就先用替散户降那道门槛的那个”。

被动唤起型读者的主要收益是：

**他原本只是想找一个“哪个平台好”的答案，读完后知道这件事不是非此即彼，而是“工具选择决定流程”。**

风险：如果标题过度功能化、过度教程化，比如写成“聚宽 vs 米筐 vs 优矿，谁更适合你”，正文没有按这个方向给出排名，读者会产生心理落差。

### 3. 分层结论

本篇最适合的标题策略是混合型：

**主动需求型主体 + 被动唤起型现实经验 + 结构性认知缺口。**

也就是：

- 标题里最好有“散户 / 量化 / 平台”之一，告诉读者文章讲什么；
- 标题里最好有“回测 / 实盘 / 卡住 / 跑不起来”之一，告诉普通读者和自己有关；
- 标题里最好有反差或问题，告诉读者这里有他不知道的机制。

## 三、六维传播审查

### 1. 社交货币

文章有社交货币。

读者转发时展示的不是情绪，而是认知能力：

- 我不只是看“哪个平台好”这种表面问题；
- 我知道散户量化的真实门槛在数据、回测、学习和执行四类上；
- 我能用“选平台就是选策略流程”跟人聊。

最适合转发的句子是：

> 工具不是替散户赚钱，而是替散户组织流程。

具体转发对象和场景：

| 对象 | 场景 | 对话价值 |
|---|---|---|
| 学量化的朋友 | 问“学量化用哪个平台好” | “别比功能，先看你卡在哪。” |
| 卡在“回测好但实盘差”的朋友 | 群聊讨论量化收益 | “不是策略问题，是流程问题。” |
| 同事 | 午饭聊投资工具、量化学习路径 | “选平台其实是选怎么把策略跑下去。” |
| 量化研究爱好者 | 聊因子研究、严谨性 | “优矿不强在功能，强在把研究流程整理得严谨。” |
| 自己 | 复看、收藏 | “随时能复用的判断口诀。” |

结论：社交货币合格。

### 2. 诱因 / 前置上下文

本文需要的前置上下文较低。

大多数目标读者已经知道：

- 量化大致是写策略、回测、再挂单；
- 聚宽、米筐、优矿都是常见的量化平台名字；
- 平台之间有差别，但差别到底是什么说不清；
- 回测和实盘经常“长得不一样”。

读者不需要提前知道：

- JQData / RQSDK / RQAlpha Plus 等组件细节；
- 基础版 / 企业版资源差；
- PIT（时间点一致性）的金融工程含义。

正文已经补足必要背景。

结论：前置上下文合格，适合信息流分发。

### 3. 情绪

本文情绪不是强烈焦虑型，而是“恍然大悟 + 自我代入”。

可唤起的情绪包括：

- 熟悉感：原来我回测跑得动、实盘跑不动，不是我的问题；
- 反差感：平台看起来差不多，用起来却不一样；
- 清醒感：选平台不是比功能，是比流程；
- 认同感：确实解释了“卡住”到底卡在哪。

这类情绪适合认知类文章，不适合用过激标题放大。

标题不能把情绪升级成控诉，比如“散户被平台坑惨了”“量化就是割韭菜”。正文不是这个方向，放大会造成承诺风险。

结论：情绪强度中等偏稳，适合做长期粉丝沉淀，不适合用标题党打法强拉点击。

### 4. 公共性

公共性合格。

回测、模拟盘、选股、择时、仓位管理、回撤控制，是非常普遍的散户话题。聚宽、米筐、优矿这三个名字，则在量化圈和投资类信息流里频繁出现。

本文不是私人经验，也不是小众知识点，而是用三个平台解释一个大多数散户都见过的现象：

**同样叫量化平台，散户用起来的体验差别却很大。**

结论：公共性较强。

### 5. 实用价值

本文不是工具型实用文，但有认知实用价值。

读者能获得三种实用收获：

1. 重新理解“哪个平台适合我”：不是看功能列表，而是看自己卡在哪类门槛；
2. 重新理解“散户为什么跑不通”：往往不是策略问题，是流程问题；
3. 重新理解“工具是什么”：工具不是替赚钱，是替组织流程。

这种价值更适合收藏和转发，而不是直接操作。

结论：认知实用价值合格。

### 6. 故事

故事性中等。

本文不是强情节故事，但有清楚的四维推进：

数据门槛 → 回测门槛 → 学习门槛 → 执行门槛 → 选平台就是选策略组织方式。

不足是：人物冲突不强，情节戏剧性不强。

但对认知类横评文章来说，这不是硬伤。只要标题不要承诺“平台爆料”“惊人评测”，正文的故事强度是够的。

结论：故事性合格，但标题不能按强故事标题来包装。

## 四、冷启动风险判断

### 1. 点击率风险

如果标题过窄，点击率会偏低。

例如只写：

- “聚宽米筐优矿横评”；
- “散户量化平台对比”；
- “选量化平台是选流程”。

这些标题对主动读者友好，但在信息流中会显得偏冷。

### 2. 完读率风险

如果标题过泛，完读率会偏低。

例如只写：

- “散户量化到底行不行”；
- “学量化要不要选平台”；
- “量化平台套路有多深”。

这些标题可能吸引大量现实焦虑型读者，但正文主体是四维门槛与选择标准。读者如果期待“平台爆料”或“避坑指南”，会有落差。

### 3. 收藏/转发风险

收藏和转发依赖正文的结构收获，而不是标题的刺激程度。

本文最可收藏、可转发的地方是“选平台就是选策略组织方式”与“看你卡在哪，就先用替散户降那道门槛的那个”。如果标题没有暗示这个认知收获，读者可能把它当成普通横评，看完虽然觉得顺，但不一定收藏。

### 4. 粉丝沉淀风险

如果标题过度追求被动流量，会损害粉丝沉淀。

本系列不是单篇爽文流量，而是吸引对量化投资、平台工具、策略机制感兴趣的稳定读者。因此标题必须保留一定“认知类横评文章”的气质，不能完全改造成情绪标题。

### 5. 冷启动结论

最佳标题不是点击最大化，而是：

**中等偏强点击 + 较高完读 + 明确收藏理由 + 准确读者筛选。**

## 五、标题承诺风险

### 1. 高风险标题方向

#### 现实焦虑过强

如“散户被平台坑惨了”“量化就是割韭菜”。

问题：正文不是批判平台，题文承诺不符。

#### 教程腔过强

如“聚宽米筐优矿，到底选哪个”。

问题：容易把正文期待成教程，而正文给的是判断框架。

#### 抽象概念过强

如“选平台就是选策略组织方式”。

问题：主动读者可能喜欢，但信息流点击弱。

#### 主体模糊

如“它改变了散户的命运”。

问题：刻意隐瞒主体，不利于平台审核，也不利于精准读者进入。

### 2. 低风险标题方向

#### 历史/平台主体 + 现实机制

如“散户选量化平台，最该比的不是功能”。

优点：题材清楚，承诺明确，正文能兑现。

#### 现实问题 + 平台答案

如“聚宽、米筐、优矿：散户量化真正卡在哪”。

优点：低门槛，但主体明确。

#### 反差命题 + 平台主体

如“回测都跑得动，凭什么实盘就掉链子”。

优点：有反差，有认知缺口，也不夸张。

## 六、最终结论

### 1. 文章能不能行

**能行。**

从传播学角度看，正文已经具备信息流认知类文章的基本条件：

- 入口有现实经验；
- 主体有平台识别度；
- 机制有认知增量；
- 结尾有可转述判断；
- 读者有明确转发对象和场景。

### 2. 需不需要改正文

**正文暂不需要再改。**

第 3 轮修订后，正文已经完成承诺兑现。继续改正文，收益不大，反而可能破坏现有的稳定结构。

### 3. 真正需要解决的问题

真正需要解决的是标题。

标题必须承担四个任务：

1. 告诉主动读者：这篇讲散户量化平台比较；
2. 告诉被动读者：这篇与你熟悉的回测、实盘、卡住、跑不起来有关；
3. 制造认知缺口：功能差不多，为什么用起来差这么多；
4. 保证承诺兑现：正文不是平台排名，而是平台差异与选择框架。

### 4. 标题方向建议

最优标题方向应当是：

**散户/量化/平台这样的明确主体 + 回测/实盘/卡住这样的现实经验 + 选流程的结构暗示。**

也就是说，本篇标题最好不是纯工具标题，也不是纯情绪标题，而是混合命题标题。
