# 日本金融系列

> 日本金融帝国：它如何悄悄影响整个东亚

---

## 系列定位

**通过日本金融和资本运作的故事，揭示东亚产业链上不为人知的力量格局。**

核心角度进化：

```
起点：日本是一个被低估的国家
  ↓
第一版：日本是"隐形玩家"（已写烂）
  ↓
第二版：日本有"第三种崛起模式"（还不够狠）
  ↓
第三版：日本是"经济寄生虫"（最终版本）
```

**核心判断**：

> 表面上是美国控制流量，底层却是日本控制管道。
> 前者决定涨跌，后者决定生死。

**目标读者**：头条上对国际资本、产业控制、东亚格局感兴趣的成熟读者。

## 选题方法论

**三步筛选法**：

1. 这个角度被写烂了吗？→ "日本失去 30 年" ❌
2. 有反直觉发现吗？→ "日本海外资产增长" ⚠️ 改进
3. 能写出"阴险感"吗？→ "日本经济寄生模式" ✅

**核心判断标准**：

- 有没有颠覆认知？
- 有没有"细思极恐"的感觉？
- 读者会不会想转发？

## 标题方法论

**爆款公式**：反常识 + 具体 + 悬念

**变体**：

- 头条：更短、更爆
- 公众号：更长、更深
- 小红书：更情绪、更短

## 结构方法论

**爆款文章标准结构**：

```
开篇（10%）：反常识开场 + 核心数据炸弹 + 预告全文逻辑
正文（80%）：现象 → 数据 → 案例 → 原因 → 证据 → 结论
结尾（10%）：金句炸弹 + 下篇预告 + 行动召唤
```

**每段必须有**：

- 每个数据后 → 必须有一句"翻译结论"
- 每个案例后 → 必须有一句"情绪强化"
- 每个对比后 → 必须有一个"赢家宣言"
- 每 3 段后 → 必须有一个"普通人钩子"

## 金句方法论

**公式**：对比 + 极端化 + 押韵/对仗

**金句类型**：

- 对比型："A 决定 X，B 决定 Y"
- 极端型："最 X 的不是 A，是 B"
- 押韵型：四个短句

**已验证金句**：

1. "美国控制流量，日本控制管道。"
2. "前者决定涨跌，后者决定生死。"
3. "日本不是衰落，而是在转移。"
4. "最阴险的控制，是让你上瘾而不是服从。"
5. "你以为你在发展经济，其实你只是在给日本交租。"
