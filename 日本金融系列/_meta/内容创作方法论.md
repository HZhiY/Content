## 一、选题方法论

### 1.1 如何找到"爆款角度"

**三步筛选法：**

| 步骤 | 问题 | 淘汰 | 保留 |
|------|------|------|------|
| 第一步 | 这个角度被写烂了吗？ | "日本失去30年" | ❌ |
| 第二步 | 有反直觉发现吗？ | "日本海外资产增长" | ⚠️ 改进 |
| 第三步 | 能写出"阴险感"吗？ | "日本经济寄生模式" | ✅ |

**核心判断标准：**
- 有没有颠覆认知？
- 有没有"细思极恐"的感觉？
- 读者会不会想转发？

### 1.2 角度进化路径

```
起点：发现一个被低估的国家
  ↓
第一版：日本是"隐形玩家"（已写烂）
  ↓
第二版：日本有"第三种崛起模式"（还不够狠）
  ↓
第三版：日本是"经济寄生虫"（最终版本）
```

**进化逻辑：**
- 第一层：说别人没说的
- 第二层：说别人没想到的
- 第三层：说别人不敢说的

## 二、标题方法论

### 2.1 爆款标题公式

**公式：反常识 + 具体 + 悬念**

| 要素 | 示例 | 效果 |
|------|------|------|
| 反常识 | "你以为美国在控制亚洲？" | 颠覆认知 |
| 具体 | "其实日本才是最隐形玩家" | 明确对象 |
| 悬念 | ？"到底是谁" | 引发好奇 |

### 2.2 副标题配合

**副标题 = 解释 + 强化**

> 表面上是美国，底层却是日本。

### 2.3 标题变体

针对不同平台：

| 平台 | 标题风格 | 示例 |
|------|----------|------|
| 头条 | 更短、更爆 | "日本才是亚洲真正的主人？" |
| 公众号 | 更长、更深 | "你以为美国在控制亚洲？其实日本才是最隐形玩家" |
| 小红书 | 更情绪、更短 | "日本瞒了全世界30年" |

## 三、结构方法论

### 3.1 爆款文章标准结构

```
开篇（10%）
├── 反常识开场
├── 核心数据炸弹
└── 预告全文逻辑

正文（80%）
├── 第一部分：现象
├── 第二部分：数据支撑
├── 第三部分：案例解析
├── 第四部分：原因分析
├── 第五部分：证据链
└── 第六部分：结论

结尾（10%）
├── 金句炸弹
├── 下篇预告
└── 行动召唤
```

### 3.2 每部分的标准节奏

| 部分 | 字数占比 | 必须有 |
|------|----------|--------|
| 开篇 | 10% | 反常识 + 数据 |
| 数据段 | 15% | 表格 + 结论句 |
| 案例段 | 25% | 对比 + 细节 |
| 分析段 | 20% | 逻辑 + 洞察 |
| 结尾 | 10% | 金句 + 悬念 |

### 3.3 "每段必须有"的清单

- [ ] 每个数据后 → 必须有一句"翻译结论"
- [ ] 每个案例后 → 必须有一句"情绪强化"
- [ ] 每个对比后 → 必须有一个"赢家宣言"
- [ ] 每3段后 → 必须有一个"普通人钩子"

## 四、金句方法论

### 4.1 金句制造公式

**公式：对比 + 极端化 + 押韵/对仗**

| 金句类型 | 公式 | 示例 |
|----------|------|------|
| 对比型 | "A决定X，B决定Y" | "美国决定涨跌，日本决定生死" |
| 极端型 | "最X的不是A，是B" | "最阴险的控制不是让你服从，而是让你上瘾" |
| 押韵型 | 四个短句 | "前者来势汹汹，后者无处不在" |

### 4.2 金句放置位置

| 位置 | 金句类型 | 字数 |
|------|----------|------|
| 开篇 | 反常识型 | 20字内 |
| 中段 | 强化型 | 15字内 |
| 结尾 | 传播型 | 30字内 |

### 4.3 爆款金句库

**日本系列已验证金句：**

1. "美国控制流量，日本控制管道。"
2. "前者决定涨跌，后者决定生死。"
3. "日本不是衰落，而是在转移。"
4. "最阴险的控制，是让你上瘾而不是服从。"
5. "你以为你在发展经济，其实你只是在给日本交租。"

## 五、数据方法论

### 5.1 数据选择标准

| 标准 | 问自己 | 通过条件 |
|------|--------|----------|
| 震撼性 | 这个数字让人震惊吗？ | 是 → 保留 |
| 可验证性 | 能查到来源吗？ | 是 → 保留 |
| 对比性 | 能形成对比吗？ | 是 → 保留 |
| 情感性 | 让人愤怒/惊讶吗？ | 是 → 保留 |

### 5.2 数据呈现方式

**表格 > 文字 > 纯数字**

```
❌ 差："日本海外净资产为533万亿日元"
✅ 好：
| 指标 | 日本 | 对比 |
|------|------|------|
| 海外净资产 | 533万亿日元 | 全球第二 |
| 持有美债 | 1.225万亿美元 | 全球第一 |
```

### 5.3 数据后的"锤句"

**每个数据后必须跟一句话：**

```
数据：日本海外净资产533万亿日元
翻译锤：这意味着，日本本土在"变穷"，但日本在全球在"变富"。
```

## 六、情绪方法论

### 6.1 爆款情绪曲线

```
开篇：好奇（10%）
  ↓
第一段：认同（20%）"对对对，我也这么觉得"
  ↓
第二段：惊讶（40%）"什么？我不知道这个"
  ↓
第三段：愤怒/兴奋（60%）"太阴险了！"
  ↓
第四段：思考（80%）"原来如此"
  ↓
结尾：传播欲（100%）"我一定要转发"
```

### 6.2 三种情绪钩子

| 类型 | 触发情绪 | 示例 |
|------|----------|------|
| 普通人钩子 | 代入感 | "你买一辆国产电动车，钱就流向日本了" |
| 颠覆钩子 | 愤怒 | "你以为你在崛起，其实你在交租" |
| 优越钩子 | 转发 | "看完这个，你就知道谁才是真正的玩家" |

### 6.3 "普通人代价"段落写法

**公式：具体场景 + 数字 + 情感冲击**

```
你买一辆10万元的国产电动车：
- 电池材料：可能有一部分流向日本
- 变速箱：如果混动，可能是日本爱信
- 精密轴承：日本NSK

你以为你在支持国货，
实际上你每一次购买，都在给日本交租。
```

## 七、系列方法论

### 7.1 系列结构设计

**三层结构：**

| 层次 | 篇目 | 目的 | 节奏 |
|------|------|------|------|
| 引流层 | 第1-3篇 | 建立认知、吸引关注 | 连续发 |
| 深化层 | 第4-10篇 | 体系拆解、建立壁垒 | 每天1篇 |
| 转化层 | 第11-15篇 | 案例冲击、行动召唤 | 隔天发 |

### 7.2 篇与篇的衔接

**每篇结尾必须包含：**

```
1. 本篇核心结论（1句话）
2. 下篇预告（1句话）
3. 关注引导（1句话）
```

**示例：**
> 本文核心：日本的渗透不是投资，是产业控制。
> 下篇预告：日本的钱是怎么一步步绑住东南亚的？
> 关注引导：关注我，看清被忽视的资本力量。

### 7.3 角度进化路径

```
篇1：发现现象
"日本是隐形玩家"
  ↓
篇2：证明判断
"日本不是衰落，是转移"
  ↓
篇3：展现手段
"日本是这样渗透的"
  ↓
篇4-6：体系拆解
"日本的控制系统是这样的"
  ↓
篇7-10：东亚布局
"日本在每个国家都布了局"
  ↓
篇11-13：真实案例
"看这个具体案例"
  ↓
篇14-15：未来判断
"未来会怎样"
```

## 八、敏感词处理方法论

### 8.1 敏感词检测清单

| 类型 | 替换方案 |
|------|----------|
| "卡脖子" | "关键环节仍掌握在..." |
| "依赖" | "存在供应链关联" |
| "控制" | "深度绑定" |
| "殖民" | "长期合作关系" |

### 8.2 安全表达公式

```
❌ 直接："中国被日本卡脖子"
✅ 安全："下游在中国，上游核心技术仍掌握在日本企业手中"

❌ 直接："日本吸血亚洲"
✅ 安全："日本通过长期绑定，从亚洲持续获取收益"
```

### 8.3 保持力度的技巧

- 用"绑定"代替"控制"
- 用"依赖"代替"被控制"
- 用"让对手上瘾"代替"剥削"

## 九、图片配合方法论

### 9.1 配图节奏

| 位置 | 配图类型 | 尺寸 | 作用 |
|------|----------|------|------|
| 开篇前 | 封面图 | 1200x675 | 提高点击率 |
| 数据后 | 对比图 | 1080x1080 | 增强记忆 |
| 案例后 | 流程图/地图 | 1200x800 | 可视化信息 |
| 结尾前 | 金句图 | 1080x1080 | 促转发 |

### 9.2 图片文案公式

**封面图文案：**
```
主标题（颠覆认知）：日本才是亚洲真正的主人？
副标题（具体化）：美国控制流量，日本控制管道
金句（促转发）：前者决定涨跌，后者决定生死
```

**数据对比图文案：**
```
标题：中日韩东南亚FDI对比（2024）
数据：柱状图
结论：谁在加码，谁在撤退？
```

### 9.3 图注写法

```
❌ 差："日本在东南亚的投资"
✅ 好："每一条铁路、每一个港口，都是一条通往东京的管道"
```
