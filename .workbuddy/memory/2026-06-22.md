### 关键技术踩坑
1. **Windows GBK 编码 emoji 报错**：所有 Python 脚本（含 init_expert.py）必须 `PYTHONIOENCODING=utf-8` + `sys.stdout = io.TextIOWrapper(..., errors="replace")`
2. **ImageGen 并发调用 output_dir 失效**：并发多个 DeferExecuteTool 时 output_dir 被竞争覆盖。**必须串行**调用，每个等返回后再发下一个
3. **agent md frontmatter**：必须去掉 subagent 的 `model: inherit`，改用 `maxTurns: 50`；不能加 `tools:` 字段
4. **init_expert 失败但 mkdir 已执行**：emoji 报错会让 init_expert 半失败（目录建了但 plugin.json 没建）。需要先 `rm -rf my-experts/plugins/*` 清空再 init
5. **displayDescription.zh 字符数**：要求 40-50 字；超出只是 warn 不是 error，可接受
