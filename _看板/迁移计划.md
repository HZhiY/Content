# 迁移计划

> 把现有仓库结构对齐到 [_看板/目录约定.md](./目录约定.md) 的执行计划
> 由于 shell 在当前环境下不可靠，**本计划需要用户手动执行**
> 配套脚本见 [_看板/迁移脚本.ps1](./迁移脚本.ps1)

---

## 一、为什么要做

当前仓库的目录结构和命名存在 7 个问题（详见 [_看板/系列状态汇总.md](./系列状态汇总.md) 第 5 节），主要影响：

1. **新文章归档时容易放错位置**（articles/ 角色不明确）
2. **跨系列查找时路径不一致**（_meta 命名不一致）
3. **发布版和工作版混淆**（.md 和 .html 混在同文件夹）
4. **废弃稿干扰新选题**（articles/ 里夹着废弃稿）

本计划只调整"住址"，不重写任何内容。所有文章原文不动。

## 三、迁移分四步

### 步骤 1：低风险（推荐先做）

**改 1 处根目录 + 1 处子目录名**：

```powershell
# 把 "美国金融资本与产业资本系列" 改名为 "美国金融资本与产业资本"
Rename-Item -LiteralPath "美国金融资本与产业资本系列" -NewName "美国金融资本与产业资本"

# 把 "_meta_美国金融资本与产业资本" 改名为 "_meta"
cd "美国金融资本与产业资本"
Rename-Item -LiteralPath "_meta_美国金融资本与产业资本" -NewName "_meta"
cd ..
```

**风险**：低，纯改名，文件内容不动。

**验证**：

```bash
# 在 PowerShell 中
Get-ChildItem -Name
# 应该看到 美国金融资本与产业资本 而不是 美国金融资本与产业资本系列
```

### 步骤 2：建立系列根目录骨架

为每个系列建立 `选题池/` 和 `废弃/` 目录，从 `articles/` 合并 `候选题目.md`：

```powershell
# 三个系列都做
foreach ($series in @("中国历代政治得失", "日本金融系列", "美国金融资本与产业资本")) {
    $path = $series
    New-Item -ItemType Directory -Path "$path/选题池" -Force
    New-Item -ItemType Directory -Path "$path/废弃" -Force
}
```

## 七、回滚方案

迁移前：

```bash
# 提交当前状态作为一个 milestone
git add -A
git commit -m "snapshot: 迁移前状态"
```

如果迁移出问题：

```bash
# 完全回滚
git reset --hard HEAD
```

如果只是部分回滚：

```bash
# 撤销特定文件
git checkout HEAD -- <path>
```
