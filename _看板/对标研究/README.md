## 三、脚本与可复跑性

- `run_<account>_parse.ps1`：读取 `原始输入/<account>_input.txt`，生成 `脚本/benchmark_<account>_output.md`。
- `run_<account>_finalize.ps1`：把 `benchmark_*.md` 与 `<account>_header.md` / `<account>_footer.md` 拼装为 `数据/对标数据_2026-06-09_<账号>.md`。
- `gen_*.ps1` / `transform_*.ps1` / `wrap_benchmark.ps1` / `parse_diyuan.py`：早期清洗与转码工具，保留以备复查。

`原始输入/` 是从头条主页复制的原始文本（已带阅读量、评论数、日期），是脚本的唯一数据源。

## 三点五、2026-08 复核结论

`数据/` 下的 2702 条原始标题**有效且有用**，但三份 `标题起法方法论 v1/v2/v3` 的加工层不可用（分桶实为分账号、结构判据实为数标点符号），已在 v3 顶部标注缺陷。

**正确用法**：只看单个账号**内部**的高低对照。同账号 = 同读者 = 同分发环境，落差只能来自标题本身；跨账号比较全部作废。

最有参考价值的两个账号：

- **文化纵横**（340 篇，中位 388，10 篇 ≥10 万）——严肃制度分析，内部落差跨 5 个数量级，是最好的对照组
- **思想史万有引力**（114 篇，中位 1908）——不标题党的学院文风，和自有账号定位最接近

抽出的五条已写进 `_配置/头条号/文风与格式.md` 第 6.2 节，逐条附了证据行。验证机制见 `_工作流/_反馈/标题预测.md`。
