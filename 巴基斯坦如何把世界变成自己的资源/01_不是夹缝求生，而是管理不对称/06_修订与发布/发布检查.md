## 六、标题阶段边界

### 6.1 标题可以承诺

1. 巴基斯坦同时经营中国（耐心）、美国（阀门）、海湾（避险）三组不对称依赖——这是文章的核心发现
2. 巴基斯坦能靠这套结构性位置换生存，但难换到国内改革和产业升级——有 §六 五证（IMF 四轮安排/IMF 净口径/沙特展期/SBP 储备/FATF）支撑
3. "兑换术"是一种被结构性需求反复挤压出来的活法，不是可以模仿的范式——有孟加拉/斯里兰卡/尼泊尔三国对比 + 巴方"核武国家+印巴博弈+伊斯兰世界+中国能源通道"四重稀缺位置支撑

### 6.2 标题不能承诺

1. 巴基斯坦必然崩溃 / 必然崛起 / 即将成为超级大国 / 即将彻底失败——超出正文证明范围，违反系列"既不崩溃也不崛起"基调
2. 巴基斯坦是军政府 / SIFC=军方接管经济 / 恐怖主义国家 / 失败国家——违反 B20/B21/B08；正文使用"民选文官政府+军方外交否决权"+"军民联合投资治理平台"中性表述
3. 中国是巴基斯坦最大债主 / 沙特存款=无偿援助 / 海湾被中国挤压——违反 B10/B18/B17；正文使用"中国是双边最大债权方之一"+"展期不是新钱"+"海湾避险+宗派+能源复合驱动"
4. 巴方在 2025 印巴冲突中获胜 / 印度在 2025 印巴冲突中获胜 / 巴方击落印方四架战机——违反 B01/B02；正文使用三口径并列
5. 中国控制了巴基斯坦 / 美国放弃了巴基斯坦 / 海湾操控了巴基斯坦——阴谋论表述；正文使用"结构性需求"机制框架
