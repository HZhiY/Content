## 二、方向主承诺

### 2.1 一句话主承诺

```text
巴基斯坦不是"在大国之间选边"，而是同时经营中国、美国、海湾三组不对称依赖；这种多线兑换能换生存、难换转型——关键不在它有多聪明，而在于结构性需求不断被再生产出来。
```

### 2.3 主承诺成立条件

1. **4 候选必须并引为单篇主机制**——候选 1 提供"三组不对称依赖 + 三组结构性约束相互绑定"主承诺；候选 2 提供"军方定边界 / 文官做交易 / IMF 当信用阀门"分工联盟机制；候选 3 提供"IMF 净口径 + 海湾展期 + FATF 灰白名单"收尾机制；任一缺失触发"承诺无法兑现"一票否决。
2. **7 个"快不了了"反常识时刻必须被机制解释覆盖**——不是事件堆叠，而是要说明每个时刻都对应同一机制的显形。
3. **三组不对称依赖必须各占一节**——按"中国 → 海湾 → 美国"顺序，每节用 M02 数据时点对位承载机制证据。
4. **5 证换生存难换转型 + 4 证分工联盟必须全部出现**——E01-P0-05 + E01-P1-01 + E01-P0-13 + E01-P0-20 + E01-P1-11 五条缺一打回；SIFC + CPEC Authority + Rubio 通话 + IMF 历轮安排四条缺一打回。
5. **P0 限定语全部守住**——CPEC 双口径并列（D01）、IMF 净口径 16.5 亿（财政部口径，D03）、2025-05 斡旋方三口径并列（D05）、2026-04 用"承诺 + 尚未签 MoU"（B16）、Rubio 通话用"5 月 9-10 日"模糊时间（B15）、CSF 2018 用"约 7 亿/3.5 亿/3 亿"近似口径（B16）、卡塔尔 2016 LNG 不并入存款（B11）、2025-2026 节点标刷新时点。
6. **三红线自检全部通过**——英文字符 = 0（首现缩写括号标注与必要术语框除外）、把多因素写成唯一原因 = 0、阴谋论与扁平标签 = 0。
