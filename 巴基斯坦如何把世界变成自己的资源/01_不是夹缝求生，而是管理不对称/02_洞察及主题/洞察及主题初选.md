## 三、外部内容约束

### 3.1 必须避开的常见写法

1. **W01 夹缝求生 / 战略支轴叙事**——把巴方定位为"地缘支轴 / 枢纽 / 缓冲 / 连接器"，浪漫化"结构位置"为"天赋"；外部用烂，本文仅作引言"普通认知"对照，不作主机制。
2. **W02 矿产外交 / 关键矿产叙事**——把 2025-2026 巴方与美方 Reko Diq 协议描述为"对冲中国 / 摆脱依赖"，常把"协议金额"与"实际投资"混为一谈；偏离"三组不对称依赖"主机制，违反"换生存难换转型"主承诺。
3. **W09 中美博弈 × 巴方 / W10 CPEC 巴方生命线叙事**——把巴方在中美博弈中描述为"两面下注 / 走钢丝 / 渔利"或把 CPEC 写成"已改变巴方命运"；违反 B22"不是机会主义"、B09"CPEC 双口径并列"、B10"中国是双边最大债权方之一"。

### 3.2 可以借鉴但必须改造的传播机制

1. **M01 反常识时刻 → 机制解释入口**（EPW 2023 / Dawn Prism 2023）——本文引言可借鉴"快不行了→再次获得支持"反常识时刻做入口；正文必须从"反常识时刻"过渡到"三组约束绑定"机制，不停留在反差修辞。
2. **M02 数据时点对位承载机制**（DAWN 2023-07 / Anadolu 2026-04 / Tribune 2022-08）——可在"海湾现金—IMF 解锁"主线中用 2022-08、2023-07、2026-04 三个时点对位承载机制证据；不堆叠更多流水账。
3. **M06 军方 / 文官 / IMF 分工三主体归位**（News18 / Brookings 沙特协议评 / DAWN 2023-08《Institutionalising army's role in business》）——本文"分工联盟"机制可借鉴"三主体归位"——军方定边界、文官做交易、IMF 当信用阀门；但须按 B20/B21 不写"军政府""接管"。
4. **M08 可复述谈资：每一组依赖具体给什么**（EPW 2023 摘要"three major countries"）——主承诺可借鉴此结构——"中国给战略背书 + 海湾给现金流 + 美国给援助与合法性"；按本文 P0 事实"三组不对称依赖"具体落实，不空喊。
5. **M09 结构性需求被再生产作为收尾**（Phenomenal World 2023 Jafri / EPW 2023 "razor's edge" / ORF 2023 "episodic attention"）——结尾可借鉴"结构性需求不断被再生产"作为反共识收尾；不进入"巴方崛起 / 巴方崩溃"二选一。

### 候选 2：分工联盟——巴基斯坦不是"统一谈判方"，是"军方定边界、文官做交易、IMF 当信用阀门"的三主体

| 项目 | 内容 |
|---|---|

## 六、初步推荐

### 推荐进入后续分析的候选

```text
候选 1（主）+ 候选 2（机制支撑）+ 候选 3（收尾机制）= 合并为单篇主机制
```

推荐理由：

1. **候选 1 覆盖核心问题"为什么总能在'快不行了'时刻获得支持"**——它的三组不对称依赖（中国战略背书 / 海湾现金流 / 美国援助与合法性）+ 三组结构性约束绑定（对印安全 / 对阿边境 / 经济脆弱性）+ 多线兑换 + 换生存难换转型，是本系列"外部资源结构"层的主机制，且能通过外部约束 1 + 7 + 8 的"一句话复述 + 可复述谈资 + 三红线自检"三道检验。
2. **候选 2 补足"谁掌握兑换资格"子问题**——它的"分工联盟（军方定边界 / 文官做交易 / IMF 当信用阀门）"用 SIFC（2023-06-20）+ CPEC Authority（2019-10）+ 2025-05 Rubio 5 月 9-10 日与 Asim Munir 直接通话 + IMF 1958-2023 23 笔安排四条证据并引，落实外部约束 2；如不补这一子问题，正文会出现"国家统一谈判方"的误读，违反"三组不对称依赖"的机制基础。
3. **候选 3 补足"为什么能换生存、难换转型"子问题**——它的 IMF 净口径（E01-P1-01 财政部口径 16.5 亿）+ 沙特存款展期不是新钱（E01-P0-13）+ 巴方部分执行 + 反复延期（E01-P0-05）+ SBP 储备 2023-01 9 年低点 → 2023-07 海湾 + IMF 注入后 117 亿（E01-P0-20）五条证据并引，让"换生存"和"难换转型"同时显形；如不补这一子问题，主承诺会塌成"巴方换资源 = 巴方生存"，违反 M09"结构性需求被再生产"反共识收尾。
