## 一、评估依据摘要

### 2.1 当前文章结构前提

- **表面题材**：2025 印巴危机、2026 阿巴边境、IMF 谈判等节点事件本身。
- **真正命题**：对印安全竞争 + 对阿边境压力 + 经济脆弱性三条结构性约束相互绑定，使巴基斯坦同时具备三组"不可替代的卖品"，从而向中国（战略背书 / 基础设施）、美国（援助 / 合法性）、海湾（现金 / 能源赊账）持续多线兑换——能换生存、难换转型。
- **必须同时承担的三子问题**：
  1. 谁掌握"兑换"资格——军方、文官、IMF 各掌握什么谈判资格；
  2. 三组不对称依赖分别提供什么——为何彼此不可替代；
  3. 为什么能换生存、难换转型。
- **合格标准**（审查卡 5.4 复述）：一句话可压 + 同时含"能换"与"难换" + 把"兑换"还原为结构性需求再生产 + 把"分工联盟"拆为军方、文官、IMF 三方资格 + 把"三组不对称依赖"拆为中、美、海湾 + 把"三组约束"拆为对印 / 对阿 / 经济相互绑定 + 明确本文属"外部资源结构"层 + 不依赖扁平标签 / 阴谋论 / 情绪化褒贬。

#### 6. 机制链

```text
起点问题（巴基斯坦为什么总能在危机时获得支持）
→ 旧办法解决了什么（中巴铁杆叙事能解释中巴关系、印巴世仇能解释对印安全、海湾资金能解释现金来源、IMF 援助能解释短期过桥）
→ 旧办法解决不了什么（无法解释海湾资金时点对位 2023-07 IMF SBA 与 2022-08 IMF 重启、无法解释军方外交否决权与文官谈判资格的分工、无法解释 IMF 净口径下 2019 EFF 实际净流入仅 16.5 亿美元、无法解释海湾存款展期不是新钱却反复续作）
→ 新办法如何出现（三组不对称依赖：中 / 美 / 海湾各自提供不可替代资源；三组结构性约束：对印安全 + 对阿边境 + 经济脆弱性相互绑定）
→ 新办法带来什么结果（综合议价包 + 多线兑换，巴方同时向三组供给方持续兑换支持，但回流到国内的常被军方、文官、宗教网络分流，未充分转化为产业升级与税制改革）
→ 这个结果揭示什么规律（巴基斯坦的"兑换术"能换生存、难换转型，关键不在它有多聪明，而在于结构性需求不断被再生产出来）
```
