## 一、本文传播前提

### 1.1 平台与阅读场景

本篇主要分发与阅读场景：

1. 今日头条信息流（首屏标题 + 开头 300-500 字定生死）；
2. 微信公众号长文（手机端竖屏阅读，收藏/转发为主要传播动作）；
3. 手机端竖屏阅读（窄屏 + 跳读 + 多任务并存）；
4. 非专业但对南亚、一带一路、IMF/中美博弈有先验兴趣的泛国际读者。

平台阅读特点对本文传播的硬约束：

- 标题与首段必须承接——标题提出对象与解释承诺，开头 300 字内出现核心问题、500 字内出现本文主承诺。
- 段落默认 1-4 行、最长不超过 6 行；每 600-1000 字设置一个具有"路标功能"的小标题。
- 机构与制度缩写（IMF、CPEC、SAARC、SIFC、FATF、TTP、NCA 等）首次出现给中文全称 + 英文缩写 + 简短说明；同一篇文章内口径前后一致。
- 任何"反常识时刻"必须用具体年份/事件/数字/场景承载，禁止用"震惊""炸裂""彻底"等情绪词制造入口。

### 1.2 目标读者进入方式

本系列默认服务"混合型读者"——兴趣存在但需要标题与开头帮忙进入。本文进入方式可包括（但不必全用）：

1. 反常识问题入口：巴基斯坦总能在"快不行了"的时刻再次获得支持；
2. 危机场景入口：1998 核试验、2008 IMF 危机、2018-2019 外汇危机、2022-2023 洪灾、2025 印巴四天冲突等"快不行了"时刻；
3. 制度资格入口：谁真正拍板巴基斯坦的对外红线（军方、文官、IMF、海湾）；
4. 经济直觉入口：现金、贷款、存款、能源、IMF 通道；
5. 现实回声入口：中巴关系、海湾能源、IMF 改革、印巴核威慑。

### 1.3 本文传播承诺

按本文暂定核心判断与系列基调，正文应当向读者兑现以下传播承诺（任一兑现不到位即视为承诺断裂）：

1. 一句可复述的机制判断：巴基斯坦不是"在大国之间选边"，而是同时经营中国、美国、海湾国家三组不对称依赖；
2. 一组结构性解释：为什么"多线经营"在表面像机会主义、长期却稳定（来自对印安全竞争 + 对阿边境压力 + 经济脆弱性三者捆绑）；
3. 一组可对照的资源分工：中国给的是战略背书与基础设施平台，美国给的是援助与合法性，海湾给的是现金、存款、能源；
4. 一组反向判断：这种"兑换术"能换生存、难换结构转型；
5. 一层明确的"三层棋局"定位：本文主要服务"外部资源结构"层，并显式点出该层如何被"区域安全结构""国内权力结构"反向约束。

### 1.4 本文不能承诺的内容

下列内容不得通过标题、开头或正文做传播承诺（出现即视为承诺越界）：

1. 不承诺"揭秘内幕""独家爆料""真相大白"——本文不做揭密；
2. 不承诺"巴铁牢不可破""印巴世仇"等情绪化关系判断——本文不做情感叙事；
3. 不承诺"巴基斯坦必然崩溃"或"巴基斯坦必然崛起"等单一终局判断；
4. 不承诺一份完整的南亚通史或政策百科——本文只打一颗主钉；
5. 不承诺对印 / 对美 / 对华 / 对海湾任一方的道德评判——本文只做结构解释；
6. 不承诺未在事实核查清单中标"通过"或"按口径通过"的具体数字、年份、口径；
7. 不承诺 2025 印巴危机、2026 阿巴边境等高度流动局势的"定局"判断；
8. 不承诺给读者"攻略""操作建议"——本文不是理财/旅行/政策操作指南。

### 3.2 匹配判断问题

1. 这个候选洞察是否落在目标客户（C1/C2/C3/C4）已经关心、正在经历或容易被唤起的问题上？
2. 目标客户是否具备理解这个洞察所需的前置知识？如果不具备，文章能否用 1-2 句生活类比/机构类比/制度类比低成本补齐？
3. 目标客户读完后，是否能获得"一句判断 + 一个框架 + 一个可转述的机制故事"中的至少两项？
4. 如果目标客户其实并不适合这个洞察（例如该洞察更适合"军事爱好者"或"印度读者"或"中东研究者"），后续分析卡是否应该允许直接放弃该候选，而不是强行寻找优势？

### 3.3 不合格信号

- 只有作者觉得重要，目标客户（C1-C4）没有明显兴趣入口；
- 目标客户缺少关键前置知识（如 IMF 通道、海湾存款机制、CPEC 双口径），且文章很难在 1-2 句内补齐；
- 洞察本身有传播点，但不属于 C1-C4 中任一预测读者群的关心范围（例如纯军事 / 纯宗教 / 纯巴方国内政治 / 纯印度视角）；
- 只能靠"巴铁""印巴世仇""恐怖主义国家""失败国家"等扁平标签制造入口，正文无法让目标客户持续读完或产生转述；
- 候选洞察的"主要读者"是 C4（次要读者群），但作者把它包装成"全篇都为 C4 服务"，导致 C1/C2/C3 大量掉线。

## 四、维度一：社交货币

### 4.1 核心问题

读者读完本文后，能用什么"认知形象"在朋友/同事/家庭群/同事群/饭桌/茶歇中转述本文？他会转给谁、在什么场景下转？

### 4.2 当前文章审查问题

1. 候选洞察是否能让读者获得一个"压缩到一句话"的机制判断（参考系列基调要求的"兑换术""三组不对称依赖""综合议价包""换生存难换转型"等表达口径）？
2. 候选洞察是否帮读者把"巴基斯坦到底是怎么回事"这件事，从"模糊感受"升级为"可以讲清楚的机制故事"？
3. 候选洞察是否让读者在转述时不需要站在任何"反西方""反印度"等情绪化立场上，就能完成对国际机制的解释？

### 4.3 转给谁及场景要求

| 要素 | 当前文章必须回答的问题 | 不合格表现 |
|---|---|---|
| 具体关系 | 转给谁？同事（财经/政策/能源行业）？朋友（对南亚/IMF 感兴趣）？家人（关心一带一路/海外利益）？饭桌/茶歇闲聊对象？自媒体/知乎/微博二次创作者？ | 没有明确转述对象；或只能转给"专业人士"（传播半径过窄） |
| 当下场景 | 在什么场景下转？饭桌/办公室/通勤地铁/家庭群/行业群/朋友圈？ | 没有具体场景；或只在"看完很激动"的情绪场景下才能转 |
| 对方已有上下文 | 对方是否已知道"中巴关系""印巴对立""IMF 援助"？本文是否能在对方已有上下文上做"机制升级"而不是从零科普？ | 候选洞察需要对方从 1947 分治开始听才能懂；或候选洞察只对"已经知道 IMF/海湾机制"的高阶读者有效 |
| 转发后的对话价值 | 转完之后对方能接什么话？本文是否给对方准备了"可以延续讨论"的入口（例如"那中国到底拿到了什么""海湾为什么愿意展期"）？ | 转发即结束——对方只能回"哦"或"挺有意思"；或引发对方强烈反弹但没有机制抓手继续讨论 |

### 4.4 合格标准

1. 候选洞察能压缩成一句不超过 30 字、可独立成立的判断（例如"巴基斯坦不是选边，是同时管理三组不对称依赖"）；
2. 候选洞察能让 C1/C2/C3 至少三类读者在 24 小时之内产生"想转给某个人"的冲动；
3. 候选洞察的转述动作不依赖"反西方""反印度"等情绪立场即可完成；
4. 候选洞察让读者转述时能同时获得一个"可复述的机制故事"，而不是一个"看完就忘的情绪段子"。

### 5.3 合格标准

1. 候选洞察在"知识 / 经历 / 情绪 / 问题 / 社交 / 承诺匹配"六个前置上下文维度中，至少 4 项合格；
2. 候选洞察的入口必须能挂上"快不行了"的反常识时刻（1998 / 2008 / 2018-2019 / 2022-2023 / 2025 / 2026），不能只挂在抽象概念上；

## 六、维度三：情绪

### 6.1 当前文章适合的情绪

1. 恍然大悟：原来"快不行了"不是偶然，是结构性产物；
2. 原来如此：巴基斯坦不是被中国养着，而是同时经营三组不对称依赖；
3. 反常识惊讶：海湾存款续作不是新援助，沙特 30 亿展期不是新钱；
4. 对结构性机制的冷静警觉：能识别"兑换术"换生存易、换转型难的现实约束；
5. 适度的张力（tension）：能让读者意识到"地缘租金型国家"的活法既理性又脆弱。

### 6.2 当前文章不适合的情绪

1. 愤怒煽动：借"反西方""反印度"立场制造对立；
2. 阴谋恐惧：暗示"某大国暗中操盘""某组织代理某国"；
3. 民粹控诉：把复杂制度变化简化为道德审判；
4. 幸灾乐祸：暗示"巴基斯坦快不行了""印度稳赢""美国阴谋得逞"；
5. 过度悲观或过度乐观："巴基斯坦必然崩溃""巴基斯坦必然崛起"；
6. 鸡汤化金句：把结构性机制浓缩为抒情金句堆叠；
7. 扁平标签情绪："巴铁牢不可破""印巴世仇不共戴天""伊斯兰世界困境"等。

### 6.3 审查问题

1. 候选洞察是否避免了"愤怒煽动 / 阴谋恐惧 / 民粹控诉 / 幸灾乐祸 / 过度悲观 / 过度乐观"中的任一项？
2. 候选洞察是否让情绪只服务理解、不替代机制？情绪是否能在 1-2 句内收束？
3. 候选洞察是否避免了"巴铁""恐怖主义国家""失败国家""代理人国家""帝国棋局"等扁平标签？
4. 候选洞察的"恍然大悟"是否建立在具体年份/事件/数字/机构之上，而不是建立在概念类比上？

### 6.4 合格标准

1. 候选洞察的预期情绪落点必须在"6.1 适合情绪"列表内，且至少匹配 2 项；
2. 候选洞察的预期情绪不踩"6.2 不适合情绪"列表中的任一项；
3. 候选洞察的情绪密度与正文 4-7 节节奏匹配——不允许"情绪词堆叠"或"全程冷静到无一句具体情绪"；
4. 候选洞察的"张力"必须由结构性需求驱动，不允许由情绪化立场驱动。

## 七、维度四：公共性

### 8.1 核心问题

候选洞察是否落在足够多读者"共同经历过、看见过、讨论过"的生活经验上？是否能从"个人观察"上升到"共同理解"？

### 8.2 当前文章可用的公共经验

1. 个人现金流与债务体验：贷款、存款、展期、抵押、现金流枯竭、紧急救援——读者大概率经历过房贷、信用卡、工资延发等类似情境；
2. 工作场景中的"老板-员工"关系：谁掌握资源、谁掌握否决权、谁有现金流阀门——读者大概率经历过组织内部资源分配；
3. 大国与小国关系：超市里的"店长-店员"、产业链上的"上游-下游"、婚姻里的"双方家庭"——读者大概率用生活类比理解过类似结构；
4. 国际新闻的"危机感反复":2008 全球金融危机、2020 新冠、2022 俄乌、2023 洪灾——读者对"快不行了又撑过去了"的情节有先验共鸣；
5. "中巴关系"在中国主流语境中的"巴铁"印象与"到底怎么回事"的模糊好奇——读者大概率听过这个词但不知道具体机制。

### 8.3 不合格信号

- 候选洞察只能挂在"巴基斯坦军方内部权力斗争""巴基斯坦俾路支省地方政治"等极少数读者熟悉的小众语境上；
- 候选洞察只能挂在专业术语（NCA、SIFC、APS、FATF 等）上，没有生活类比入口；
- 候选洞察需要读者熟悉"南亚地缘史 1947-2026 全过程"才能理解——该经验在 C1-C4 中不具备公共性；
- 候选洞察只对"已经知道 IMF 通道机制"的高阶读者有效，无法在更广读者群中唤起共同理解；
- 候选洞察只在中国大陆中文语境成立，跨国/跨文化语境下完全失效。

### 8.4 合格标准

1. 候选洞察至少能挂上 2-3 个"个人 / 工作 / 生活"层面读者大概率经历过的类比；
2. 候选洞察的公共经验不依赖"南亚史 / 区域研究 / 巴基斯坦军方内部史料"等小众知识；
3. 候选洞察的"共同理解"必须由结构性需求驱动，不允许由"同情巴基斯坦"或"厌恶印度"等情绪立场驱动；
4. 候选洞察的公共性必须可验证——读者能通过"我家房贷""我们公司现金流"等具体场景反推"巴方现金流"机制。

## 八、维度五：实用价值

### 9.1 核心问题

读者读完本文后，能否获得一句判断、一个解释框架、一个可转述的机制故事，或一个可迁移的认知工具？是否能用本文框架理解"巴基斯坦之外的"类似国家或类似机制？

### 9.2 当前文章可提供的认知实用

1. 一句判断：巴基斯坦不是"在大国之间选边"，而是同时经营三组不对称依赖；
2. 一个解释框架：三组不对称依赖（中国 = 战略背书 + 基础设施；美国 = 援助 + 合法性；海湾 = 现金 + 存款 + 能源）+ 三条结构性约束的相互绑定 + 综合议价包 + 多线兑换 + 换生存难换转型；
3. 一个可转述的机制故事：可挂上 2008 IMF 危机、2018 沙特救援包、2023 海湾与 IMF 同步入账、2025 印巴四天冲突、2026 海湾 50 亿承诺中至少一个具体危机场景；
4. 一个可迁移的认知工具：可解释其他"地缘租金型国家"或"小国外交"的活法（如朝鲜、伊朗、阿根廷、孟加拉等类似处境的国家）；
5. 一个看现实的角度：能用本文机制理解中巴关系、海湾能源博弈、IMF 改革、印巴核威慑等任一现实议题。

### 9.3 不合格信号

- 候选洞察只让读者获得"原来如此"的情绪，没有提供可复述的机制；
- 候选洞察只能解释巴基斯坦一个国家，无法迁移到任何其他类似处境的国家；
- 候选洞察的解释框架是"中巴铁杆""印巴世仇"等扁平标签——读者无法用这个框架做新的判断；
- 候选洞察的"实用价值"只停留在"知道了一个八卦"层面，无法转化为判断、解释或谈资；
- 候选洞察的可迁移性需要读者读完后再去查大量背景资料才能成立。

### 9.4 合格标准

1. 候选洞察必须让读者至少获得"一句判断 + 一个解释框架 + 一个机制故事"三项中的一项以上；
2. 候选洞察的解释框架必须可在 4-7 节正文内被具体年份/事件/数字/机构承载；
3. 候选洞察的可迁移性必须在 2-3 句内可演示——读者看完能用框架解释另一案例；
4. 候选洞察的实用价值必须落到"判断 / 解释 / 谈资"层面，不允许只到"感慨"或"震惊"层面。

## 九、维度六：故事

### 10.1 核心问题

候选洞察是否能用具体故事材料（事件、机构、人物、危机场景）承载和证明？故事是否能"进入机制"而不是"盖过机制"？

### 10.2 当前文章故事链要求

1. 候选洞察必须能挂上至少一个"快不行了"的反常识时刻作为入口：1998 核试验后国际孤立、2008 IMF 紧急过桥、2018-2019 外汇危机、2022-2023 洪灾与 IMF 谈判、2025 印巴四天冲突、2026 海湾 50 亿承诺；
2. 候选洞察必须能挂上至少一组"分工联盟"的角色证据：军方（陆军参谋长 + SIFC + CPEC Authority）、文官（总理 + 财政部 + 外交部）、IMF 通道、海湾央行（SBP 存款入口）等具体机构；
3. 候选洞察必须能挂上至少一组"资源流向"的具体数字：CPEC 620 亿框架 vs 247 亿已落地、IMF SBA/EFF 关键节点（76 亿、66.4 亿、60 亿、30 亿等按口径通过数字）、海湾存款 30 亿展期 3 次 + 2026 50 亿承诺 + UAE 35 亿偿还（按口径通过数字）；
4. 候选洞察必须用"故事进入机制"而不是"故事盖过机制"——故事占比不超过 30% 的正文篇幅，机制解释必须占主导。

### 10.3 不合格信号

- 候选洞察只挂一个故事（例如只讲 2025 印巴四天冲突），无法承载"三组不对称依赖 + 三条结构性约束"的多线机制；
- 候选洞察的故事材料只能靠"巴方表述""印方表述""第三方研究"中单一来源支撑，没有交叉验证；
- 候选洞察把"快不行了"的故事渲染到超过正文 1/3 篇幅，机制尚未出场；
- 候选洞察用"巴方击落印方四架战机"等"刺激但未独立核实"的细节做故事钩子（违反事实核查清单 B02）；
- 候选洞察用"巴铁牢不可破""印巴世仇"等情绪化叙事做故事钩子，机制尚未出场；
- 候选洞察的故事无法挂上"海湾存款展期 3 次""IMF SBA/EFF 时间线"等任一可验证的现金流证据。

### 10.4 合格标准

1. 候选洞察的故事链必须包含至少 2 个"快不行了"反常识时刻的交叉支撑；
2. 候选洞察的故事材料必须有具体机构、具体年份、具体数字作为骨架，不允许只靠概念或情绪；
3. 候选洞察的故事占比不超过正文 30%；机制解释占比不低于 50%；
4. 候选洞察的故事材料全部来自事实核查清单标"通过"或"按口径通过"的事实；
5. 候选洞察的故事在结尾必须能"回收"到"三组不对称依赖 + 综合议价包 + 换生存难换转型"的主承诺上。

## 十、当前文章一票否决项

下列任一情况，候选洞察直接打回，不进入大纲与正文：

1. 照搬外部内容：候选洞察是"巴方在中美之间选边""巴铁牢不可破""巴基斯坦是某国代理人""帝国棋局暗中操盘"等外部常见写法的复读，无新机制增量；
2. 违背三红线：候选洞察以"英文字符连续夹用""把多因素写成唯一原因""阴谋论与扁平标签"中任一形式呈现；
3. 事实未放行：候选洞察的核心支点来自事实核查清单标"不通过""待补资料""不采用"或未明确标注"通过 / 按口径通过"的事实；
4. 目标客户明显不匹配：候选洞察主要服务于"军事爱好者""印度读者""中东研究者""军事评论员"等 C1-C4 之外的读者群；
5. 标题承诺无法兑现：候选洞察的标题承诺（一旦后续进入标题阶段拟出）大于 4-7 节正文能承载的机制；
6. 把"巴铁 / 恐怖主义国家 / 失败国家 / 代理人国家 / 帝国棋局"等扁平标签当机制使用：候选洞察以这些标签替代结构性解释；
7. 把多因素写成唯一原因：候选洞察把"巴基斯坦总能在危机时获得支持"归因为"中国是最大支持者"或"美国通过 IMF 控制"或"海湾现金救援"等单一因素；
8. 阴谋论化：候选洞察暗示"中情局设计了一切""巴基斯坦军方早就计划好""海湾国家操控巴方经济""印度一直在算计"等无证据指控；
9. 越界使用未核实数字：候选洞察使用"巴方击落印方四架战机""2026-04 海湾 50 亿已到账""2026-04 50 亿已签 MoU"等事实核查清单明确禁止的具体细节（违反 B02 / B16）；
10. 把复杂制度变化压成单一坏人或单一原因：候选洞察把 IMF 改革失败、CPEC 推进缓慢、海湾存款展期等复杂过程简化为"美国恶意拖延""中国控制巴方""海湾买下巴方"等单因解释；
11. 升维失控：候选洞察在结尾突然升到"文明冲突""伊斯兰世界困境""历史终局"等正文没有铺垫的宏大结论；
12. 与三层棋局无关：候选洞察无法回答"它属于三层棋局（国内权力结构 / 区域安全结构 / 外部资源结构）中的哪一层"；
13. 与系列母题脱节：候选洞察与"巴基斯坦如何把结构性条件持续兑换成外部资源"系列母题无关；
14. 平台风险词：候选洞察以"震惊""炸裂""内幕""真相大白""所有人""刚刚""终于"等禁用词作为标题或开头钩子。
