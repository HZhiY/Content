## 二、同题标题生态概览

本篇主题为"巴基斯坦为什么总能在危机时获得支持"与"巴基斯坦如何同时经营中、美、海湾三组不对称依赖"，同题内容在外部（中文 12 + 英文 26 个样本，约 38 个）已形成以下主要标题模式：

**最常见的入口角度**
- "为什么巴基斯坦总能在最后获得支持"——以 EPW 2023《A failed economy saved by geography》为代表，天然带反常识 + 时间纵深，读者共情强
- "真正原因不是 X 而是 Y"——以 Dawn Prism 2023《Pakistan's days of extracting geopolitical rent are over. What next?》为代表，反转 + 解释力强，但"真正原因"措辞易变爆款腔
- "A 不是 B，而是 C"——以"不是夹缝求生，而是管理不对称"为本文工作标题原型，纠偏感强，适合本文反常识核心

**外部已高强度占用的标题词**
- "战略支轴 / 缓冲 / 中间人"——W01 叙事高频使用，身份标签浪漫化风险高
- "夹缝求生"——W01 叙事核心词，本文工作标题已在纠偏，属于已被外部用滥的入口
- "军政府 / SIFC 军方接管"——W05 叙事高频使用，扁平标签风险高
- "failed economy / 失败国家"——A02/B08 明确禁用
- "秘密委员会 / 内幕 / 真相大白"——T04/T05 高风险标题词
- "中国是最大债主 / 沙特存款 = 无偿援助 / 海湾被中国挤压"——A04/A17/A15 禁用表达

**外部相对低饱和的角度**
- "分工联盟"三主体分工机制——外部多被简化为"军政府"或"秘密委员会"，机制化表达空间大
- "兑换术"——外部有 rentier geopolitics 叙事，但"兑换术"作为中文机制词 + "结构性产物"定位，是本文差异化切入点
- "换生存难换转型"两面承诺——外部多写"能换到"或"换不到"单面，较少同时呈现两面
- "管理不对称"——比"选边"更准确描述巴基斯坦的实际状态，且中文语境低饱和

## 四、可差异化角度

基于方向把控主承诺（"巴基斯坦不是选边，是同时经营中、美、海湾三组不对称依赖；能换生存、难换转型"）与传播学分析卡七维度评估（候选 1 总分 33，候选 2/3 辅助），本文标题可差异化于外部的以下角度：

1. **"管理不对称"替代"选边"**
外部几乎全部使用"选边 / 夹缝 / 战略支轴 / 两边下注"描述巴基斯坦，标题已先入为主把巴基斯坦放在"被动应对"框架里。本文核心发现是"主动管理三组不对称依赖"，这是外部同题内容未完整出现的机制定位，差异化空间最大。工作标题"不是夹缝求生，而是管理不对称"已建立此差异化方向。

2. **"换生存难换转型"两面承诺**
外部同题标题多写"能换到"（A07/A17 方向）或"换不到"（A18/失败国家方向）单面，未完整呈现"能换生存、难换转型"两面机制。本文 C2 叙事反转（巴方主动重置 35 亿）+ C3 结尾升维（孟加拉/斯里兰卡/尼泊尔 + 四重稀缺位置）是外部未完整出现的收尾逻辑。

3. **"分工联盟"机制替代"军政府/秘密委员会"**
外部 W05 叙事（SIFC/军方接管）高强度占用，把三主体分工简化为单一主体控制。本文"军方定边界 / 文官做交易 / IMF 当信用阀门"分工联盟机制在标题层面可差异化呈现为"谁在管巴基斯坦的钱袋子"类结构，外部未完整出现此类角度。

4. **"兑换术"中文机制词**
外部有 rentier geopolitics 学术叙事，但中文语境缺少一个可迁移的机制词。"兑换术"作为本文定义的母题词汇，可差异化用于"巴基斯坦的'兑换术'"类标题，外部无同表达。

5. **年度/危机节点+机制承诺**
外部多以"结果"或"判断"做标题（"总能在最后获得支持"），本文最新抓手是 2025-05 印巴四天 + 2026-04 海湾 50 亿承诺，可与"为什么[年份事件]说明[机制]"结构结合，提供时效性差异化入口。

## 五、给标题方案的约束清单

来源：发布检查 §六（标题阶段边界）+ 方向把控 §二.2（主承诺拆解）+ 标题方法论配置 §六（优先结构）

1. **可承诺：同时经营三组不对称依赖**
标题可承诺"巴基斯坦同时经营中国（耐心）、美国（阀门）、海湾（避险）三组不对称依赖"——这是文章核心发现，§一至§六全部显形；禁止写成"巴基斯坦在选边"或"巴基斯坦被迫依赖某一方"。

2. **可承诺：换生存易、换转型难**
标题可承诺"能换生存、难换转型"两面——有 §六 五证（IMF 四轮安排/IMF 净口径/沙特展期/SBP 储备/FATF）支撑；禁止只承诺单面（"能换到"或"换不到"）导致承诺不完整。

3. **可承诺：巴方是主动管理方**
标题叙事方向应反映"巴方是主动管理方，不是被动等救助"——与 C2 叙事反转（巴方主动重置 35 亿）对齐；禁止把巴基斯坦写成"被大国施救的弱者"被动框架。

4. **不可承诺：崩溃/崛起/军政府/恐怖主义国家/最大债主**
标题禁止承诺：巴基斯坦必然崩溃 / 必然崛起 / 即将成为超级大国 / 即将彻底失败；巴基斯坦是军政府 / SIFC=军方接管经济 / 恐怖主义国家 / 失败国家；中国是巴基斯坦最大债主；沙特存款=无偿援助；海湾被中国挤压；巴方在 2025 印巴冲突中获胜/印度获胜；巴方击落印方四架战机；中国控制了巴基斯坦 / 美国放弃了巴基斯坦 / 海湾操控了巴基斯坦——以上均超出正文证明范围或违反 B 编号限定语。

5. **不可承诺：2026-04 已签 MoU/已到账**
标题如涉及 2026 年 4 月沙特+卡塔尔 50 亿援助，必须用"承诺"；禁止写"已到账""已签协议""已签 MoU"——B16 明确所有独立源均确认"no formal agreements signed"。

6. **如涉及 CPEC 金额必须双口径并列**
标题如涉及 CPEC 金额，必须并列"框架约 620 亿美元 / 已落地约 247 亿美元"；禁止单引 620 亿框架金额——D01 事实核查清单明确双口径要求。

7. **如涉及 IMF 2019 年安排必须用净口径**
标题如涉及 2019 年 IMF 安排，必须用"60 亿合同中约 16.50 亿净流入"；禁止单引 60 亿合同额——D03 财政部口径要求。

8. **如涉及 2025-05 印巴停火必须三口径并列**
标题如涉及 2025 年 5 月印巴停火，禁止单方采纳（美方称美国促成 / 印方称印巴直接谈 / 巴方感谢斡旋三口径并列）——D05 事实核查清单要求。

9. **叙事方向：反映"主动管理"而非"被动求生"**
工作标题"巴基斯坦的三份工：同时经营中国、美国、海湾"已建立"主动管理"叙事方向；标题方案应延续此方向，禁止倒退至"夹缝求生""走钢丝""被大国救助"被动框架。

10. **文风约束：禁用表达零出现**
标题禁用：巴铁牢不可破 / 震惊 / 炸裂 / 颠覆认知 / 内幕 / 真相大白 / 所有人 / 刚刚 / 终于 / 彻底 / 彻底改变 / 彻底失败——以上为文风禁用清单与平台风险词；系列基调配置明令禁止情绪化褒贬。

## 六、标题阶段禁止事项

来源：发布检查 §六.2（标题不能承诺）+ §六.3（禁用或慎用表达）+ 方向把控 §七（必须放弃项）+ 标题方法论配置 §七（禁用）

**事实类禁止**
- 承诺正文未证明的结论（崩溃/崛起/超级大国/彻底失败）
- 使用未经事实核查清单放行的数字、年份、机构（"已签 MoU" / "已到账 50 亿" / "巴方击落四架战机" / "中国是最大债主"）
- 单引 CPEC 620 亿框架金额而不并列 247 亿落地金额
- 单引 IMF 60 亿合同额而不说明净流入 16.50 亿口径
- 单方采纳 2025-05 印巴斡旋方某一方说法

**定性类禁止**
- 使用"军政府 / SIFC=军方接管"定性巴基斯坦
- 使用"恐怖主义国家 / 失败国家 / 代理人国家 / 帝国棋局"扁平标签
- 使用"沙特存款=无偿援助 / 海湾被中国挤压 / 中美零和博弈"误导性等式
- 把巴基斯坦定性为"被操控的棋子"或"阴谋论"框架

**文风类禁止**
- 使用"震惊 / 炸裂 / 彻底 / 终于 / 内幕 / 真相大白"等平台风险词
- 使用"巴铁牢不可破"情绪化褒贬
- 使用"选边 / 走钢丝 / 两边下注 / 机会主义"等机会主义叙事词
- 使用"秘密 / 阴谋 / 被忽视的 X"等阴谋论标题套路
- 使用"战略支轴 / 缓冲 / 中间人"等身份标签做主标题核心词

**结构类禁止**
- 把多因素写成唯一原因（如"巴基斯坦能活下来只是因为中国"）
- 把复杂制度变化压成单一阴谋或单一坏人
- 标题承诺超出正文证明范围（如承诺"巴基斯坦将崛起"而正文只证明了"能换生存"）
