## 二、标题方法论适配

### 2.1 当前文章适合的标题方法

| 方法 | 是否采用 | 适配理由 | 使用方式 |
|---|---|---|---|
| 机制解释型（"巴基斯坦为什么[结果]：因为[机制]"） | 是 | 文章核心是解释"为什么巴基斯坦总能获得支持"的机制；三组不对称依赖 + 换生存难换转型是文章已证明的机制；标题方法论 §6.1 明确推荐 | 适合用于主推标题和问题入口；机制承诺须在正文中兑现 |
| 反常识纠偏型（"不是 A，而是 B"） | 是 | 工作标题"不是夹缝求生，而是管理不对称"已建立此方向；外部生态中"选边/夹缝"叙事高饱和，"管理不对称"是差异化切入点；方向把控 §2 明确以"不是选边，是同时管理三组不对称依赖"为主承诺 | 适合用于主推标题和反差入口；"不是 A 而 B"结构在信息流场景点击率稳定 |
| 双段式机制型（"[短钩子]：[解释承诺]"） | 是 | 标题方法论 §6.4 明确推荐；文章"三组不对称依赖 + 换生存难换转型"双层承诺适合分两段呈现 | 前半句做钩子（"活下来"或"换生存"），后半句补足机制；冒号前后不重复 |
| 问题入口型（"为什么……"） | 是 | 读者画像 §5 明确推荐"反常识问题"入口；标题生态搜索指出"为什么巴基斯坦总能在最后获得支持"是外部高饱和词，需差异化 | 用"为什么"引出问题，后半句必须给出机制答案，不能只问不答 |
| 关系冲突型（"A 和 B 之间"） | 部分 | 文章确实涉及中国、美国、海湾三国关系，但标题方法论 §6 禁止"A 国战略 × B 国"双主体对抗框架；标题生态搜索 §三.2.12 明确禁用"中美零和博弈" | 标题结构可提三国关系，但不得写中美对抗框架；用"同时经营"而非"在中美之间走钢丝" |
| "从 A 到 B"转折型 | 否 | 文章是机制解释而非历史转折叙述；没有清晰的"A → B"历史变化链条；时效性弱 | 不适用 |
| 年份/危机转折型 | 否 | 2025-05 印巴四天 + 2026-04 海湾 50 亿承诺是机制显形而非叙事主线；标题方法论 §6.6 要求"年份必须准确、结果不能夸大"；S1 瓜达尔港数量待核实 | 不作为主打 |
| 生活场景入口型（"巴基斯坦的现金流感官"） | 否 | "现金、贷款、存款、侨汇"等生活词在文章中有，但不构成核心入口；文章核心是三组不对称依赖机制，不是现金流机制 | 仅作为正文辅助类比，不进入标题主结构 |

## 三、发布检查边界摘要

### 3.1 标题可以承诺

1. 巴基斯坦同时经营中国（耐心）、美国（阀门）、海湾（避险）三组不对称依赖——文章核心发现，§一至§六全部显形
2. 巴基斯坦能靠这套结构性位置换生存，但难换到国内改革和产业升级——有 §六 五证（IMF 四轮安排/IMF 净口径/沙特展期/SBP 储备/FATF）支撑
3. "兑换术"是一种被结构性需求反复挤压出来的活法，不是可以模仿的范式——有孟加拉/斯里兰卡/尼泊尔三国对比 + 四重稀缺位置支撑

### 3.2 标题不能承诺

1. 巴基斯坦必然崩溃 / 必然崛起 / 即将成为超级大国 / 即将彻底失败——超出正文证明范围，违反系列"既不崩溃也不崛起"基调
2. 巴基斯坦是军政府 / SIFC=军方接管经济 / 恐怖主义国家 / 失败国家——违反 B20/B21/B08；正文使用"民选文官政府+军方外交否决权"+"军民联合投资治理平台"
3. 中国是巴基斯坦最大债主 / 沙特存款=无偿援助 / 海湾被中国挤压——违反 B10/B18/B17；正文使用"中国是双边最大债权方之一"+"展期不是新钱"+"市场避险+宗派+能源复合驱动"
4. 巴方在 2025 印巴冲突中获胜 / 印度在 2025 印巴冲突中获胜 / 巴方击落印方四架战机——违反 B01/B02；正文使用三口径并列
5. 中国控制了巴基斯坦 / 美国放弃了巴基斯坦 / 海湾操控了巴基斯坦——阴谋论表述；正文使用"结构性需求"机制框架

## 四、标题策略方向

### 4.1 推荐主策略

```text
本文标题应走"反常识纠偏 + 机制解释"双轨路径：
第一轨：以"不是夹缝求生，而是管理不对称"建立反常识入口，把读者从"选边/夹缝"框架升级到"管理三组不对称依赖"机制——这是外部同题内容未完整出现的差异化定位，工作标题已建立方向，标题方案应延续。
第二轨：标题承诺必须落在"换生存易、换转型难"两面——这是文章核心机制，有五证（IMF 四轮/净口径/沙特展期/SBP 储备/FATF）支撑；禁止只承诺单面（"能换到"或"换不到"）导致承诺不完整。
叙事方向必须反映"巴方是主动管理方"——C2 叙事反转（巴方主动重置 35 亿）是 v5 核心增量，标题方案应延续此方向，禁止倒退至"被大国救助的弱者"被动框架。
读者入口应优先用"问题入口"（"为什么总能在危机时获得支持"）或"反差入口"（"不是选边，是管理不对称"），而非纯国家标题或纯机制词。
```

### 4.2 读者入口设计

| 入口 | 是否采用 | 理由 | 标题表达方向 |
|---|---|---|---|
| 问题入口 | 是 | 读者画像 §5 明确推荐"反常识问题"入口；"为什么巴基斯坦总能在危机时获得支持"是 C1/C2/C3/C4 共同兴趣；标题生态搜索 §四.1 确认此方向差异化空间大 | 用"为什么……"引出，后半句必须给出机制答案；避免只问不答 |
| 人物入口 | 否 | 本文核心是机制，不是人物；Rubio/Asif Munir 等人物是分工联盟机制的证据，不是主角 | 不适用 |
| 反差入口 | 是 | 工作标题"不是夹缝求生，而是管理不对称"已建立此方向；标题生态搜索 §四.1 确认"管理不对称"比"选边"更准确且中文语境低饱和；方向把控 §2.2 确认"不是选边，是管理三组不对称依赖"为反差洞察 | 用"不是 A，而是 B"结构；B 段必须补足机制，不能只做反转没有内容 |

| 后果入口 | 是 | "能换生存、难换转型"是文章的核心后果判断；五证（IMF 四轮/净口径/沙特展期/SBP 储备/FATF）支撑充分 | "能换……难换……"两面结构；不能只写一面 |
| 误解纠偏入口 | 是 | 读者普遍误以为巴基斯坦"会选边"或"在走钢丝"；本文能证明读者误解 | "不是选边，是管理不对称"；"不是走钢丝，是同时经营三组不对称依赖" |
