## 一、目标读者画像

来源于系列配置 `巴基斯坦如何把世界变成自己的资源/_meta/_config/读者画像配置.md`，本篇直接锁定的目标读者：

```text
对南亚、国际关系、IMF/世界银行、中美博弈、一带一路有兴趣，
但不一定受过专业区域研究训练的成熟中文读者。
阅读场景：公众号 + 今日头条信息流 + 手机端阅读。
```

读者大概率已经知道：

- 中巴关系被官方称为"铁杆"或"全天候战略合作伙伴"；
- 印巴长期对立、发生过战争；
- 巴基斯坦是伊斯兰国家，也拥有核武器；
- 阿富汗问题、塔利班、反恐战争大概听过；
- IMF、世界银行、债务、贷款等概念大致熟悉。

读者大概率不知道：

- 巴基斯坦外交到底谁拍板：军方还是文官；
- CPEC 真实进度、二阶段升级、安全成本与债务结构；
- 巴基斯坦与海湾国家（沙特、阿联酋、卡塔尔）的现金流关系有多深；
- 1998 年后"全谱威慑"真实针对的问题；
- 阿富汗塔利班上台后 TTP 反而成为巴方更头痛的问题；
- SAARC 为什么停摆、巴基斯坦为何转投联合国等多边平台。

本篇不能假定读者具备上述专业知识；所有制度缩写、机构缩写、核战略术语、外交术语在首现时必须做普通话翻译。

## 二、总目标

本篇作为「巴基斯坦如何把世界变成自己的资源」系列的开篇，不追求全景观，而是**把"为什么巴基斯坦总能在'快不行了'的时刻再次获得支持"这一反常识现象，拆解为一套可被读者复述的机制**。

具体目标：

1. 交付一组主机制：**三组不对称依赖 + 三条结构性约束的相互绑定 → 综合议价包 → 多线兑换 → 换生存难换转型**；
2. 让读者在读完之后，能复述"中国给的是战略背书、海湾给的是现金流、美国给的是援助与合法性"，并理解这三类资源为何彼此不能替代；
3. 让读者把本篇机制放回系列"三层棋局"（国内权力结构 / 区域安全结构 / 外部资源结构）中识别本篇所属的那一层；
4. 给读者留下一个可带走的判断框架：**巴基斯坦的"兑换术"能换生存、难换转型，关键不在它有多聪明，而在于结构性需求不断被再生产出来**。

不在本篇目标之内：

- 不试图讲清巴基斯坦全史；
- 不同时交付军方、文官、宗教、IMF、海湾、中美等多个大问题；
- 不替系列后续篇下结论；
- 不预设"中国是最大支持者"或"美国才是真正操盘者"等立场化结论。

## 三、核心问题

本篇核心问题：

```text
为什么巴基斯坦总能在外界认为"快不行了"的时刻重新获得支持？
```

围绕这一核心问题，本篇需在正文中显式拆出三个子问题：

1. **谁掌握"兑换"资格**：巴基斯坦的对外红线由谁拍板？军方、文官、IMF 谁掌握谈判资格？是谁决定"什么时候向谁要"？
2. **三组不对称依赖分别提供什么**：中国、美国、海湾国家各自在巴基斯坦的需求结构中提供的是哪一类不同资源？为什么这三类资源在结构上不能被同一方替代？
3. **为什么能换生存、难换转型**：这种多线兑换为什么在长期能稳定维持外部资源流入，却很难转化为国内的结构性改革和产业升级？

## 四、暂定逻辑链

> 待资料研究后补全。以下为**暂定**结构主线，仅作为方向把控、文风卡、大纲阶段的输入，不作为正文定稿依据。

```text
[1] 反常识切入：
     "巴基斯坦总在'快不行了'的时刻再次获得支持"是一个被反复观察到的现象。

[2] 普通认知 vs 本文机制：
     普通认知："巴铁"关系 / 印巴世仇 / 阴谋论
     本文机制：巴基斯坦同时经营中国、美国、海湾三组不对称依赖

[3] 谁掌握兑换资格：
     军方定边界 + 文官做交易 + IMF 当信用阀门
     → 巴基斯坦不是"统一谈判方"，是"分工联盟"

[4] 三组不对称依赖分别提供什么：
     中国 → 战略背书 + 基础设施与贷款（CPEC）
     美国 → 援助、IMF 通道、外交合法性
     海湾 → 现金存款、能源赊账、紧急援助
     三组资源在结构上彼此不可替代

[5] 为什么多线兑换能持续：
     对印安全竞争 + 对阿边境压力 + 经济脆弱性
     → 三条结构性约束相互绑定，使巴基斯坦同时具备三组"不可替代的卖品"

[6] 为什么能换生存、难换转型：
     兑换的回报是现金流、合法性、安全背书，
     但回流到国内的常被军方、文官、宗教网络分流，
     未充分转化为产业升级与税制改革
     → "地缘租金"型国家的活法

[7] 结尾回收：
     巴基斯坦的"兑换术"不是机会主义，也不是设计出来的胜利，
     而是结构性需求不断被再生产出来的结果；
     它能换生存、难换转型。
```

> 资料研究完成后，逻辑链需要被事实核查清单与证据台账校验：
> 任何"巴基斯坦换了什么、换了多少、谁批准、谁回流"必须可追溯到具体年份、机构、文件。
> 校验后该逻辑链才进入 02_洞察及主题 阶段。

## 五、写作边界

本篇严格遵守以下边界，任何越界都需要在新一轮方向把控中重新讨论：

1. **不写巴基斯坦全史**：不写 1947 分治的完整叙事，不写 1971 东巴分离的详细过程，不写历届军政府编年。
2. **不写全要素**：本篇只交付一组主机制；不在一篇文章里同时讲清军方、文官、宗教、IMF、海湾、中美。
3. **不写阴谋论**：不写"巴基斯坦是某国代理人""某大国暗中操盘"等无证据指控；一切结构性解释必须落到具体利益与约束。
4. **不写情绪化褒贬**：不使用"巴铁牢不可破""印巴世仇""南亚火药桶""恐怖主义国家"等扁平标签。
5. **不写 2025-2026 局势的硬性结论**：若使用 2025 印巴四天冲突、2025-2026 阿巴边境事件等近期素材，必须在事实核查清单中标注口径与刷新节点；不在资料未确认前下判断。
6. **不替系列后续篇下结论**：本篇只属于"外部资源结构"层，不在结尾上升到"巴基斯坦必然崩溃"或"巴基斯坦必然崛起"。
7. **不堆叠英文字符**：除首现缩写的括号标注与必要术语框外，正文不得夹英文；不写"CPEC = 中国-巴基斯坦经济走廊"以外的英文叙事。
8. **不把单因素写成唯一原因**：所有"因为 A 所以 B"必须可拆为多条结构性需求，不允许把多因素简化为单一原因。

## 六、证据缺口

> 当前为 0.1 项目初始化阶段，**未进入资料研究**。以下四组关键证据缺口在进入 `01-source-research` 之前必须先明确范围与口径，但**不需要在本阶段完成资料填充**。

1. **IMF 历年借款规模与条件**

   - 待补资料：IMF 对巴历年贷款计划（SBA / EFF / RFI 等）金额、条件、关键节点（1980s、1993、2008、2013、2019、2023 等）；
   - 待补资料：每轮 IMF 计划附带的关键政策条件（电力、税制、补贴、汇率、国企改革）与执行偏差；
   - 待补资料：IMF 资金与"美国在 IMF 的话语权"之间的可证明关联（事实层面，不做阴谋论判断）。
2. **中国对巴贷款与投资规模（CPEC）**

   - 待补资料：CPEC 累计承诺金额、已落实金额、已完工金额的最新口径（以官方公开数据为准，需注明截止时点）；
   - 待补资料：能源、交通、瓜达尔港三大板块的项目分类金额与进度；
   - 待补资料：CPEC 一阶段 vs 二阶段（含 ML-1 铁路、特区、农业）的差异；
   - 待补资料：中方对巴主权贷款、商业贷款、政策性贷款的结构（需注明口径来源）。
3. **沙特、阿联酋、卡塔尔对巴存款与援助时间线**

   - 待补资料：海湾三国对巴中央银行存款（直接存款 / 展期）的关键年份与金额；
   - 待补资料：紧急援助与油价补贴时间线（典型如 2018、2022、2023 等节点，需以官方公开口径为准）；
   - 待补资料：海湾三国对巴援助背后的政治逻辑（也门战争、阿富汗、巴勒斯坦议题、能源安全等）。
4. **美国对巴援助与反恐资金时间线**

   - 待补资料：CSF（Coalition Support Funds）等反恐资金累计金额、关键节点、与停付/恢复记录；
   - 待补资料：非军事援助（经济援助、健康、教育）历年口径；
   - 待补资料：美国对巴援助的"看人下菜"机制（军政府 / 民选政府、FATF 灰名单/白名单、印巴关系节点）。

上述四组证据缺口进入 `01-source-research` 阶段后须按"先核实官方口径、再核实二手研究、最后做交叉验证"的顺序处理；任何引用须写入 `01_资料/证据台账.md`，并由 `01-source-research` → `01-evidence-ledger` → `01-fact-check` 三道关卡校验。

## 七、文风原则

本篇文风口径严格遵守系列四份配置，仅提炼要点，不复制全文：

1. **系列基调配置**：克制、清楚、有结构感、有历史纵深；用危机与机制承载故事，用结构解释现实；情绪强度"有 tension，但不煽动；有判断，但不控诉"；一句话原则是"不写'谁坏'，写'什么结构性需求让结果一步步变成这样'"。
2. **读者画像配置**：核心读者是"对南亚、IMF/世界银行、中美博弈、一带一路有兴趣，但不一定受过专业区域研究训练的成熟中文读者"；阅读场景是公众号 + 头条信息流 + 手机端；术语首现必须翻译；不依赖读者读过前文。
3. **文章结构与格式配置**：默认结构"标题 → 引言 → 正文 4-7 节 → 结尾"；引言 150-350 字，用"普通认知 → 关键反转 → 入口承诺"三层进入法；小标题像路标，避免"背景介绍 / 制度演变 / 影响分析 / 总结"等抽象词；术语框 / 制度框 / 时间线只服务机制，不做装饰；结尾回收本文主承诺，不写成全系列总论。
4. **平台与阅读方式配置**：默认面向今日头条信息流 / 微信公众号长文 / 手机端阅读；段落 1-4 行、最长不超过 6 行；每 600-1000 字一个小标题；前 300 字出现核心问题，前 500 字出现主承诺；禁止标题党、仿官方通知、恐吓式表达、夸张绝对判断、无依据现实影射。

本系列三红线自检（本篇在草稿、审阅、修订、终稿各阶段都保留）：

```text
英文字符 = 0
把多因素写成唯一原因 = 0
阴谋论与扁平标签 = 0
```

## 八、审稿机制

本篇审稿遵循系列配置 `_meta/_config/审稿政策配置.md`，按阶段推进：

1. **大纲审阅**：通过 03-outline-review 校验方向、洞察角色、标题-引言-正文-结尾承诺链、事实边界、文风合规性。
2. **草稿阶段 A**：完成 04-draft-write 草稿后，并行触发：
   - 05-free-review（零上下文自由审读）
   - 05-reader-review（按读者画像审读）
   - 05-density-edit（内容密度审读）
3. **主编阶段 A**：由 05-editor-review 整合上述三方意见，输出"主编修改建议 v1"。
4. **阶段 A 修订**：由 06-draft-revise 完成"修订稿 v1"，再次进入 free-review + reader-review + density-edit 的小循环，直至主编判断可进入阶段 B。
5. **草稿阶段 B / 修订稿阶段 B**：以"主编修改建议 阶段B vN"驱动"修订稿 vN"（N=1..5），每版附带"自由审读_修订稿 阶段B vN"，并由主编整合输出"主编修改建议 阶段B vN+1"。
6. **发布检查**：06-release-check 在主编明确"内容冻结"后执行内容闭环检查（不处理格式 / 不处理 HTML）。
7. **成稿终审**：06-format-final-check 在 HTML 构建前完成格式与卫生检查。
8. **HTML 阶段**：09-html-build 仅做排版与格式实现，不重写正文。

每轮审稿必须满足"三红线自检 + 结构承诺链未断 + 单篇独立成立"三道硬约束，否则打回修订。

## 十、最终交付标准

本篇完成（HTML 终稿阶段）的判定标准：

1. **结构**：标题、引言、正文 4-7 节、结尾，承诺链闭合；小标题像路标；术语框 / 制度框 / 时间线只服务机制。
2. **机制**：读者读完后能复述"中国给战略背书、海湾给现金流、美国给援助与合法性"以及"换生存难换转型"。
3. **三层棋局定位**：本篇明确属于"外部资源结构"层，并在结尾显式回收这一层与"区域安全结构""国内权力结构"的相互约束。
4. **数据可追溯**：所有关键数字、年份、机构来自事实核查清单，可在证据台账中找到来源；2025-2026 局势部分标注口径与刷新节点。
5. **三红线自检全通过**：英文字符 = 0；把多因素写成唯一原因 = 0；阴谋论与扁平标签 = 0。
6. **平台可读性**：段落 1-4 行、最长不超过 6 行；每 600-1000 字一个小标题；前 300 字出现核心问题，前 500 字出现主承诺。
7. **审稿链路完整**：阶段 A / 阶段 B 审稿记录完整，主编"内容冻结"明确，发布检查通过，成稿终审通过，标题方案与插图方案锁定。
8. **HTML 排版规范**：标题层级清楚、小标题路标强化、不让样式盖过正文机制、`<abbr>` 标签覆盖所有首现缩写。
