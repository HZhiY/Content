# 文风禁用清单

> 适用系列：巴基斯坦如何把世界变成自己的资源
> 用途：供文风、大纲、草稿、审稿、修订、发布检查和标题阶段识别禁用表达、风险语气和不合系列气质的写法。
> 核心原则：写机制，不写情绪；写结构，不写阴谋；写清楚，不写玄乎。

---

## 一、总禁区

本系列禁止以下总体风格：

1. 标题党；
2. 短视频腔；
3. 阴谋论腔；
4. 地缘控诉腔；
5. 论文腔；
6. AI 腔；
7. 过度鸡汤或金句腔；
8. 过度宏大叙事腔；
9. 借"反西方""反印度"等情绪化立场代替结构解释。

---

## 二、标题党与短视频腔

### 2.1 禁用词

禁止使用：

```text
震惊
炸裂
彻底
终于
刚刚
重磅
惊人
内幕
真相大白
看完沉默
不看后悔
所有人都错了
```

### 2.2 禁用句式

禁止：

- "你绝对想不到……"；
- "背后真相令人……"；
- "巴基斯坦不装了……"；
- "美国摊牌了……"；
- "这一切早有预谋……"；
- "看懂这个，你就看懂了全部……"；
- "所有小国的结局都一样……"；
- "一文讲透南亚地缘全部真相"。

### 2.3 替代表达

| 不推荐 | 推荐 |
|---|---|
| 真相令人震惊 | 机制比表面更关键 |
| 美国摊牌 | 美方在某个议题上调整了介入方式 |
| 巴基斯坦彻底变了 | 巴基斯坦的对外操作开始出现新支点 |
| 一切都因为中国 | 中国是结构性需求中最重要的供给者之一 |

---

## 三、阴谋论腔

### 3.1 禁止方向

禁止把复杂结构写成少数人密谋：

- "中情局设计了一切"；
- "巴基斯坦军方早就计划好"；
- "海湾国家操控巴基斯坦经济"；
- "印度一直在算计"；
- "巴塔是某方代理人"；
- "南亚地缘从一开始就是骗局"。

### 3.2 推荐改法

改写为：

```text
巴基斯坦的"兑换术"能成功，很多时候不是靠哪一方精心设计，
而是靠结构性需求（对印安全、对阿边境、能源与现金、IMF 资金）
反复叠加、各方在自身利益下做出选择。
```

---

## 四、地缘控诉腔

禁止只用道德批判替代机制分析。

### 4.1 慎用词

```text
吸血
绑架
掠夺
帝国的獠牙
大国博弈的棋子
文明冲突
代理人
恐怖主义
```

这些词除非正文有非常明确的历史语境和证据，否则不得使用。

### 4.2 推荐表达

| 控诉腔 | 机制表达 |
|---|---|
| 巴基斯坦被大国绑架 | 巴基斯坦同时管理多组不对称依赖 |
| 印度一直在算计 | 印方在某个议题上调整了政策边界 |
| 中国控制巴方 | 中国是结构性需求中最重要的供给者之一 |
| 海湾国家用钱换忠诚 | 海湾存款和侨汇构成巴方现金流安全阀 |
| 美国暗中颠覆 | 美方在某个时间节点暂停或恢复特定援助 |

---

## 五、论文腔与术语堆叠

### 5.1 禁止写法

禁止连续堆叠抽象概念：

```text
巴基斯坦通过制度性不对称依赖结构完成对外部资源的再生产。
```

禁止用学术概念替代解释：

- 主体性；
- 现代性；
- 结构性张力；
- 资本逻辑；
- 制度性安排；
- 历史必然性；
- 后殖民语境。

不是完全不能用，而是不能不解释就用。

### 5.2 推荐写法

```text
巴基斯坦的对外操作看起来像在多个大国之间周旋，
但实际是同时管理三组不对称依赖：
中国给的是长期战略背书和基础设施平台，
美国给的是外交与国际金融环境，
海湾给的是现金、存款、劳务和能源。
```

## 六、AI 腔

禁止出现：

- "本文将从三个维度展开分析"；
- "综上所述"；
- "值得注意的是"；
- "不可否认的是"；
- "从某种意义上说"；
- "这不仅是……更是……"连续套用；
- "它深刻揭示了……"；
- "具有重要启示意义"。

推荐改为具体判断：

```text
问题不在于巴基斯坦有多少朋友，而在于谁能决定现金、贷款、存款的入口。
```

---

## 七、过度绝对化

禁止或慎用：

```text
唯一原因
全部原因
彻底改变
完全控制
必然导致
从此以后再也没有
所有国家都
没有任何例外
铁杆兄弟
血盟
```

推荐降级：

| 绝对表达 | 降级表达 |
|---|---|
| 唯一原因 | 关键原因之一 |
| 彻底改变 | 开始改变 / 逐渐调整 |
| 完全控制 | 获得更强影响力 |
| 必然导致 | 往往会推动 / 容易造成 |
| 所有国家 | 越来越多国家 / 一类国家 |
| 铁杆兄弟 | 长期战略合作伙伴关系 |

---

## 八、过度升维

禁止每篇结尾都升到：

- 文明冲突；
- 人类命运；
- 历史终局；
- 时代答案；
- 国家命运；
- 世界秩序大变局；
- 伊斯兰世界困境。

本系列允许升维，但必须从正文机制自然推出。

推荐结尾落点：

```text
巴基斯坦的"兑换术"能换生存、难换转型，
关键不在于它有多聪明，而在于结构性需求不断被再生产出来。
```

---

## 九、代词悬空

慎用：

```text
它
这件事
他们
这一切
那个东西
你
```

尤其在标题、小标题和开头中，优先使用具体对象（巴基斯坦、IMF、CPEC、印巴、阿富汗等）。

不推荐：

```text
它为什么能换来支持？
```

推荐：

```text
巴基斯坦为什么总能在危机边缘获得外援？
```

## 十、英文与翻译腔

发布版本中应避免英文字符和英文式表达。

如果必须出现英文缩写（NCA、CPEC、SIFC、APS、FATF、IMF、SAARC、TTP 等），应在事实核查或发布检查阶段确认是否允许，并提供首次出现时的中文释义。

禁止翻译腔：

- "进行一个决定"；
- "扮演了重要角色"；
- "产生了深远影响"；
- "在某某方面发挥作用"；
- "对于某某而言是重要的"。

推荐改为具体动作：

```text
它改变了谁能拿到现金。
它决定了谁有资格进入 IMF 谈判桌。
它让军方开始按安全逻辑改写发展议题。
```

---

## 十一、扁平标签腔

禁止把巴基斯坦写成扁平标签的集合：

- "失败国家"；
- "军国国家"；
- "代理人国家"；
- "恐怖主义国家"；
- "动荡国家"；
- "穆斯林国家"；
- "南亚火药桶"；
- "巴铁"（作为情绪化褒贬）。

正确写法是拆开写：

- 谁拥有正式权力；
- 谁拥有事实否决权；
- 谁掌握现金流阀门；
- 谁负责对外表述与谈判；
- 谁有街头动员能力。

如果非要使用国家层面的概括语，应使用更克制、更具结构感的表达，例如：

- "安全国家"（指"先安全、后发展"的国家逻辑）；
- "地缘租金型国家"（指经济上长期依赖外部资源输入的结构特征）；
- "复合权力结构"（指军方、文官、宗教势力共同塑形的对外决策）；
- "南亚区域合作瘫痪的受害者"（指 SAARC 失败对巴方的具体影响）。

---

## 十二、地区与宗教标签

本系列应避免把对巴基斯坦的分析套成对整个伊斯兰世界、整个中东或整个"全球南方"的判断。

- 写巴基斯坦时不要把其他穆斯林国家拖进同一叙事；
- 涉及"伊斯兰因素"时，应具体到政党、教派、组织、学校等可识别主体；
- 避免"穆斯林国家天然如何"的句式；
- 涉及俾路支、普什图、旁遮普等族裔或地方时，使用具体地理与制度语境，不空泛形容。
