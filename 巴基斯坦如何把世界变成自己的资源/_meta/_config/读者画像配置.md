# 读者画像配置

> 适用系列：巴基斯坦如何把世界变成自己的资源
> 用途：供传播、方向、文风、大纲、读者审读、标题等 agent 判断目标读者、理解门槛、兴趣入口和阅读风险。
> 核心原则：读者想获得的不是南亚地缘知识点，而是一套解释"小国如何在大国夹缝中生存与不能转型"的机制框架。

---

## 一、核心读者

本系列核心读者是：

```text
对南亚、国际关系、IMF/世界银行、中美博弈、一带一路有兴趣，
但不一定受过专业区域研究训练的成熟中文读者。
```

他们可能包括：

- 泛国际时政读者；
- 对中巴关系、一带一路感兴趣的商业/产业读者；
- 想理解"为什么世界总有局部战争与制裁还能运转"的现实机制读者；
- 对伊斯兰世界、南亚区域主义、核武器与危机管理有兴趣的读者；
- 喜欢用"一个国家问题打穿一个国际机制"的深度内容读者。

---

## 二、读者已有认知

### 2.1 可能知道

读者大概率知道：

- 中巴关系被官方称为"铁杆"或"全天候战略合作伙伴"；
- 印巴长期对立、发生过战争；
- 巴基斯坦是伊斯兰国家，也拥有核武器；
- 阿富汗问题、塔利班、反恐战争大概听过；
- IMF、世界银行、债务、贷款等词大概熟悉。

### 2.2 可能不知道

读者不一定知道：

- 巴基斯坦外交到底谁在拍板：军方还是文官；
- CPEC 真实进度、二阶段升级、安全成本与债务结构；
- 巴基斯坦与海湾国家（沙特、阿联酋、卡塔尔）的现金流关系有多深；
- 1998 年后"全谱威慑"真实针对的问题；
- 阿富汗塔利班上台后 TTP 反而成为巴方更头痛的问题；
- 巴基斯坦在联合国维和与安理会席位上的实际投入与回报；
- 巴基斯坦"地缘租金"型国家的经济结构特征；
- SAARC 为什么停摆、巴基斯坦为何转投联合国等多边平台。

## 三、读者阅读动机

| 动机 | 内容应如何回应 |
|---|---|
| 想看懂巴基斯坦为什么"总能在夹缝里活下去" | 用三组不对称依赖解释结构性来源 |
| 想理解中巴关系到底有多深、有多复杂 | 用资源主轴连续替换解释 |
| 想获得一个判断小国外交的现实框架 | 每篇交付一条可复述机制 |
| 想读有故事的深度文章 | 用人物、危机、场景承载机制 |
| 不想读百科式南亚通史 | 避免流水账和制度堆叠 |
| 不满足于"巴铁""恐怖主义"等扁平标签 | 写结构性需求与利益计算 |

## 四、读者理解门槛

### 4.1 必须降低的门槛

以下内容必须翻译成普通读者能懂的话：

- NCA、SPD、SIFC、NAP、FATF、CPEC、APS、TTP、SAARC 等制度与机构缩写；
- "全谱威慑"（full-spectrum deterrence）等核战略术语；
- IMF 援助条件、债务展期、外汇储备等财政概念；
- 巴美同盟、反恐前线国、战略纵深等地缘安全术语；
- 宪制、Chief of Defence Forces、SIFC 决策机制等政治制度术语；
- 侨汇、劳务市场、能源安全等经济外交术语。

### 4.2 解释方式

优先使用：

1. 生活类比（贷款、存款、雇主、抵押）；
2. 机构/人物（巴军方、IMF、沙特央行、克什米尔线、阿富汗边境）；
3. 制度资格（谁有权否决、谁有权开支、谁有权签约）；
4. 资源流向（钱从哪来、风险给谁、谁获得控制权）；
5. "表面看是 A，实际机制是 B"。

避免：

- 直接抛英文缩写；
- 长段背景史；
- 大量年份堆叠；
- 论文式定义；
- 只讲结论不讲机制；
- 过度依赖"巴铁"或"印巴世仇"等情绪词。

## 五、读者最有效入口

| 入口 | 适用场景 | 示例 |
|---|---|---|
| 反常识问题 | 巴基斯坦总能在最后获得支持？ | 为什么它总能在"快不行了"的时刻获得支持？ |
| 危机场景 | 印巴冲突、阿富汗、IMF 谈判 | 2025 印巴四天冲突说明什么？ |
| 制度资格 | 军方、文官、宗教势力、IMF | 谁真正决定巴基斯坦的外交红线？ |
| 经济直觉 | 现金、贷款、存款、侨汇 | 巴基斯坦的现金流安全阀是什么？ |
| 现实回声 | 中国一带一路、海湾能源、IMF 改革 | CPEC 给巴基斯坦带来的不只是路 |
| 对比场景 | SAARC vs 联合国、CPEC vs 马歇尔 | 区域机制瘫痪时，联合国舞台为什么重要？ |

## 六、读者掉线风险

读者容易在以下位置掉线：

1. 开头直接抛"南亚地缘"概念；
2. 连续出现 NCA、CPEC、SIFC、APS、FATF 等缩写；
3. 历史背景铺太久（1947、1971、1998、2001、2015 接连抛出）；
4. 没有明确"这和巴基斯坦'兑换术'有什么关系"；
5. 小标题不能提示推进；
6. 人物故事讲太久但机制没有出来；
7. 结尾突然升到"文明冲突"或"伊斯兰世界困境"等宏大判断。

处理方式：

- 每个复杂概念第一次出现时做普通话翻译；
- 每节都回答"这一步让谁获得了什么资源，谁的边界被强化"；
- 用一句短判断收束每个关键机制；
- 不依赖读者读过前文；
- 用三组不对称依赖、三层棋局等可记忆框架反复呼应。

---

## 七、读者收获标准

读完一篇文章后，目标读者至少应该能复述：

```text
这篇文章讲的是巴基斯坦在哪一层"兑换"上做文章。
中国 / 美国 / 海湾各提供了哪类不同的资源。
这一次兑换让巴基斯坦获得了什么、又让它的哪条边界被强化。
这件事对理解"地缘租金"型国家的活法有什么意义。
```

如果读者只能记住人物和故事，不能复述机制，文章未达标。

---

## 八、社交传播场景

读者愿意转发时，通常因为：

- 这篇文章解释了一个他以前模糊感受到的问题（如"巴铁"到底是什么意思）；
- 标题或核心判断可以变成谈资（"巴基斯坦不是选边，是管理不对称"）；
- 机制解释比普通地缘评论更深；
- 文章能帮助他理解现实中的中巴关系、IMF 援助、海湾能源博弈。

标题、开头和结尾应帮助读者形成可转述句。
