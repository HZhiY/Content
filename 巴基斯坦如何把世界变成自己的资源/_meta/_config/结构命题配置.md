# 结构命题配置

> 适用系列：巴基斯坦如何把世界变成自己的资源
> 用途：供结构标准、结构分析、方向把控、大纲和审稿阶段判断文章的洞察组合、承诺链和证明链是否成立。
> 核心原则：结构不是资料顺序，而是读者理解机制的顺序。

---

## 一、结构命题定位

本系列每篇文章都应围绕一个结构命题展开：

```text
某个结构性条件（对印安全 / 对阿边境 / 国内权力 / 财政脆弱性），
如何让巴基斯坦获得一组外部资源（战略 / 金融 / 现金 / 合法性），
又为什么这种"兑换"常常只换来生存、难换来结构转型。
```

结构命题必须能回答：

1. 文章从三层棋局中的哪一层进入；
2. 核心机制是什么；
3. 巴基斯坦获得了什么资源；
4. 谁承担了什么约束；
5. 这一步如何服务"三层棋局"的总框架。

---

## 二、六类洞察分工

### 2.1 入口洞察

作用：把读者带进问题。

要求：

- 具体；
- 好懂；
- 有问题感；
- 不需要专业背景。

常见入口：

- 一个危机场景（2025 印巴冲突、APS 惨案、阿巴空袭）；
- 一个制度规则（NCA、CPEC 升级、SIFC 决策机制）；
- 一个 IMF 谈判或海湾存款事件；
- 一个反常识问题（"为什么总能在最后获得支持？"）。

### 2.2 骨架命题

作用：支撑全文主线。

格式：

```text
因为 A，巴基斯坦获得了 B 资源；当 B 资源变重要，C 就开始被 B 的逻辑反向重塑。
```

要求：

- 可被正文证明；
- 不过度抽象；
- 不超过事实边界；
- 能贯穿每个小节。

### 2.3 副洞察

作用：辅助主命题，解释某个环节。

要求：

- 不能抢主线；
- 不能引入另一篇文章的主题；
- 必须服务骨架命题。

### 2.4 新意洞察

作用：让文章区别于常见写法。

要求：

- 是解释角度的新意，不是事实猎奇；
- 必须被证据支撑；
- 不能为了新意牺牲准确。

### 2.5 反差洞察

作用：制造读者想读下去的张力。

常见反差：

- 表面是外交选择，实际是结构性需求再生产；
- 表面是反恐合作，实际是巴方议价筹码；
- 表面是 CPEC 帮助发展，实际是地缘 + 治理 + 安全的复合工程；
- 表面是核威慑让战争消失，实际是核威慑只抬高门槛；
- 表面是 SAARC 失败，实际是印巴矛盾绑架区域合作；
- 表面是巴铁，实际是分轴经营。

反差必须能被正文兑现。

### 2.6 结尾升维洞察

作用：把本篇机制放回三层棋局暗线。

要求：

- 只升一层；
- 从正文自然推出；
- 不引入新事实；
- 不写成宏大控诉；
- 不暗示"巴基斯坦必然崩溃"或"必然崛起"。

---

## 三、承诺链

文章必须形成清楚的承诺链：

```text
标题承诺
→ 引言提出问题
→ 方向主承诺
→ 大纲小节证明
→ 草稿正文兑现
→ 结尾回收
```

任一环节断裂，都应退回对应阶段。

---

## 四、证明链

证明链应按"机制理解顺序"组织，而不是按资料出现顺序组织。

推荐链条：

1. 表面现象；
2. 读者常见理解；
3. 关键反转；
4. 核心机制；
5. 机制如何运转；
6. 巴基斯坦获得了什么资源；
7. 谁被反向重塑；
8. 本篇在三层棋局中的位置。

---

## 五、结构评分维度

每个候选结构命题按 1-5 分评分。

| 维度 | 权重 | 说明 |
|---|---:|---|
| 主承诺清晰度 | 5 | 是否一句话说清文章要证明什么 |
| 证明链完整度 | 5 | 是否能从事实推到结论 |
| 层次适配度 | 5 | 是否服务三层棋局（国内 / 区域 / 外部） |
| 读者理解顺序 | 4 | 是否按读者能理解的顺序推进 |
| 事实安全 | 5 | 是否不突破事实边界 |
| 反差有效性 | 4 | 是否有张力且能兑现 |
| 副洞察克制 | 4 | 是否不抢主线 |
| 结尾升维安全 | 4 | 是否自然回到三层棋局 |

事实安全低于 4 分，结构命题不得通过。

---

## 六、一票否决项

出现以下任一项，结构命题不通过：

1. 主承诺无法被事实核查清单支撑；
2. 文章试图同时证明多个主命题；
3. 结构只是资料顺序，不是论证顺序；
4. 入口洞察和骨架命题不一致；
5. 反差洞察正文无法兑现；
6. 结尾升维超出正文证明；
7. 副洞察变成另一篇文章；
8. 方向把控已放弃的内容被重新引入；
9. 需要读者读过前文才能理解；
10. 把复杂机制压成单一原因；
11. 把"巴铁""印巴世仇"等情绪词当作机制使用；
12. 直接套用对印、对美、对华等情绪化立场。

## 七、按文章类型的结构建议

### 7.1 机制型 × 分析型

结构：

```text
现象 → 机制部件 → 传导链路 → 失效或转折 → 框架提炼
```

适合：三组不对称依赖、CPEC、SIFC、SAARC 等。

### 7.2 逻辑型 × 分析型

结构：

```text
表面选择 → 各方利益 → 行为逻辑 → 制度放大 → 底层判断
```

适合：1971 创伤、2025 印巴危机、IMF 谈判、海湾存款。

### 7.3 对比型 × 分析型

结构：

```text
A 路径 → B 路径 → 差异点 → 资源入口 → 胜负逻辑
```

适合：SAARC vs 联合国、CPEC vs 马歇尔、倚美时代 vs 走廊时代。

### 7.4 叙事型 × 分析型

结构：

```text
强场景 → 人物 / 机构行动 → 约束条件 → 机制浮现 → 制度化结果
```

适合：2025 印巴危机、APS 惨案、阿巴空袭、IMF 关键谈判。

叙事型必须注意：故事只是入口，机制才是交付。

### 7.5 规律型 × 分析型

结构：

```text
多个案例 → 共同机制 → 条件边界 → 规律提炼 → 系列收束
```

适合：西向多线平衡、收束篇。

## 八、大纲检查问题

生成或审阅大纲时必须问：

```text
[ ] 本文主承诺是否一句话可说清？
[ ] 每节是否服务同一个骨架命题？
[ ] 是否有一节只是在堆资料？
[ ] 是否按读者理解顺序推进？
[ ] 是否过早使用抽象概念？
[ ] 是否把故事讲成了目的？
[ ] 是否有副洞察抢主线？
[ ] 结尾是否自然回到三层棋局？
[ ] 标题、引言、大纲、结尾是否承诺一致？
[ ] 是否避免使用"巴铁""恐怖主义国家"等扁平标签？
[ ] 2025-2026 局势是否标注口径与刷新节点？
[ ] 是否在 `03_文风与大纲/自由审读_大纲.md` 落点生成自由审稿产物？
[ ] 大纲审阅是否在 `大纲审阅.md` 中对自由审稿产物逐条回应？
```

---

## 九、方向把控输出要求

方向把控最终必须明确：

1. 方向主承诺；
2. 入口洞察；
3. 骨架命题；
4. 可用副洞察；
5. 应放弃洞察；
6. 标题承诺边界；
7. 大纲必须证明的链条；
8. 结尾允许升维到哪里。

不得只写"方向可行"这类空泛结论。

---

## 十、跨篇勾稽约束

为避免不同文章之间出现事实或叙事冲突，应统一以下口径：

- 三层棋局统一表述：国内权力结构 + 区域安全结构 + 外部资源结构；
- 三组不对称依赖统一表述：中国（战略背书 / 基础设施 / 军工）+ 美国（外交环境 / 国际金融）+ 海湾（现金 / 能源 / 侨汇）；
- 时间线统一锚点：1947、1971、1998、2001、2015、2022、2025、2026；
- 制度名首次出现给中文释义，后续使用保持一致；
- 不在两篇文章中给出互相矛盾的事实结论；
- 引用同一份数据时使用同一时间口径。
