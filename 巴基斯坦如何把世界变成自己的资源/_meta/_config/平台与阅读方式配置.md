# 平台与阅读方式配置

> 适用系列：巴基斯坦如何把世界变成自己的资源
> 用途：统一今日头条 / 微信公众号类中文长文的阅读场景、手机端节奏、信息流入口和发布格式要求。
> 核心原则：先让读者看懂入口，再让读者愿意继续读机制。

---

## 一、默认平台场景

本系列默认面向：

1. 今日头条信息流；
2. 微信公众号长文；
3. 手机端阅读；
4. 非专业但有兴趣的泛国际时政、商业、一带一路、南亚观察读者。

平台阅读特点：

| 场景 | 特点 | 写作要求 |
|---|---|---|
| 信息流首屏 | 读者先看标题和前几行 | 标题、开头、小标题必须快速降低理解成本 |
| 手机阅读 | 屏幕窄，跳读多 | 段落短，小标题密，逻辑节点清楚 |
| 长文阅读 | 读者耐心有限 | 每 3-5 段要有推进，不要长时间铺背景 |
| 收藏转发 | 读者需要可复述收获 | 文章必须有一句能带走的机制判断 |

---

## 二、阅读节奏

### 2.1 段落长度

默认段落长度：

```text
1-4 行为主，最长不超过 6 行。
```

长段只适合：

- 必须完整解释一个机制链；
- 段内有清楚的因果推进；
- 不含多个并列概念。

### 2.2 句子长度

默认句子要求：

- 多用短句和中句；
- 少用多重从句；
- 一句话只推进一个判断；
- 避免英文式长定语；
- 不用论文式嵌套。

### 2.3 小标题密度

建议每 600-1000 字设置一个小标题。

小标题要承担"路标"功能：

1. 告诉读者本节解决什么问题；
2. 帮助跳读读者快速回到主线；
3. 不要只写抽象词。

推荐小标题格式：

```text
问题句 / 机制判断句 / 对比句
```

不推荐：

```text
背景介绍
制度演变
影响分析
结论
```

## 三、开头进入方式

本系列开头不能直接抛作者已经想明白的金句。

推荐"三层进入法"：

1. **先给普通认知**：读者通常怎样理解这个题材（如"巴基斯坦总在夹缝求生"）；
2. **再给关键反转**：本文真正要讲的不是表面故事，而是背后的机制（如"它不是夹缝求生，而是同时管理三组不对称依赖"）；
3. **最后点出入口**：这个机制如何改变巴基斯坦的实际命运（如"这套机制能换生存、难换转型"）。

开头必须回答：

```text
读者为什么现在要读这篇？
读者不懂这个机制，会误解什么？
本文会帮读者看懂什么？
```

## 四、信息流识别要求

### 4.1 标题与首段

标题和首段必须形成承接：

- 标题提出对象和解释承诺；
- 首段迅速确认文章不会跑题；
- 前 300 字内出现核心问题；
- 前 500 字内出现本文主承诺。

### 4.2 关键词前置

尽量在标题、开头、小标题中前置：

- 国家名（巴基斯坦）；
- 机构名（IMF、CPEC、SAARC、联合国、塔利班）；
- 制度名（NCA、SIFC、FATF）；
- 危机名（2025 印巴冲突、APS、阿巴空袭）；
- 概念词（核威慑、克什米尔、地缘租金、安全国家）。

避免开头连续使用：

- 抽象概念；
- 大判断；
- 空泛金句；
- 没有解释的隐喻；
- "巴铁""恐怖主义国家"等扁平标签。

---

## 五、手机端可读性检查

正文发布前检查：

```text
[ ] 连续长段是否过多？
[ ] 每个小标题是否能独立提示本节内容？
[ ] 前 300 字是否降低理解门槛？
[ ] 是否有超过 6 行的段落可拆分？
[ ] 是否有过多抽象词连续出现？
[ ] 是否存在英文式句子或翻译腔？
[ ] 是否有读者跳读时会断线的位置？
[ ] 是否避免了"巴铁""恐怖主义国家"等扁平标签？
```

## 六、标题、插图与 HTML 的平台要求

### 6.1 标题

标题优先级：

```text
主题清楚 > 文题一致 > 点击入口 > 解释承诺 > 系列一致
```

不允许为了点击牺牲文题一致。

### 6.2 插图

插图应服务：

- 标题承诺；
- 核心机制；
- 读者入口。

不应制造正文没有的阴谋感、恐慌感或宏大对抗感。

可考虑类型（具体由插图阶段决定）：

- 三层棋局关系图；
- 三组不对称依赖流向图；
- 时间线（1947—2026 关键节点）；
- 印巴、阿巴、巴伊边境示意图；
- 巴基斯坦战略位置图（含克什米尔、瓜达尔、阿富汗、霍尔木兹方向）；
- SAARC vs 联合国舞台对照图。

### 6.3 HTML

HTML 排版应：

- 保持标题层级清楚；
- 强化小标题路标；
- 避免过度装饰；
- 不让样式盖过正文机制。

---

## 七、平台风险

禁止：

1. 标题党；
2. 仿官方通知；
3. 恐吓式表达；
4. 夸张绝对判断；
5. 无依据现实影射；
6. 情绪煽动；
7. 生硬蹭热点；
8. 用隐喻替代事实；
9. 借"反西方""反印度"立场代替结构解释。

---

## 八、术语首现规范

由于本系列涉及 NCA、CPEC、SIFC、APS、FATF、SAARC、TTP 等大量英文缩写，发布版必须遵守：

- 首次出现给中文全称 + 英文缩写；
- 后续段落可直接使用缩写；
- HTML 端可加 `<abbr>` 标签，鼠标悬停显示全称；
- 同一篇文章内术语口径前后一致。

推荐首现模板：

```text
国家指挥当局（National Command Authority，下文简称 NCA）
中巴经济走廊（China-Pakistan Economic Corridor，下文简称 CPEC）
特别投资促进委员会（Special Investment Facilitation Council，下文简称 SIFC）
```

如果术语在不同文章中含义不同（如 SIFC 在不同年份的运行机制），应在文章内说明。
