# 系列基调配置

> 适用系列：巴基斯坦如何把世界变成自己的资源
> 用途：供方向、文风、大纲、审稿、修订、发布检查等 agent 读取，统一系列气质、解释边界和表达原则。
> 核心母题：巴基斯坦不是"在大国之间选边"，而是把不安全感、地理位置和制度短板，持续经营成一张外部资源网。

---

## 一、系列定位

本系列是**国际机制解释型深度长文**，不是单纯南亚通史、外交回忆录、阴谋论揭密，也不是"巴铁"式情感叙事。

它要回答：

```text
巴基斯坦是怎么把地缘位置、安全焦虑和制度脆弱性，一步步变成外部资源的？
为什么一个看上去总在"夹缝求生"的国家，常常能在最不被看好的时候再次获得支持？
这种"兑换术"为什么能换来生存，却很难换来结构转型？
```

核心叙述不是"巴基斯坦天生会外交"，也不是"巴基斯坦是地缘棋子"，而是：

```text
巴基斯坦最擅长的不是"在大国之间选边"，
而是把对印安全竞争、对阿边境压力、国内军民权力格局和经济脆弱性，
捆成一个整体，向中国、美国、海湾国家和多边平台持续兑换支持。
这种"转换术"能换来生存，却很难换来结构转型。
```

---

## 二、系列总气质

| 维度 | 要求 |
|---|---|
| 总体气质 | 克制、清楚、有结构感、有历史纵深 |
| 解释方式 | 用危机与机制承载故事，用结构解释现实 |
| 叙述视角 | 看国内权力结构、区域安全压力、外部资源需求如何相互塑造 |
| 情绪强度 | 有 tension，但不煽动；有判断，但不控诉 |
| 现实连接 | 可以点出现实回声（如中巴关系、海湾能源、IMF 改革），但不能把历史材料粗暴套到当下 |
| 读者收获 | 读完获得一套判断小国如何在大国博弈中生存的框架 |

一句话原则：

```text
不写"谁坏"，写"什么结构性需求让结果一步步变成这样"。
```

---

## 三、三层棋局框架

全系列围绕"巴基斯坦如何把结构性条件持续兑换成外部资源"展开。

| 层次 | 核心问题 | 典型材料 |
|---|---|---|
| 国内权力结构 | 谁真正决定对外红线 | 军方、联合政府、SIFC、司法、宗教动员 |
| 区域安全结构 | 巴基斯坦最怕什么 | 印度常规优势、克什米尔、阿富汗边境、TTP、核门槛 |
| 外部资源结构 | 谁给钱、谁给路、谁给合法性 | CPEC、IMF、海湾存款与侨汇、联合国平台 |

每篇文章必须明确自己主要服务哪一层，不要一篇文章同时吃下三层。

三层之间的相互作用：

```
国内权力结构 → 决定  → 区域安全议程 → 触发  → 外部资源需求
外部资源输入  → 强化  → 国内权力格局 → 反向  → 区域安全选择
区域安全结构 → 决定  → 外部资源可获得性 → 再影响 → 国内合法性叙事
```

## 四、写作总原则

### 4.1 单篇独立

每篇文章都必须独立成立。

读者不看前文，也能理解：

1. 本篇在问什么；
2. 本篇讲哪个机制；
3. 本篇结论是什么；
4. 本篇如何放回"三层棋局"的暗线。

### 4.2 暗线统一

每篇文章都从不同角度回答：

```text
巴基斯坦如何把结构性不安全感、经营短板和地缘位置，
持续兑换成外部资源？
又为什么这种"兑换"常常只换来生存，不换来转型？
```

但正文中不要机械重复"兑换"这个词，要让读者从机制里自己看到这个结论。

### 4.3 每篇只打一颗主钉

一篇文章只解决一个核心问题，交付一个核心机制。

禁止：

- 同时讲军方、文官、宗教、IMF、海湾、中美等多个大问题；
- 在结尾突然升到全系列总论；
- 为了宏大感牺牲单篇清晰度。

### 4.4 不写阴谋论

禁止把巴基斯坦写成神秘操盘者或被动棋子。

推荐写法：

```text
巴基斯坦的"兑换术"能成功，很多时候不是靠哪一方精心设计，
而是靠结构性需求（对印安全、对阿边境、能源与现金、IMF 资金）反复叠加、
各方在自身利益下做出选择。
```

### 4.5 不写教科书

不要按年代平铺，不做术语介绍大全。

每篇必须从一个反常识问题进入，用故事承载机制，用机制解释现实。

### 4.6 慎用"标签国家"框架

禁止把巴基斯坦写成单纯的"失败国家""军国国家""代理人国家""恐怖主义国家"。

正确写法是拆开写：

- 谁拥有正式权力；
- 谁拥有事实否决权；
- 谁掌握现金流阀门；
- 谁负责对外表述与谈判；
- 谁有街头动员能力。

## 五、优先内容类型

根据本系列母题与执行摘要，建议优先采用：

| 类型 | 用法 |
|---|---|
| 机制型 | 解释三组不对称依赖、三层权力分工、区域安全压力如何运转 |
| 逻辑型 | 解释巴基斯坦为什么把外部危机当谈判筹码，为什么能换生存难换转型 |
| 分析型 | 提炼框架，帮助读者获得判断工具 |
| 对比型 | 用于 SAARC vs 联合国、CPEC vs 马歇尔、倚美时代 vs 走廊时代等天然反差题 |
| 叙事型 | 只作为入口，不作为默认结构；故事必须服务机制 |
| 规律型 | 只用于多案例归纳或收束篇，避免空泛 |

最优先组合：

```text
机制型 × 分析型
```

## 六、表达口径

### 6.1 推荐表达

- "兑换术"
- "机制"
- "三组不对称依赖"
- "国内权力结构 / 区域安全结构 / 外部资源结构"
- "安全国家本能"
- "现金流感官"
- "合法性包装"
- "分轴经营"
- "综合议价包"
- "把结构性需求持续换成外部资源"

### 6.2 慎用表达

- "巴铁"作为情绪化褒贬；
- "恐怖主义国家""失败国家""军国国家"等扁平标签；
- "代理人战争""帝国棋局"等阴谋论框架；
- "南亚火药桶"等老套意象；
- "彻底改变""唯一原因"等绝对化表达；
- "中巴友谊万岁"等口号化措辞。

慎用词只有在事实和正文充分支撑时才能使用，并必须降级为机制解释。

### 6.3 禁止表达

- 阴谋论口吻；
- 民粹控诉腔；
- 没有证据的道德审判；
- 把复杂制度变化归因给单个坏人或单次阴谋；
- 把南亚历史直接套成对当代具体国家的判断；
- 用"穆斯林国家天然如何"替代机制分析；
- 借"反西方"或"反印度"立场代替结构解释。

---

## 七、结尾基调

结尾应该完成三件事：

1. 回收本篇机制；
2. 点出本篇属于三层棋局中的哪一层；
3. 给读者一个可带走的判断框架。

结尾不应：

- 突然升到文明冲突或地缘终局；
- 强行预测未来；
- 写成金句堆叠；
- 把历史案例直接变成现实立场；
- 暗示"巴基斯坦必然崩溃"或"巴基斯坦必然崛起"等单一结局。

推荐结尾力度：

```text
克制地指出：巴基斯坦的"兑换术"能换生存、难换转型，
关键不在于它有多聪明，而在于结构性需求不断被再生产出来。
```
