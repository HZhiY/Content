# 传播评估配置

> 适用系列：巴基斯坦如何把世界变成自己的资源
> 用途：供传播标准、传播分析、方向把控和标题阶段判断候选洞察是否具备传播价值。
> 核心原则：传播不是把话说得更刺激，而是让目标读者一眼看见"这和我理解世界有关"。

---

## 一、传播定位

本系列传播卖点不是猎奇，也不是情绪宣泄，而是：

```text
用巴基斯坦对外操作的真实机制，解释一个小国如何把结构性需求
持续兑换成外部资源，又为什么这种"兑换"能换生存、难换转型。
```

读者愿意点击、读完、收藏或转发，是因为他获得：

1. 一个解释小国外交的反常识框架；
2. 一个可兑现的判断（"管理不对称""地缘租金""安全国家本能"等）；
3. 一个能转述给别人的机制故事；
4. 一个理解中巴关系、IMF 援助、海湾能源博弈、印巴核威慑的工具。

---

## 二、阅读意图分层

| 类型 | 特征 | 本系列策略 |
|---|---|---|
| 主动需求型 | 本来就想理解巴基斯坦、南亚、一带一路、中美博弈 | 提供准确对象、机制承诺和历史纵深 |
| 被动唤起型 | 信息流刷到，被标题问题吸引 | 用具体对象、危机场景、反差问题降低门槛 |
| 混合型 | 对大主题有兴趣，但需要强入口 | 标题和开头必须具体，正文交付机制 |

本系列默认服务"混合型读者"：有兴趣，但需要标题和开头帮他进入。

---

## 三、传播维度

### 3.1 目标读者匹配

判断候选洞察是否匹配：

1. 泛国际时政、商业、产业、一带一路读者是否关心；
2. 普通读者是否能通过一个国家或机构进入；
3. 读者是否能把洞察和现实问题（中巴关系、IMF 改革、海湾能源）联系起来；
4. 是否需要过多专业前置知识。

### 3.2 社交货币

读者转发时想展示：

- 我不是只看热闹，我能看懂国际机制的运行；
- 我理解小国在大国夹缝中的真实活法；
- 我能用历史解释现实；
- 我能把复杂国际问题讲清楚。

候选洞察应能压缩成一句可转述判断。

### 3.3 诱因 / 前置上下文

常见诱因：

- 对中巴关系、CPEC 进展的兴趣；
- 对印巴冲突、核武器与危机管理的疑问；
- 对 IMF 援助、海湾能源合作的现实感受；
- 对塔利班、阿富汗、TTP、跨境治理的模糊认知；
- 对"巴基斯坦为什么总能在最后获得支持"的好奇。

### 3.4 情绪

允许情绪：

- 恍然大悟；
- 原来如此；
- 反常识惊讶；
- 对结构性机制的冷静警觉。

不允许情绪：

- 愤怒煽动；
- 阴谋恐惧；
- 民粹控诉；
- 幸灾乐祸；
- 过度悲观或过度乐观；
- 借"反西方""反印度"立场代替结构解释。

### 3.5 公共性

好洞察不能只属于专业圈。

它应能连接：

- 中国一带一路、中巴关系、CPEC；
- IMF、世界银行、债务与改革；
- 沙特、阿联酋、卡塔尔、海湾能源；
- 印巴冲突、核武、克什米尔；
- 阿富汗、塔利班、反恐、TTP；
- 联合国、维和、安理会、SAARC。

### 3.6 实用价值

读者读完后应获得：

1. 一句判断；
2. 一个解释框架（三层棋局 / 三组不对称依赖 / 兑换术）；
3. 一个看现实的角度；
4. 一个能向别人复述的机制故事。

### 3.7 故事

故事是入口，不是目的。

故事必须承载机制：

- 巴基斯坦做了什么；
- IMF / 美国 / 海湾 / 中国为什么这样选择；
- 制度如何奖励或惩罚；
- 结构性需求如何被再生产；
- 资源如何从一方流向另一方。

---

## 四、传播评分

每个候选洞察按 1-5 分评分。

| 维度 | 权重 | 说明 |
|---|---:|---|
| 读者入口清晰度 | 5 | 是否一眼知道为什么要读 |
| 机制解释价值 | 5 | 是否能交付一套机制 |
| 目标读者匹配 | 5 | 是否匹配泛国际/商业/历史读者 |
| 社交货币 | 4 | 是否值得转述、收藏、分享 |
| 反常识或新意 | 4 | 是否有新角度但不违背事实 |
| 事实安全 | 5 | 是否不突破事实边界 |
| 系列一致性 | 4 | 是否服务"三层棋局"母题 |
| 平台风险 | 5 | 是否避免误导、夸张、阴谋腔 |

如"事实安全"低于 4 分，候选洞察不得进入方向把控。

---

## 五、一票否决项

出现以下任一项，传播评价直接不通过：

1. 事实核查未放行；
2. 标题或洞察承诺正文无法兑现；
3. 明显阴谋论；
4. 明显控诉腔；
5. 目标读者看不懂入口；
6. 与系列母题无关；
7. 照搬外部常见写法；
8. 只剩情绪，没有机制；
9. 需要过多专业知识才能理解；
10. 把复杂制度变化压成单一坏人或单一原因；
11. 把"巴铁""印巴世仇""伊斯兰世界"等情绪词当机制；
12. 直接套用对印、对美、对华等情绪化立场。

---

## 六、优先传播方向

优先选择：

1. 机制型 × 分析型；
2. 具体国家/机构/危机 + 机制承诺；
3. 经济直觉（现金、贷款、存款、能源）+ 制度解释；
4. 国家竞争 + 资源依赖（中美、海湾、IMF）；
5. 危机场景 + 协调/反噬（2025 印巴、2026 阿巴、APS）；
6. 反常识纠偏 + 正文可证明。

慎用：

1. 纯叙事；
2. 纯人物；
3. 纯地缘术语；
4. 纯宏大判断；
5. 纯情绪冲突。

---

## 七、传播分析输出要求

传播分析应回答：

```text
这个洞察谁会关心？
读者为什么会点？
读者读完能带走什么？
读者会把它转给谁？
标题和正文之间有什么承诺风险？
它与同题内容相比差异在哪里？
```

不得只写"有传播性""读者会感兴趣"这类泛泛判断。

---

## 八、传播自检

```text
[ ] 是否有明确目标读者？
[ ] 是否有具体读者入口？
[ ] 是否能压缩成一句可转述判断？
[ ] 是否有机制解释价值？
[ ] 是否服务三层棋局框架？
[ ] 是否避免阴谋论和控诉腔？
[ ] 是否不突破事实边界？
[ ] 是否能与标题承诺对应？
[ ] 是否避免使用"巴铁""恐怖主义国家"等扁平标签？
```
