# 标题方法论配置

> 适用系列：巴基斯坦如何把世界变成自己的资源
> 适用平台：今日头条 / 微信公众号类中文长文平台
> 适用任务：供 `07-title-write.md` 在标题阶段读取，用于生成、筛选、评分和解释标题候选。
> 核心原则：标题不是把文章说得更大，而是把文章已经证明的承诺说得更有入口。

---

## 一、账号标题定位

本系列不是消息型新闻，也不是纯文学化历史叙事，而是**国际机制解释型深度长文**。

读者点击标题，不只是为了知道发生了什么，而是为了理解：

```text
巴基斯坦为什么"总能在最后获得支持"？
它和中国 / 美国 / 海湾国家之间的关系到底在运转什么机制？
我读完后能不能获得一个更深的解释框架？
```

因此，本系列标题最适合采用：

```text
新闻钩子 / 国家对象 / 危机场景 + 制度冲突词 + 可兑现的解释承诺
```

标题必须同时满足：

1. 一眼知道文章讲什么（巴基斯坦、哪个机制）；
2. 看得出文章会解释什么机制（三组不对称 / 安全国家 / 核威慑 / 战略纵深）；
3. 有足够具体的对象或场景（中国、美国、海湾、IMF、印巴、阿富汗、克什米尔）；
4. 有可被正文兑现的冲突、悖论或解释承诺；
5. 不靠空洞悬念、夸张情绪或标题党骗点击。

---

## 二、标题总原则

### 2.1 首要原则

| 原则 | 要求 |
|---|---|
| 主题清楚 | 读者 3 秒内知道文章对象和大概问题 |
| 文题一致 | 标题承诺必须能被正文证明，不得超出正文 |
| 解释承诺 | 标题要显露"读完能懂什么机制" |
| 具体锚点 | 优先使用国家、机构、制度、危机、人物、地名 |
| 亮点前置 | 重要对象或关键词尽量前置，减少首屏识别成本 |
| 合规克制 | 避免夸张、误导、仿官方、悬念隐藏、情绪煽动 |
| 系列一致 | 保持"机制解释 + 三层棋局 + 历史纵深"的系列气质 |

### 2.2 一句话判断

```text
好标题像一扇门：读者一眼知道门后是什么，而且愿意推门进去。
```

### 2.3 禁止原则

标题不得：

1. 把局部事实写成全局规律；
2. 把相关关系写成因果关系；
3. 把多因素解释写成唯一原因；
4. 把审慎判断写成绝对判断；
5. 用抽象概念替代具体入口；
6. 用成语、隐喻、金句遮蔽主题关键词；
7. 用"震惊、炸裂、彻底、终于、看完沉默"等营销号表达；
8. 为了悬念故意隐藏关键信息；
9. 模仿官方通知、警告、紧急提醒口吻；
10. 承诺正文没有证明的结论。

## 三、本系列有效的标题逻辑

根据美国系列复盘经验与本系列母题，本系列高表现标题通常同时满足三点：

1. **具体对象前置**：国家、机构、人物、危机、地理坐标清楚。
2. **冲突或悖论明确**：例如"活下来""换来的不是发展""反噬""不是 A，而是 B"。
3. **解释承诺清楚**：例如"为什么""如何""真正逻辑""从来不靠……"。

### 3.1 高表现信号

| 信号 | 标题表现 | 方法论含义 | 实操提醒 |
|---|---|---|---|
| 具体对象前置 | "巴基斯坦为什么总能在最后获得支持" | 抽象议题要落到可识别对象 | 优先前置国家、机构、机制名 |
| 冲突词有效 | "活下来""换来的不是发展""反噬""困局" | 本账号适合制度冲突词 | 冲突词必须被正文兑现 |
| 解释承诺强 | "真正逻辑""为何""如何" | 核心卖点是解释能力 | 标题要说明读完能懂什么 |
| 双段式适配 | "活下来：巴基斯坦的'兑换术'与天花板" | 前段钩子，后段兑现 | 前段不要喧宾夺主 |
| 抽象词易空 | "地缘哲学" | 抽象概念会降低首屏识别 | 把抽象词降级成 CPEC、IMF、APS、克什米尔等实词 |
| 代词损失点击 | "为何它总是没事？" | 代词会打断识别 | 信息流标题慎用"它、这件事" |

### 3.2 本系列优先组合

根据本系列母题，优先采用：

```text
机制型 × 分析型
```

即：标题应尽量让读者感到——

```text
这篇文章会帮我拆开巴基斯坦的对外操作，看懂里面怎么转。
```

## 四、标题决策流程

每次生成标题前，必须按以下步骤处理。

### 4.1 压缩主旨

先回答：

```text
如果只允许用一句话概括全文，它到底在说什么？
```

要求：

- 不超过 60 字；
- 包含对象（巴基斯坦 / 某具体机制）；
- 包含机制或变化；
- 不使用空泛抽象词。

### 4.2 抽取冲突

找出文章最强的矛盾：

```text
谁和谁冲突？
什么和什么冲突？
表面动作和真实机制之间有什么反差？
```

常见冲突对：

- 生存 / 转型；
- 外部危机 / 内部议价；
- 现金 / 战略；
- 安全 / 经济；
- 国家利益 / 军方利益；
- 中美 / 印巴 / 阿巴；
- 区域主义 / 多边主义。

### 4.3 找读者入口

判断普通读者最容易从哪里进入：

| 入口类型 | 适合情况 | 示例方向 |
|---|---|---|
| 国家入口 | 文章核心是巴基斯坦 | 巴基斯坦为什么总能在最后获得支持？ |
| 危机入口 | 文章核心是 2025 印巴 / 阿巴冲突 | 2025 印巴四天冲突说明了什么？ |
| 制度入口 | 文章核心是 NCA、CPEC、SIFC、SAARC | CPEC 修了一路，为什么没有自动改掉国家脆弱性？ |
| 经济直觉 | 文章核心是 IMF、存款、贷款、侨汇 | 巴基斯坦为什么离不开海湾国家的现金流？ |
| 武器入口 | 文章核心是核武 / 印巴危机 | 核武为什么没有让印巴不再冲突？ |
| 反常识入口 | 正文能证明读者常识有误 | 巴基斯坦不是在选边，而是在管理不对称 |

### 4.4 选择主打面

每篇文章只选一个主打面，避免标题过载。

| 主打面 | 适合文章 | 标题倾向 |
|---|---|---|
| 机制解释 | 最适合本系列 | "为什么""如何""真正逻辑" |
| 制度冲突 | 有明显制度/权力冲突 | "活下来""换来的不是发展""困局" |
| 危机场景 | 有 2025 危机、APS 惨案 | "四天""空袭""从来不靠……" |
| 人物/事件 | 有 NCA、IMF 谈判、克什米尔线 | "关键时刻 X 做了 Y，后来 Z" |
| 反常识纠偏 | 正文能证明读者常识有误 | "不是为了 X，而是为了 Y" |
| 系列品牌 | 需要保持系列统一 | "巴基斯坦如何把世界变成自己的资源：……" |

### 4.5 组织关键词

必须列出：

1. 必须前置的关键词（巴基斯坦、中国、美国、海湾、CPEC、IMF、克什米尔、印巴、阿富汗、核武器等）；
2. 可放后半句的解释词；
3. 可用但慎用的冲突词（活下来、困局、反噬、代价等）；
4. 禁止使用或必须降级的词。

标题不能只有修辞，没有关键词。

### 4.6 生成结构壳

先选结构，再写标题。

优先结构：

1. `巴基斯坦为什么[结果]：因为[机制]`
2. `[对象]不是为了 A，而是为了 B`
3. `从 A 到 B：[主线]如何改写[对象]`
4. `[年份]年，[国家 / 机构]做了一个动作，后来[结果]`
5. `表面动作背后：真正变化的不是 A，而是 B`
6. `当 A 开始 B，C 就已经改变`
7. `[短钩子]：[解释承诺]`
8. `[反常识判断]：因为[机制]`

### 4.7 风险过滤

删除或降级以下标题：

1. 一眼看不出主题；
2. 只有成语或隐喻，没有实义关键词；
3. 过度抽象，如"哲学、启示、底层逻辑"单独做中心词；
4. 标题承诺超过正文证明；
5. 冲突词正文无法兑现；
6. 事实、年份、数字、人物、机构不安全；
7. 过度情绪化或平台风险高；
8. 关键词堆砌、不像自然中文；
9. 与同题常见标题过度同质化；
10. 系列感强但单篇打开率弱。

### 4.8 变体排序

最终至少输出：

1. 主推标题；
2. 稳健标题；
3. 信息流标题；
4. 系列一致性标题；
5. 高风险但可讨论标题。

## 五、标题评分表

每个标题必须按以下维度评分。默认每项 1-10 分，再乘以权重。

| 维度 | 权重 | 说明 |
|---|---:|---|
| 主题核心 | 10 | 读者必须一眼知道这篇在讲什么 |
| 文题一致 | 10 | 长期价值来自信任，不来自一次性骗点 |
| 读者入口 | 9 | 复杂议题需要人人能懂的入口 |
| 冲突与反常识 | 9 | 冲突决定点开冲动，但必须能兑现 |
| 解释承诺 | 9 | 本账号卖点是"看懂机制" |
| 平台合规风险 | 9 | 标题必须准确、清晰、反误导 |
| 具体锚点 | 8 | 国家、机构、制度、年份、人物降低理解门槛 |
| 信息密度 | 8 | 最好同时包含对象、冲突、结论中的至少两项 |
| 可读性与节奏 | 8 | 句式要有换气点，双段式适合本系列 |
| 搜索友好度 | 7 | 核心关键词前置，避免堆词 |
| 长度与格式 | 7 | 适合移动端单行或一行半识别 |
| 差异化 | 7 | 同题竞争下不能写成百科式标题 |
| 系列一致性 | 6 | 保持品牌感，但不能牺牲单篇打开率 |
| 情感基调 | 6 | 要有 tension，但不要像营销号 |

如标题在"文题一致"或"平台合规风险"低于 7 分，即使综合分高，也不得作为主推。

## 六、本系列优先使用的标题结构

### 6.1 机制解释型

```text
巴基斯坦为什么[结果]：因为[机制]
```

适用：解释国家、机构或制度选择。

示例方向：

```text
巴基斯坦为什么总能在最后获得支持：因为它在同时经营三组不对称依赖
```

### 6.2 从 A 到 B 型

```text
从 A 到 B：[主线]如何改写[对象]
```

适用：文章有清楚历史变化链条。

示例方向：

```text
从倚美前线国到中巴走廊枢纽：巴基斯坦的"换主"与"分轴"
```

### 6.3 不是 A，而是 B 型

```text
[对象]不是为了 A，而是为了 B
```

适用：纠正常见误解。

示例方向：

```text
巴基斯坦不是为了反恐而存在，而是把反恐当成对外议价工具
```

### 6.4 双段式机制型

```text
[短钩子]：[解释承诺]
```

适用：需要兼顾记忆点和解释承诺。

要求：

- 前半句不能空；
- 后半句必须补足对象和机制；
- 冒号前后不能重复同一信息。

示例方向：

```text
活下来：巴基斯坦的"兑换术"与天花板
```

### 6.5 反常识纠偏型

```text
你以为在 A，其实在 B
```

适用：正文能证明普通读者的第一理解有偏差。

注意：

- 慎用"你"；
- 如果"你以为"显得过强，可改成"看起来是 A，其实是 B"；
- 不得把复杂机制压成廉价反转。

### 6.6 年份/危机转折型

```text
[年份]年，[国家 / 机构]做了一个动作，后来[结果]
```

适用：关键年份、关键机构、关键事件非常明确。

注意：

- 年份必须准确；
- 结果不能夸大；
- 不要写成传奇故事，必须保留机制承诺。

### 6.7 生活场景入口型

```text
[生活场景]不是先[常识动作]，而是先[机制变化]
```

适用：现金、贷款、存款、雇主、能源等普通读者可感词明显时。

示例方向：

```text
巴基斯坦的现金流感官：不是先有发展，而是先有海湾存款
```

## 七、本系列慎用或禁用的标题方式

### 7.1 慎用

| 类型 | 问题 | 改法 |
|---|---|---|
| 纯成语开头 | 首屏关键词弱 | 成语后必须接具体对象，或把关键词前置 |
| 纯国家标题 | 容易像百科介绍 | 补机制承诺 |
| 纯抽象概念 | 像论文或书章 | 降级成具体制度、工具、行为 |
| 强冲突词 | 容易超过正文 | 检查正文是否兑现 |
| 过长双段式 | 手机端识别差 | 前半句短，后半句负责说明 |

### 7.2 禁用

1. 震惊式：`震惊、惊人、炸裂、彻底、终于`；
2. 恐吓式：`危险来了、所有人都要小心`；
3. 悬念隐藏式：`背后原因你想不到、真相让人沉默`；
4. 仿官方通知式：`重磅通知、紧急提醒、刚刚宣布`；
5. 过度绝对式：`唯一原因、彻底改变、一切都因为`；
6. 空泛鸡汤式：`时代的答案、历史的选择、人性的真相`；
7. 代词悬空式：`这件事说明了什么、为什么它会失败`；
8. 关键词堆砌式：把多个热词并列，不形成自然句子；
9. 把复杂制度变化压成单一阴谋或单一坏人。

## 八、平台与格式约束

### 8.1 长度

默认标题长度建议：

```text
18-32 个汉字
```

可接受范围：

- 短标题：12-18 字，适合高识别度对象；
- 标准标题：18-32 字，适合本系列大多数文章；
- 长标题：32-42 字，只在双段式且信息密度高时使用；
- 超过 42 字，需要强理由，否则重写。

### 8.2 移动端识别

标题必须适合手机首屏阅读：

1. 关键词尽量靠前；
2. 冒号前半句尽量短；
3. 避免连续三个以上抽象词；
4. 避免多个引号、括号、破折号堆叠；
5. 不用生僻制度名做唯一入口，除非读者画像明确适配。

### 8.3 搜索友好

标题中尽量包含至少一个可搜索关键词：

- 国家：巴基斯坦、印度、阿富汗；
- 机构：IMF、CPEC、SAARC、联合国、塔利班；
- 制度：核武、克什米尔、APS、FATF；
- 事件：2025 印巴冲突、反恐战争、分治；
- 概念：地缘政治、生存、外交、军事、安全。

避免为了 SEO 堆砌关键词。关键词必须自然进入句子。

## 九、标题生成输出要求

`07-title-write.md` 使用本配置时，必须输出以下类型标题。

### 9.1 主推标题

1-3 个。

要求：

- 主题清晰；
- 机制承诺强；
- 正文兑现充分；
- 事实口径安全；
- 适合当前平台发布。

### 9.2 稳健标题

3-5 个。

要求：

- 承诺克制；
- 事实安全；
- 适合审核敏感或风险较高文章。

### 9.3 信息流标题

3-5 个。

要求：

- 第一眼能懂；
- 入口强；
- 不使用标题党套路；
- 不隐藏关键信息。

### 9.4 系列一致性标题

2-4 个。

要求：

- 保持本系列"巴基斯坦如何把世界变成自己的资源"的长期品牌；
- 能与其他篇章并列；
- 不能为了系列感牺牲单篇打开率。

### 9.5 高风险但可讨论标题

0-3 个。

要求：

- 必须标注"不建议直接采用"；
- 必须说明风险；
- 必须给出降级改法。

## 十、A/B 测试规则

当需要 A/B 测试时，每组只改变一个变量。

可测试变量：

1. 关键词前置 vs 冲突前置；
2. 危机场景入口 vs 制度入口；
3. 人物/机构入口 vs 机制入口；
4. "如何/为何"问句 vs 判断句；
5. 短标题 vs 双段式标题；
6. 稳健表达 vs 反常识表达。

每组输出：

```text
组别名称：
标题 A：
标题 B：
标题 C：
测试变量：
预期优势：
风险：
```

不得用标题党方式做测试变量。

## 十一、定稿前自检清单

标题定稿前必须回答：

```text
[ ] 读者第一眼知道我在讲什么吗？
[ ] 读者能看出这篇会解释什么吗？
[ ] 标题中的国家、机构、制度、人物或场景够具体吗？
[ ] 标题承诺能被正文兑现吗？
[ ] 是否把局部事实写成全局结论？
[ ] 是否把相关写成因果？
[ ] 是否把多因素解释写成唯一原因？
[ ] 是否使用了事实核查清单不允许的事实？
[ ] 是否存在平台风险或标题党风险？
[ ] 是否有更具体、更短、更清楚的版本？
[ ] 是否保留了系列气质但没有牺牲单篇打开率？

```

如任一高风险项为"否"或"不确定"，不得作为主推标题。

## 十三、给标题 agent 的执行约束

当 `07-title-write.md` 读取本配置时，必须遵守：

1. 先看 `发布检查.md` 是否允许进入标题阶段；
2. 再看正文实际证明了什么；
3. 再用本配置生成标题方向；
4. 再按事实核查清单过滤风险；
5. 必要时读取证据台账复核具体事实；
6. 每个标题都要说明：
   - 命名理由；
   - 适配受众；
   - 承诺内容；
   - 正文兑现位置；
   - 风险提醒；
   - 评分；
7. 最终推荐必须优先选择"主题清楚 + 机制承诺强 + 文题一致 + 平台安全"的标题，而不是单纯最刺激的标题。

- 优先标题结构；
- 禁用表达；

- 示例标题库；
