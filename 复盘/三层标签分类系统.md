# 文章分类三层标签系统

> 基于核心洞察 + 写作目的 + 数据表现的综合分类框架
>
> 核心理念：用历史或国外的事情，讲不变的东西。

---

## 一、核心洞察类型（你挖出了什么）

决定文章"挖出了什么不变的东西"，按从素材中提取的洞察类型划分。

> 你的内容本质上都是"用历史或国外的事情讲不变的东西"，这一层分类的就是：你从素材中提取的是什么。

---

### 1.1 机制型

**目的**：揭示制度/系统运转的底层机制，让读者看到"里面是怎么转的"。

**读者收获**："原来是这样运转的"——搞懂一个系统或制度的内部运作方式。

**常用结构**：
1. 现象引入：某个制度/系统的表面表现
2. 机制拆解：把系统拆成几个核心部件，逐一讲解
3. 传导链路：部件之间如何联动、如何传导
4. 失效点：这个机制在什么地方会出问题
5. 规律提炼：这个机制的运作规律是什么

**示例**：
- "补丁困局：为什么制度越改越烂？"
- "集权死循环：为什么好制度总被执行者'做数字'"
- "影子宰相：为什么皇帝需要非正式权力？"

---

### 1.2 模式型

**目的**：提炼反复出现的失败/成功模式，让读者看到"历史总是相似的"。

**读者收获**："原来每次都是这个死法"——识别出一种反复出现的模式，以后遇到类似情况能快速判断。

**常用结构**：
1. 具体案例：一个完整的改革/事件过程
2. 关键转折：这个案例中决定成败的关键节点
3. 模式提炼：把具体案例抽象成一个通用模式
4. 其他验证：用 2-3 个类似案例验证这个模式
5. 读者应用：这个模式能帮读者判断什么

**示例**：
- "王安石变法：谁在反对，为什么反对？"
- "张居正一条鞭法：改革者为什么没有好下场"
- "免役钱与差役法：两种思路，同一种失败"
- "历代税改：为什么越改越复杂？"

---

### 1.3 规律型

**目的**：发现跨时代、跨地域的普遍规律，让读者看到"古今中外都一样"。

**读者收获**："原来古今中外都一样"——获得一个可以用来观察世界的底层规律。

**常用结构**：
1. 体系全景：这个系统/现象的全貌
2. 核心规律：提出一个跨时代的普遍规律
3. 多案例验证：用不同国家/不同时代的案例验证
4. 规律边界：这个规律在什么条件下成立、什么条件下失效
5. 当下映射：这个规律对今天的启示

**示例**：
- "日本资本循环：不是一次投资，是无限复利"
- "白银化：一场没人设计的货币革命"

---

### 1.4 逻辑型

**目的**：揭示权力/利益/人性的底层逻辑，让读者看到"背后到底是什么在驱动"。

**读者收获**："原来背后的逻辑是这样"——理解表面事件之下的真正驱动力。

**常用结构**：
1. 表面现象：一个引人关注的事件或现象
2. 利益拆解：各方在这个事件中想要什么、得到什么
3. 逻辑链条：从利益到行为的因果链
4. 历史重复：同样的逻辑在不同时代的体现
5. 底层洞见：这个逻辑揭示了什么不变的人性/权力法则

**示例**：
- "从陈胜吴广到范进中举：野心被装进笼子"
- "唐朝衰败：当体制不再能收编野心"

---

### 1.5 命运型

**目的**：通过个体在时代中的命运轨迹，让读者感受到"人逃不出这个局"。

**读者收获**："原来人逃不出这个局"——通过一个人的命运，理解时代的重量。

**常用结构**：
1. 人物出场：这个人是谁，起点在哪里
2. 时代背景：这个时代给了什么条件、设了什么限制
3. 关键抉择：面临什么选择，为什么这样选
4. 命运转折：选择之后发生了什么
5. 时代折射：这个人的命运说明了什么不变的道理

**示例**：
- "田中健太：一个人的创业三十年"

## 二、目的类型（写作目的/结构导向）

决定文章"怎么写"，按读者收获和内容结构划分。

### 2.1 解释型（Expository / Explainer）

**目的**：帮助读者理解某个概念、事件或机制。

**读者收获**：搞懂一件事

**常用结构**：
1. 引言 / 问题提出
2. 背景 / 原理
3. 详细解释（数据、案例、分析）
4. 结论或建议

**示例**：
- "为什么英镑能长期保持价值？"
- "一条鞭法如何把风险交给农民"

---

### 2.2 冲突型（Conflict / Controversy / Debate）

**目的**：呈现对立观点或矛盾事件，引发读者思考或共鸣。

**读者收获**：看到矛盾

**常用结构**：
1. 事件 / 问题引出
2. 双方或多方观点展示
3. 分析利弊、底层逻辑
4. 结论或提示读者自己判断

**示例**：
- "王安石 vs 司马光：好政策为什么总走样？"
- "日本持刀闯使馆事件后，一个人的认知是如何被塑造的？"

---

### 2.3 叙事型（Narrative / Storytelling）

**目的**：通过讲故事抓住读者，强调经历、事件发展或人物命运。

**读者收获**：感受经历

**常用结构**：
1. 背景铺垫
2. 事件展开
3. 高潮或转折
4. 收束或反思

**示例**：
- "他的三十年：省吃俭用还债"
- "从陈胜吴广到范进中举：野心被装进笼子"

---

### 2.4 分析型 / 框架型（Analytical / Framework）

**目的**：提炼规律或模式，把复杂信息抽象成框架。

**读者收获**：获得判断工具

**常用结构**：
1. 提出核心判断 / 框架
2. 拆解核心因素
3. 案例验证或数据支撑
4. 总结与延伸

**示例**：
- "从王安石到张居正：为什么好制度总被执行者'做数字'"
- "日本资本循环：不是一次投资，是无限复利"

---

### 2.5 对比型（Comparative / Contrast）

**目的**：通过对比不同对象、制度、国家或时期来突出差异或规律。

**读者收获**：发现规律

**常用结构**：
1. 对比对象介绍
2. 横向对比维度
3. 结论 / 洞察

**示例**：
- "日本模式 vs 世界银行模式"
- "英美债务应对：为什么英国没有崩溃？"

---

### 2.6 指导型 / 操作型（How-to / Practical Guide）

**目的**：提供具体操作步骤、建议或策略，帮助读者解决问题。

**读者收获**：知道怎么做

**常用结构**：
1. 问题或场景提出
2. 步骤或方法
3. 注意事项 / 案例

**示例**：
- "上海老人陪诊指南：一种情况一个办法"

---

## 三、目的类型选择轴（汇总）

| 类型 | 核心导向 | 读者收获 |
|------|----------|----------|
| 解释型 | 知识 / 原理 | 搞懂一件事 |
| 冲突型 | 观点 / 争议 | 看到矛盾 |
| 叙事型 | 事件 / 人物故事 | 感受经历 |
| 分析型 | 框架 / 逻辑 | 获得判断工具 |
| 对比型 | 差异 / 规律 | 发现规律 |
| 指导型 | 可操作 / 指南 | 知道怎么做 |

## 五、写作工作流

```
第一步：确定核心洞察类型
└─ 从素材中挖出了什么不变的东西？
   └─ 机制 / 模式 / 规律 / 逻辑 / 命运

第二步：选择目的类型
└─ 用什么方式呈现给读者？
   └─ 解释 / 冲突 / 叙事 / 分析 / 对比 / 指导

第三步：匹配结构
└─ 按目的类型的常用结构组织内容
└─ 确保结构能兑现核心洞察

第四步：发布并记录
└─ 发布后记录数据表现标签

第五步：定期复盘
└─ 统计各洞察类型 × 目的类型的数据表现
└─ 找出"什么洞察 + 什么呈现方式"的组合效果最好
```

---

## 六、选类型的关键问题

1. **这篇想让读者获得什么？**（目的）
2. **读者读完后能带走什么？**（收获）
3. **什么结构最能兑现标题的承诺？**（结构）

> 类型不是固定的，一篇文章可以混合多种类型，但必须有**主导类型**来决定整体结构。
