# 头条深度文章项目

> 用历史或国外的事情，讲不变的东西。
> 给头条成熟男性读者，写有判断、有质感的深度非虚构。

---

## 这是什么

这是一个个人写作项目的资料仓库，不是代码项目。

项目通过三个并行系列，持续在头条平台发布深度解读文章。每个系列都从特定素材出发（钱穆视角的中国古代制度 / 日本金融与东亚产业链 / 美国 150 年金融产业史），挖掘底层制度、机制、规律，让读者带走"对现实更稳的判断"。

**目标读者画像**：40+ 男性，受过完整教育，中高收入，对制度运行、组织秩序、权力结构有天然兴趣。读头条是为了在工作生活之外获得高质量精神放松和现实判断力，不是为了谈资和情绪刺激。

## _看板/ 是什么

`_看板/` 是项目级的"指挥台"，放跨系列共享的文档：

- **看板.md** — 一张表横向看三个系列的状态、节奏、数据表现
- **系列状态汇总.md** — 每个系列详细的篇目进度
- **目录约定.md** — 文件夹与文件命名规范
- **迁移计划.md** — 目录结构标准化计划
- **迁移脚本.ps1** — 执行目录迁移的 PowerShell 脚本

## 写作工作流

```
1. 选题：把候选题目放进对应系列的"待写清单"
            ↓
2. 大纲：在 <序号>_<标题>/大纲.md 里写结构
            ↓
3. 草稿：在同一个文件夹的 草稿.md 里完成全文（源文件唯一）
            ↓
4. 配图：放到 <序号>_<标题>/配图/ 子目录
            ↓
5. 定稿：草稿转成 定稿.html 准备发布
            ↓
6. 发布：在 复盘/<日期>_全系列文章数据记录.md 里追加数据
            ↓
7. 复盘：每月回看 复盘/三层标签标注与组合分析.md
```

## 跨系列通用方法论

放在 `复盘/` 下，是所有系列共享的：

- **[三层标签分类系统.md](./复盘/三层标签分类系统.md)** — 文章按"核心洞察类型（机制/模式/规律/逻辑/命运）"和"目的类型（解释/冲突/叙事/分析/对比/指导）"打二维标签，发布后补"数据表现"标签 🔥。所有文章发布后都要打三层标签。

每个系列还有自己的方法论：

- 《中国历代政治得失》→ `中国历代政治得失/_meta/定位简报.md`（14 节）+ `执行策略.md`（15 节）
- 《日本金融系列》→ `日本金融系列/_meta/内容创作方法论.md`（12 节实战手册）
- 《美国金融资本与产业资本系列》→ `美国金融资本与产业资本系列/_meta_美国金融资本与产业资本/内容撰写总纲.md`

## 命名约定

| 元素 | 规则 | 示例 |
|------|------|------|
| 编号 | 两位数字 `01`、`02`，同主题多角度用 `02a`、`02b` | `01_皇权与相权如何长期拉扯` |
| 分隔符 | 编号和标题之间用**单下划线** `_` | |
| 特殊篇 | 非数字编号的篇单独加 `特_` 前缀 | `特_特朗普与资本之争` |
| 单篇文件夹 | 最多 4 类文件：`大纲.md`、`草稿.md`、`定稿.html`、`配图/` | |
| 源 vs 发布 | 源一定是 `.md`，发布版是 `.html` | `草稿.md` → `定稿.html` |
| 废弃稿 | 统一放 `<系列>/废弃/`，不要藏在主目录 | |

详细规范见 [_看板/目录约定.md](./_看板/目录约定.md)。
