# 美国金融资本与产业资本系列

> 历史是镜子，照见当下。
> 美国 150 年金融产业史的 12 个关键节点。

---

## 系列定位

**表面**：美国金融资本与产业资本 150 年的共生史
**镜子里**：映射美国当下的官僚化、金融精英控制、实体经济空心化
**内核**：反官僚、反精英剥削——制度如何被设计来收割普通人

**核心论点**：

> 美国资本史的主流叙事（"金融资本剥削产业资本"）是倒因为果。
> 真实故事是：工业需求创造了金融制度——但后来，这个制度被精英捕获，变成了收割工具。

**叙事策略**：每篇结语从历史轻轻转向当下，让读者自己得出结论
**反面教训**：共生的逻辑如何变成寄生的逻辑

**目标读者**：对美国金融史、商业史、当下政经关系感兴趣的成熟读者。

## 系列统一结语方向

每篇文章结尾轻轻带出当代映射，让读者自己思考：

- 当年设计的"秩序"，如何变成今天的"收割"？
- 当年的"金融创新"，代价由谁承担？
- 为什么每一代人都相信"这次不一样"？
