# _工作流

内容生产流程。一篇文章从立项到成稿通常 13 次 agent 调用，两个人工决策点。

## 从哪开始

**要写一篇新文章** → 读 [`00_执行手册.md`](00_执行手册.md)，或者直接发给主 agent：

```text
文章标题：【标题】
按 _工作流/00_执行手册.md 执行。
```

**要改流程** → 改 [`01_agents/`](01_agents/) 下的模板，然后整文件复制到 `.cursor/agents/`（对照表在执行手册末尾）。

**要开一个新系列** → 复制 [`02_系列配置模板/系列配置.md`](02_系列配置模板/系列配置.md) 到 `【系列】/_meta/`，填好顶部的「账号：X」。读者、平台、文风、格式、标题方法都在账号级 `_配置/【账号】/`，不用重写。

## 目录

```text
00_执行手册.md          主 agent 唯一执行脚本
01_agents/              12 个 agent 模板（源），改这里
02_系列配置模板/         系列级薄配置模板 + 已用论点模板
_反馈/
  原始数据.tsv           平台数据，手动录入
  表现台账.md            脚本生成，含期内百分位与诊断分类
  首次复盘_30篇.md       2026-08 首轮分析
  观察池.md              单篇观察，未验证
  已验证规律.md          攒够 3 次同向才进来，唯一可据以改提示词的地方
  提示词变更日志.md       改了什么、依据哪条、怎么验证
_scripts/
  check.mjs             闸门校验，每段跑一次
  build-html.mjs        长文成稿 HTML，纯格式转换
  ledger.mjs            重算表现台账
_archive/               旧版流程（27 个 subagent），不再执行
```

## 流程一览

| 段 | 做什么 | agent | 停 |
|---|---|---|---|
| 0 | 立项：核心问题 + 读者已知 + 赌注 | project-init | |
| 1 | 事实：检索建表 + 独立复核 | fact-collect → fact-audit | |
| 2 | 角度：3-5 个候选 | angle-propose | **你选** |
| 3 | 结构：大纲 + 反方审查 | outline-plan → outline-redteam | |
| 4 | 草稿 | draft-write | |
| 5 | 审稿：最多 2 轮 | blind-read → hard-review（严格串行） | |
| 6 | 标题 + HTML | title-write + 脚本 | **你选** |
| 7 | 复盘（发布后异步） | retro-analyze | |
| — | 挖规律（攒够 3 条同向观察） | pattern-mine | **你确认升格** |

## 命令

运行要求：**Node.js 18 或更高版本**。当前脚本使用 ESM、空值合并和 `.at()`；Node 12 无法执行。先用 `node --version` 检查，版本不足时不要把语法报错误判为闸门失败。

```bash
# 闸门校验
node _工作流/_scripts/check.mjs "<项目路径>" --gate=3
node _工作流/_scripts/check.mjs "<项目路径>" --all
node _工作流/_scripts/check.mjs "<项目路径>" --config

# 生成 HTML（长文形态）
node _工作流/_scripts/build-html.mjs "<项目路径>"

# 录入新数据后重算表现台账
node _工作流/_scripts/ledger.mjs
```

闸门退出码非 0 即未通过。主 agent 不得用自己的判断代替脚本结论。

## 这版和旧版的区别

| | 旧版 | 这版 |
|---|---|---|
| agent 数 | 27 | 12（含发布后复盘与跨篇挖规律） |
| 单篇调用 | 27 起，实际 40-60 | 通常 13，返工时 14-16 |
| 中间文件 | 20+ | 9 |
| 审稿轮次 | 两阶段各 5 轮 | 1 段最多 2 轮 |
| 闸门判定 | agent 自述 | 脚本判定 |
| HTML | agent 生成 | 脚本生成 |
| 人工介入 | 只在崩溃时 | 两个固定决策点 |
| 系列配置 | 每系列 9 份 | 账号级 2 份 + 系列级 1 份 |

砍掉的是传播学分析卡、结构命题分析卡、密度审读、发布检查、成稿终审等中间产物——它们的读者只有下一个 agent，而下一个 agent 需要的信息量远小于文档本身。

保留的三个核心设计来自旧版：**检索与复核分成两个 agent**（防自证）、**零上下文盲读**（唯一不被剧透的视角）、**成稿卫生硬扫描**（防施工痕迹泄漏）。大纲不再让普通读者盲读，改用结构反方审查；硬审必须等同轮盲读落盘后再启动。
