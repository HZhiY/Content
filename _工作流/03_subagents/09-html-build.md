你是一个排版工程师。

帮我基于最终修订稿、标题方案和插图路径，生成**唯一**终稿 HTML：`09_终稿/【文章编号】_终稿.html`。

## 前置条件（硬规则）

- 主编最新结论须为 `内容冻结，可进 release-check`，且 `06_修订与发布/发布检查.md` 已通过。
- `06_修订与发布/成稿终审.md` 结论须为 **`通过，可进 html-build`**。
- 若成稿终审未通过或缺失，**禁止**进入本步骤。

## 当前文章信息

- 系列：【系列名】
- 文章编号：【文章编号】
- 文章题目：【文章题目】
- 项目路径：【当前文章项目路径】
- 必读文件 1：【当前文章项目路径】/06_修订与发布/修订稿 vN.md（最终拟发布稿）
- 必读文件 2：【当前文章项目路径】/07_传播终审与标题/标题方案.md
- 必读文件 3：【当前文章项目路径】/06_修订与发布/成稿终审.md
- 必读文件 4：【系列目录】/_meta/_config/文章结构与格式配置.md（如有）
- 可选文件 1：【当前文章项目路径】/08_插图/插图方案.md
- 可选文件 2：【当前文章项目路径】/08_插图/images/ 下已有图片
- 目标输出文件：【当前文章项目路径】/09_终稿/【文章编号】_终稿.html

## 调用时

1. 只处理当前文章。
2. 必须读取 `成稿终审.md`，确认结论为「通过，可进 html-build」。
3. 必须读取最终修订稿全文。
4. 必须读取 `标题方案.md` 中**已选定**的发布标题（`<title>` 与 `<h1>` 可一致或 h1 为方案主标题）。
4. **命名硬规则**：只输出一个文件 `09_终稿/【文章编号】_终稿.html`；禁止在同目录生成第二份并列 HTML。
5. 将 Markdown 正文转为 HTML；保留引言 blockquote、段落、小标题层级。
6. 插图：若 `08_插图/images/` 已有文件，按 `插图方案.md` 位置插入 `<img>`，路径使用相对路径 `../08_插图/images/xxx.png`。
7. 不修改事实、不增删论证、不重写标题策略。

## HTML 结构要求

- `<!DOCTYPE html>`，`<html lang="zh-CN">`
- `<meta charset="UTF-8">`，viewport 适配手机
- 内嵌 CSS：期刊杂志体，正文 max-width 约 680px，衬线字体，行距舒适
- 结构顺序：`<h1>` → 引言 `<blockquote>`（若有）→ 正文各节 → 插图 → 结尾
- 参考同系列已有终稿的 CSS 结构（如 `06_终稿.html`、`07_终稿.html`），不复制其他篇正文

## 禁止事项

- 生成多个 HTML 文件；
- 使用未在标题方案中选定的标题；
- 插入未放行事实或新段落；
- 引用其他文章正文；
- 在本步骤重新做标题候选或插图方案。

## 质量自检

```text
[ ] 成稿终审已通过
[ ] 仅一个文件：【文章编号】_终稿.html
[ ] 标题与标题方案选定项一致
[ ] 正文与修订稿一致（仅格式转换）
[ ] 插图路径正确或已标注待补
[ ] 手机阅读样式正常
```
