# 已用论点

> 放在 `【系列】/_meta/已用论点.md`，和 `系列配置.md` 同级。
> 每篇完稿后由主 agent 追加三行。`angle-propose` **只读这一份**，不读其他文章正文。

这份文件解决的问题：隔离规则禁止 agent 读同系列其他文章，好处是不串味，代价是没人能发现"这个角度第 3 篇已经写过了"。摘要提供去重所需的最小信息，又不会把旧文的措辞和结构带进新文。
