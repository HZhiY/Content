## 二、每个文件职责

### 0.1 项目初始化

- `README.md`：项目入口，含 8 条选题表、系列 9 件套配置引用、执行原则、当前状态。
- `总计划.md`：主题包计划书，明确共享资料范围与 8 条边界。
- `00_目录结构.md`：本文件。

### 1. 资料阶段（主题包共享）

- `01_资料/资料.md`：网页、小程序、公众号、App、验证工具、复杂度等共享资料；按概念分类；标注待补。
- `01_资料/证据台账.md`：P0/P1/P2 事实主张、来源、风险等级、推荐措辞。
- `01_资料/事实核查清单.md`：核验结论，决定能否进入大纲与草稿。

### 2. 洞察与方向

- `02_洞察及主题/外部内容搜索.md`：小红书等平台同类「产品形态选择」科普的外部角度与差异化约束。
- `02_洞察及主题/洞察及主题初选.md`：候选洞察；覆盖 8 条图文。
- 传播学/结构命题四卡：对主题包结构命题打分。
- `02_洞察及主题/方向把控.md`：主题包价值、各条目方向、事实边界。

### 3. 文风与大纲

- `03_文风与大纲/文风卡.md`：本篇文风卡（提炼自系列 9 件套 + 方向把控）。
- `03_文风与大纲/大纲.md`：**图文条目拆分大纲**（非长文大纲）；含 8 条拆分表与卡片结构。
- `03_文风与大纲/读者审稿卡.md`：读者侧审稿维度。
- `03_文风与大纲/自由审读_大纲.md`、`大纲审阅.md`：大纲阶段审阅。

### 4. 草稿

- `04_草稿/草稿.md`：**图文组合集**格式；含 8 条图文（每条 6 卡 + caption）。

### 5. 审阅

- 阶段 A/B 标准审稿链；审稿对象 = 全包图文组合集或单条（按审稿政策）。
- 内容密度审读按**单条图文**检查 500-800 字、卡片 30-90 字。

### 6. 修订与发布

- `06_修订与发布/修订稿 vN.md`：审稿通过后的图文组合集。
- `发布检查.md`：内容闭环（主编内容冻结后）。
- `成稿终审.md`：格式终审（HTML 前）；逐条逐卡检查。

### 7–9. 标题、插图、终稿

- `标题方案.md`：主题包工作标题 + 各条目发布标题（3-5 候选 + 1 选定）。
- `08_插图/`：按「图文 NN / 卡片 N」组织视觉方案。
- `09_终稿/01_终稿.html` … `08_终稿.html`：各条目图文预览页。

## 三、文件使用规则

1. **层级**：栏目 → 主题包（本项目）→ 图文条目（发布单元）→ 卡片页。
2. **命名**：版本号 `v1`、`v2`…；终稿 HTML 为 `01_终稿.html` … `08_终稿.html`。
3. **大纲/草稿格式**：服从 `_meta/_config/文章结构与格式配置.md`；不得写成长文结构。
4. **不需要的模块**：长文式引言、正文分节、结尾、小尾巴、相关文章、学术脚注——按配置不需要。
5. **HTML 禁止重写正文**：排版与格式实现 only；正文修改须回到修订稿。
6. **不引入未核事实**：关键口径先入证据台账。
7. **风险边界**：不写灰色教程、规避教程、暴富话术；国外仅参考系。

## 四、阶段推进顺序

```text
project-setup → source-research → evidence-ledger → fact-check
→ ecosystem-scan → insight-select → communication/structure 链 → direction-decide
→ style-guide → reader-criteria → outline-plan → free-review → outline-review
→ draft-write
→ [每轮审稿] free-review + reader-review + density-edit → editor-review → draft-revise
→ release-check（内容闭环，须主编「内容冻结」）
→ title-ecosystem → title-write → illustration-plan
→ format-final-check（成稿终审）→ html-build
```

### 阶段说明

| 阶段 | subagent | 输出 | 备注 |
|---|---|---|---|
| 0.1 project-setup | project-setup | 本目录三文件 + 子目录 | 已完成 |
| 1.1 source-research | source-research | `01_资料/资料.md` | 全包共享资料 |
| 1.2 evidence-ledger | evidence-ledger | `证据台账.md` | 优先各条目 P0 |
| 1.3 fact-check | fact-check | `事实核查清单.md` | P0 通过后方可起草 |
| 2.x 洞察链 | ecosystem-scan 等 | `02_洞察及主题/*` | 覆盖 8 条 |
| 3.x 文风大纲 | style-guide 等 | `03_文风与大纲/*` | 大纲含 8 条 |
| 4.1 draft-write | draft-write | `04_草稿/草稿.md` | 8 条图文组合集 |
| 5.x 审稿 | free/reader/density/editor | `05_审阅/*` | — |
| 6.x 修订发布 | draft-revise / release-check | `06_修订与发布/*` | — |
| 7.x 标题 | title-ecosystem / title-write | `07_传播终审与标题/*` | 各条目标题 |
| 8.1 插图 | illustration-plan | `08_插图/*` | 各卡视觉 |
| 8.2 成稿终审 | format-final-check | `成稿终审.md` | 逐卡字数 |
| 9.1 HTML | html-build | `09_终稿/*.html` | 图文预览页 |

### 硬约束

1. 每条图文独立可发布，不强制依赖同包其他条目。
2. 单条图文 500-800 字；单卡 30-90 字。
3. 无禁用表达（见文风禁用清单）。
4. 事实准确，风险边界守住。
5. 不以暴富、标题党、灰色教程换传播力。
