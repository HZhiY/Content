# 02_第一款产品形态选择

> 系列：一个人做产品  
> 栏目：03 产品形态选择  
> 项目类型：主题包（02 单篇项目）

---

## 文章定位

本主题是「一个人做产品」系列的第二个主题包，面向有基础编程能力、准备做第一款小产品的中国个人开发者，系统整理**第一款产品形态选择**所需的概念与判断框架。

主题包覆盖网页、小程序、公众号、App 等形态的特点、适用场景，以及个人开发者常见的形态选择与复杂度避坑。生产单位为整个主题包（资料一次查、草稿一次写），发布单元为 8 条独立图文。

一句话定位：

```text
代码能写出来后，第一款产品该做成网页、小程序、公众号还是 App？先搞清楚各自适合什么。
```

---

## 核心问题

一个中国个人开发者做第一款产品时，网页、小程序、公众号、App 各自适合什么场景？为什么很多个人项目不适合一开始做 App 或做太复杂？有没有更轻的验证方式？

---

## 暂定核心判断

第一款产品的形态选择，本质是在「触达用户的方式」和「开发与维护成本」之间做权衡；个人开发者通常更适合从低成本、可快速迭代的形态起步，待需求验证后再考虑更重的产品形态。待资料研究后确定。
