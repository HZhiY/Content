# 一个人做产品

> 小红书图文系列。记录中国个人开发者做小产品时的基础设施问题。  
> **服从** `_工作流/02_单篇文章从0到HTML成稿执行手册.md`；单篇项目 = 主题包；发布单元 = 图文条目。

---

## 系列定位

```text
一个中国开发者做小产品时的基础设施笔记。
```

- **主线**：国内个人开发者基础设施（域名、备案、支付、小程序、AI 开发、分发等）
- **辅助**：国外工具作参考系，不写规避教程
- **形态**：每条图文 500-800 字、6-8 张卡片；资料一次查、草稿一次写、按条目发布

---

## 层级结构

```text
栏目 → 主题包（02 单篇项目）→ 图文条目（发布）→ 卡片页
```

示例：

```text
栏目：上线与部署
主题包：01_网站上线基础设施        ← 按 02 从 0 跑到 HTML
图文条目：备案到底是什么？         ← 发小红书的一条
卡片页：图 1-6                     ← 单张图
```
