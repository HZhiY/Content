## 二、本文一句话文风定义

本文应采用「手机翻页友好的机制纠偏笔记体」：用 6 张短卡从「买了域名为什么还打不开」这一处境切入，先破「域名=网站」误解，再逐卡托出 DNS 寻址分工与访问链路，国内实名仅作边界轻点，语气像开发者给开发者递可截图笔记，不像建站营销或培训号。

## 三、系列继承规则

本文必须继承的系列规则：

1. **生产与发布分离**：主题包一次查资料，试水仅产出条目 01；单条图文 500–800 字、6 张卡片，可独立搜索、收藏、发布。
2. **解释边界**：只讲一个点——「域名是什么」；以国内个人开发者场景为主；国外工具不出现在本篇。
3. **气质与姿态**：清楚、克制、真实、可收藏；「我把自己会遇到的问题整理出来」，不承诺收益、不贩卖焦虑。
4. **推荐句式**：「很多人以为……」「但真正开始做以后会发现……」「这不一定难，但很容易卡住」「关键词不是 A，而是 B」。
5. **风险边界**：不写绕备案、绕支付、海外收款规避、税务优化；涉及合规仅信息整理，不作法律建议。

本文不得继承的内容：

1. 不继承其他文章的具体事实；
2. 不继承其他文章的具体标题；
3. 不继承其他文章的具体比喻；
4. 不继承其他文章的具体结构链条；
5. 除非当前文章证据台账重新核查，否则不复用旧文事实。

## 四、本文微调策略

### 4.1 本文入口

- 推荐入口：**处境入口 + 概念纠偏入口**（混合型）
- 推荐原因：目标客户同时有主动搜索（「域名到底是什么」）与被动唤起（「买了域名为什么还打不开」）；处境钩低门槛，纠偏钩建立翻页理由；与 P0 事实 E0103/E0106 对齐
- 禁止入口：
  - 以「代码写完了还要过 DNS/服务器/备案全套关卡」作封面主轴（主题包价值，scope 过宽）
  - 以「十大避坑」「选错后缀就完了」作封面（候选 3 清单体，易同质且冲淡「是什么」）
  - 以「保姆级注册/建站/免备案」作入口（培训号腔 + 系列禁区）
  - 先抛 RFC 术语树或 DNS 记录类型表（门槛过高，违反 B10）

### 4.2 本文主线

- 主线类型：**机制解释型 + 认知纠偏型**
- 主线说明：全文结构命题 = 候选 1「寻址名，不是网站本体」——域名是 DNS 分层寻址名称，解决「别人怎么找到你」，不解决「网页内容是什么」；机制链：误解破冰 → 寻址名定义 → IP/域名/DNS 分工 → 访问链路 → 买了≠能访问 → 国内名字资产轻点 → 收束
- 主线风险：
  - 门牌号类比单飞（外部 W01 同质化 + 易误导为 B04）
  - 候选 2 实名/审核写多，滑向「怎么买域名」教程
  - 候选 3 辟谣项挤占 6 卡，冲淡机制主轴
  - 主题包价值升格为标题承诺，6 卡无法闭环

### 4.3 本文判断节奏

- 判断应当前置还是后置：**逐步浮出**（前 2 卡先挂处境与误解，第 3 卡起托机制，末卡收束判断）
- 原因：小红书前 3 张图须完成「问题—破误解—值得翻完」；若封面即抛完整判断，翻页动力不足；若判断全后置，读者在卡 1–2 不知收获
- 关键概念出现时机：
  - 卡 1：处境或问句（「域名到底是什么 / 买了为什么还打不开」）
  - 卡 2：破「域名=网站 / 买了就能访问」（反差，不展开 DNS 配置）
  - 卡 3：寻址名定义 + 门牌号类比**同卡或下一卡必须接 DNS 翻译 + 内容在服务器**
  - 卡 4：IP / 域名 / DNS 三句话分工（可截图收藏卡）
  - 卡 5：访问链路四步 + 「注册只是第一步」（E0105/E0106）
  - 卡 6：国内名字资产轻点（候选 2，≤1 卡）+ 主题包一句钩子（DNS/服务器/备案留给后续条目）

## 五、平台与手机阅读要求

### 5.1 句子长度

- 单句要求：卡片内以 8–18 字短句为主；解释句可至 25 字，但一卡内不超过 2 句长句；caption 单句 15–25 字
- 禁止：连续 3 句以上口号式短句；单卡超过 8 行字；一句里堆 DNS/A 记录/CNAME/ServerHold 多个术语
- 示例原则：短句可以用，但不能连续口号化；术语第一次出现须同句或下一句给一句人话翻译

### 5.2 段落节奏

- 每段建议：**每张卡片 = 一个段落单元**（30–90 字）；一条图文 6 卡 ≈ 6 个视觉节拍；总字数 500–800
- 历史信息段：本篇无历史叙事；RFC/DNS 机制用「三句话分工」「四步箭头链路」代替百科段落，不写发展史
- 抽象判断段：抽象判断（「域名≠网站」「买了≠能访问」）后必须跟一张机制卡或分工卡，禁止连续 2 卡只有判断没有分工

### 5.3 开头节奏

- 前 3 段（前 3 张卡）必须完成：
  1. 抛出一个清楚问题（「域名到底是什么？」或「买了域名为什么还打不开？」）
  2. 打破「域名=网站 / 买了就能访问」常见误解
  3. 让读者知道翻完能带走：寻址分工 + 一张可截图对照（是什么/不是什么，或 IP/域名/DNS 分工）
- 不允许：封面写「上线全套攻略」「十分钟搞定域名」；卡 1 堆 5 个名词；卡 1–3 仍不回答「域名是什么」

### 5.4 关键句使用

- 是否允许关键短句：**允许，但限 2–3 句/条图文**
- 使用条件：须出现在机制钉之后；可截图；能独立复述；例如「域名解决找到你，不解决内容是什么」「买了域名 ≠ 有了网站」
- 禁止：震惊体（「原来一直搞错了！」）；短视频腔（「听懂了吗？」「划重点！」）；培训口号（「看完这条你就懂了上线」）

## 六、事实与表达红线

### 6.1 事实红线

| 事实/口径 | 必须怎么写 | 不能怎么写 |
|---|---|---|
| 域名定义与分工（E0101–E0104） | 域名是给人记的网站地址名称；DNS 把域名翻译成 IP；内容在服务器上 | 域名=网站；域名里存着网页 |
| 访问链路（E0105） | 输入域名 → DNS 查 IP → 连服务器 → 返回网页 | 输入域名就打开网页 |
| 仅有域名不能访问（E0106） | 注册只是第一步；还要解析、服务器和实际内容 | 买了域名就能上线/访问 |
| 备案边界（E01P1-08） | 关键看服务器在哪里，不是看后缀 | .com 不用备案 |
| 账号与域名实名（E01P1-13） | 账号实名和域名实名是两件事 | 账号实名了域名就不用实名 |
| 备案与买域名（E01P1-14） | 备案和买域名是两件事 | 备案=买域名 |
| 审核/宽限期/赎回期（E01P1-04 等） | 须带「通常」「约」「以后缀和注册商为准」 | 写死「1 天搞定」「30 天宽限期」作普适事实 |
| 264 号文个人域名要求 | 第一条第一款：个人从事互联网信息服务的，域名注册者应为互联网信息服务者本人 | 误写为「第四条」 |
| P0 机制来源 | 以 RFC 1034/1035 + 腾讯云《域名简介》为准 | 以 Wikipedia、建站营销文、开发者社区帖单独支撑 P0 |
| 价格（G01） | 不写或写「以注册商页面为准」 | 写死促销价「首年 0 元」「1 元购」 |
| SEO/后缀（B07） | 后缀是名字分类；个人常见 .com / .cn | .cn 百度加权、选后缀决定排名 |

### 6.2 外部内容避坑

| 外部常见写法 | 本文处理 |
|---|---|
| W01 门牌号类比单飞 | 避开单飞；门牌号后同卡或下一卡必须接 DNS→IP→服务器内容链 |
| W03/W05 开店全套 / 保姆级建站 | 避开；条目 01 只做概念，不展开全流程 |
| W06/T05 免备案攻略 | 避开；境外场景不写操作路径 |
| T01「X 到底是啥」问句标题 | 可保留问句入口；正文靠机制纠偏差异化，不单喊口号 |
| M01「域名≠网站」反常识纠偏 | 采用，须带 E0103–E0106 机制钉 |
| M02 IP/域名/DNS 三句话分工 | 采用为辅助收藏卡，不抢主洞察 |
| T04「避坑指南」「十大误区」 | 避开清单体；最多 1 张「是什么/不是什么」对照，2–3 条以内 |
| 培训号「新手必看 / 从 0 到 1 当天上线」 | 避开 |

### 6.3 系列禁区

1. 灰色教程：绕备案、绕审核、海外收款规避、注册海外公司收款、税务优化。
2. 收益承诺：暴富、躺赚、月入、零成本创业、普通人翻身。
3. 培训号腔：保姆级、十分钟搞定、全网最全、必看、不看后悔。
4. 长文模块：引言、结尾小尾巴、相关文章、公众号式铺陈。
5. 一条图文多概念：本篇不得同时主讲 DNS 配置、备案流程、后缀选购、续费细则。
6. AI 变现玄学、低质搬运话术。

## 七、正面写作规范

1. **一卡一点**：6 张卡沿机制链推进——误解破冰 → 寻址名 → 三句话分工 → 访问链路 → 买了≠能访问 → 国内轻点 + 收束；禁止一卡混讲实名+备案+后缀。
2. **类比必须带机制钉**：凡用门牌号，同屏或下一卡出现「DNS 翻译 IP」「网页内容在服务器」；避免只剩比喻。
3. **收藏卡硬性**：至少 1 张可截图卡——「IP / 域名 / DNS 三句话分工」或「域名是什么 / 不是什么」对照；用箭头或短列表，不用长段落。
4. **国内差异化限幅**：候选 2「双重身份」最多 1 卡，写「名字资产 + 实名边界 + 账号实名≠域名实名」，不写注册步骤、不写审核天数表。
5. **个人开发者锚点**：每 2 卡内至少一次回到「我做第一款产品为什么要关心」——如「注册第一个域名时」「买了却打不开时」「向朋友解释要不要买域名时」。
6. **术语首次翻译**：DNS → 「把域名翻译成 IP 的系统」；IP → 「给机器看的数字地址」；解析 → 「让域名指向哪台服务器」；ServerHold 可不出现或括号一句带过。
7. **结尾升维一句**：末卡或 caption 可轻点「域名只是上线地图第一块」，引出后续条目，不暗示本篇已覆盖 DNS/服务器/备案全貌。
8. **caption 分工**：100–200 字；说明为什么写、补一个场景、加标签；不复制 6 卡全文；可加合规声明「这不是法律或税务建议，只是个人开发者视角的信息整理」。

7. **试水 scope**：大纲、草稿、审稿仅覆盖条目 01；资料可查全包，但表达不预支其他 9 条篇幅。
