## 一、核心资料结论

1. **技术定义**：域名（Domain Name）是互联网上用于标识计算机或计算机组的一串由点分隔的字符名称；DNS 负责将域名解析为 IP 地址，使用户不必记忆数字 IP。来源：RFC 1034/1035；腾讯云《域名简介》。
2. **白话理解**：域名更像网站的「门牌号」或「访问入口」，不是网站本身；网站是部署在服务器上的页面、程序和数据，域名通过 DNS 解析指向服务器后才能被访问。来源：腾讯云《域名简介》；维基百科「域名」条目（二手材料）。
3. **与 IP、DNS 的关系**：IP 是机器可识别的数字地址；域名是人类可读的别名；DNS 是分布式查询系统，把域名翻译成 IP（正向解析）。三者分工不同，缺一不可完成「输入网址 → 打开网页」。来源：RFC 1034；腾讯云开发者社区 DNS 科普文（二手材料）。
4. **国内个人注册基本路径**：在境内有资质的注册商（如腾讯云、阿里云、华为云等）查询可用域名 → 创建并实名认证信息模板 → 注册并支付 → 等待命名审核与实名审核 → 如需解析到国内服务器，还需 ICP 备案。来源：腾讯云《快速注册域名及实名认证》《域名实名认证》；《互联网域名管理办法》第三十条。
5. **实名认证是硬门槛**：工信部 2017 年起要求存量与新注册域名均须实名；未通过实名审核的域名可被注册局暂停解析（ServerHold）。来源：腾讯云《域名实名认证》。
6. **与备案的关系**：备案针对的是「域名解析到中国大陆服务器」这一场景，不是域名注册本身；备案前须先有已实名且信息一致的域名；备案主体与域名持有者实名信息须一致（个人备案比对姓名、证件类型、证件号码）。来源：工信部信管〔2017〕264 号通知；腾讯云《准备 ICP 备案域名》；阿里云《ICP 备案流程概述》。
7. **后缀选择无绝对优劣**：`.com` 国际通用认知度高；`.cn` 中国国家顶级域名，由 CNNIC 管理，个人可注册；后缀本身不决定是否备案，**服务器是否在中国大陆**才是备案判断的关键口径之一。来源：CNNIC《国家顶级域名注册实施细则》；阿里云《ICP 备案流程概述》。
8. **常见卡点**：混淆「域名=网站」、混淆「账号实名=域名实名」、忘记续费进入赎回期、备案时域名实名信息未同步入库（建议实名通过后等待约 3 天再提交备案）、境外注册商域名无法直接备案。来源：腾讯云《域名续费相关》《准备 ICP 备案域名》。
9. **服务器**：服务器是网站程序与数据实际运行、存放的环境；云服务器（如 CVM）是按需获取的虚拟计算资源，个人开发者常见入门形态还包括轻量应用服务器。来源：腾讯云《云服务器概述》《轻量应用服务器 产品概述》。
10. **备案**：ICP 备案是在中国大陆境内服务器开办网站或 APP 前须履行的非经营性互联网信息服务备案手续；备案成功获备案号后方可对外开通访问。来源：腾讯云《如何快速备案您的网站或 APP》；《非经营性互联网信息服务备案管理办法》（工信部，阿里云转载第五条）。
11. **SSL 与 CDN**：SSL 证书用于 HTTPS 加密传输与网站身份验证，部署在服务器或接入 CDN 等节点；CDN 是在源站前增加缓存加速层，降低访问延迟，属于上线后的可选优化。来源：腾讯云 SSL 产品页；《内容分发网络 CDN 产品概述》。
12. **上线关系链**：域名解决「怎么找到你」，服务器解决「内容放哪里」，DNS 把域名指向服务器 IP；用中国内地服务器对外服务时，还须 ICP 备案把主体、域名、接入商关联起来。来源：腾讯云《域名简介》；阿里云《如何通过阿里云搭建网站》。
13. **静态站 vs 轻量服务器**：纯 HTML/前端构建产物可走对象存储静态托管；需要跑后端、数据库或自定义环境时，更适合轻量应用服务器或 CVM。来源：腾讯云 COS《设置静态网站》《托管静态网站》；《与云服务器 CVM 对比》。

## 三、分主题资料整理

### 3.1 域名是什么（技术定义 + 白话）

#### 基本资料

- 域名（Domain Name）是为便于记忆 IP 地址而设计的人类可读标识；互联网上通过 DNS 将域名映射为 IP。来源：维基百科「域名」条目（二手材料）；RFC 1034。
- RFC 1034 定义：域名标识域名空间中的一个域（domain）；域名系统以层次结构组织名称空间。来源：RFC 1034（IETF）。
- 腾讯云官方表述：Internet 上每台主机有 IP 地址，但 IP 难记，于是有了域名；域名与 IP 相互对应，由 DNS 进行转换；在浏览器输入域名后，DNS 完成转换才能找到服务器并打开网页。来源：腾讯云《域名简介》（https://cloud.tencent.com/document/product/242/8569）。
- 域名组成：通常由英文字母、阿拉伯数字、连字符「-」和点「.」等组成；完整域名长度等规则在 Wikipedia 有汇总（如标签长度限制），正文引用宜保守。来源：维基百科「域名」条目（二手材料）。
- 全球域名体系由 ICANN 协调管理顶级域名等；`.cn` 中国国家顶级域名由 CNNIC 担任注册管理机构。来源：维基百科「域名」条目（二手材料）；CNNIC 官网说明（二手材料）。

#### 口径差异

- 口径 A（技术向）：域名是 DNS 名称空间中的命名标识，本身不存储网页内容。来源：RFC 1034。
- 口径 B（产品向）：域名是「获得一年或多年使用权的付费标识」，是建站第一步。来源：腾讯云《域名简介》。
- 当前建议：条目 01 可同时呈现——技术上它是寻址名称，实践中它是上线前要买的「名字资产」；待后续事实核查确认两处表述不冲突。

#### 可用于正文的解释

- 用「门牌号」类比：域名解决「别人怎么找到你」，不解决「房子里有什么」。

#### 风险提示

- 不要把域名描述成「买了就能上线」；需配合 DNS 解析、服务器上的网站内容。
- Wikipedia、建站营销文仅宜作理解辅助，关键机制以 RFC 与国内注册商官方文档为准。

### 3.2 域名与 IP、DNS 的关系

#### 基本资料

- IP 地址：网络上唯一标识计算机的数字地址（IPv4 为点分十进制，如 RFC 1035 所述 A 记录格式）。来源：RFC 1035。
- DNS：分布式数据库/查询系统，将域名映射到 IP（正向解析），也可反向查询。DNS 最早技术规范见于 RFC 882/883，现行核心为 RFC 1034/1035（1987）。来源：维基百科「域名系统」条目（二手材料）；RFC 1034/1035。
- 访问链路（简化）：用户在浏览器输入域名 → 本地/递归 DNS 查询 → 获得 IP → 浏览器连接该 IP 上的服务器 → 返回网页内容。来源：腾讯云《域名简介》；腾讯云开发者社区 DNS 科普文（二手材料）。
- 常见 DNS 记录（条目 01 可点到为止，详细留给主题包后续条目）：A 记录（域名→IPv4）、AAAA（域名→IPv6）、CNAME（别名→另一域名）。来源：维基百科「域名系统」条目（二手材料）；RFC 1035。
- 层次结构：以 `www.example.com` 为例，`.com` 为顶级域（TLD），`example.com` 为二级域（备案时常说的「主域名」），`www` 为三级子域。来源：腾讯云《准备 ICP 备案域名》。

#### 口径差异

- 口径 A：DNS 是「电话簿/索引」，域名是「名字」，IP 是「号码」。来源：维基百科「域名系统」（二手材料）。
- 口径 B：「域名像门牌号，IP 是 GPS 坐标，服务器是房子」。来源：多个建站科普站（二手材料）。
- 当前建议：正文可用门牌号类比，但应补一句「真正打开网页还要连到服务器」；避免暗示 DNS 配置等于域名本身。

#### 可用于正文的解释

- 记住三句话：IP 给机器看，域名给人记，DNS 负责翻译。

#### 风险提示

- 条目 01 不要展开成 DNS 配置教程；只建立概念关系即可。
- 一个 IP 可对应多个域名、一个域名也可因 CDN 等原因对应多个 IP，正文不宜过度简化。

### 3.3 域名 ≠ 网站（读者最常见误解）

#### 基本资料

- 仅有域名、未部署网站程序与内容时，访问可能看到空白页、默认页或报错。来源：聚名网建站科普文（二手材料）。
- 腾讯云流程说明：注册域名后，还需完成实名认证、ICP 备案（如适用）、域名解析等步骤，网站/APP 才能被外部访问。来源：腾讯云《域名简介》。
- 建站要素拆分：域名（入口）+ 服务器/主机（运行环境）+ 网站程序与内容（用户看到的东西）+ DNS 解析（把入口连到环境）。来源：多个建站科普文（二手材料）。

#### 口径差异

- 口径 A：域名是命名空间中的名称权，不等于托管内容。来源：RFC 1034 语义。
- 口径 B：商业语境下「做网站」常把买域名与建站打包，导致新手混用。来源：注册商快速入门文档。
- 当前建议：条目 01 应明确写「域名不等于网站」，并用一句话列出还需服务器与解析。

#### 可用于正文的解释

- 买域名像先拿下门牌号；装修、上架、开门营业还要服务器和网站内容。

#### 风险提示

- 二手营销文案例较多，正文避免引用夸张案例（如抢注要价十万等）。

### 3.4 国内个人开发者：域名注册、实名、续费基本流程

#### 基本资料

**注册前**

- 在境内有资质的域名注册服务商注册（腾讯云、阿里云、华为云、火山引擎等均有文档）。来源：各云厂商帮助中心。
- 《互联网域名管理办法》第三十条：注册服务机构应要求申请者提供真实、准确、完整的身份信息，并对真实性、完整性核验；信息不准确不得提供注册服务。来源：工信部令第 43 号。
- 国内实践：须先创建「域名信息模板」并完成实名认证，新注册域名需关联已审核通过的模板。来源：腾讯云《域名实名认证》《快速注册域名及实名认证》；华为云域名快速入门。

**注册步骤（以腾讯云为例，其他厂商步骤类似）**

1. 创建域名信息模板（个人填身份证等信息）并等待审核（一般 1–3 个工作日，部分更长）。来源：腾讯云《快速注册域名及实名认证》。
2. 查询域名是否可注册（先申请先注册原则）。来源：腾讯云《单个域名注册》；《互联网域名管理办法》第二十六条。
3. 加入购物车、选择年限、绑定已实名模板、支付。来源：腾讯云《单个域名注册》。
4. 注册后等待命名审核（约 1 个工作日）及实名认证审核。来源：腾讯云《快速注册域名及实名认证》。

**.cn 域名额外说明**

- 自然人可申请 `.cn` / `.中国` 国家顶级域名。来源：CNNIC《国家顶级域名注册实施细则》第十八条。
- 须提交姓名、证件号码、证件类型、地址、电话、邮箱等；CNNIC 复审约 2 个工作日（注册服务机构先初审）。来源：CNNIC《CN 域名注册常见问题及解答》。

**实名认证**

- 工信部 2017 年起要求所有存量与新注册域名实名。来源：腾讯云《域名实名认证》。
- 个人可用身份证、护照等（各注册商列表略有差异）。来源：腾讯云《域名实名认证》。
- 未通过实名：注册局可暂停解析（ServerHold），域名无法正常访问；通过后约 1–2 个工作日恢复。来源：腾讯云《域名实名认证》。

**续费**

- 域名注册属于即时产品，续费成功后一般不支持退款。来源：腾讯云《域名续费相关》。
- 有效期总年限：一般最长不超过 10 年（`.co` 等特殊后缀规则不同）。来源：腾讯云《域名续费相关》。
- 建议在到期前续费；过期后先进入续费宽限期（约 30 天，各后缀可能不同），可按正常续费价续费。来源：腾讯云《域名续费相关》。

**过期与赎回**

- 超过续费宽限期进入赎回期：国际域名（如 `.com`）赎回期约 30 天，赎回费用高于正常续费；国内域名（如 `.cn`）赎回期约 15 天。来源：腾讯云《域名续费相关》。
- 国际域名赎回期后还有约 5 天待删除期，期间不能续费或赎回，之后开放重新注册。来源：腾讯云《域名续费相关》。
- 赎回成功后 DNS 恢复可能需要 24–48 小时。来源：腾讯云《域名续费相关》；阿里云《域名赎回》。
- 部分后缀无赎回机制（如 `.hk` 过期超宽限期直接删除）。来源：阿里云《域名赎回》。

#### 口径差异

- 口径 A（法规）：注册服务机构须核验真实身份信息。来源：《互联网域名管理办法》。
- 口径 B（平台）：账号实名认证 ≠ 域名实名认证；前者是云平台账号，后者提交注册局审核。来源：腾讯云《域名实名认证》。
- 口径 C（时间）：模板审核 1–3 工作日；CNNIC 复审 2 工作日；命名审核约 1 工作日——实际叠加后新手体感「要等几天」。来源：腾讯云、CNNIC 文档。
- 当前建议：正文写流程时用「通常」「约」，并提示以控制台状态为准。

#### 可用于正文的解释

- 国内个人开发者注册域名，核心不是「会不会写代码」，而是「实名模板 + 等审核 + 记得续费」。

#### 风险提示

- 价格不写死具体促销价；活动价变化快。
- 不要把「模板审核时间」写成统一 1 天。

### 3.5 常见后缀（.com / .cn 等）适用场景

#### 基本资料

- `.com`：国际通用顶级域名（gTLD），商业历史上最广泛认知的后缀之一，全球通用。来源：维基百科「域名」条目（二手材料）；腾讯云域名产品介绍。
- `.cn`：中国国家顶级域名（ccTLD），CNNIC 为注册管理机构；自然人、法人和非法人组织均可申请（细则另有规定除外）。来源：CNNIC《国家顶级域名注册实施细则》。
- `.com.cn`、`.net` 等：腾讯云等平台同时提供；备案时须使用工信部批复的后缀，境外注册商注册的域名不能直接备案，需转入境内有资质服务商。来源：腾讯云《准备 ICP 备案域名》。
- 新后缀（`.xyz`、`.top`、`.site` 等）：注册价常较低，用户认知度与信任感普遍弱于 `.com`；是否可备案须查工信部批复列表。来源：腾讯云《准备 ICP 备案域名》；火山引擎备案文档（二手材料）。

#### 口径差异

- 口径 A（合规向）：后缀不决定是否备案；**解析到中国大陆服务器**须备案，与用途（网站/API/内网穿透）无关。来源：阿里云《ICP 备案流程概述》。
- 口径 B（选型向）：`.com` 通用性高；`.cn` 本土标识强、部分场景下可选名更多。来源：多个域名选购博客（二手材料，含 SEO 争议说法）。
- 口径 C（营销向）：`.cn` 备案更快、更便宜、百度加权——缺乏权威一手来源，不宜作为 P0 事实。
- 当前建议：正文采用克制表述——「个人项目常见先从 .com 或 .cn 里选；关键看品牌、可注册性和后续是否走国内服务器备案」，不写 SEO 排名承诺。

#### 可用于正文的解释

- 后缀主要是「名字的后半段分类」，不是「买了就能用」的开关；国内个人开发者更该同时考虑：好不好记、能不能注册、以后要不要备案。

#### 风险提示

- 避免「.com 不用备案」的绝对化说法——取决于服务器位置。
- 避免推荐一堆冷门后缀充字数。

### 3.6 个人开发者常见误解与卡点

#### 基本资料

| 误解/卡点 | 实际情况 | 来源线索 |
|---|---|---|
| 域名 = 网站 | 域名是入口名称，网站内容在服务器上 | 腾讯云《域名简介》；RFC 1034 语义 |
| 买了域名就能访问 | 还需 DNS 解析指向有效服务器，且服务器上有可访问内容 | 腾讯云《域名简介》 |
| 账号实名了就不用域名实名 | 两者独立，域名实名提交注册局审核 | 腾讯云《域名实名认证》 |
| 备案 = 买域名 | 备案是接入中国大陆服务器前的行政流程，与域名注册不同 | 阿里云《ICP 备案流程概述》 |
| .com 一定不用备案 | 服务器在中国大陆仍须备案 | 阿里云《ICP 备案流程概述》 |
| 域名过期立刻被别人抢走 | 通常有宽限期→赎回期→待删除期 | 腾讯云《域名续费相关》 |
| 备案被驳回：域名信息不一致 | 备案主体须与域名持有者实名信息一致 | 腾讯云《准备 ICP 备案域名》 |
| 刚实名完立刻备案失败 | 实名信息同步工信部数据库约需 3 天 | 腾讯云《准备 ICP 备案域名》 |
| 域名在境外注册商 | 不能直接备案，需转入境内有资质服务商 | 腾讯云《准备 ICP 备案域名》 |
| 忘记域名在哪个账号 | 可通过 Whois 查注册商，再找回账号 | 腾讯云《域名续费相关》 |

#### 口径差异

- 口径 A：过期后 30 天宽限期 + 30 天赎回期（国际域名）。来源：腾讯云。
- 口径 B：`.cn` 赎回期约 15 天，错过后直接开放重新注册（无 5 天待删除期描述与 `.com` 不同）。来源：腾讯云《域名续费相关》。
- 当前建议：正文写「过期后不是立刻没救，但越拖越贵、越难挽回」，具体天数脚注「以后缀和注册商为准」。

#### 可用于正文的解释

- 个人开发者真正卡住的，常常是「概念没分清」和「审核等待」，不是技术难度。

#### 风险提示

- 不写「如何规避备案」类内容。
- 过户、实名失败等个案较多，正文只列高频卡点。

### 3.7 域名与 ICP 备案的关系（政策口径）

#### 基本资料

- 《非经营性互联网信息服务备案管理办法》：中国内地服务器须在接入商平台完成备案，否则面临关停风险；海外服务器不需要（就阿里云文档所述场景）。来源：阿里云《ICP 备案流程概述》。
- 工信部信管〔2017〕264 号《关于规范互联网信息服务使用域名的通知》（2018-01-01 施行）要点：
  - 互联网信息服务使用的域名应依法依规注册所有；
  - 个人性质：域名注册者应为本人；单位性质：应为 unit、股东、主要负责人或高级管理人员（接入核验比对）；
  - 接入服务商须查验域名注册者真实身份信息；
  - 域名注册管理机构/服务机构须加强真实身份信息注册管理，不得为未提供真实身份信息的域名提供解析服务；
  - 域名不存在、过期且未提供真实身份信息等情形，接入服务商应停止接入。来源：工信部官网通知（腾讯云备案文档转载）；腾讯云《准备 ICP 备案域名》。
- 备案前域名要求（腾讯云归纳，与华为云、火山引擎等口径基本一致）：
  - 域名在有效期内；
  - 已完成实名认证；
  - 实名信息同步入库建议等待约 3 天；
  - 后缀须为工信部批复；
  - 境外注册商域名须转入境内有资质服务商；
  - 备案主体与域名所有者实名信息一致（个人比对姓名、证件类型、证件号码）。来源：腾讯云《准备 ICP 备案域名》；华为云《准备可备案的域名》。
- 备案与域名转入是独立操作；备案不要求先把域名转入备案所用云厂商。来源：腾讯云《准备 ICP 备案域名》。
- 域名不用于网站（API、内网穿透等），只要解析到中国大陆服务器 IP，仍须备案。来源：阿里云《ICP 备案流程概述》。
- ICP 备案时通常备案的是二级域名（如 `example.com`），三级子域在二级备案后可使用。来源：腾讯云《准备 ICP 备案域名》。

#### 口径差异

- 口径 A：必须先有域名并完成实名，才能走 ICP 备案。来源：各云厂商备案前准备文档。
- 口径 B：备案是「接入中国大陆服务器」的要求，不是「持有域名」的必然要求——若服务器在境外，域名可注册解析但适用不同合规场景（条目 01 仅作边界提示，不展开）。来源：阿里云《ICP 备案流程概述》。
- 当前建议：正文写清「在国内服务器上线，域名和备案会先后遇到」，不写规避路径。

#### 可用于正文的解释

- 备案不是域名注册的一部分，而是「用国内服务器对外提供服务」时的另一道关卡；两者通过「域名实名信息」连在一起。

#### 风险提示

- 政策条文以工信部及省管局最新规则为准；本文档为信息整理，非法律意见。
- 不写境外主机「免备案攻略」。

### 3.8 服务器是什么（条目 02）

#### 基本资料

- **技术定义**：云服务器 CVM（Cloud Virtual Machine）是腾讯云提供的可扩展计算服务；用户无需购买实体硬件，可在短时间内启动虚拟计算实例并部署应用程序，可按需调整 CPU、内存、硬盘、网络、安全等资源。来源：腾讯云《云服务器概述》（https://cloud.tencent.com/document/product/213/495）。
- **白话理解**：服务器是网站程序、数据库和文件实际运行、存放的「房子」；用户通过 IP 或经 DNS 解析后的域名访问到这台机器上的服务，才能看到网页或调用接口。来源：腾讯云《域名简介》；腾讯云《云服务器概述》。
- **云服务器核心组成（概念级）**：实例（CPU/内存/系统）、镜像（预装操作系统）、云硬盘（存储）、私有网络、公网 IP / 弹性 IP、安全组（虚拟防火墙）。来源：腾讯云《云服务器概述》「相关概念」。
- **与传统物理服务器关系**：云服务器避免了传统模式下预估容量和前期硬件投入；对个人开发者而言，常见路径是购买云厂商的虚拟实例，而非自建机房。来源：腾讯云《云服务器概述》。
- **个人开发者常见产品形态**：
  - **云服务器 CVM**：配置灵活、可扩展性强，适合需要自定义环境、后期可能扩容的项目。来源：腾讯云《云服务器概述》。
  - **轻量应用服务器（Lighthouse）**：开箱即用、套餐式售卖、控制台更简化，面向中小企业、开发者、学生等轻量场景。来源：腾讯云《轻量应用服务器 产品概述》（https://cloud.tencent.com/document/product/1207/44361）。
- **服务器 ≠ 域名**：域名是访问入口名称；服务器是承载内容的环境；二者通过 DNS 解析（域名 → IP）连接。来源：腾讯云《域名简介》。

#### 口径差异

- 口径 A（技术向）：服务器是提供计算与存储资源的机器环境（物理机或虚拟机）。来源：腾讯云《云服务器概述》。
- 口径 B（产品向）：「买服务器」在云平台语境下通常指购买云主机实例（含公网 IP、系统盘等）。来源：各云厂商购买页说明（二手归纳）。
- 口径 C（类比向）：「域名像门牌号，服务器是房子」——便于理解，但需补一句「房子里还要部署网站程序」。来源：建站科普文（二手材料）。
- 当前建议：条目 02 采用「运行环境/放代码的地方」白话定义，CVM 与轻量服务器的选型留给条目 10；待后续事实核查确认与条目 01 门牌号类比不冲突。

#### 可用于正文的解释

- 代码写在本地，真正对外提供服务时，通常要部署到一台有公网可达能力的云服务器（或等价的托管环境）上。

#### 风险提示

- 不要把「服务器」写成「买了就能访问」；还需部署代码、配置端口、完成解析，内地服务器还须备案。
- 条目 02 不宜展开成 Linux 运维教程或安全组配置教程。
- CVM 与轻量服务器差异细节留给条目 10，条目 02 点到为止。

### 3.9 备案是什么（条目 03；条目 07 政策依据见本节后段）

#### 基本资料

- **定义**：ICP 备案（非经营性互联网信息服务备案）是对在中华人民共和国境内提供非经营性互联网信息服务实行的备案制度；使用中国大陆境内服务器开办网站或 APP，须先办理 ICP 备案，取得通信管理局下发的备案号后方可开通对外访问。来源：腾讯云《如何快速备案您的网站或 APP》（https://cloud.tencent.com/document/product/243/39038）；阿里云《ICP 备案流程概述》。
- **法规依据（要点）**：《非经营性互联网信息服务备案管理办法》第五条规定，在境内提供非经营性互联网信息服务应依法履行备案手续，未经备案不得在境内从事该类服务；所称境内提供服务，包括利用域名访问的网站，或仅能通过 IP 访问的网站。来源：阿里云《ICP 备案的法律法规依据》（转载办法第五条）；办法原文待 fact-check 逐字核对。
- **备案 ≠ 域名注册**：域名注册解决「名字归属」；ICP 备案解决「在境内服务器上对外提供互联网信息服务」的合规接入。来源：腾讯云《准备 ICP 备案域名》；阿里云《ICP 备案流程概述》。
- **备案前提（腾讯云归纳）**：
  1. 符合要求的域名（已注册、已实名、后缀可备案等）；
  2. 符合条件的云服务资源（云服务器、轻量应用服务器、Serverless 资源包、负载均衡或备案授权码等）；
  3. 各省管局要求的备案材料；
  4. 账号已完成实名认证。来源：腾讯云《如何快速备案您的网站或 APP》；《备案限制说明》。
- **备案费用**：腾讯云 ICP 备案服务本身免费；但备案前通常需购买符合备案条件的云资源。来源：腾讯云《ICP 备案 新手指引》。
- **个人备案常见限制（腾讯云）**：
  - 一个腾讯云主账号只能为一个备案主体备案；
  - 个人备案：账号实名认证名称须与备案主体一致；
  - 个人备案订单最多新增 1 个网站，每个网站只能包含 1 个域名；
  - 备案负责人信息与域名所有者实名认证信息须一致（比对姓名、证件类型、证件号码）；
  - 系统目前只支持域名备案，不支持 IP 备案。来源：腾讯云《备案限制说明》（https://cloud.tencent.com/document/product/243/18911）。
- **备案流程（简化）**：验证备案类型 → 填写主体与服务信息 → 上传材料/视频核验 → 云厂商初审（约 1–2 个工作日）→ 工信部短信核验（24 小时内）→ 省通信管理局审核（文档写约 20 个工作日）→ 备案完成。来源：腾讯云《如何快速备案您的网站或 APP》；工信部办事指南（二十个工作日内予以备案）。来源：工信部政务服务事项说明（https://ythzxfw.miit.gov.cn/bssx/alx/dxhhlw/art/2025/art_88c400fc83904008bcf5b11bc08ec18f.html）。
- **备案后义务**：
  - 网站首页底部中央标明备案编号，并链接至工信部备案管理系统网址；
  - 网站/App 开通后 30 日内须完成公安联网备案（另有一套流程）；
  - 经营性网站/App 还须另行申请 ICP 许可证（本文主题包以非经营性个人项目为主，仅作边界提示）。来源：阿里云《ICP 备案流程概述》；腾讯云《如何快速备案您的网站或 APP》。

#### 口径差异

- 口径 A（法规向）：在境内提供非经营性互联网信息服务须备案，无论通过域名还是 IP 访问。来源：《非经营性互联网信息服务备案管理办法》第五条（阿里云转载）。
- 口径 B（平台向）：使用阿里云/腾讯云**中国内地节点**服务器须在该接入商完成备案；香港、海外节点服务器无需 ICP 备案。来源：阿里云《ICP 备案流程概述》。
- 口径 C（用途向）：备案要求以域名是否解析到中国内地服务器为准，与是否「建站」无关；API、内网穿透等解析到内地 IP 仍须备案。来源：阿里云《ICP 备案流程概述》。
- 当前建议：条目 03 写「备案是什么、个人开发者会交什么材料、大致等多久」；条目 07 写「为什么内地服务器通常要备案」时引用法规与管理逻辑，不写规避路径。

#### 可用于正文的解释

- 备案本质上是「主体 + 域名 + 接入商（云厂商）」在工信系统的登记；个人开发者第一次遇到时，容易把它和「买域名」混成一件事。

#### 风险提示

- 审核时长因省份、材料、是否首次备案而异，正文用「通常」「约」。
- 公安联网备案、经营性 ICP 许可与条目 03 核心问题关联较弱，仅边界提示。
- 不写「如何免备案」「如何选境外服务器绕过」类内容（系列风险边界）。

### 3.10 SSL 证书是什么（条目 04）

#### 基本资料

- **SSL 是什么**：SSL（Secure Sockets Layer，安全套接层）是一种安全协议，目的是为互联网通信提供安全及数据完整性保障；在浏览器地址栏体现为 HTTPS（HTTP over SSL/TLS）。来源：腾讯云 SSL 产品页（https://cloud.tencent.com.cn/product/ssl）；腾讯云开发者社区 SSL 科普文（二手材料）。
- **SSL 证书是什么**：由 CA（数字证书认证机构）签发、安装在服务器上的证书文件，用于实现数据传输加密和服务器身份验证；证书证明持有者合法拥有所列公钥。来源：腾讯云 SSL 产品页。
- **解决什么问题**：
  1. 浏览器与服务器之间的传输加密（防窃听、防篡改）；
  2. 向用户证明「你访问的站点身份经过 CA 核验」（域名型证书主要核验域名所有权）。来源：腾讯云 SSL 产品页；腾讯云《SSL 证书介绍》文档线索。
- **证书类型（概念级，腾讯云）**：
  - **DV（域名型）**：仅审核域名所有权，签发快，适合个人网站、小型项目；
  - **OV（企业型）**：审核企业真实性，签发较慢；
  - **EV（增强型）**：审核更严格，常见于金融等机构。来源：腾讯云 SSL 产品页。
- **与备案的关系**：SSL/HTTPS 解决传输安全；ICP 备案解决境内接入合规；二者独立，上线内地网站时可能都需要，但不互相替代。来源：阿里云《如何通过阿里云搭建网站》；腾讯云备案文档。
- **部署位置**：证书需部署在对外提供 HTTPS 服务的节点上，如 Nginx/Apache 等 Web 服务器、负载均衡、CDN、轻量应用服务器等；签发后需将证书文件配置到服务器或一键部署到云产品。来源：腾讯云 SSL 产品页；腾讯云《Nginx 服务器 SSL 证书安装部署》（文档线索）。
- **有效期**：全球 CA 自 2020 年 9 月起不再签发超过 2 年期的 SSL 证书；续期相当于重新申请新证书并重新部署。来源：腾讯云《免费证书续期流程》（文档线索）。

#### 口径差异

- 口径 A：SSL 证书 = HTTPS 的必要文件。来源：腾讯云 SSL 产品页、开发者社区文（二手）。
- 口径 B：装了 SSL 不等于网站绝对安全，只解决传输层加密与身份核验的一部分。来源：腾讯云开发者社区文（二手）。
- 当前建议：条目 04 强调「小锁标志 / HTTPS 是什么、为什么个人站点也建议配」；不写 SEO 排名承诺（阿里云建站文有提及，缺乏作为 P0 的依据）。

#### 可用于正文的解释

- 没有 SSL 时，用户仍可能通过 HTTP 访问；有了 SSL 并正确部署后，浏览器与服务器之间的数据走加密通道，地址栏显示 HTTPS。

#### 风险提示

- 不要把 SSL 写成「上线第一步」或「备案替代品」。
- 免费 DV 证书与付费证书差异、国密证书等进阶话题超出条目 04 scope。
- 开发者社区文为二手材料，P0 事实以腾讯云 SSL 产品页及官方文档为准。

### 3.11 CDN 是什么（条目 05）

#### 基本资料

- **定义**：CDN（Content Delivery Network，内容分发网络）是在现有 Internet 上增加的一层网络架构，由遍布全球的高性能加速节点构成；节点按缓存策略存储业务内容，用户请求会被调度至最接近用户的节点，由节点直接响应，降低访问延迟、提升可用性。来源：腾讯云《内容分发网络 CDN 产品概述》（https://cloud.tencent.com/document/product/228/2939）。
- **解决什么问题**：
  1. 用户与源站物理距离远，传输延迟高；
  2. 跨运营商访问需多次互联转发；
  3. 源站带宽和处理能力有限，海量请求时响应变慢。来源：腾讯云《CDN 产品概述》。
- **加速原理（简化）**：用户请求域名 → DNS 解析到 CDN 分配的 CNAME → 调度至最佳边缘节点 → 若节点有缓存则直接返回，无缓存则回源站拉取后缓存再返回。来源：腾讯云《CDN 产品概述》「加速原理」。
- **关键概念**：
  - **源站**：用户业务实际所在的服务器或对象存储；
  - **边缘节点**：CDN 缓存内容的分布式节点；
  - **回源**：节点无缓存时向源站请求资源；
  - **CNAME**：接入 CDN 后，需将业务域名 CNAME 到 CDN 分配的加速域名。来源：腾讯云《CDN 基本概念》；《配置 CNAME》。
- **是否上线必需**：CDN 是性能与可用性优化层，不是网站上线的必要前提；个人小项目可先源站直连，访问量变后再考虑 CDN。来源：产品定位归纳（基于 CDN 文档「接入简单、无需调整业务结构」）。
- **与 SSL 的关系**：CDN 可配置 HTTPS 证书，实现「用户 ↔ CDN 节点」加密；也可配置 HTTPS 回源，实现全链路加密。来源：腾讯云 SSL/CDN 产品说明（二手材料）；CDN 控制台功能描述。

#### 口径差异

- 口径 A（必需向，营销语境）：「网站都要上 CDN」——对个人首版小项目过度。
- 口径 B（官方产品向）：CDN 降低延迟、减轻源站压力，接入需额外配置 CNAME 与缓存策略。来源：腾讯云《CDN 产品概述》。
- 当前建议：条目 05 明确「CDN 是加速器，不是门禁」；与域名、服务器、备案区分开。

#### 可用于正文的解释

- 官方类比：CDN 像在全国设仓库的电商——货（内容）提前放到离买家近的仓库，发货更快；源站仍是「总仓」。

#### 风险提示

- 不要把 CDN 写成「买了域名就要买 CDN」。
- 条目 05 不展开缓存刷新、鉴权、费用计费细节。
- 一个域名经 CDN 后可能对应多个 IP，与条目 01 DNS 简化说明需前后一致。

### 3.12 域名、服务器、备案是什么关系（条目 06）

#### 基本资料

- **三者分工**：
  | 概念 | 解决什么问题 | 一句话 |
  |---|---|---|
  | 域名 | 用户怎么记住和输入你的地址 | 门牌号 / 访问入口名称 |
  | 服务器 | 网站程序和数据放哪里、在哪运行 | 房子 / 运行环境 |
  | ICP 备案 | 在境内服务器对外提供互联网信息服务时的合规登记 | 内地开业的登记（非域名注册的一部分） |
  来源：腾讯云《域名简介》；阿里云《ICP 备案流程概述》；本主题包 3.1–3.3、3.8、3.9 归纳。
- **技术连接链**：用户输入域名 → DNS 将域名解析为服务器 IP → 浏览器连接该 IP 上的服务 → 返回网页；备案不参与 DNS 解析，但在内地场景下是「对外开通服务」的前置条件之一。来源：腾讯云《域名简介》；RFC 1034（DNS 部分）。
- **先后关系（常见个人路径，非唯一）**：
  1. 注册域名并完成域名实名；
  2. 购买中国内地云服务器（或轻量服务器）；
  3. 提交 ICP 备案（备案期间可同步开发、部署内容到服务器）；
  4. 备案通过后，将域名解析到服务器公网 IP；
  5. （建议）配置 SSL 实现 HTTPS；
  6. （可选）接入 CDN。来源：阿里云《如何通过阿里云搭建网站》；腾讯云《域名简介》注册流程图；腾讯云《如何快速备案您的网站或 APP》。
- **备案把三者连在一起的方式**：备案订单需填写备案主体、备案域名、接入云服务（服务器）；域名持有者实名信息须与备案主体一致；备案通过后域名解析到该接入资源方可合规对外服务。来源：腾讯云《准备 ICP 备案域名》；《备案限制说明》。
- **常见误解对照**：
  | 误解 | 实际情况 |
  |---|---|
  | 有域名就有网站 | 还要服务器 + 部署内容 + 解析 |
  | 买了服务器就能用域名访问 | 还要 DNS 解析；内地还要备案 |
  | 备案 = 买域名 | 备案针对境内服务器接入，是另一套流程 |
  | 备案 = 公安备案 | ICP 备案与公安联网备案是不同阶段（ICP 先，公安后 30 日内） |
  来源：腾讯云备案文档；阿里云 ICP 文档。

#### 口径差异

- 口径 A：严格顺序「先备案后解析」——各地管局与接入商实操中，常见做法是在备案审核期间用 IP 内测，备案通过后再解析域名正式对外（平台文档表述为备案成功后解析域名访问）。来源：腾讯云《如何快速备案您的网站或 APP》「下一步操作」。
- 口径 B：备案与开发可并行——阿里云明确可在等待管局审核期间部署完善网站内容。来源：阿里云《如何通过阿里云搭建网站》。
- 当前建议：条目 06 用「分工 + 常见先后」呈现，不写成死板流水线；强调「三者各管一件事，内地场景会先后遇到」。

#### 可用于正文的解释

- 记一张心智图：域名是名字，服务器是场地，DNS 是指路牌，备案是内地场地的开业登记。

#### 风险提示

- 不写境外服务器「三者关系更简单」的规避暗示。
- 公安备案、经营性许可仅点到为止。

### 3.13 为什么国内服务器通常要备案 & 网页上线要经过哪几步（条目 07 + 条目 08）

#### 基本资料

**为什么内地服务器通常要备案（条目 07）**

- 《非经营性互联网信息服务备案管理办法》确立：在境内提供非经营性互联网信息服务实行备案制度；未经备案不得在境内从事该类服务。来源：办法原文（工信部；阿里云法规依据页转载第五条）。
- 阿里云口径：域名解析至**中国内地**服务器并开通 Web 访问需备案，未备案不得提供非经营性互联网信息服务；海外（含香港）服务器不需要 ICP 备案。来源：阿里云《ICP 备案流程概述》。
- 管理逻辑（官方表述归纳）：便于对互联网信息服务实行准入与责任追溯，保障网络信息安全与行业健康发展。来源：《非经营性互联网信息服务备案管理办法》第一条（立法目的，待 fact-check 逐字引用）。
- **判断关键**：是否使用中国内地服务器对外提供互联网信息服务，而非域名后缀、是否「正式建站」或项目大小。来源：阿里云《ICP 备案流程概述》FAQ。
- **个人开发者要记住**：选内地服务器，就要把备案时间算进上线计划；这不是可选优化，而是合规前提（就阿里云/腾讯云所述内地场景）。

**网页上线标准步骤（条目 08，内地个人路径）**

阿里云《如何通过阿里云搭建网站》归纳的端到端流程：

| 步骤 | 做什么 | 耗时参考（官方/平台） |
|---|---|---|
| 1 | 注册域名并完成实名认证 | 注册约 5 分钟；实名审核约 1–3 个工作日 |
| 2 | 购买并配置服务器（ECS/轻量等） | 视技术栈而定；内地服务器须满足备案条件 |
| 3 | 提交 ICP 备案 | 云厂商初审 1–2 工作日 + 短信核验 + 管局 1–20 工作日 |
| 4 | 部署网站内容到服务器 | 可与备案审核并行 |
| 5 | 配置域名解析（A 记录等指向服务器 IP） | 首次添加通常实时生效 |
| 6 | 部署 SSL 证书，启用 HTTPS | 签发约 1–15 分钟（视证书类型） |
| （备案后） | 网站底部添加备案号；30 日内公安联网备案 | 法规/平台要求 |
| （可选） | 接入 CDN 加速 | 非必需 |

来源：阿里云《如何通过阿里云搭建网站》（https://help.aliyun.com/zh/dws/getting-started/the-whole-process-of-website-building/）；腾讯云《域名简介》；腾讯云《如何快速备案您的网站或 APP》。

- **腾讯云域名注册路径（简化版）**：注册域名 → 实名认证 → ICP 备案（如适用）→ 域名解析 → 外部可访问。来源：腾讯云《域名简介》。

#### 口径差异

- 口径 A：「上线 = 能打开网页」——技术视角，可能仅用 IP 内测。
- 口径 B：「上线 = 合规的对外服务」——内地场景须含备案与备案号展示。
- 当前建议：条目 08 以「个人开发者第一次把产品给别人用」为上线定义，步骤包含备案与 HTTPS 建议；内测阶段可单独说明「IP 访问 ≠ 正式对外上线」。

#### 可用于正文的解释

- 很多人以为「代码写完 = 上线」，实际上内地路径里还横着备案等待期；聪明的做法是备案审核期间先把内容和解析方案准备好。

#### 风险提示

- 管局审核 1–20 个工作日区间大，正文不写死「7 天必过」。
- 不写「先上境外服务器免备案」教程。
- 阿里云建站文提及 SEO，不宜作为 P0 事实。

### 3.14 静态网站与轻量服务器：适合什么项目（条目 09 + 条目 10）

#### 基本资料

**静态网站是什么（条目 09）**

- **定义**：静态网站指包含静态内容（如 HTML）或客户端脚本的网站；动态网站包含 PHP、JSP、ASP.NET 等服务器端脚本，需服务器端处理。来源：腾讯云 COS《设置静态网站》（https://www.tencentcloud.com/zh/document/product/436/30958）。
- **COS 静态托管能力**：对象存储 COS 支持静态网站托管，**不支持**服务器端脚本；适合将 HTML/CSS/JS 等文件上传到存储桶，通过静态网站域名或自定义域名访问。来源：腾讯云 COS《设置静态网站》；《托管静态网站》（https://cloud.tencent.com/document/product/436/9512）。
- **典型适用项目**：
  - 个人主页、作品展示页；
  - 前端单页应用（Vue/React 构建后的 `dist`/`build` 产物）；
  - 文档站、活动落地页；
  - 不需要后端 API、数据库、服务器端渲染的项目。来源：腾讯云《使用 COS 静态网站功能搭建前端单页应用》；《托管静态网站》。
- **不太适合**：
  - 需要用户登录态服务端校验、表单写数据库；
  - 需要 PHP/Node/Python 等后端常驻进程；
  - 需要 WebSocket 服务端、复杂服务端逻辑。来源：COS 文档「动态网站推荐 CVM」表述。
- **内地合规提示**：COS 静态托管若使用自定义域名且解析到内地节点，仍须 ICP 备案；COS 实践文档将「注册域名与备案」列为前提步骤。来源：腾讯云《托管静态网站》「步骤1：注册域名与备案」。
- **2024 年后注意**：2024 年 1 月 1 日后创建的存储桶，使用 COS 默认域名访问对象不支持预览；静态网站建议配置自定义域名（源站类型选静态网站）并解析。来源：腾讯云 COS《设置静态网站》安全通知说明。

**轻量应用服务器适合什么（条目 10）**

- **定义**：轻量应用服务器（Tencent Cloud Lighthouse）是面向轻量应用场景的开箱即用云服务器产品，套餐式售卖，整合常用基础云服务，提供应用镜像一键部署。来源：腾讯云《轻量应用服务器 产品概述》。
- **典型适用场景**：企业官网、博客、论坛、微信小程序/小游戏后端、跨境电商独立站、云盘/图床、开发测试与学习环境等轻量级、中低负载应用。来源：腾讯云《与云服务器 CVM 对比》（https://cloud.tencent.com/document/product/1207/49819）。
- **与 CVM 对比（选型要点）**：
  | 维度 | 轻量应用服务器 | 云服务器 CVM |
  |---|---|---|
  | 目标用户 | 开发者、中小企业、入门者 | 中大型企业、复杂架构 |
  | 售卖方式 | 高性价比套餐包 | 灵活选配、独立计费 |
  | 使用体验 | 控制台简化、可一键装应用 | 需自行搭建，VPC/子网等概念更多 |
  | 典型场景 | 中小型网站、个人项目 | 高并发、大型游戏、分布式集群、GPU 等 |
  | 扩展性 | 套餐整体升级，不支持降级；有功能限制 | 丰富实例类型，弹性伸缩 |
  来源：腾讯云《与云服务器 CVM 对比》。
- **个人开发者选型建议（资料归纳，非官方承诺）**：
  - **首选轻量**：第一款小产品、需要跑 Node/PHP/MySQL、想要预装环境、访问量不大；
  - **考虑 CVM**：确定需要灵活扩缩容、复杂网络、异构计算（GPU 等）或集群架构；
  - **首选静态托管**：纯前端产物、无后端、访问量低、希望运维最少。来源：基于腾讯云产品文档的场景描述归纳。

#### 口径差异

- 口径 A（静态托管向）：「个人项目都应该静态托管」——忽略后端需求。
- 口径 B（轻量向）：「个人项目都应该买轻量服务器」——纯展示站可能过度。
- 口径 C（官方产品向）：按是否需要服务端逻辑、运维能力、扩展需求选择。来源：COS 与 Lighthouse 官方场景描述。
- 当前建议：条目 09/10 提供选择框架，不给出绝对推荐；写清「静态 = 无服务端脚本」「轻量 = 有后端但不想折腾复杂云架构」。

#### 可用于正文的解释

- 第一款产品如果是纯前端落地页，可以优先问「能不能静态托管」；如果需要接口和数据库，再考虑轻量服务器。

#### 风险提示

- 静态托管不等于「不用备案」——内地自定义域名仍可能涉及备案。
- 不写具体套餐价格；活动价变化快。
- Serverless、容器等更多形态超出条目 09/10 scope，仅背景或不写。
