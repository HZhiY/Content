说明：

1. 6 条 P0 核心事实均已对照 RFC 1034/1035 与腾讯云《域名简介》等一手来源核查，定义、分工、访问链路与「域名≠网站」均可放行。
2. E0105、E0106 的二手辅助来源（开发者社区、聚名网）不作为 P0 支撑依据；机制表述以 RFC + 腾讯云官方文档为准，正文须按此口径。

4. 续费宽限期/赎回期、审核时长、域名价格等 P1/P2 项存在后缀与平台差异，已有保守写法（「通常」「约」「以后缀和注册商为准」），不阻断条目 01 概念科普。
5. 域名价格（G01）、ICANN 官方定义（G05）等待补项不影响条目 01 核心论证，可保留待补。
6. `_meta/_config/风险边界配置.md` 路径已确认存在；规避教程类表述已在台账 X01 标记不采用，不阻断 P0 放行。

## 二、P0 事实核查

| 编号 | 事实钉子 | 台账推荐口径 | 核查结论 | 正文建议口径 | 风险 | 处理意见 |
|---|---|---|---|---|---|---|
| E0101 | 域名是为便于记忆 IP 而设的人类可读标识；DNS 负责将域名映射为 IP | 域名是「给人记的网站地址名称」；DNS 把域名翻译成 IP | 通过 | 域名是给人记的网站地址名称；DNS 负责把域名翻译成 IP，浏览器才能找到服务器 | 低 | RFC 1034 定义域名名称空间与 DNS 映射机制；腾讯云《域名简介》官方表述一致 |
| E0102 | RFC 1034：域名标识 DNS 名称空间中的一个域；名称空间以层次结构组织 | 域名不是随意字符串，而是 DNS 体系里的分层命名 | 通过 | 域名是 DNS 分层命名体系中的名称，从右往左由大到小 | 低 | RFC 1034 §3.1 明确「domain name space is a tree structure」「domain name of a node is the list of labels on the path from the node to the root」 |
| E0103 | 域名标识寻址名称，本身不存储网页内容；网站在服务器上 | 域名更像「门牌号/访问入口」，不等于网站本身 | 通过 | 域名解决「别人怎么找到你」，不解决「网页内容是什么」；内容在服务器上 | 低 | RFC 1034 语义（名称空间标识，非内容托管）+ 腾讯云建站流程说明一致 |
| E0104 | IP 是数字地址；域名是人类可读别名；DNS 是分布式查询系统，负责正向解析 | 三句话：IP 给机器看，域名给人记，DNS 负责翻译 | 通过 | 同上三句话；三者分工不同，缺一不可 | 低 | RFC 1034/1035 + 腾讯云《域名简介》均已核对 |
| E0105 | 访问链路：输入域名 → DNS 查询得 IP → 连接服务器 → 返回网页 | 输入网址后还要 DNS 解析、连上服务器才能看到页面 | 按口径通过 | 同上；不写「输入域名即打开网页」 | 中 | 机制以 RFC + 腾讯云官方为准；开发者社区 DNS 科普文不得单独支撑 |
| E0106 | 仅有域名、未部署内容与解析时，访问可能空白/默认页/报错；注册后还需实名、备案（如适用）、解析等 | 买了域名不等于能打开网站 | 按口径通过 | 注册域名只是第一步；还要解析、服务器和实际内容；备案在国内服务器场景下另有一道关卡 | 中 | 腾讯云《域名简介》明确「注册域名后，您还需完成实名认证、ICP 备案、域名解析等步骤」；聚名网仅辅助，不作 P0 依据 |

## 三、P1 事实核查

| 编号 | 事实钉子 | 核查结论 | 正文建议口径 | 风险 | 处理意见 |
|---|---|---|---|---|---|
| E01P1-01 | 域名注册遵循「先申请先注册」 | 通过 | 好域名可能被他人先注册，查到要尽早申请 | 低 | 《互联网域名管理办法》第二十六条 + 腾讯云《单个域名注册》 |
| E01P1-02 | 注册服务机构须核验申请者真实、准确、完整身份信息 | 通过 | 国内注册域名，身份信息必须真实完整 | 低 | 工信部令第 43 号第三十条 |
| E01P1-03 | 2017 年起存量与新注册域名均须实名；未实名可被暂停解析（ServerHold） | 通过 | 国内域名必须实名；未通过时可能无法正常访问 | 低 | 腾讯云《域名实名认证》；政策背景与《互联网域名管理办法》（2017-11-01 施行）一致 |
| E01P1-04 | 须先创建信息模板并完成实名；模板审核一般 1–3 个工作日 | 按口径通过 | 个人注册通常要先建实名模板并等审核，常见约 1–3 个工作日 | 中 | 腾讯云《域名实名认证》「认证等待时间」已核对；正文必带「通常」「约」 |
| E01P1-05 | 自然人可申请 `.cn` / `.中国` | 通过 | 个人开发者可以注册 `.cn` 域名 | 低 | CNNIC《国家顶级域名注册实施细则》第十八条已核对原文 |
| E01P1-06 | 过期后先续费宽限期（约 30 天），再进入赎回期 | 按口径通过 | 过期后不是立刻没救，但越拖越贵；具体天数以后缀和注册商为准 | 中 | 腾讯云《域名续费相关》已核对；`.com` 与 `.cn` 规则不同，见 D02 |
| E01P1-07 | 中国内地服务器提供互联网信息服务须 ICP 备案 | 通过 | 用国内服务器对外提供服务，通常还要走 ICP 备案 | 低 | 阿里云《ICP 备案流程概述》+《非经营性互联网信息服务备案管理办法》 |
| E01P1-08 | 备案关键看域名是否解析到中国大陆服务器，与后缀、是否「建站」无必然对应 | 通过 | 不是「买了 .com 就不用备案」，关键看服务器在哪里 | 低 | 阿里云文档明确「备案要求以域名是否解析到中国内地服务器为准，与域名的具体用途无关」 |
| E01P1-09 | 备案主体信息应与域名所有者实名认证信息一致（个人比对姓名、证件类型、证件号码） | 通过 | 备案时域名实名信息要和备案主体对得上 | 中 | 264 号文第一条第一款 + 腾讯云《准备 ICP 备案域名》已核对；注意条文位置为第一条（一），非第四条 |
| E01P1-10 | 域名实名完成后建议等待约 3 天再提交 ICP 备案 | 通过 | 刚实名完立刻备案可能失败，常见建议等几天 | 中 | 腾讯云《准备 ICP 备案域名》原文：「实名认证完成后需要约三天时间将实名认证信息入库工信部」 |
| E01P1-11 | 境外注册商域名不能直接备案，需转入境内有资质服务商 | 通过 | 域名如果在境外买的，备案前通常要转回国内注册商 | 低 | 腾讯云《准备 ICP 备案域名》 |
| E01P1-12 | `.com` 国际通用认知度高；`.cn` 由 CNNIC 管理 | 通过 | 个人项目常见从 `.com` 或 `.cn` 里选；后缀是名字分类，不是「买了就能用」的开关 | 低 | CNNIC 细则 + 腾讯云产品介绍；SEO/排名说法不采用 |
| E01P1-13 | 云平台账号实名 ≠ 域名实名 | 通过 | 账号实名了，域名还要单独做实名 | 低 | 腾讯云《域名实名认证》明确区分两者 |
| E01P1-14 | ICP 备案不是域名注册本身 | 通过 | 备案和买域名是两件事，在国内服务器上线时会先后遇到 | 低 | 阿里云 + 腾讯云备案文档 |
| E01P1-15 | 备案前须先有已实名域名；服务器在境外适用不同合规场景 | 通过 | 在国内服务器上线，域名和备案会先后遇到 | 低 | 各云厂商备案前准备文档一致 |

## 六、禁止写法与红线

| 编号 | 禁止写法 | 原因 | 替代写法 |
|---|---|---|---|
| B01 | 「买了域名就能上线/访问网站」 | 忽略 DNS 解析、服务器、内容部署 | 「注册域名只是第一步，还要解析、服务器和实际内容」 |
| B02 | 「.com 不用备案」 | 备案取决于服务器是否在中国大陆，与后缀无必然对应 | 「关键看服务器在哪里，不是看后缀」 |
| B03 | 「账号实名了域名就不用实名」 | 两者独立，域名实名提交注册局审核 | 「账号实名和域名实名是两件事」 |
| B04 | 「域名 = 网站」 | 域名是寻址名称，不存储网页内容 | 「域名像门牌号，网站内容在服务器上」 |
| B05 | 「备案 = 买域名」 | 备案是接入内地服务器前的行政流程 | 「备案和买域名是两件事」 |
| B06 | 写死促销价（「首年 0 元」「1 元购域名」） | 活动时效强，缺官方实时价（G01） | 不写具体价格，或写「以注册商页面为准」 |
| B07 | SEO/排名与后缀强关联（「.cn 百度加权」） | 无权威一手来源 | 删除；仅写后缀为名字分类 |
| B08 | 境外免备案操作教程 | 系列风险边界禁止规避教程 | 不写；境外场景仅作边界提示 |
| B09 | 以 Wikipedia 或建站营销文单独支撑 P0 | 二手材料 | P0 须 RFC/法规/注册商官方来源 |
| B10 | DNS 配置步骤详解 | 条目 01 scope 是「是什么」，不是「怎么配」 | 最多一句建立 IP/域名/DNS 概念关系 |

## 八、放行结论

```text
有条件通过：可以进入洞察与大纲阶段。
```

必须遵守的限定口径：

1. P0 机制表述以 RFC 1034/1035 + 腾讯云《域名简介》为准，不以二手建站文单独支撑。
2. 264 号文引用须写「第一条第一款：个人从事互联网信息服务的，域名注册者应为互联网信息服务者本人」，勿误写为「第四条」。
3. 审核时长、宽限期、赎回期须带「通常」「约」「以后缀和注册商为准」。
4. 不写具体促销价、SEO 承诺、规避备案教程。
5. 备案、续费、后缀细节在条目 01 仅作边界提示，不展开流程。
