## 图文 02｜服务器到底是什么？

**主线**：服务器不是「放网站的那台电脑」这么简单，它是一台 7×24 小时、装在机房或云里的机器，给用户跑程序和回传数据。

**贯穿实例**：`mytool.com` 这次找到了那台机器 `203.0.113.10`，网页就放在它上面。

### 图 1｜封面
服务器到底是什么？
没它，域名解析了也没东西能响应——上线最后一步。

### 图 2｜破误解
很多人以为服务器就是「我电脑一直开着」。
其实它更像一台不停机的、装在专业机房里替你值班的电脑。
对个人开发者：上线花钱和选规格的对象，就是它。

### 图 3｜定义
服务器是 7×24 小时在线、对外提供服务的机器。
`mytool.com` 的网页就放在一台服务器上，浏览器请求进来，它把页面内容送回去。

### 图 4｜三种形态
个人开发者常见三种：
① 云服务器 ECS/CVM：远程租一台
② 虚拟主机 / 共享主机：和别人合租一台
③ Serverless：把代码丢给云平台托管

### 图 5｜域名和服务器的关系
域名解决「别人怎么找到你」，
服务器解决「被找到后由谁来回应」。
`mytool.com` + 服务器 + 解析，才算凑齐一回完整链路。

### 图 6｜个人开发者要记住什么
服务器要付租金、要选地域、要续费。
国内做网站，服务器在国内就要考虑备案。
后面条目会拆云服务器、虚拟主机、Serverless 怎么选。

### caption
你为什么会在意：上线前第一个要付费的「重资产」，选错地域就影响备案和访问速度。场景：下单了一台云服务器、拿到公网 IP，可浏览器输入 IP 还是看不到——通常是没装程序、没开端口。个人开发者视角整理。#个人开发者 #独立开发 #产品上线

## 图文 03｜备案到底是什么？

**主线**：ICP 备案不是买域名的一部分，是「把网站放到中国大陆服务器前」的行政流程；不办就用不了。

**贯穿实例**：`mytool.com` 想挂在大陆服务器 `203.0.113.10`，就绕不开这道手续。

### 图 1｜封面
备案到底是什么？
没备就关停，国内服务器上线第一道门。

### 图 2｜破误解
备案不是给网站内容「过审」。
它是「域名 + 服务器」绑在一起、报给工信部的一步行政登记。
对个人开发者：跳过这一步，国内服务器站点直接开不起来。

### 图 3｜三句话分工
主体：你（个人 / 公司）是谁
网站：放什么服务
接入商：你买的哪家云平台

### 图 4｜什么场景才要备案
域名解析到中国大陆服务器，就必须备案。
服务器在境外，目前不要求。
跟 `.com` 还是 `.cn` 后缀没关系，看服务器在哪里。

### 图 5｜大致时长与卡点
首次备案一般 1–20 个工作日，因地因人而异。
常见被驳回：域名实名信息和备案主体不一致；服务器不在你户籍地或常驻地。
具体以接入商控制台和管局口径为准。

### 图 6｜个人开发者要记住什么
备案是接入门票，不是内容审核。
`mytool.com` 想进大陆服务器，要走完这一步才合法「开门」。
DNS 怎么配、接入商怎么填，见后续条目。

### caption
你为什么会在意：国内服务器上线动作里最慢的一步，新手排期 2–3 周主要就在等它。场景：朋友说「我网站要备案两周」，其实备的是「谁、用哪个域名、放在哪台服务器」。个人开发者视角整理，非法律建议。#个人开发者 #独立开发 #产品上线

## 图文 04｜SSL 证书到底是什么？

**主线**：SSL 证书让浏览器和服务器之间的对话「加密 + 身份可验」，是 https 锁头图标的来源。

**贯穿实例**：访问 `https://mytool.com` 时，证书在告诉浏览器「这台 `203.0.113.10` 确实是 `mytool.com` 的」。

### 图 1｜封面
SSL 证书到底是什么？
没它浏览器标红「不安全」，小程序和微信生态直接拒绝接入。

### 图 2｜破误解
SSL 证书不是「让网站变高级」的装饰。
它是浏览器和服务器之间的「身份证 + 加密锁」。
对个人开发者：现在的小程序、支付、第三方登录，基本都强制 https。

### 图 3｜三件事
① 加密：传输内容不让中间人偷看
② 身份：证明这台服务器就是 `mytool.com` 声明的那台
③ 信任：由可信第三方（CA）签发

### 图 4｜常见类型
DV（域名验证）：只验证你能控制这个域名，最快
OV（组织验证）：再加验证机构身份
EV（扩展验证）：更严，浏览器地址栏展示更多

### 图 5｜个人开发者路径
云平台一键申请免费证书（通常 DV）。
绑定域名 `mytool.com` 后，到期前续签或重新申请。
证书过期没换，浏览器会直接红色警告。

### 图 6｜个人开发者要记住什么
网站不装证书，浏览器会标「不安全」。
个人项目先用云厂商免费 DV 就够。
`mytool.com` 的「锁」是基本动作，不是加分项。

### caption
你为什么会在意：现在不装证书，新用户打开就被警告，小程序和支付场景会直接被拒。场景：刚上线的小程序或官网，出现「您的连接不是私密连接」通常是证书没装、过期或域名没在证书里。个人开发者视角整理。#个人开发者 #独立开发 #产品上线

## 图文 05｜CDN 到底是什么？

**主线**：CDN 不是云服务商的「加速包」，它是一层地理分布的「内容中转站」，让用户从离自己最近的节点拿网页。

**贯穿实例**：`mytool.com` 的服务器在 `203.0.113.10`（北京），但深圳用户不用千里迢迢去北京——CDN 在深圳就有副本。

### 图 1｜封面
CDN 到底是什么？
流量从 0 到 1000，省钱和不被压垮的关键开关。

### 图 2｜破误解
CDN 不是「让网站变快」的玄学开关。
它是在全国各地放「复印点」，让用户就近拿内容。
对个人开发者：也是第一次面对「被攻击 / 被爬」时的第一道缓冲。

### 图 3｜三句话分工
源站：真正的服务器 `203.0.113.10`
节点：分散各地的副本
调度：DNS 把用户指向最近的节点

### 图 4｜CDN 解决什么问题
减少延迟：物理距离近
抗突发：单点压力大时分流
隐藏源站：用户拿不到真实 IP

### 图 5｜CDN 不解决什么问题
动态接口（要实时算的）不一定加速
配错缓存策略可能「改完不生效」
HTTPS 证书要和源站/域名对齐

### 图 6｜个人开发者要记住什么
流量上来后再上 CDN，先把源站跑稳。
`mytool.com` 装 CDN 后，DNS 解析会指向 CDN 节点，不是源 IP。
国内 CDN 也要看接入合规要求。

### caption
你为什么会在意：起步阶段省钱的工具，流量起来后变成「服务器不被压垮」的关键。场景：刚上线没人访问，先别买 CDN。CDN 是放大器，不是补药。个人开发者视角整理。#个人开发者 #独立开发 #产品上线

## 图文 06｜域名、服务器、备案是什么关系？

**主线**：三件事各自独立，又通过「域名解析 + 服务器位置」串在一起；漏一件或顺序错都会卡。

**贯穿实例**：`mytool.com` → 解析到大陆服务器 → 备案通过 → 浏览器才能打开。

### 图 1｜封面
域名、服务器、备案是什么关系？
新手第一次上线卡得最久的，就是这条顺序链。

### 图 2｜一句话分工
域名：别人怎么找到你
服务器：被找到后由谁来回应
备案：在中国大陆合法「开门营业」的入场券
对个人开发者：上线动作里最容易错位的一组概念。

### 图 3｜顺序
① 注册域名 + 实名
② 买服务器（地域先想好）
③ 备案（域名实名 + 服务器 + 接入商三合一）
④ 解析：把域名指向服务器 IP
⑤ 上线：放页面 / 程序

### 图 4｜错位会卡在哪
只买域名没解析 → 浏览器找不到
只买服务器没备案 → 大陆站点会被关停
先备案再买域名 → 备案主体信息对不上

### 图 5｜境外服务器场景
服务器在境外，目前不要求 ICP 备案。
访问速度、合规要求、支付方式各自不同。
`mytool.com` 想出海才考虑这条路。

### 图 6｜个人开发者要记住什么
这是上线基础设施里最常错位的一条链。
顺序对、概念清，剩下是填表和等审核。
后续条目拆每一步怎么落地。

### caption
你为什么会在意：上线失败 80% 不是代码错，是这条链上某一步没串起来。场景：朋友问「域名买了，服务器也买了，怎么还看不到」——通常是顺序错或备案没通过。个人开发者视角整理。#个人开发者 #独立开发 #产品上线

## 图文 07｜为什么国内服务器通常要备案？

**主线**：备案是国家对「在中国大陆提供互联网信息服务」的合规要求；不办就关停，不是技术问题。

**贯穿实例**：`mytool.com` 解析到大陆 `203.0.113.10`，接入商必须在工信部系统里登记。

### 图 1｜封面
为什么国内服务器通常要备案？
新手项目最常见的「上线失败」原因之一。

### 图 2｜一句话回答
中国大陆对提供互联网信息服务的站点做登记。
没登记就不能在大陆服务器上对外提供服务。
对个人开发者：这是出海攻略忽悠你「免备案」前必须知道的事实。

### 图 3｜谁在管
工信部 + 省通信管理局。
接入商（云平台）代为提交、查验。

### 图 4｜不备案会怎样
网站被关停，域名被列入黑名单。
个人开发者新项目最常见的「上线失败」原因之一。

### 图 5｜什么场景不用备
服务器在境外。
纯内网、不对外暴露。
后端 API 仍解析到大陆 IP 也要备。

### 图 6｜个人开发者要记住什么
备案是入场券，不是审核你的代码写得好不好。
`mytool.com` 想做大陆用户，先把备案当成必须项排进时间表。

### caption
你为什么会在意：跳过这一步，国内服务器上的站点会被关停，新项目排期会延 2–3 周。场景：很多出海教程鼓吹「免备案」，但服务器在国内就绕不开。把它当成上线地图上的固定关卡。个人开发者视角整理，非法律建议。#个人开发者 #独立开发 #产品上线

## 图文 08｜一个网页上线要经过哪几步？

**主线**：上线不是「做完就完」，是一条 6 步链——注册域名、买服务器、备案、解析、上传内容、测试。

**贯穿实例**：`mytool.com` 的上线清单，从注册到打开浏览器看到内容。

### 图 1｜封面
一个网页上线要经过哪几步？
第一次上线排期的全部真相。

### 图 2｜破误解
不是写完代码就直接上线。
中间还有 4–5 道手续，每一道都可能卡你几天。
对个人开发者：上线排期主要不是写代码，是这套流程。

### 图 3｜六步链
① 注册域名 → ② 实名认证
③ 买服务器 → ④ 备案（大陆必走）
⑤ 域名解析 → ⑥ 上传网站 / 测试

### 图 4｜每一步耗时
注册域名：几分钟
实名审核：通常 1–3 个工作日
备案：通常 1–20 个工作日
解析生效：几分钟到几小时

### 图 5｜常见错位
先备案后买域名 → 信息对不上
只解析没上传内容 → 空白页
只备案没解析 → 还是打不开

### 图 6｜个人开发者要记住什么
这是上线地图的标准路径。
`mytool.com` 这条链全跑通，才算「上线」二字。
后面条目拆每一步具体怎么做。

### caption
你为什么会在意：第一次上线预计 2–3 周，主要时间花在实名 + 备案等待；把这些时间算进排期。场景：卡在上线当天才发现没排进审核时间。个人开发者视角整理。#个人开发者 #独立开发 #产品上线

## 图文 09｜静态网站适合什么项目？

**主线**：静态网站 = 不依赖后端程序就能跑的网页（HTML/CSS/JS），适合个人主页、文档站、产品落地页等「只展示、不交互」的场景。

**贯穿实例**：`mytool.com` 第一版只是产品介绍页 → 静态站就能搞定。

### 图 1｜封面
静态网站适合什么项目？
验证想法阶段最便宜也最快的一档选择。

### 图 2｜一句话定义
不需要数据库、不需要后端语言的网站。
HTML/CSS/JS 文件直接放在服务器上就能跑。
对个人开发者：决定第一版要不要先堆后端的关键判断。

### 图 3｜适合场景
个人主页
产品介绍 / 落地页
开源文档
活动页 / 一次性宣传页

### 图 4｜不适合场景
用户登录、评论、收藏
电商下单、支付
实时数据（聊天、看板）

### 图 5｜为什么个人开发者爱用
部署简单：上传文件即可
成本低：静态托管便宜甚至免费
速度快：没有后端拖累
备案要求同：服务器在大陆仍要备案

### 图 6｜个人开发者要记住什么
先问：是不是「只展示、不交互」？
是 → 静态站。
不是 → 后面条目会拆「轻量服务器」「Serverless」怎么选。

### caption
你为什么会在意：先静态后动态，把验证期成本压到最低，错过的只是「看起来复杂」。场景：产品还在验证阶段，先做静态落地页测流量。个人开发者视角整理。#个人开发者 #独立开发 #产品上线

## 图文 10｜轻量服务器适合什么项目？

**主线**：轻量服务器是云厂商为新手打包的「够用就行」套餐，介于虚拟主机和 ECS 之间，适合小产品、个人项目、原型期。

**贯穿实例**：`mytool.com` 上线后想跑点小工具 → 轻量服务器 + Node/Python 即可。

### 图 1｜封面
轻量服务器适合什么项目？
起步阶段最划算的一档「够用就好」。

### 图 2｜一句话定义
云厂商为个人开发者打包的入门套餐。
固定配置、按月付、自带常用运行环境。
对个人开发者：决定起步成本和未来升级路径的关键档位。

### 图 3｜适合场景
个人博客 / 小程序后端
小型 API 服务
学习、试验、原型
流量不大的工具站

### 图 4｜不适合场景
大流量电商
复杂微服务架构
对内核参数、网络性能有专业要求

### 图 5｜个人开发者要避的坑
资源上限低：高负载会卡
套餐绑死：升级/迁移可能受限
国内仍要备案：跟普通服务器规则一样

### 图 6｜个人开发者要记住什么
起步阶段够用，比共享主机自由，比 ECS 便宜。
`mytool.com` 跑第一版先选轻量，等量起来了再升。
后续条目会拆「云服务器 ECS 怎么选」。

### caption
你为什么会在意：起步阶段省下的几百到一千，决定第一款产品能多撑几个月。场景：第一款产品上线，先用轻量服务器撑 3–6 个月，等日活稳定再升级。个人开发者视角整理。#个人开发者 #独立开发 #产品上线
