## 六、标题阶段边界

### 6.1 标题可以承诺

1. 「域名到底是什么」——概念问句入口
2. 「买了域名 / 买了 mytool.com 为什么还打不开」——处境钩（可用泛化表述，不必固定 mytool.com）
3. 「域名是寻址名，不是网站本身」——纠偏主承诺
4. 「买了域名只是第一步，还要解析、服务器和页面」——E0106 反差
5. 「IP / 域名 / DNS 三句话分工」——收藏向副承诺
6. 「个人开发者上线第一个基础设施概念块」——scope 内升维

### 6.2 标题不能承诺

1. 保姆级建站、十分钟上线、DNS 手把手配置
2. 免备案攻略、.com 不用备案、境外规避路径
3. 备案全流程、后缀选购、续费赎回详解
4. 上线基础设施全景 / 域名服务器备案一次讲清
5. mytool.com 或示例 IP 作为真实故障案例
6. 实名「1–3 天必过」、促销价、SEO 后缀排名

### 6.3 标题禁用或慎用表达

| 表达 | 禁用/慎用 | 原因 | 替代方向 |
|---|---|---|---|
| 保姆级 / 十分钟搞定 / 全网最全 | 禁用 | 文风禁用清单 | 「域名到底是什么」问句 |
| 买了就能访问 / 注册即上线 | 禁用 | 事实 B01 | 「买了为什么还打不开」 |
| .com 不用备案 | 禁用 | 事实 B02 | 「关键看服务器在哪里」 |
| 上线全攻略 / 一套讲清 DNS 服务器 备案 | 慎用 | 超出条目 01 scope | 「上线地图第一格」 |
| 264 号文第四条 | 禁用 | 条文位置错误 | 不出现或写「第一条第一款」 |
| mytool.com 真实案例 | 禁用 | 教学虚构 | 「比如你刚注册的域名」 |

### 6.4 标题必须保留的限定口径

| 口径 | 标题阶段必须如何处理 | 来源 |
|---|---|---|
| 域名≠网站；寻址名不托管内容 | 标题可纠偏，不得暗示「域名=网站」 | 方向把控 / E0103 |
| 买了≠能访问 | 处境钩须留「还要解析/服务器/页面」空间 | E0106 / 事实核查 B01 |
| 备案看服务器位置，非看后缀 | 不得写「.com 免备案」 | E01P1-08 |
| 账号实名≠域名实名 | 可轻点国内差异，不展开教程 | E01P1-13 |
| 审核/宽限期 | 若提及须带「通常」「约」 | 事实核查 |
| 条目 01 只讲「是什么」 | 标题不得等于条目 06/08 的流程承诺 | 方向把控放弃项 |
