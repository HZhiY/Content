# 主题包：网站上线基础设施

## 图文 01｜域名到底是什么？

### 图 1｜封面

域名到底是什么？
买了域名，为什么还打不开？

### 图 2｜破误解

很多人以为买了域名就有了网站。注册第一个域名时，常会卡在这：域名更像门牌号，不是网站本体。网页内容在服务器上。

### 图 3｜寻址名定义

域名是给人记的网站地址名称，是 DNS 分层命名体系里的名称，从右往左由大到小。DNS 是把域名翻译成 IP 的系统。域名解决「别人怎么找到你」，不解决「网页内容是什么」。

### 图 4｜三句话分工

IP → 给机器看的数字地址
域名 → 给人记的名字
DNS → 把域名翻译成 IP 的系统
三者分工不同，缺一不可

### 图 5｜访问链路

输入域名 → DNS 查 IP → 连服务器 → 返回网页
注册域名只是第一步，还要解析（让域名指向哪台服务器）、服务器和实际内容
国内服务器场景下，备案另有一道关卡

### 图 6｜收束

技术上它是寻址名；在国内它还是要花年费、过实名的名字资产。
账号实名了，域名还要单独实名。
域名解决找到你，不解决内容是什么。
搞清域名，只是上线地图第一块。

### caption
