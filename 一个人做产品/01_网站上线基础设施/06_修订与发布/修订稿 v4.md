## 图文 02｜服务器到底是什么？

**主线**：服务器不是「放网站的那台电脑」这么简单，它是一台 7×24 小时、装在机房或云里的机器，给用户跑程序和回传数据。

**贯穿实例**：`mytool.com` 这次找到了那台机器 `203.0.113.10`，网页就放在它上面。

### 图 1｜封面
服务器到底是什么？
没它，域名解析了也没东西能响应——上线最后一步。

### 图 2｜破误解 + 在意点
很多人以为服务器就是「我电脑一直开着」。
其实它更像一台不停机的、装在专业机房里替你值班的电脑。
对个人开发者：上线花钱和选规格的对象，就是它。

### 图 3｜定义
服务器是 7×24 小时在线、对外提供服务的机器。
`mytool.com` 的网页就放在一台服务器上，浏览器请求进来，它把页面内容送回去。

### 图 4｜三种形态
个人开发者常见三种：
① 云服务器 ECS/CVM：远程租一台
② 虚拟主机 / 共享主机：和别人合租一台
③ Serverless：把代码丢给云平台托管

### 图 5｜域名和服务器的关系
域名解决「别人怎么找到你」，
服务器解决「被找到后由谁来回应」。
`mytool.com` + 服务器 + 解析，才算凑齐一回完整链路。

### 图 6｜个人开发者要记住什么

服务器要付租金、要选地域、要续费。
国内做网站，服务器在国内就要考虑备案。
后面条目会拆云服务器、虚拟主机、Serverless 怎么选。

### 图 7｜三种形态的取舍 ⭐（v4 新增）
云服务器：自由度高，能装任何东西，但运维要自己扛。
共享主机：便宜省心，但跑不动大流量、配置锁死。
Serverless：不用管服务器，按调用付费，但冷启动 + 调试复杂。
`mytool.com` 第一版只是静态页——共享主机够；要做用户登录 + 数据存储——必须云服务器或 Serverless。

### 图 8｜什么时候升级 ⭐（v4 新增）
升级信号三个：① CPU 长期 > 70% ② 月流量超过套餐阈值 ③ 部署发布脚本开始变成体力活。
升级路径：共享主机 → 轻量 / 云服务器 → ECS / 自建集群。
不要在第一版就上 ECS——还没验证需求，钱白花。

### caption
你为什么会在意：上线前第一个要付费的「重资产」，选错地域就影响备案和访问速度。场景：下单了一台云服务器、拿到公网 IP，浏览器输入 IP 还是看不到——通常是没装程序、没开端口。个人开发者视角整理。#个人开发者 #独立开发 #产品上线

## 图文 03｜备案到底是什么？

**主线**：ICP 备案不是买域名的一部分，是「把网站放到中国大陆服务器前」的行政流程；不办就用不了。

**贯穿实例**：`mytool.com` 想挂在大陆服务器 `203.0.113.10`，就绕不开这道手续。

### 图 1｜封面
备案到底是什么？
没备就关停，国内服务器上线第一道门。

### 图 2｜破误解 + 在意点
备案不是给网站内容「过审」。
它是「域名 + 服务器」绑在一起、报给工信部的一步行政登记。
对个人开发者：跳过这一步，国内服务器站点直接开不起来。

### 图 3｜三句话分工
主体：你（个人 / 公司）是谁
网站：放什么服务
接入商：你买的哪家云平台

### 图 4｜什么场景才要备案
域名解析到中国大陆服务器，就必须备案。
服务器在境外，目前不要求。
跟 `.com` 还是 `.cn` 后缀没关系，看服务器在哪里。

### 图 5｜大致时长与卡点
首次备案一般 1–20 个工作日，因地因人而异。
常见被驳回：域名实名信息和备案主体不一致；服务器不在你户籍地或常驻地。
具体以接入商控制台和管局口径为准。

### 图 6｜个人开发者要记住什么

备案是接入门票，不是内容审核。
`mytool.com` 想进大陆服务器，要走完这一步才合法「开门」。
DNS 怎么配、接入商怎么填，见后续条目。

### 图 7｜真实场景剖面 ⭐（v4 新增）
同一个 `mytool.com`、同一台国内服务器——
做「产品官网」备案：填主体 + 网站名 + ICP 备案号；接入商初审 1–3 天；管局抽审 7–14 天。
做「小程序后端」备案：除上面之外，还要填「服务类目」「接入方式」，接入商会要求小程序 AppID；驳回率明显更高，因为类目填错就退回。
同一台机器，**备案要填的东西、走的关卡、卡住的概率完全不同**——用途决定代价。

### 图 8｜你会在哪里卡住 ⭐（v4 新增）
三类真实驳回 + 解法方向：
①「主体信息与域名实名不一致」：你备案填的是张三，域名实名是李四——一般卡 5 个工作日；解法：改域名模板或换备案主体，二选一。
②「网站名称不合规」：叫「我的测试」会被打回，必须含「网站」/「工作室」类词——卡 3 个工作日；解法：改名字重新提交。
③「服务器不在户籍地或常驻地」：你在北京，服务器买了上海——个人备案常被退回——要换接入商或加居住证明。

### caption
你会在哪里卡住：备案不是技术问题，是**三次过审**——接入商初审、管局抽审、驳回再提交。首次备案排 2–3 周不是夸张，是保守估计。场景：你周一晚上提交备案，周二看到「接入商审核中」，周五上午被驳回，原因是「网站名称不含规范词」。改完再提交，又要等 5 天。**第一次上线真正卡人的，是这条流程里某一步骤的等待时间，不是写代码。** 个人开发者视角整理，非法律建议。#个人开发者 #独立开发 #产品上线

## 图文 04｜SSL 证书到底是什么？

**主线**：SSL 证书让浏览器和服务器之间的对话「加密 + 身份可验」，是 https 锁头图标的来源。

**贯穿实例**：访问 `https://mytool.com` 时，证书在告诉浏览器「这台 `203.0.113.10` 确实是 `mytool.com` 的」。

### 图 1｜封面
SSL 证书到底是什么？
没它浏览器标红「不安全」，小程序和微信生态直接拒绝接入。

### 图 2｜破误解 + 在意点
SSL 证书不是「让网站变高级」的装饰。
它是浏览器和服务器之间的「身份证 + 加密锁」。
对个人开发者：现在的小程序、支付、第三方登录，基本都强制 https。

### 图 3｜三件事
① 加密：传输内容不让中间人偷看
② 身份：证明这台服务器就是 `mytool.com` 声明的那台
③ 信任：由可信第三方（CA）签发

### 图 4｜常见类型
DV（域名验证）：只验证你能控制这个域名，最快
OV（组织验证）：再加验证机构身份
EV（扩展验证）：更严，浏览器地址栏展示更多

### 图 5｜个人开发者路径
云平台一键申请免费证书（通常 DV）。
绑定域名 `mytool.com` 后，到期前续签或重新申请。
证书过期没换，浏览器会直接红色警告。

### 图 6｜个人开发者要记住什么

网站不装证书，浏览器会标「不安全」。
个人项目先用云厂商免费 DV 就够。
`mytool.com` 的「锁」是基本动作，不是加分项。

### 图 7｜不装证书的真实代价 ⭐（v4 新增）
浏览器地址栏直接标「不安全」——90% 用户会关掉。
微信内嵌页、公众号 H5、小程序 web-view——不装证书直接打不开。
支付场景（微信支付、支付宝）——回调地址必须 https。
第三方登录（GitHub OAuth、微信开放平台）——回调白名单只接受 https。
**不装证书 = 把一半用户挡在门外**——这不是「加分项」。

### 图 8｜续期 / 配错会怎样 ⭐（v4 新增）
三类常见事故：
① 证书过期没换：浏览器红屏；最坏情况是凌晨 2 点收到报警电话。
② 证书绑错域名：买了 `mytool.com` 的证书挂在 `www.mytool.com`——浏览器提示「证书与域名不匹配」。
③ 私钥泄露：必须立刻吊销 + 重签——但客户端要刷新才能看到新证书。
云平台免费证书通常 90 天到期——**建议日历提前 14 天提醒续期**。

### caption
你为什么会在意：现在不装证书，新用户打开就被警告，小程序和支付场景会直接被拒。场景：刚上线的小程序或官网，出现「您的连接不是私密连接」通常是证书没装、过期或域名没在证书里。个人开发者视角整理。#个人开发者 #独立开发 #产品上线

## 图文 05｜CDN 到底是什么？

**主线**：CDN 不是云服务商的「加速包」，它是一层地理分布的「内容中转站」，让用户从离自己最近的节点拿网页。

**贯穿实例**：`mytool.com` 的服务器在 `203.0.113.10`（北京），但深圳用户不用千里迢迢去北京——CDN 在深圳就有副本。

### 图 1｜封面
CDN 到底是什么？
流量从 0 到 1000，省钱和不被压垮的关键开关。

### 图 2｜破误解 + 在意点
CDN 不是「让网站变快」的玄学开关。
它是在全国各地放「复印点」，让用户就近拿内容。
对个人开发者：也是第一次面对「被攻击 / 被爬」时的第一道缓冲。

### 图 3｜三句话分工
源站：真正的服务器 `203.0.113.10`
节点：分散各地的副本
调度：DNS 把用户指向最近的节点

### 图 4｜CDN 解决什么问题
减少延迟：物理距离近
抗突发：单点压力大时分流
隐藏源站：用户拿不到真实 IP

### 图 5｜CDN 不解决什么问题
动态接口（要实时算的）不一定加速
配错缓存策略可能「改完不生效」
HTTPS 证书要和源站/域名对齐

### 图 6｜个人开发者要记住什么

流量上来后再上 CDN，先把源站跑稳。
`mytool.com` 装 CDN 后，DNS 解析会指向 CDN 节点，不是源 IP。
国内 CDN 也要看接入合规要求。

### 图 7｜配错会怎样 ⭐（v4 新增）
三类常见 CDN 事故：
① 缓存策略配错：更新了首页文案，用户看到的是旧版本——解法：手动刷新 URL 或临时关缓存。
② 动态接口被缓存：用户 A 看到的下单结果是用户 B 的——这是血泪级事故，必须严格设置「不缓存 POST / 带 Cookie / 带参数」。
③ 源站 IP 暴露：CDN 没开「回源鉴权」，被扫到 IP 后绕过 CDN 直接打源站——CDN 形同虚设。
`mytool.com` 配错一次缓存，回滚花了 4 个小时——**首次接入 CDN 一定要在测试域名上跑一遍**。

### 图 8｜什么时候需要 CDN ⭐（v4 新增）
判断信号三个：① 月流量超过 100 GB ② 源站 CPU 经常被打满 ③ 国内多地域访问慢。
不急着接的信号：① 日活 < 100 ② 几乎全是动态内容 ③ 还没做 HTTPS。
**起步阶段不上 CDN**——先让源站跑稳，流量起来再考虑；CDN 是放大器，不是补药。

### caption
你为什么会在意：起步阶段省钱的工具，流量起来后变成「服务器不被压垮」的关键。场景：刚上线没人访问，先别买 CDN。CDN 是放大器，不是补药。个人开发者视角整理。#个人开发者 #独立开发 #产品上线

## 图文 06｜域名、服务器、备案是什么关系？

**主线**：三件事各自独立，又通过「域名解析 + 服务器位置」串在一起；漏一件或顺序错都会卡。

**贯穿实例**：`mytool.com` → 解析到大陆服务器 → 备案通过 → 浏览器才能打开。

### 图 1｜封面
域名、服务器、备案是什么关系？
新手第一次上线卡得最久的，就是这条顺序链。

### 图 2｜一句话分工
域名：别人怎么找到你
服务器：被找到后由谁来回应
备案：在中国大陆合法「开门营业」的入场券
对个人开发者：上线动作里最容易错位的一组概念。

### 图 3｜顺序
① 注册域名 + 实名
② 买服务器（地域先想好）
③ 备案（域名实名 + 服务器 + 接入商三合一）
④ 解析：把域名指向服务器 IP
⑤ 上线：放页面 / 程序

### 图 4｜错位会卡在哪
只买域名没解析 → 浏览器找不到
只买服务器没备案 → 大陆站点会被关停
先备案再买域名 → 备案主体信息对不上

### 图 5｜境外服务器场景
服务器在境外，目前不要求 ICP 备案。
访问速度、合规要求、支付方式各自不同。
`mytool.com` 想出海才考虑这条路。

### 图 6｜个人开发者要记住什么

这是上线基础设施里最常错位的一条链。
顺序对、概念清，剩下是填表和等审核。
后续条目拆每一步怎么落地。

### 图 7｜境外服务器的真实剖面 ⭐（v4 新增）
访问体验：国内用户访问境外服务器，延迟 200–500ms；晚高峰更慢。
合规要求：域名仍要实名；不能做新闻 / 出版 / 医疗等敏感类目。
支付方式：境外信用卡 + Stripe 通用；微信支付 / 支付宝要单独申请跨境资质。
适用场景：① 出海产品 ② 国内开发 + 海外用户 ③ 工具类 / 文档类（对延迟不敏感）。
不适用场景：① 国内用户为主 ② 需要备案才能上的功能（如小程序）③ 任何要 ICP 备案号才能接入的渠道。

### 图 8｜错位的具体成本 ⭐（v4 新增）
错位一：先备案后买域名 → 备案主体信息对不上 → 重新提交 = 5–15 个工作日。
错位二：服务器地域选错 → 想从香港迁回大陆 = 数据迁移 + 重新备案 = 1–2 个月。
错位三：解析配错类型（A 写成 CNAME 或反过来）→ 站点时通时不通 → 排查半天。
**上线地图的错位成本以周计，不以小时计**——顺序先对，再动手。

### caption
你为什么会在意：上线失败 80% 不是代码错，是这条链上某一步没串起来。场景：朋友问「域名买了，服务器也买了，怎么还看不到」——通常是顺序错或备案没通过。个人开发者视角整理。#个人开发者 #独立开发 #产品上线

## 图文 07｜为什么国内服务器通常要备案？

**主线**：备案是国家对「在中国大陆提供互联网信息服务」的合规要求；不办就关停，不是技术问题。

**贯穿实例**：`mytool.com` 解析到大陆 `203.0.113.10`，接入商必须在工信部系统里登记。

### 图 1｜封面
为什么国内服务器通常要备案？
新手项目最常见的「上线失败」原因之一。

### 图 2｜一句话回答
中国大陆对提供互联网信息服务的站点做登记。
没登记就不能在大陆服务器上对外提供服务。
对个人开发者：这是出海攻略忽悠你「免备案」前必须知道的事实。

### 图 3｜谁在管
工信部 + 省通信管理局。
接入商（云平台）代为提交、查验。

### 图 4｜不备案会怎样
网站被关停，域名被列入黑名单。
个人开发者新项目最常见的「上线失败」原因之一。

### 图 5｜什么场景不用备
服务器在境外。
纯内网、不对外暴露。
后端 API 仍解析到大陆 IP 也要备。

### 图 6｜个人开发者要记住什么

备案是入场券，不是审核你的代码写得好不好。
`mytool.com` 想做大陆用户，先把备案当成必须项排进时间表。

### 图 7｜不备案的真实链路 ⭐（v4 新增）
第一天：服务器 IP 还能访问。
第三天：接入商检测到未备案，短信 + 站内信提醒。
第七天：仍未备案，HTTP 80 / 443 端口被屏蔽。
第十四天：域名被加入工信部黑名单 → 其他接入商也不能用。
**「暂时不备」不是免费午餐——是倒计时**。想做长期项目，第一周就把备案排上。

### 图 8｜常见的"以为不用备" ⭐（v4 新增）
误解一：「只是个人项目，没流量」——没用，没备案照样关。
误解二：「我不放内容，只放 API」——后端 API 解析到大陆 IP 也要备。
误解三：「用对象存储放静态文件」——只要走 CDN 走大陆节点，还是要备。
误解四：「公司网站才要备，个人不用」——错，个人备案更常见。
误解五：「试运行几天再补」——接入商检测是实时的，不会等你。

不是写完代码就直接上线。

## 图文 09｜静态网站适合什么项目？

**主线**：静态网站 = 不依赖后端程序就能跑的网页（HTML/CSS/JS），适合个人主页、文档站、产品落地页等「只展示、不交互」的场景。

**贯穿实例**：`mytool.com` 第一版只是产品介绍页 → 静态站就能搞定。

### 图 1｜封面
静态网站适合什么项目？
验证想法阶段最便宜也最快的一档选择。

### 图 2｜一句话定义
不需要数据库、不需要后端语言的网站。
HTML/CSS/JS 文件直接放在服务器上就能跑。
对个人开发者：决定第一版要不要先堆后端的关键判断。

### 图 3｜适合场景
个人主页
产品介绍 / 落地页
开源文档
活动页 / 一次性宣传页

### 图 4｜不适合场景
用户登录、评论、收藏
电商下单、支付
实时数据（聊天、看板）

### 图 5｜为什么个人开发者爱用
部署简单：上传文件即可
成本低：静态托管便宜甚至免费
速度快：没有后端拖累
备案要求同：服务器在大陆仍要备案

### 图 6｜个人开发者要记住什么

先问：是不是「只展示、不交互」？
是 → 静态站。
不是 → 后面条目会拆「轻量服务器」「Serverless」怎么选。

### 图 7｜什么时候必须升级 ⭐（v4 新增）
升级信号三个：① 需要用户系统（注册 / 登录 / 收藏）② 需要提交表单（联系、试用申请、订阅）③ 想要看到访问数据（埋点、A/B）。
升级路径：静态站 + Serverless 函数（最便宜）→ 静态站 + 单独后端 → 全部重写为动态站。
**验证需求阶段别急着升级**——先用静态页测流量，确认有人要看，再决定要不要后端。

### 图 8｜个人项目避坑 ⭐（v4 新增）
坑一：把博客也做成静态站——内容超过 50 篇后，每次更新都要重新部署——解法：用 Hexo / Hugo / Astro 等静态生成器。
坑二：以为静态站不用备案——服务器在大陆仍要备案，没例外。
坑三：在静态站里塞 jQuery 写"动态"——不如直接用 Vue / React + 静态导出。
坑四：把支付 / 登录硬塞进静态站——这是反模式，会让简单的事变复杂。

## 图文 10｜轻量服务器适合什么项目？

**主线**：轻量服务器是云厂商为新手打包的「够用就行」套餐，介于虚拟主机和 ECS 之间，适合小产品、个人项目、原型期。

**贯穿实例**：`mytool.com` 上线后想跑点小工具 → 轻量服务器 + Node/Python 即可。

### 图 1｜封面
轻量服务器适合什么项目？
起步阶段最划算的一档「够用就好」。

### 图 2｜一句话定义
云厂商为个人开发者打包的入门套餐。
固定配置、按月付、自带常用运行环境。
对个人开发者：决定起步成本和未来升级路径的关键档位。

### 图 3｜适合场景
个人博客 / 小程序后端
小型 API 服务
学习、试验、原型
流量不大的工具站

### 图 4｜不适合场景
大流量电商
复杂微服务架构
对内核参数、网络性能有专业要求

### 图 5｜个人开发者要避的坑
资源上限低：高负载会卡
套餐绑死：升级/迁移可能受限
国内仍要备案：跟普通服务器规则一样

### 图 6｜个人开发者要记住什么

起步阶段够用，比共享主机自由，比 ECS 便宜。
`mytool.com` 跑第一版先选轻量，等量起来了再升。
后续条目会拆「云服务器 ECS 怎么选」。

### 图 7｜什么时候换型 ⭐（v4 新增）
换型信号三个：① CPU 长期 > 60% ② 月流量超出套餐 1.5 倍 ③ 需要的功能（GPU、对象存储、独立数据库）套餐里没有。
换型路径：轻量 → ECS 同区域（同厂商迁移最方便）→ 多台 ECS + 负载均衡。
**不要等到崩了才换**——看到信号就提前 1–2 周规划。

### 图 8｜轻量 vs ECS 真实差距 ⭐（v4 新增）
价格：轻量首年几十到几百，ECS 同配置贵 30%–50%。
性能：轻量 CPU 共享，ECS 可选独享；高并发差距明显。
自由度：ECS 可改内核参数、可挂多网卡；轻量锁死。
运维：轻量自带镜像 + 控制台一键；ECS 要自己搭监控 + 备份。
**起步选轻量没错，但心里要知道它的天花板**——这是"够用就好"，不是"永远够用"。
