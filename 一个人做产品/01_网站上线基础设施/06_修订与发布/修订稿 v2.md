# 主题包：网站上线基础设施

## 图文 01｜域名到底是什么？

### 图 1｜封面

域名到底是什么？
买了 mytool.com，为什么还打不开？

### 图 2｜破误解

很多人以为买了域名就有了网站。
比如你花年费注册 `mytool.com`，浏览器却提示无法访问——域名只是名字，网页文件还在服务器上。

### 图 3｜寻址名定义

拿 `mytool.com` 举例：它是给人记的寻址名，不是网站本身。
DNS 负责把它翻译成 IP（示例：`203.0.113.10`），浏览器才能找到那台机器。

### 图 4｜三句话分工

还是 `mytool.com` 这一条链：
`203.0.113.10` → 给机器看的数字地址
`mytool.com` → 给人记的名字
DNS → 把名字翻译成 IP

### 图 5｜访问链路

浏览器输入 `mytool.com`
→ DNS 查到 `203.0.113.10`
→ 连上那台服务器 → 返回网页
光有域名不够，还要解析指向服务器，服务器上也要有页面

### 图 6｜收束

`mytool.com` 在国内还要单独实名，和腾讯云账号实名不是一回事。
域名帮别人找到你，不替你放网页内容。
搞清这一步，才算摸上线地图第一格。

### caption

场景：你刚注册 `mytool.com`，打开却是空白——通常是域名、解析、服务器、页面四件事没串起来，不是「买错了」。备案和买域名也是两回事；实名审核常见约 1–3 个工作日。DNS 怎么配、服务器放哪，见后续条目。个人开发者视角整理，非法律建议。#个人开发者 #独立开发 #产品上线
