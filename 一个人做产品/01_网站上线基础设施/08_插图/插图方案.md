## 一、插图需求分析

### 1.1 卡片结构（与修订稿 1:1）

| 卡片 | 修订稿任务 | 插图机会 |
|---|---|---|
| 图 1 封面 | 双问句入口：域名是什么 + 买了为什么打不开 | 封面停驻；大字问句 |
| 图 2 破误解 | 破「买了域名就有网站」 | 反差对照；示例域名标注 |
| 图 3 寻址名定义 | 域名是寻址名；DNS 翻译 IP | 概念钉；示例 IP 标注 |
| 图 4 三句话分工 | IP / 域名 / DNS 分工 | 收藏卡；三行清单 |
| 图 5 访问链路 | 四步访问链 + 买了≠能访问 | 箭头流程图（本条目唯一机制图） |
| 图 6 收束 | 国内实名边界 + 系列地图第一格 | 收束判断；轻点合规差异 |

### 1.2 插图数量决策

**6 张**（每张卡片 = 一张竖图，小红书图文原生形态）

理由：
- 本系列发布单元即 6 卡图文，插图与卡片一一对应，不做额外装饰图；
- 图 4、图 5 承担「可截图收藏」机制图职责；
- caption 不单独成图，留在发布正文。

### 1.3 视觉风格决策

| 维度 | 决策 |
|---|---|
| 整体风格 | 小型 PPT / 产品文档笔记；清楚、克制；非营销海报 |
| 底色 | 白底或浅米色底 |
| 字体色 | 黑色正文 |
| 强调色 | 蓝色（主）+ 橙色（仅用于箭头、示例标注、关键术语） |
| 版式 | 大标题 + 短段；每卡 ≤ 8 行；页码 01/06 … 06/06 |
| 辅助元素 | 细线框、短箭头、三行清单；图 5 用横向/纵向箭头流程 |
| 禁止 | 阴谋论视觉、实名人物肖像、营销贴纸、暴富培训腔、未核实数据图表 |

## 三、插图边界检查

### 3.1 与发布检查边界的一致性

| 检查项 | 状态 | 说明 |
|---|---|---|
| mytool.com 为教学虚构 | ✓ | 图 2–6 均标注「示例」，不作真实故障案例 |
| 203.0.113.10 为 RFC 5737 示例 | ✓ | 图 3–5 标注「示例 IP」，不作真实服务地址 |
| 不写 DNS 配置教程 | ✓ | 图 5 只画访问链，不出现 A/CNAME 配置界面 |
| 不写备案全流程 | ✓ | 图 6 仅一句实名边界，不展开流程 |
| 不写「买了就能访问」 | ✓ | 图 2、图 5 明确「光有域名不够」 |
| 账号实名 ≠ 域名实名 | ✓ | 图 6 保留对照句 |
| 审核天数 | ✓ | 卡片正文未写死天数；caption 不在本阶段成图 |

### 3.2 与系列风格的一致性

- 白底/米色底、黑字、单强调色；像笔记不像海报
- 页码 01/06 … 06/06 增强 PPT 感
- 克制、可收藏；无培训号/暴富视觉
