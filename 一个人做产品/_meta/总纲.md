# 一个人做产品｜系列总纲 v1

> 版本：v1（适配 `_工作流/02`）  
> 平台：小红书  
> 形态：图文卡片 / 类 PPT  
> 生产：主题包一次查资料、一次写草稿，拆多条图文发布

---

## 一、与工作流的关系

本系列**严格服从** `_工作流/02_单篇文章从0到HTML成稿执行手册.md`。

不另建流程。差异只在 `_meta/_config/` 里定义：

```text
02 的「单篇文章项目」= 一个主题包（如「网站上线基础设施」）
一个主题包产出 5-12 条小红书图文
每条图文 500-800 字、6-8 张卡片
```

启动示例：

```text
文章标题：网站上线基础设施
系列：一个人做产品
按 _工作流/02_单篇文章从0到HTML成稿执行手册.md 执行，从 0 跑到 HTML 成稿。
```

---

## 二、系列母题

```text
一个中国个人开发者做小产品，需要理解哪些基础设施？
```

代码只是其中一环。域名、服务器、备案、支付、分发、AI 流程等，决定产品能否进入真实世界。

## 三、层级结构

```text
系列
└── 栏目（_meta/栏目地图.md）
    └── 主题包（= 02 单篇项目）
        └── 图文条目（= 发布单元）
            └── 卡片页（图 1-7）
```

---

## 四、内容边界

**主线**：国内个人开发者基础设施  
**辅助**：国外工具参考系  
**禁止**：出海教程、灰色操作、暴富话术、绕规则指南

---

## 五、生产流程（02 各阶段在本系列的含义）

| 阶段 | 本系列产物 |
|---|---|
| 资料链 | 整个主题包的共享资料 |
| 洞察链 | 主题包价值 + 条目拆分方向 |
| 大纲 | 图文条目拆分表 |
| 草稿 | 全包图文写在一个 `草稿.md` |
| 审稿 | 审口径统一 + 每条可发布 |
| 标题 | 每条图文的发布标题 |
| 插图 | 每条每张卡片视觉 |
| HTML | 图文组预览页 |

---

## 六、单条图文规格

- 500-800 字（含 caption）
- 6-8 张卡片，每张 30-90 字
- 每张图一个点
- 类型：概念科普 / 选择建议 / 流程拆解 / 避坑 / 国外对照

模板见 `_meta/图文模板.md`；结构规则见 `_config/文章结构与格式配置.md`。

---

## 七、不需要的长文模块

引言、长文式结尾、小尾巴、相关文章、脚注——**按配置不需要**。见 `文章结构与格式配置.md`。
