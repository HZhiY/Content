## 一，插图需求分析

### 1.1 正文章节结构

| 章节 | 核心内容 | 插图机会 |
|---|---|---|
| 引言 | 场景：亏20%扛三个月，赚5%就想跑；引出大脑机制问题 | 无需插图 |
| 第一节 | 损失厌恶（A洞察）：已到手收益消失比同等收益增加更痛；考试改答案、健身卡类比 | 图1：损失厌恶的不对称痛感 |
| 第二节 | 处置效应（B展开）：焦虑转化为卖出盈利资产；Odean数据；售盈持亏 | 图2：处置效应——售盈持亏的行为对比 |
| 第三节 | 动机区分（D洞察）：同一卖出动作，可能是计划，也可能是焦虑；判断问题 | 图3：落袋为安的二元判断框架 |
| 第四节 | 规则护栏（C洞察）：预设规则在情绪最强时保护计划系统；Quitter's Day类比 | 无需独立插图 |
| 结尾 | 带回判断问题；量化思维是用规则对抗自身弱点 | 无需插图 |

### 1.2 插图数量决策

**推荐：3张**

理由：
- 第一节：损失厌恶机制需要视觉化——不对称痛感是文章独家差异化入口，需要信息图支撑
- 第二节：处置效应（售盈持亏）是行为数据核心，需要对比图示
- 第三节：动机区分是全文最强可交付工具，二元判断框架需要清晰的视觉结构
- 第四节无独立插图需求：规则护栏概念通过类比（Quitter's Day）已在文字中清晰表达，再加图会堆砌
- 封面独立一张（封面图在微信公众号等平台具有强入口价值）

**不选择4张的理由**：第一节和第四节的 Quitter's Day 类比已足够文字化；过多插图会稀释信息密度。

### 1.3 视觉风格决策

| 维度 | 决策 |
|---|---|
| 整体风格 | 克制、信息图为主，非装饰图；杂志期刊体 |
| 色调 | 冷灰/深蓝为主色，辅以暖色（橙/红）标注关键情绪节点 |
| 图表类型 | 数据图示（fig01/02）+ 结构判断图（fig03）+ 封面人物/场景 |
| 字体 | 无限制（AI生图层面），正文图上文字需大、少、适合手机 |
| 隐喻 | 可用天平/称量意象表达不对称痛感；可用分叉路表达判断框架 |
| 禁止 | 阴谋论视觉、实名人物肖像、未核实数据的图表 |

### 图0：封面图 `cover.png`

| 属性 | 内容 |
|---|---|
| 插入位置 | 公众号/头条文章顶部，标题下方 |
| 画面作用 | 激活"赚钱拿不住"的场景感，强化标题承诺；建立专业但亲近的系列感 |
| 画面描述 | 一只手正在犹豫是否卖出正在盈利的投资组合；背景是K线图或资产曲线，画面中有隐性的"天平"或"称量"意象，暗示大脑在称量"落袋"与"继续持有"的分量；色调偏冷，专业感，不浮夸 |
| 图上文字 | 无（封面图通常不放文字，避免与标题重叠） |
| 手机阅读要求 | 主体元素居中或偏左，视觉重心稳定，避免过散；最小可辨识尺寸在320px宽度下依然清晰 |

### 图1：损失厌恶不对称痛感 `fig01_loss_aversion.png`

| 属性 | 内容 |
|---|---|
| 插入位置 | 第一节结尾 / 第二节开头之前（即"丢了100块的痛苦，大约是同等数额赚到的快乐的约两倍左右"这段之后） |
| 画面作用 | 视觉化"损失厌恶"机制；用天平静喻直观呈现"痛苦 > 快乐"的不对称关系 |
| 画面描述 | 天平意象：左边托盘放置金币（代表收益），右边托盘放置相同物理重量的金币但标注"损失"；天平明显倾向右侧（损失端更低）；整体简洁，无多余装饰，信息密度低，适合手机阅读 |
| 图上文字 | 左侧标注"赚100元"；右侧标注"亏100元"；底部小字"损失厌恶：损失的痛感大约是同等收益快乐感的约两倍" |
| 手机阅读要求 | 文字最小14pt；天平两侧视觉重量差在手机小屏上仍可辨识；避免在320px以下出现内容挤压 |

### 图2：处置效应对比图 `fig02_disposition_effect.png`

| 属性 | 内容 |
|---|---|
| 插入位置 | 第二节结尾（即"处置效应让人在市场里做出一个看似理性、实际很贵的行为"这段之后） |
| 画面作用 | 直观呈现"卖出盈利 vs 保留亏损"的行为对比；配合Odean数据强化说服力 |
| 画面描述 | 两组柱状图或条形图对比：横轴为"卖出盈利股票"vs"卖出亏损股票"；纵轴为百分比或相对强度；用暖色（橙/红）标注"卖出盈利"组，用冷色（蓝/灰）标注"卖出亏损"组；数据来源于 Odean 1987-1993 年美国折扣券商账户样本（14.8% vs 9.8%），图表旁注明"样本来源：1987-1993年美国折扣券商账户" |
| 图上文字 | 主标题：Loss of gains hurts more than gains from losses / 中文副标题：处置效应示意；两组柱状图下方分别标注"卖出盈利 14.8%"和"卖出亏损 9.8%" |
| 手机阅读要求 | 柱状图在手机窄屏上保持可读；标签字号不小于12pt；可考虑竖向柱状图以适应手机比例 |

### 图3：落袋为安二元判断框架 `fig03_decision_framework.png`

| 属性 | 内容 |
|---|---|
| 插入位置 | 第三节结尾（即"我现在是在执行计划，还是在缓解焦虑？"这个判断问题出现的位置） |
| 画面作用 | 将"动机区分"这个可带走判断工具视觉化；帮助读者在阅读后仍能快速回忆和使用 |
| 画面描述 | 一个简洁的二选一决策树或分叉路结构：顶端为"卖出决策"；分出两条路：左侧标注"有预设规则 → 计划性止盈 → 纪律"，右侧标注"无预设规则，凭感觉 → 焦虑性落袋 → 情绪交易"；两路径用颜色区分（绿/冷 vs 红/暖）；底部回收至同一判断问题："我现在是在执行计划，还是在缓解焦虑？" |
| 图上文字 | 决策树/分叉路各节点标签（文字需大、少）；底部判断问题可加粗突出 |
| 手机阅读要求 | 决策树在手机竖屏上从上到下阅读流畅；文字不小于14pt；两路径视觉差异在320px宽度下仍可辨识 |

## 三，插图边界检查

### 3.1 与发布检查边界的一致性

| 检查项 | 状态 | 说明 |
|---|---|---|
| 损失厌恶"两倍"数字 | ✓ 安全 | 图1天平隐喻不以精确数字呈现；底部文字"约两倍"保留"约"字，符合E01口径 |
| Odean数据样本限定 | ✓ 安全 | 图2明确注明"1987-1993年美国折扣券商账户"，不泛化为"所有投资者" |
| 规则护栏效果 | ✓ 安全 | 图3描述"规则"而非"变成机器"；符合C洞察边界 |
| 落袋为安二元区分 | ✓ 安全 | 图3明确体现"计划 vs 焦虑"二元判断框架，符合文章独家差异化承诺 |
| 禁止投资承诺 | ✓ 安全 | 三张图均无任何具体投资标的、买卖建议或收益预测 |

### 3.2 与系列风格的一致性

- 克制、清楚、信息图为主
- 冷灰/深蓝为主色调，暖色辅助情绪节点
- 无阴谋论视觉、装饰图
- 与系列期刊杂志体一致
