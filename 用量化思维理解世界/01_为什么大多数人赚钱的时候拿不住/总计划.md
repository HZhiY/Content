## 一、目标读者画像

来源于系列配置 `用量化思维理解世界/_meta/_config/读者画像配置.md`，本篇直接锁定的目标读者：

```text
20-30 岁，对赚钱、投资、基金、股票、AI、量化有兴趣，
但没有系统金融训练，也不想先学一堆公式和代码的普通中文读者。
```

本篇尤其适合以下读者：

- 买过基金或股票，经历过小赚就跑、大亏硬扛；
- 对“落袋为安”有强烈认同，但不知道它什么时候会伤害长期结果；
- 听过量化，但以为量化就是机器人炒股或复杂代码；
- 想获得简单、清楚、能立刻用的判断框架。

读者大概率已经知道：

- 赚钱应该拿住，亏钱应该控制；
- 但真实操作时，经常做不到；
- 市场有风险，投资要谨慎；
- 量化听起来和模型、程序、AI 有关。

读者大概率不知道：

- 损失厌恶为什么会影响止盈和止损；
- 处置效应为什么会让人卖出盈利、保留亏损；
- “落袋为安”什么时候是纪律，什么时候只是缓解焦虑；
- 量化思维为什么首先不是预测，而是规则化决策。

## 二、总目标

本篇作为「用量化思维理解世界」系列开篇，不追求技术完整性，而是要把一个普通投资者最熟悉的动作讲透：

```text
为什么亏钱能扛很久，赚钱却很快想跑？
```

具体目标：

1. 交付一组主机制：**损失厌恶 + 处置效应 → 小赚就跑、大亏硬扛 → 长期盈亏结构被扭曲**；
2. 让读者读完后能复述：“赚钱拿不住，不只是胆小，而是人脑对已到手收益可能消失特别敏感”；
3. 让读者第一次理解“量化思维不是神秘代码，而是用规则防止临场情绪变形”；
4. 给读者留下一个可立刻使用的问题：**我现在是在执行计划，还是只是在缓解焦虑？**

不在本篇目标之内：

- 不讲具体量化策略；
- 不讲股票、基金、币的买卖建议；
- 不讲复杂公式；
- 不讲有效市场、过拟合、回测等后续主题；
- 不把文章写成人生鸡汤。

---

## 三、核心问题

本篇核心问题：

```text
为什么大多数人赚钱的时候拿不住？
```

围绕这一核心问题，本篇需在正文中显式拆出三个子问题：

1. **为什么已到手收益让人更焦虑**：赚钱后，人为什么会担心利润回吐？
2. **为什么亏损反而让人拖延行动**：亏钱时，人为什么会期待“回本再说”？
3. **为什么量化要先写规则**：规则如何帮助人减少临场情绪对交易动作的接管？

---

## 四、暂定逻辑链

```text
[1] 反常识切入：
     很多人不是亏钱时最容易乱动，而是赚钱时最容易乱动。

[2] 普通认知 vs 本文机制：
     普通认知：赚钱拿不住是胆小、没格局、缺经验。
     本文机制：人对亏损和收益的感受不对称。

[3] 损失厌恶：
     已到手收益可能消失，会让人产生强烈不安。
     所以很多人赚钱后急着“确定下来”。

[4] 处置效应：
     人容易卖出盈利资产，继续持有亏损资产。
     这让人短期心理舒服，长期盈亏结构变差。

[5] “落袋为安”的边界：
     落袋为安不是永远错。
     如果它来自计划，是纪律；
     如果它只是为了缓解焦虑，就是情绪交易。

[6] 量化思维出场：
     量化不是预测明天涨跌，
     而是把规则提前说清楚，
     避免人在压力下临场改剧本。

[7] 结尾回收：
     量化思维的第一课，
     不是让你变成机器，
     而是在你最容易被情绪推着走的时候，
     让规则替你挡一下。
```

## 五、写作边界

本篇严格遵守以下边界：

1. **不荐股、不荐基、不荐币**：不出现具体标的与买卖建议。
2. **不承诺收益**：不写“学会就能赚钱”“长期必胜”。
3. **不羞辱普通读者**：不写“韭菜”“穷人思维”“活该亏钱”。
4. **不神秘化量化**：不写“机器碾压人类”“散户毫无机会”。
5. **不把落袋为安绝对错误化**：必须承认有计划的止盈可能是纪律。
6. **不把损失厌恶写成唯一原因**：还要承认现金流需求、风险承受力、标的质量、市场环境等约束。
7. **不写策略大全**：不展开双均线、网格、因子、回测代码等技术内容。
8. **不写人生鸡汤**：结尾只做轻微迁移，不拔高到“坚持就是胜利”。

## 六、证据缺口

当前为 0.1 项目初始化阶段，未进入资料研究。以下资料缺口在进入 `01-source-research` 后处理：

1. **损失厌恶基础来源**
   - 待补资料：前景理论中损失厌恶的基础解释；
   - 待补资料：适合普通读者引用的简化表述；
   - 待补资料：避免夸大“亏损痛苦是收益快乐两倍”等传播化说法的准确口径。

2. **处置效应研究来源**
   - 待补资料：处置效应的经典定义；
   - 待补资料：普通投资者卖出盈利资产、保留亏损资产的典型研究；
   - 待补资料：中文读者能理解的例子。

3. **行为金融与量化规则的连接**
   - 待补资料：规则化决策、预设交易计划、风险控制如何减少临场情绪影响；
   - 待补资料：不涉及荐股的通用解释材料。

4. **生活化类比素材**
   - 待补资料：考试、健身、减肥、游戏、排队等能解释“短期舒服 vs 长期结果”的例子；
   - 待补资料：能解释“计划动作”和“焦虑动作”区别的例子。

资料处理原则：

- 先找可靠基础来源，再找通俗解释；
- 不追求论文堆叠；
- 所有研究结论必须降级为“帮助理解机制”，不作为投资建议；
- 不引用未经核实的收益数据。

## 七、文风原则

本篇文风口径严格遵守系列配置，仅提炼要点：

1. **系列基调**：清楚、克制、有判断、不端着；像一个比读者早想明白几年的朋友。
2. **读者画像**：面向 20-30 岁普通读者，不预设金融训练，不用术语压人。
3. **文章结构**：问题 → 误区 → 机制 → 方法 → 一句话带走。
4. **平台节奏**：移动端优先，段落 1-3 行，最长不超过 5 行；前 300 字出现核心问题，前 500 字出现主承诺。
5. **术语解释**：损失厌恶、处置效应首现必须普通话解释，不写成学术课。
6. **结尾基调**：克制收束，不推荐产品，不拔高鸡汤。

本篇三红线自检：

```text
投资建议 = 0
收益承诺 = 0
羞辱普通读者 = 0
```

## 八、审稿机制

本篇按标准内容工作流推进：

1. **大纲审阅**：通过 03-outline-review 校验方向、标题-引言-正文-结尾承诺链、事实边界、文风合规性。
2. **草稿阶段**：完成 04-draft-write 草稿后，并行触发：
   - 05-free-review（零上下文自由审读）
   - 05-reader-review（按读者画像审读）
   - 05-density-edit（内容密度审读）
3. **主编阶段**：由 05-editor-review 整合上述三方意见，输出主编修改建议。
4. **修订阶段**：由 draft-revise 完成修订稿，必要时进入下一轮审读。
5. **发布检查**：06-release-check 在主编明确内容冻结后执行内容闭环检查。
6. **成稿终审**：06-format-final-check 在 HTML 构建前完成格式与卫生检查。
7. **HTML 阶段**：09-html-build 仅做排版与格式实现，不重写正文。

每轮审稿必须满足：

```text
单篇只打一颗主钉
不荐股、不承诺收益、不羞辱读者
结尾有可带走判断
```

## 十、最终交付标准

本篇完成（HTML 终稿阶段）的判定标准：

1. **结构**：标题、引言、正文 4-6 节、结尾，承诺链闭合；
2. **机制**：读者读完后能复述“损失厌恶 + 处置效应 → 赚钱拿不住、亏钱不愿走”；
3. **量化连接**：自然引出“量化思维是用规则减少临场情绪接管”；
4. **事实安全**：所有研究口径来自资料与证据台账，不夸大；
5. **合规安全**：不荐股、不荐基、不荐币、不承诺收益；
6. **读者友好**：术语首现有解释，段落短，语气不端着；
7. **可带走判断**：明确给出“我是在执行计划，还是缓解焦虑？”；
8. **审稿链路完整**：审稿记录、修订记录、发布检查、成稿终审完整；
9. **HTML 排版规范**：标题层级清楚，小标题像路标，样式不盖过正文机制。
