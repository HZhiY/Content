## 一、整体阅读感受

> 这一节先写整体体感，再进入分项评分。不要只罗列问题，要模拟目标读者读完后的真实第一反应。

### 1.1 一句话体感

```text
读起来像是在说"我自己"，而且最后给的那个判断问题真的能让我在下次想卖的时候卡住想一想。
```

### 1.2 整体判断

| 项目 | 判断 | 说明 |
|---|---|---|
| 第一反应 | 想继续读 | 开头"亏了20%能扛三个月，赚了5%就想跑"——这不是我本人吗？立刻想读下去 |
| 最大优点 | 开头场景共鸣极强 | 第一段就把读者的真实经历说出来，读者立刻觉得"这不是写我吗"，没有距离感 |
| 最大阻碍 | 处置效应的解释略偏学术 | "处置效应"这个专业词出现后，解释只有一句，读者可能还没反应过来这个词是什么意思，就进入了下一段 |
| 最容易掉线的位置 | 第二节中段（Odean数据之后到"落袋为安"判断之前） | 大段数据论证，读者刚建立起的代入感被打断；如果读者不是特别关注数字，会感觉"这些数字和我有什么关系"而走神 |
| 最有获得感的位置 | 第三节：同一动作，两个理由 | 读到"计划性止盈 vs 焦虑性落袋"的对比时，有强烈的"原来如此"感——这是读者第一次被告知"同一件事动机可以完全不同" |
| 读完后的残留印象 | 清楚 | 记得核心机制是损失厌恶，记得"落袋为安有时候是纪律有时候是逃跑"，记得走的时候要问自己"我是在执行计划还是在缓解焦虑" |

### 1.3 读者复述测试

读完后，目标读者能否用一句话复述这篇文章？

```text
能复述："赚钱的时候拿不住，不是因为我胆小，而是因为大脑对已到手收益消失的恐惧比对收益增加更敏感——而且'落袋为安'有时候是纪律，有时候只是因为焦虑在推动。"
```

### 1.4 整体建议

```text
1. 保留全文最强的两处读者体验支点：开头场景共鸣（读者自己的买卖经历）和动机区分（"计划vs焦虑"的判断工具）。修订时不要削弱这两处。
2. 处置效应第一次出现时的解释需要补强——读者需要听到"大白话说就是"而不是只有专业术语，否则读者会感觉"这是学术课"。
3. Odean数据段落需要有更直接的读者经验连接——不能让读者停下来想"这和我有什么关系"。
4. 全文节奏基本合格，但第二节中段是读者最容易走神的地方，需要增加承接到读者经验的过渡句。
5. 结尾"没有计划，那大概率就是焦虑在接管"——这句话力度很强，可以再往前放一放，让读者带着这句话进入结尾。
```

## 六、可保留项

| 内容 | 为什么对读者有效 | 修订时注意 |
|---|---|---|
| 引言开头场景（亏20%扛三个月，赚5%就想跑） | 完全对标目标读者真实经历，是全文最强的读者激活点 | 不得改成学术定义或数字开头；不得删减 |
| 损失厌恶的"约两倍左右"+注脚 | 数字准确又有注脚，读者感觉"这是有出处的"，而不是营销号夸张 | 保持注脚完整；不得改成"两倍"精确值 |
| "落袋为安有什么问题？问题不在于"卖"这个动作本身。问题在于：卖掉的理由是什么。" | 这是一个极好的读者思考引导——把读者从"落袋为安是对的还是错的"这个二元思维里抽出来 | 不得提前给出答案；不得删减 |
| 场景一（计划性止盈）：设定了目标收益率10%，到了目标果断卖出 | 具体、可对号入座；读者立刻能判断"我有没有这个计划" | 不得抽象化；不得删除对比 |
| 场景二（焦虑性落袋）：刚建仓一个月，账户突然涨了5%，没有预设目标，"万一又跌回去呢，先出来再说" | 真实感强；读者会"这就是我" | 不得删除或弱化；保持"刚建仓一个月"和"突然涨了5%"的具体感 |
| 结尾带走向量问题："下一次你想'落袋为安'的时候，先问自己这个问题" | 这是全文最强可带走工具；读者当下就能用；不需要额外知识 | 不得删除；不得升维成鸡汤 |
| 考试改答案类比（第28-32段） | 把考场和市场的决策情境打通，读者立刻明白"临场变形"是什么 | 不得删除；保持与市场卖出的连接句 |
| Quitter's Day类比（第118-120段） | 轻微自嘲式幽默，降低防御心；让读者觉得"我们都这样" | 不得删除；不得改成道德审判 |

## 八、给修订阶段的读者侧提醒

1. **处置效应首现时，读者需要听到"这就是在说你"**——加一句连接读者经验的句子（见R1），让读者知道这个专业词和自己的买卖行为有什么关系，不要让读者感觉术语课来了就走神。

2. **Odean数据段落要给读者一面镜子**——在数据之后立刻加一句"你买基金的时候是不是也这样"（见S1），把数据和读者的日常经验打通。

3. **全文最强的两处读者体验支点不要修坏**：一是引言开头的场景共鸣（读者自己的买卖经历），二是动机区分的"我现在是在执行计划还是在缓解焦虑？"这个判断工具。修订时确保这两处不受影响。

4. **结尾收束要干脆**——读者读完要有清晰的方向感，而不是被推着进入下一个话题。结尾带走向量问题（"先问自己这个问题"）力度已经很强，不需要再补充新内容。

5. **第二节中段（Odean数据）是读者最容易走神的地方**——这条提醒优先级高，因为这是全文信息密度最高的段落之一，读者刚建立好的代入感可能在这里被打断。
