## 一、评估依据摘要

### 2.1 当前文章结构前提

**核心问题**：为什么大多数人赚钱的时候拿不住？

**表面题材**：赚钱时拿不住、亏钱时死扛——几乎所有普通投资者都经历过的动作。

**真正要解释的问题**：为什么人在赚钱的时候比亏钱时更想做动作（卖出/落袋）？这个动作背后是什么心理机制在驱动？量化思维如何帮人绕开这个弱点？

**系列结构命题格式**（来自结构命题配置）：

```text
因为 [行为/概率机制]，人在 [场景] 中容易做出 [错误动作]；
市场会放大这个弱点；量化思维通过 [方法] 来绕开它。
```

**骨架命题须同时满足**：
- 可被 E01/E02/E03 这三个 P0 事实直接支撑
- 不被 B01-B07 禁止写法破坏
- 只打一颗主钉，不同时论证多个独立主命题
- 机制层解释"为什么"，不止步于描述"是什么"

## 三、逐条评估

### 候选命题 A：不对称痛感

#### 1. 候选原文

> 人在赚钱时感受到的焦虑不是胆小或贪心，而是损失厌恶在驱动——已到手的收益还没捂热，人就开始害怕它消失。

#### 2. 结构判断

| 项目 | 判断 |
|---|---|
| 表面题材 | 赚钱时拿不住、想卖出 |
| 真正命题 | 人对已到手收益消失的恐惧 > 对等额潜在收益增加的期待，这个不对称感驱动了卖出冲动 |
| 一句话压缩 | 这篇文章不是在讲"赚钱拿不住是因为胆小"，而是在解释大脑对"已到手收益可能回吐"格外敏感的系统性机制 |
| 是否为机制句 | 是 |
| 是否存在命题过大 | 否 |
| 是否符合骨架命题格式 | 部分符合——"因为损失厌恶，人在已到手收益面前更焦虑，所以更想做动作"；但单独使用时，缺少"市场放大"和"量化思维处理"两段 |

#### 3. 目标客户匹配审查

| 目标客户 | 兴趣是否匹配 | 前置知识是否足够 | 新解释/新谈资是否成立 | 是否值得继续评估 |

| 刚入场基民/股民 | 高 | 部分（需要知道"损失厌恶"这个名称） | 是——"原来是大脑机制，不是性格缺陷" | 是 |
| 对量化感兴趣的非专业读者 | 中高 | 部分 | 是——量化不是预测，而是绕开大脑弱点的规则系统 | 是 |
| 有一定投资经验但反复犯错的读者 | 高 | 是 | 是——"知道但做不到"的机制解释 | 是 |
| 对行为经济学感兴趣的非学术读者 | 中高 | 部分 | 是——损失厌恶是行为经济学核心概念 | 是 |

| 写烂风险 | 中——损失厌恶是常见话题，但多数通俗内容只写"人怕亏损"，本洞察更精确地聚焦"已到手收益消失" |

| 结论 | 成立 |

#### 5. Claim / Grounds / Warrant

| 项目 | 内容 |
|---|---|
| Claim | 人在赚钱时更想做动作，不是因为胆小或贪心，而是因为损失厌恶——已到手的收益还没捂热，人就开始害怕它消失 |
| Grounds | E01（Tversky & Kahneman 1992，损失厌恶系数"约两倍"）；E06（Gal & Rucker 2018，"两倍非普适常数"的降级支撑） |
| Warrant | 人对损失的痛苦感 > 对等额收益的快乐感，这个不对称意味着同等金额下，收益落袋带来的"安心感"弱于同等亏损带来的"痛苦感"→因此当有浮盈时，大脑对浮盈回吐的恐惧 > 对继续持有的期待→人倾向于卖出盈利资产以"锁定"收益 |
| 缺口 | 损失厌恶解释的是"为什么焦虑"，但不直接解释"为什么是卖出这个动作"——这个缺口需要处置效应（洞察B）来填补 |

#### 6. 机制链

```text
起点问题：为什么赚钱时人更想做动作（卖出），而不是继续持有？
旧办法（性格归因）：因为胆小、没格局、没经验 → 下次遇到同样场景还是会犯
旧办法解决不了的：性格归因无法自我纠正，读者知道"要坚定"但下次还是做不到
新办法（机制层）：损失厌恶——大脑对"已到手收益消失"的恐惧 > 对"等额潜在收益增加"的期待
新办法带来的结果：浮盈出现时，大脑开始焦虑"可能回吐"→人倾向卖出以"锁定"收益
规律揭示：这不是性格问题，是大脑处理收益和损失时的不对称机制；损失厌恶+处置效应共同形成"小赚就跑、大亏死扛"的完整行为链
```

### 候选命题 B：售赢持亏的自我实现伤害

#### 1. 候选原文

> "落袋为安"之所以长期伤害结果，不是因为止盈本身错了，而是因为人卖出盈利资产的动机往往是缓解焦虑，而不是执行计划。

#### 2. 结构判断

| 项目 | 判断 |
|---|---|
| 表面题材 | 投资者卖出盈利资产、持有亏损资产的行为倾向 |
| 真正命题 | 处置效应让人做出"卖出盈利、持有亏损"的动作；这个动作的动机（焦虑 vs 计划）才是判断标准 |
| 一句话压缩 | 这篇文章不是在讲"人应该止损/止盈"，而是在解释"同一个卖出动作可能来自两个完全不同的决策系统"，以及为什么区分它们比判断对错更难 |
| 是否为机制句 | 部分是——处置效应描述的是"什么"，不直接解释"为什么是大脑机制"；动机区分是方法论层判断，不是机制层解释 |
| 是否存在命题过大 | 否 |

- **命题过大风险**：中高。D本身是元框架，可以包含A+B+C；但如果把D作为全文主命题，而A+B+C只是D的"例子"，文章会变成"决策系统科普"而不是"赚钱拿不住的机制解释"
- **承诺兑现风险**：中高。D和标题承诺（"为什么赚钱时拿不住"）之间有逻辑距离；D回答的是"更深层的问题"，需要A+B+C才能让标题承诺被完整兑现
- **文风违禁风险**：低

#### 10. 结论

- 是否适合作为全文结构命题：**可作为主线候选（28分），但建议作为结构性框架引入，而非全文唯一主命题**
- 更适合作为：**全文元框架（开头1-2段引入识别视角） + A+B+C作为机制展开 + D的"判断问题"作为结尾可带走工具**
- 是否因目标客户不匹配而放弃：否
- 是否因结构深挖空间不足而放弃：**是——单独使用时机制层解释不足，建议将D作为框架引入，不作为唯一主命题**
- 需要修改的地方：
  1. 正文在开头1-2段用D建立"识别框架"，让读者知道"我们今天要学的不是判断力，是识别力"
  2. A+B+C在机制层展开，让D的框架落地
  3. 结尾用D的"判断问题"（"我现在是在执行计划还是在缓解焦虑？"）作为读者可带走的方法

## 五、全文结构命题建议

### 5.1 推荐全文结构命题

**A+B 组合作为全文结构命题**（33分）：

```text
因为损失厌恶（A），人在有浮盈时开始焦虑；
因为处置效应（B），这个焦虑转化为卖出盈利资产的冲动；
"落袋为安"是不是纪律，关键看动机是计划还是焦虑；
量化思维通过预承诺规则（C），在机制上减少情绪对决策的接管。
```

**或者压缩为单句（适合标题锚定）**：

```text
人在赚钱时拿不住，不是因为胆小——而是因为损失厌恶驱动的焦虑，让人分不清自己在执行计划还是在缓解焦虑；量化思维通过规则化决策绕开这个机制。
```

**推荐理由**：

1. **机制完整**：A（为什么焦虑）→B（做了什么动作）→C（如何绕开）形成完整的"机制-行为-方法"链条，回答了文章核心问题的所有三个子问题
2. **事实安全**：E01（损失厌恶）+ E02/E03（处置效应）+ E04（规则护栏，降级为定性）全部通过事实核查，无一票否决项
3. **目标客户全覆盖**：四个目标客户群在A+B+C链条中均能找到强共鸣点；尤其是"动机区分"（"我现在是在执行计划还是在缓解焦虑？"）是文章最有力的可带走判断工具
4. **差异化**：不是止步于"要止损/要有纪律"的常见废话，而是把"为什么知道但做不到"的机制完整拆解，并给出可操作的判断方法
5. **系列母题对接**：结尾自然过渡到"量化思维是用规则对抗自身弱点"，不拔高，不鸡汤，克制地连接到系列暗线

### 5.2 不推荐其他候选作为全文结构命题的原因

- **洞察C单独作主命题（26分）**：机制层（"为什么意志力靠不住"）解释不足，缺少A铺垫的C会让读者停留在"规则好"但不知道为什么好
- **洞察D单独作主命题（28分）**：D是强有力的元框架，但单独撑全文时缺少A+B+C的具体机制和证据，读者会觉得"有道理但不知道怎么办"；建议将D降格为结构性框架（开头引入+结尾判断工具）而非全文主命题
- **洞察A或B单独作主命题（各30分）**：单独使用时不完整——A缺"卖出动作"的机制桥，B缺"为什么"的机制层；A+B组合（33分）全面优于任一单独使用

## 七、进入大纲前的结构约束

1. **A+B+C 链条顺序约束**：大纲必须按 A（损失厌恶）→ B（处置效应）→ C（规则护栏）的顺序展开，不得打乱——因为 A 解释"为什么焦虑"，B 解释"焦虑转化为什么动作"，C 解释"规则如何绕开"；跳跃会导致机制链断裂

2. **"落袋为安"边界判断约束**：大纲必须用至少一节的篇幅，明确区分"有计划的止盈（纪律）"和"因焦虑而卖出（情绪）"；这是文章方法论交付的核心承诺，不得含糊带过

3. **动机区分的具体化约束**：洞察B的"动机区分"承诺必须在正文中有具体的"判断问题"（"我现在是在执行计划还是在缓解焦虑？"），正文不得只给出"有道理"的原则而不给"怎么用"的工具

4. **生活类比约束**：大纲在引入损失厌恶（A）和处置效应（B）时，必须同时安排生活类比（考试改答案、健身卡、Quitter's Day等），让抽象机制有可感知的具体场景

5. **量化思维的边界约束**：C（规则护栏）不得写成"变成机器"；结尾升维只允许升一层：从"规则帮助本文读者"→"量化思维是用规则对抗自身弱点"；不得引入下一篇文章的具体主题

6. **系列开篇独立性约束**：本文是系列第一篇，必须独立成立；不得依赖读者对后续篇目的认知；不得为后续篇目埋过多伏笔

## 附：候选洞察组合方案的结构评估

### 方案一：三层递进式（A 主 + B+C 副）

- **结构评估**：推荐。理由：
  - A（损失厌恶）直接回答标题核心问题，建立机制层
  - B（处置效应）连接"焦虑"和"卖出动作"，形成行为层
  - C（规则护栏）作为方法论收尾
  - A+B+C形成完整的"为什么→是什么→怎么办"链条
  - 满足骨架命题格式："因为[机制]，人在[场景]容易做出[动作]；市场放大弱点；量化思维通过[方法]绕开"

### 方案二：动机识别式（D 主 + A+B 副）

- **结构评估**：不推荐作为第一选择。理由：
  - D作为主命题时，"计划系统vs情绪系统"框架强有力，但缺少A+B+C的机制展开，读者会感到"有道理但不知道怎么办"
  - D的价值更适合作为**结构性框架引入**（开头1-2段）+ **结尾判断工具**，而不是全文主命题
  - 如果在方案一基础上加入D的框架（开头引入+结尾判断），结构会更完整

### 方案三：反差强化式（B 主 + A+C 副）

- **结构评估**：可备选，但不如方案一。理由：
  - B的"落袋为安"边界判断是文章最重要的可交付工具（"我现在是在执行计划还是在缓解焦虑？"）
  - 但B单独撑全文时缺少"为什么"的机制层；需要A铺垫损失厌恶后，B才有说服力
  - 如果以"落袋为安"的边界判断作为文章核心承诺，结构上是可行的，但建议B+A+C的顺序

**最终推荐**：方案一为主框架（A+B+C三层递进），在开头用D的元框架建立"识别视角"，在结尾用D的"判断问题"作为读者可带走工具。
