## 二、本文定调用语

### 2.1 允许用语

本文允许使用的核心表达：

1. **"落袋为安"**：作为读者熟悉的观念，是本文最强共鸣入口，可直接使用，不批评整个概念
2. **"约两倍左右"**：描述损失厌恶时，承认这是近似值而非精确常数
3. **"在这一样本中"**：引出 Odean 数据时的标准限定语
4. **"大幅减少"**：描述规则护栏效果时使用的定性表达，不加比例数字
5. **"有时候是纪律，有时候是逃跑"**：描述"落袋为安"动机区分的核心判断句
6. **"我现在是在执行计划，还是在缓解焦虑？"**：本文最强可带走判断工具，可多次出现
7. **"临场变形"**：描述人在市场压力下偏离原计划的动作
8. **"售盈持亏"**：作为"处置效应"的简洁说法，可替代学术名词
9. **"大脑对已到手收益消失的恐惧，比对同等收益增加的期待更重"**：损失厌恶的通俗解释
10. **"规则替我挡一下"**：描述量化思维价值的核心意象

### 2.2 禁止用语

本文绝对禁止的表达：

1. **"人性弱点"**：系列禁用；损失厌恶和处置效应是系统性心理现象，不是道德缺陷
2. **"意志力不够强"**：方向把控已明确禁止；不能写成读者意志力问题
3. **"散户太笨/太贪"**：嘲笑读者；本文必须站在读者一边
4. **"两倍"（不加"约"和"左右"）**：E01 事实红线；必须写"约两倍左右"并加注特定实验条件
5. **"λ=2.25"或"损失厌恶系数为2.25"**：精确常数写法禁止；E01 事实红线
6. **"所有散户都这样"**：过度泛化；E02 事实红线；用"在这一样本中"或"研究显示"
7. **"被卖出的盈利股未来一年稳赚3.4%"**：E02 事实红线；必须写"平均来看"避免写成稳赚预测
8. **"自动化执行可以减少60-80%的情绪性错误"**：E04 事实红线；禁止引用精确比例
9. **"变成机器"**：C洞察（规则护栏）禁止写法；规则不是让人失去情绪
10. **"落袋为安永远对/永远错"**：方向把控明确约束；必须区分动机
11. **"机器碾压人类"/"散户毫无机会"**：神秘化量化；系列文风禁用清单明确禁止
12. **"长期必胜"/"学会就能赚钱"/"稳赚不赔"**：投资承诺；零容忍
13. **"韭菜"/"穷人思维"/"活该亏钱"**：嘲笑读者；零容忍
14. **"颠覆认知"**：系列禁用词；营销号腔
15. **"底层逻辑"**：系列禁用词；空泛套话

### 2.3 降级表达

本文需要降级使用的表达及降级后版本：

| 原表达 | 降级后版本 | 降级原因 |
|---|---|---|
| "亏损的痛苦是收益快乐的两倍"（绝对陈述） | "亏损带来的痛苦感大约是同等收益快乐感的两倍左右" | E01事实红线；"两倍"是近似值，需加"约"字和条件注脚 |
| "λ=2.25" | "约两倍左右"+注"特定实验条件下的中位数估计" | E01事实红线；精确系数非普适常数 |
| "自动化执行减少60-80%情绪错误" | "可以大幅减少情绪性交易的干扰" | E04事实红线；60-80%来自通俗综述，不是严格金融实证 |
| "所有散户都这样" | "在这一样本中"/"研究显示" | E02事实红线；1987-1993年美国折扣券商账户数据 |
| "被卖出盈利股稳赚3.4%" | "平均来看，被卖出的盈利股未来一年收益高于保留的亏损股约3.4%" | E02事实红线；避免写成稳赚预测 |
| "人性弱点" | "心理机制"或"大脑的本能反应" | 系列文风禁用清单 |
| "意志力不够" | "临场时情绪容易变形" | 方向把控明确禁止 |
| "散户愚蠢/太贪" | （不写这类判断） | 系列文风禁用清单 |

## 三、本文语调要求

### 3.1 语速与节奏

- **总体语速**：中等偏慢，给读者消化机制的空间
- **单句长度**：移动端优先，单句不超过20-25字；多重从句禁用
- **段落节奏**：每段1-3行，最长不超过5行；连续抽象解释不超过3段
- **每节字数**：400-900字；全文2500-4500字
- **小标题密度**：每600-900字出现一个路标小标题
- **判断节奏**：判断应当**后置**——先让事实和机制建立问题感，再把结论慢慢托出来

### 3.2 人称与视角

- **主语**：用"人"和"人脑"，不用"你"；本文是机制解释，不是面向个人的操作指南
- **读者指代**：用"很多人"、"投资者"、"普通读者"，避免直接称呼"你"造成说教感
- **但**：在给出可带走判断时，可以用"下次你可以问自己"——方法论部分允许第二人称
- **例**：不用"你为什么赚钱拿不住"，而用"为什么赚钱的时候，人会特别想动"
- **禁止**：不用"你应该"、"你必须"、"你只要"等压迫性表达

### 3.3 情感温度

- **比系列基准**：持平或略低半度
- **原因**：本文核心洞察（"落袋为安有时候是纪律，有时候是逃跑"）本身已有张力，不需要再加情绪；情绪主要用来建立共鸣，不用来制造紧迫感
- **禁止**：煽情、制造焦虑、控诉市场；本文情绪应止于"原来是这样"的理性共鸣
- **可用温度**：轻微的自嘲式幽默（如引用Quitter's Day），适度的"我们都这样"降低防御心

## 四、术语翻译对照

本文涉及的术语及普通话解释版本：

| 术语 | 普通话解释版本 | 出现时机 |
|---|---|---|
| 损失厌恶 | 人对亏损比收益更敏感——同样一块钱，亏掉比赚到更痛 | 机制层首次出现 |
| 处置效应 | 人倾向于卖出正在赚钱的标的，保留正在亏钱的标的 | 行为层首次出现 |
| 售盈持亏 | 赚钱时想跑，亏钱时不想动——这是处置效应的日常说法 | 贯穿全文，可替代"处置效应" |
| 落袋为安 | 把收益先"确定下来"的动作——本文要区分它什么时候是计划，什么时候是焦虑 | 入口洞察/标题承诺 |
| 动机区分 | 同一个卖出动作，可能是执行计划，也可能是缓解焦虑——外表相同，动机不同 | 核心判断工具，D洞察 |
| 规则护栏 | 提前把规则写好，在情绪最强的时候，让规则替你做判断 | 方法论层，C洞察 |
| 预承诺 | 在情绪还没上来之前，先把规则定下来 | 方法论辅助解释 |
| 不对称痛感 | 人对损失的痛感大于对收益的快感——这是损失厌恶的核心 | A洞察机制解释 |

## 五、案例使用优先级

### 5.1 优先案例

本文优先使用的案例类型：

1. **读者自己的投资经历**：亏钱能扛、赚钱想跑——这是本文最强共鸣素材，不需外求
2. **考试改答案**：考前决定不改答案，临场看到别人翻卷子又忍不住改——D洞察的生活类比
3. **健身卡/Quitter's Day**：每年1月中旬大多数人放弃新年目标——规则执行的生活类比
4. **"落袋为安"的两种场景对比**：有计划的止盈（比如达到目标收益率）vs 因焦虑而卖出（刚赚钱就想跑）
5. ** Odean 数据的生活对应**：上万账户的卖出行为，和普通人买基金时的动作，可以形成平行叙述

### 5.2 可用但需谨慎的案例

- **12月税收异常**：仅作补充层次，说明税收动机是干扰项而非主因；不得作为核心支点
- **其他生活类比**（如排队等待、选择餐厅等）：可辅助解释，但不得喧宾夺主

### 5.3 本文禁用案例

- 具体量化策略案例（双均线、网格、CTA等）：本文是机制篇，不是策略篇
- 荐股荐基荐币类场景
- 任何具体投资标的的价格走势或收益展示
- 过度简化散户行为的讽刺类比（如"韭菜"等）

## 六、正文段落节奏建议

### 6.1 引言（150-350字）

**必须完成三件事**：
1. 写出读者熟悉的动作（赚钱就想跑），让读者觉得"说的是我"
2. 点出这个动作不是"胆小"，而是"大脑机制"
3. 承诺本文要讲清楚：为什么、以及怎么办

**禁止**：
- 以"损失厌恶"或"两倍"数字作为开头第一句
- 开头先讲学术定义或研究来源
- 写超过500字才出现核心问题

**推荐节奏**：
```
[第1段] 动作共鸣：很多人赚钱三天就想跑，亏钱能扛三个月
[第2段] 打破普通解释：这不是胆小，是大脑机制
[第3段] 本文承诺：要把这个机制讲清楚，还要给一个判断工具
```

### 6.2 第一节（损失厌恶/A洞察）

- 任务：解释"为什么赚钱后，人比亏钱时更想立刻行动"
- 字数：400-700字
- 节奏：先用日常感受建立共鸣，再用机制解释，最后给数字
- 关键句出现时机：损失厌恶的通俗解释应在第一节后半段出现，不能太早（会变成学术课）
- 必须有生活类比：考试、健身等场景均可

### 6.3 第二节（处置效应/B展开）

- 任务：解释"焦虑转化成了什么动作"
- 字数：400-700字
- 节奏：先承接第一节的焦虑，再引入卖出盈利资产的动作
- 关键数据出现时机：Odean数据在本节出现，必须加"在这一样本中"
- 12月税收异常：可在本节作为补充层次，辅助说明税收不是主因

### 6.4 第三节（动机区分/B+D洞察）

- 任务：给出本文最强可交付工具——"我现在是在执行计划，还是在缓解焦虑？"
- 字数：400-600字
- 节奏：**这是全文的判断转折点**，必须让读者感到"第一次有人这样说清楚"
- 禁止：
  - 单独给原则不给工具（必须有判断问题）
  - 判断过早前置（在机制讲清楚之前就给结论）

### 6.5 第四节（规则护栏/C洞察）

- 任务：说明规则如何绕开情绪
- 字数：300-500字
- 节奏：轻点，不过度展开——C洞察是收尾工具，不是全文主体
- 禁止：
  - 写成"变成机器"或"完全没有情绪"
  - 加任何精确效果比例
  - 作为全文主命题撑全文

### 6.6 结尾（150-350字）

- 任务：回收机制 + 带走向量 + 点出量化思维价值
- 升维边界：从"规则帮助本文读者"→"量化思维是用规则对抗自身弱点"（升一层）
- 禁止：
  - 升维到人生哲学、"坚持就是胜利"等鸡汤
  - 引入下一篇文章的具体主题
  - 推荐具体投资标的
  - 写成"关注我，带你学量化"

## 七、特殊文风决策

### 7.1 入口洞察（B洞察）的表达策略

方向把控指定B洞察（"落袋为安有时候是纪律，有时候是逃跑"）为全文主洞察，使用位置：标题+开头第一节。

**本文特有处理方式**：
- 开篇直接用"落袋为安"激活读者已有认知
- 但第一段结尾或第二段，必须出现转折暗示："但有时候，这个动作背后的理由不太一样"
- B洞察不能只出现一次——它应在第三节（动机区分）被正式展开，在结尾被再次回收
- 全文不得把"落袋为安"写成绝对正确或绝对错误——二元区分是独家差异化

### 7.2 判断节奏决策

**判断应当后置**：

- 第一层（第一节）：先让读者感受"原来是这样"
- 第二层（第二节）：再引入行为数据，让读者"原来大家都这样"
- 第三层（第三节）：**判断转折**——"同一个动作，可能有两个完全不同的理由"
- 第四层（第四节）：方法论收尾——"怎么办"

禁止在开篇第一段就给结论，或在机制还没讲清楚时就写判断句。

### 7.3 数字使用策略

- **E01（损失厌恶"约两倍"）**：首次出现必须加注"这是特定实验条件下的中位数估计"，不得写成精确常数感
- **E02（Odean数据）**：首次出现必须加"在这一样本中"限定，不得过度泛化
- **E02（3.4%数字）**：如引用，必须写"平均来看"，不得写成每年稳赚比例
- **E04（规则效果）**：不加任何比例，写成"大幅减少"即可

### 7.4 系列开篇约束的文风影响

本文是系列第一篇，必须独立成立：
- 不得预设读者知道后续篇目
- 不得为后续篇目埋过多伏笔
- 量化思维的介绍必须从"规则"讲起，不能假设读者已经了解量化

## 九、发布平台适配

### 9.1 微信公众号+今日头条

- 前3段必须完成：强共鸣+核心问题出现+本文承诺
- 信息流场景：标题决定打开率，正文前300字决定是否继续阅读
- 每600-900字必须有一个路标小标题

### 9.2 移动端阅读适配

- 句子长度：单句不超过20-25字
- 段落节奏：每段1-3行，最长不超过5行
- 术语处理：损失厌恶、处置效应首次出现必须立刻翻译成普通话
- 停留点设计：每节至少一个共鸣停留点（"这说的是我"）+ 一个机制停留点（"原来是这样"）+ 一个方法停留点（"下次我可以这样判断"）

### 9.3 手机阅读禁止

- 连续超过5行的抽象段落
- 多重从句（读者会失去主语）
- 没有配生活类比的连续机制解释
- 结论先于证据出现（判断过早）
