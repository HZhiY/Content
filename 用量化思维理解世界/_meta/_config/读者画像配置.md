# 读者画像配置

> 适用系列：用量化思维理解世界  
> 用途：供传播、方向、文风、大纲、读者审读、标题等 agent 判断目标读者、理解门槛、兴趣入口和阅读风险。  
> 核心原则：读者想获得的不是量化技术细节，而是一套能帮自己少做错决定的方法。

---

## 一、核心读者

本系列核心读者是：

```text
20-30 岁，对赚钱、投资、基金、股票、AI、量化有兴趣，
但没有系统金融训练，也不想先学一堆公式和代码的普通中文读者。
```

他们可能包括：

- 刚开始买基金、股票或指数产品的年轻人；
- 对量化、AI、自动交易感兴趣，但只停留在听说层面的读者；
- 经历过追高、割肉、拿不住、亏钱后加仓的人；
- 不一定投资，但对“如何做更理性的选择”感兴趣的人；
- 教育程度一般，不抗拒学习，但反感专业话术压迫的人；
- 喜欢读“讲清楚一个问题”的公众号 / 头条用户。

---

## 二、读者已有认知

### 2.1 可能知道

读者大概率知道：

- 股票、基金、定投、指数基金这些词；
- 买低卖高听起来很简单，做起来很难；
- AI、量化、机器人交易听起来很厉害；
- 基金经理不一定都赚钱；
- 追热点容易亏，但下次还是可能追；
- 市场有风险，但不清楚风险到底该怎么管理。

### 2.2 可能不知道

读者不一定知道：

- 为什么人赚钱时拿不住，亏钱时反而拿得住；
- 为什么“大家都在买”不代表风险更小；
- 胜率和盈亏比为什么必须一起看；
- 回测只能排除部分错误，不能保证未来赚钱；
- 过拟合为什么是量化世界最经典的陷阱；
- 为什么基金经理长期跑赢指数很难；
- 为什么一个方法知道的人越多，可能越不赚钱；
- 为什么定投不是“无脑坚持”这么简单。

## 三、读者阅读动机

| 动机 | 内容应如何回应 |
|---|---|
| 想知道自己为什么总亏 | 用行为金融解释常见错误，不羞辱读者 |
| 想理解量化到底是什么 | 把量化翻译成规则、概率、纪律和验证 |
| 想少踩投资坑 | 每篇给一个可执行的判断句或检查问题 |
| 想看懂基金经理和指数基金 | 用成本、竞争、规模解释长期结果 |
| 想获得方法论 | 把市场机制迁移到学习、职业和人生选择 |
| 不想看数学课 | 不堆公式，用生活例子解释术语 |

## 四、读者理解门槛

### 4.1 必须降低的门槛

以下内容必须翻译成普通读者能懂的话：

- 损失厌恶；
- 处置效应；
- 从众效应；
- FOMO；
- 胜率；
- 盈亏比；
- 期望值；
- 回测；
- 过拟合；
- 策略拥挤；
- 最大回撤；
- 夏普比率；
- 贝叶斯更新；
- 大数定律。

### 4.2 解释方式

推荐解释方式：

```text
先讲一个读者熟悉的动作，
再指出这个动作背后的心理机制，
再解释市场为什么会放大它，
最后给出量化思维如何处理。
```

不推荐解释方式：

```text
先抛定义，再列公式，再引用论文，最后告诉读者应该理性。
```

### 4.3 术语出现规则

1. 术语首次出现，必须立刻用普通话解释；
2. 解释必须短，不超过 5 行；
3. 术语不是为了显得专业，只能服务机制；
4. 如果一个术语不影响读者理解，应删除或替换成日常说法。

## 五、读者情绪状态

本系列读者常见状态：

- 想赚钱，但不想被说贪；
- 承认自己不懂，但不想被教育；
- 亏过钱，所以对“方法论”既期待又怀疑；
- 容易被“别人已经赚了”刺激；
- 想要确定答案，但市场总给不确定结果；
- 喜欢简单结论，但真正需要的是可重复决策框架。

写作时要站在读者这一边：

```text
不是“你怎么又犯错”，
而是“这个错太容易犯，所以我们需要一套方法帮自己绕开它”。
```

---

## 六、读者不喜欢什么

读者大概率不喜欢：

- 一上来堆模型；
- 大段英文缩写；
- 学术论文口吻；
- 高高在上的训话；
- “年轻人你不懂”的长辈腔；
- 玄学式投资格言；
- 只有观点，没有例子；
- 只有鸡汤，没有机制；
- 只有风险提示，没有可带走判断。

---

## 七、理想读后反应

每篇文章读完后，读者最好产生以下反应之一：

- “原来我之前是这样被自己骗的。”
- “这个概念我终于听懂了。”
- “下次我不能只看赚多少，还要看错了会怎样。”
- “量化不是机器人炒股，原来是规则、验证和纪律。”
- “这篇不只适合投资，也适合我做别的选择。”

最理想的长期反应：

```text
读者不一定变成量化交易者，
但会开始用概率、样本、风险和纪律看待自己的决定。
```
