# 标题方法论配置

> 适用系列：用量化思维理解世界  
> 适用平台：今日头条 / 微信公众号类中文长文平台  
> 适用任务：供 `07-title-write.md` 在标题阶段读取，用于生成、筛选、评分和解释标题候选。  
> 核心原则：标题不是把文章说得更大，而是把文章已经证明的承诺说得更有入口。

---

## 一、账号标题定位

本系列不是投资建议栏目，也不是量化策略教程，而是**普通人决策方法论型财经专栏**。

读者点击标题，不只是为了学技术，而是为了理解：

```text
我为什么会这样？
我之前错在哪里？
下次我怎么判断？
```

因此，本系列标题最适合采用：

```text
读者自己的错误动作 / 生活场景 + 行为机制词 + 可兑现的解释承诺
```

标题必须同时满足：

1. 一眼知道文章讲什么；
2. 看得出文章会解释什么机制；
3. 有足够具体的读者场景或动作；
4. 有可被正文兑现的反常识、冲突或解释承诺；
5. 不靠空洞悬念、夸张情绪或标题党骗点击。

## 二、标题总原则

### 2.1 首要原则

| 原则 | 要求 |
|---|---|
| 主题清楚 | 读者 3 秒内知道文章对象和大概问题 |
| 文题一致 | 标题承诺必须能被正文证明，不得超出正文 |
| 解释承诺 | 标题要显露"读完能懂什么机制" |
| 具体锚点 | 优先使用读者动作、场景、日常投资行为 |
| 亮点前置 | 重要关键词尽量前置，减少首屏识别成本 |
| 合规克制 | 避免夸张、误导、荐股、承诺收益 |
| 系列一致 | 保持"普通人决策方法论 + 量化思维"的系列气质 |

### 2.2 一句话判断

```text
好标题像一扇门：读者一眼知道门后是什么，而且愿意推门进去。
```

### 2.3 禁止原则

标题不得：

1. 把局部经验写成全局规律；
2. 把相关关系写成因果关系；
3. 把多因素解释写成唯一原因；
4. 把审慎判断写成绝对判断；
5. 用抽象概念替代具体入口；
6. 用成语、隐喻、金句遮蔽主题关键词；
7. 用"震惊、炸裂、彻底、终于、看完沉默"等营销号表达；
8. 为了悬念故意隐藏关键信息；
9. 模仿官方通知、警告、紧急提醒口吻；
10. 承诺正文没有证明的结论；
11. 荐股、荐基、荐币；
12. 承诺收益。

## 三、本系列有效标题逻辑

本系列高表现标题通常同时满足三点：

1. **读者场景前置**：亏钱、追高、拿不住、定投、基金经理等具体场景清楚。
2. **反常识或冲突明确**：例如"不是胆小""不只是运气""为什么反而亏更多"。
3. **解释承诺清楚**：例如"为什么""原来""真正的区别"。

### 3.1 高表现信号

| 信号 | 标题表现 | 方法论含义 | 实操提醒 |
|---|---|---|---|
| 读者场景前置 | "为什么大多数人赚钱的时候拿不住" | 抽象议题要落到可识别动作 | 优先前置亏钱、追高、定投等场景 |
| 反常识有效 | "不是胆小，是大脑在保护已到手的钱" | 机制反转制造张力 | 反常识必须被正文兑现 |
| 解释承诺强 | "为什么""原来""真正的区别" | 核心卖点是解释能力 | 标题要说明读完能懂什么 |
| 生活化入口 | "定投""基金经理""指数" | 降低理解门槛 | 金融术语必须足够日常 |
| 代词损失点击 | "为什么你总是这样" | 代词会打断识别 | 信息流标题慎用"你、它、这件事" |

### 3.2 已验证的数据倾向

| 组合 | 表现 | 标题启发 |
|---|---|---|
| 共鸣型 × 机制型 | 表现最好 | 标题优先卖"共鸣"和"机制解释" |
| 反常识纠偏型 | 稳定中高 | 适合纠正常见误解 |
| 机制型 × 分析型 | 适合量化本体篇 | 标题卖"看懂系统" |
| 迁移型 | 适合人生篇 | 但要避免鸡汤化 |
| 纯叙事型 | 整体偏弱 | 标题不要只卖故事，要补机制承诺 |

本系列优先采用：

```text
共鸣型 × 机制型 × 方法型
```

也就是说，标题应尽量让读者感到：

```text
这篇文章说的是我，而且会告诉我为什么，以及下次怎么办。
```

## 四、标题决策流程

每次生成标题前，必须按以下步骤处理。

### 4.1 压缩主旨

先回答：

```text
如果只允许用一句话概括全文，它到底在说什么？
```

产出：一句 thesis。

要求：

- 不超过 60 字；
- 包含读者场景；
- 包含机制或反转；
- 不使用空泛抽象词。

### 4.2 抽取冲突

找出文章最强的矛盾：

```text
表面理解和实际机制之间有什么反差？
读者以为的原因和真正的原因差在哪？
```

常见冲突对：

- 胆小 / 损失厌恶；
- 稳健 / 焦虑驱动；
- 坚持 / 无效坚持；
- 聪明 / 过拟合；
- 简单 / 最难执行；
- 运气 / 概率优势；
- 专业 / 不一定有效。

### 4.3 找读者入口

判断普通读者最容易从哪里进入：

| 入口类型 | 适合情况 | 示例方向 |
|---|---|---|
| 错误动作入口 | 有明确亏钱/追高/拿不住场景 | 赚钱的时候拿不住…… |
| 日常场景入口 | 有定投、买基金、看收益等日常词 | 定投为什么越投越痛苦…… |
| 反常识入口 | 正文能充分证明一个反直觉判断 | 不是胆小，是…… |
| 机制入口 | 文章卖点是系统运转 | 量化到底在赚谁的钱…… |
| 人物入口 | 有基金经理、大神等 | 基金经理为什么跑不赢…… |
| 结果入口 | 有明确的"为什么总是……" | 为什么你总能买在高点…… |

### 4.4 选择主打面

每篇文章只选一个主打面，避免标题过载。

| 主打面 | 适合文章 | 标题倾向 |
|---|---|---|
| 共鸣解释 | 最适合行为金融篇 | "为什么""总是""每次" |
| 反常识纠偏 | 有明显误解 | "不是 A，而是 B" |
| 机制解释 | 适合量化本体篇 | "到底""真正" |
| 方法入口 | 适合普通人使用篇 | "下次""怎么" |
| 迁移入口 | 适合人生篇 | "原来""本质上" |
| 系列品牌 | 需要保持系列统一 | "用量化思维理解世界 XX" |

### 4.5 组织关键词

必须列出：

1. 必须前置的关键词；
2. 可放后半句的解释词；
3. 可用但慎用的冲突词；
4. 禁止使用或必须降级的词。

标题不能只有修辞，没有关键词。

### 4.6 生成结构壳

先选结构，再写标题。

优先结构：

1. `为什么 [读者场景] 总是 [错误结果]？`
2. `[场景]不是因为 A，而是因为 B`
3. `为什么 [对象] 也 [反常识结果]？`
4. `为什么 [看似好的行为] 反而 [坏结果]？`
5. `[场景]真正的问题，不是 A，而是 B`
6. `为什么 [常见信念] 可能是错的？`
7. `[对象]和[对象]的差距，往往只在 [机制]`
8. `原来 [机制] 才是 [场景] 的关键`

### 4.7 风险过滤

删除或降级以下标题：

1. 一眼看不出主题；
2. 只有成语或隐喻，没有实义关键词；
3. 过度抽象，如"哲学、启示、底层逻辑"单独做中心词；
4. 标题承诺超过正文证明；
5. 冲突词正文无法兑现；
6. 事实、数据不安全；
7. 过度情绪化或平台风险高；
8. 关键词堆砌、不像自然中文；
9. 与同题常见标题过度同质化；
10. 系列感强但单篇打开率弱；
11. 荐股荐基荐币；
12. 承诺收益。

### 4.8 变体排序

最终至少输出：

1. 主推标题；
2. 稳健标题；
3. 信息流标题；
4. 系列一致性标题；
5. 高风险但可讨论标题。

## 五、标题评分表

每个标题必须按以下维度评分。默认每项 1-10 分，再乘以权重。

| 维度 | 权重 | 说明 |
|---|---:|---|
| 主题核心 | 10 | 读者必须一眼知道这篇在讲什么 |
| 文题一致 | 10 | 长期价值来自信任，不来自一次性骗点 |
| 读者入口 | 9 | 复杂议题需要人人能懂的入口 |
| 反常识或共鸣 | 9 | 冲突或共鸣决定点开冲动，但必须能兑现 |
| 解释承诺 | 9 | 本账号卖点是"看懂机制" |
| 平台合规风险 | 9 | 标题必须准确、清晰、反误导 |
| 具体锚点 | 8 | 读者场景、日常行为降低理解门槛 |
| 信息密度 | 8 | 最好同时包含场景、冲突、结论中的至少两项 |
| 可读性与节奏 | 8 | 句式要有换气点，适合手机阅读 |
| 搜索友好度 | 7 | 核心关键词前置，避免堆词 |
| 长度与格式 | 7 | 适合移动端单行或一行半识别 |
| 差异化 | 7 | 同题竞争下不能写成百科式标题 |
| 系列一致性 | 6 | 保持品牌感，但不能牺牲单篇打开率 |
| 情感基调 | 6 | 可以有态度，但不要像营销号 |

### 5.1 综合判断

| 综合结果 | 判断 | 处理 |
|---|---|---|
| 9 分以上 | 可直接作为主推 | 进入最终推荐 |
| 7-8.9 分 | 可用但需微调 | 作为备选或 A/B 测试 |
| 6-6.9 分 | 风险较高 | 只作为讨论方向 |
| 6 分以下 | 不建议使用 | 重写 |

如标题在"文题一致"或"平台合规风险"低于 7 分，即使综合分高，也不得作为主推。

## 六、本系列优先使用的标题结构

### 6.1 为什么型（最优先）

```text
为什么 [读者场景] 总是 [错误结果]？
```

适用：行为金融篇，共鸣最强。

示例方向：

```text
为什么大多数人赚钱的时候拿不住？
为什么你总能买在高点？
为什么亏钱的人总觉得自己快回本了？
```

### 6.2 不是 A，而是 B 型

```text
[场景]不是因为 A，而是因为 B
```

适用：纠正常见误解。

示例方向：

```text
赚钱拿不住，不是因为胆小
定投亏钱，不是因为坚持不够
```

### 6.3 对象也反常识型

```text
为什么 [专业对象] 也 [反常识结果]？
```

适用：基金经理、专业投资者等。

示例方向：

```text
基金经理为什么也经常跑不赢指数？
为什么 90% 的投资建议都没法验证？
```

### 6.4 看似好实则坏型

```text
为什么 [看似好的行为] 反而 [坏结果]？
```

适用：落袋为安、追热点等"看起来对"的行为。

示例方向：

```text
为什么"落袋为安"可能在害你？
为什么越努力盯盘，反而越容易亏？
```

### 6.5 真正的问题型

```text
[场景]真正的问题，不是 A，而是 B
```

适用：深层机制解释。

示例方向：

```text
亏钱真正的问题，不是运气差，而是没有系统
```

### 6.6 差距型

```text
[对象A]和[对象B]的差距，往往只在 [机制]
```

适用：对比型文章。

示例方向：

```text
高手和普通人的差距，往往只是多做了一百次
```

### 6.7 原来型

```text
原来 [机制] 才是 [场景] 的关键
```

适用：机制揭示。

示例方向：

```text
原来"坚持"本身是个数学题
原来赌场才是最古老的量化
```

## 七、本系列慎用或禁用的标题方式

### 7.1 慎用

| 类型 | 问题 | 改法 |
|---|---|---|
| 纯成语开头 | 首屏关键词弱 | 成语后必须接具体场景 |
| 纯鸡汤 | 读者已免疫 | 补机制承诺 |
| 纯抽象概念 | 像论文或书章 | 降级成具体行为、场景 |
| 强冲突词 | 容易超过正文 | 检查正文是否兑现 |
| 过长双段式 | 手机端识别差 | 前半句短，后半句负责说明 |

### 7.2 禁用

1. 震惊式：`震惊、惊人、炸裂、彻底、终于`；
2. 恐吓式：`危险来了、所有人都要小心`；
3. 悬念隐藏式：`背后原因你想不到、真相让人沉默`；
4. 仿官方通知式：`重磅通知、紧急提醒、刚刚宣布`；
5. 过度绝对式：`唯一原因、彻底改变、一切都因为`；
6. 空泛鸡汤式：`坚持就是胜利、相信长期主义`；
7. 代词悬空式：`这件事说明了什么、为什么它会失败`；
8. 荐股荐基荐币式：`这只基金值得买、现在是机会`；
9. 承诺收益式：`学会这招再也不亏、财富自由密码`；
10. 嘲笑读者式：`散户就是韭菜、穷人思维`。

## 八、平台与格式约束

### 8.1 长度

默认标题长度建议：

```text
18-32 个汉字
```

可接受范围：

- 短标题：12-18 字，适合高识别度问题；
- 标准标题：18-32 字，适合本系列大多数文章；
- 长标题：32-42 字，只在双段式且信息密度高时使用；
- 超过 42 字，需要强理由，否则重写。

### 8.2 移动端识别

标题必须适合手机首屏阅读：

1. 关键词尽量靠前；
2. 冒号前半句尽量短；
3. 避免连续三个以上抽象词；
4. 避免多个引号、括号、破折号堆叠；
5. 不用生僻金融术语做唯一入口。

### 8.3 搜索友好

标题中尽量包含至少一个可搜索关键词：

- 行为机制：赚钱、亏钱、拿不住、追高、定投；
- 对象：基金经理、指数、量化、散户；
- 场景：投资、基金、股票、选择；
- 系列：量化思维。

避免为了 SEO 堆砌关键词。关键词必须自然进入句子。

## 九、标题生成输出要求

`07-title-write.md` 使用本配置时，必须输出以下类型标题。

### 9.1 主推标题

1-3 个。

要求：

- 主题清晰；
- 机制承诺强；
- 正文兑现充分；
- 事实口径安全；
- 适合当前平台发布。

### 9.2 稳健标题

3-5 个。

要求：

- 承诺克制；
- 事实安全；
- 适合审核敏感或风险较高文章。

### 9.3 信息流标题

3-5 个。

要求：

- 第一眼能懂；
- 入口强；
- 不使用标题党套路；
- 不隐藏关键信息。

### 9.4 系列一致性标题

2-4 个。

要求：

- 保持本系列"用量化思维理解世界"的长期品牌；
- 能与其他篇章并列；
- 不能为了系列感牺牲单篇打开率。

### 9.5 高风险但可讨论标题

0-3 个。

要求：

- 必须标注"不建议直接采用"；
- 必须说明风险；
- 必须给出降级改法。

## 十、A/B 测试规则

当需要 A/B 测试时，每组只改变一个变量。

可测试变量：

1. 场景前置 vs 机制前置；
2. 共鸣入口 vs 反常识入口；
3. "为什么"问句 vs 判断句；
4. 短标题 vs 双段式标题；
5. 稳健表达 vs 反常识表达。

每组输出：

```text
组别名称：
标题 A：
标题 B：
标题 C：
测试变量：
预期优势：
风险：
```

不得用标题党方式做测试变量。

## 十一、定稿前自检清单

标题定稿前必须回答：

```text
[ ] 读者第一眼知道我在讲什么吗？
[ ] 读者能看出这篇会解释什么吗？
[ ] 标题中的场景、行为或对象够具体吗？
[ ] 标题承诺能被正文兑现吗？
[ ] 是否把局部经验写成全局结论？
[ ] 是否把相关写成因果？
[ ] 是否把多因素解释写成唯一原因？
[ ] 是否存在平台风险或标题党风险？
[ ] 是否荐股荐基荐币？
[ ] 是否承诺收益？
[ ] 是否嘲笑普通投资者？
[ ] 是否有更具体、更短、更清楚的版本？
[ ] 是否保留了系列气质但没有牺牲单篇打开率？
```

如任一高风险项为"否"或"不确定"，不得作为主推标题。

## 十二、示例标题库

以下示例仅用于方法参考，不得机械套用。

### 12.1 行为金融篇

| 标题 | 方法 |
|---|---|
| 为什么大多数人赚钱的时候拿不住？ | 为什么型 + 读者场景 |
| 赚钱拿不住，不是因为胆小 | 不是 A 型 + 反常识 |

## 十三、给标题 agent 的执行约束

当 `07-title-write.md` 读取本配置时，必须遵守：

1. 先看 `发布检查.md` 是否允许进入标题阶段；
2. 再看正文实际证明了什么；
3. 再用本配置生成标题方向；
4. 再按事实核查清单过滤风险；
5. 必要时读取证据台账复核具体事实；
6. 每个标题都要说明：
   - 命名理由；
   - 适配受众；
   - 承诺内容；
   - 正文兑现位置；
   - 风险提醒；
   - 评分；
7. 最终推荐必须优先选择"主题清楚 + 机制承诺强 + 文题一致 + 平台安全"的标题，而不是单纯最刺激的标题。
