# 系列基调配置

> 适用系列：用量化思维理解世界  
> 用途：供方向、文风、大纲、审稿、修订、发布检查等 agent 统一系列气质、解释边界和表达原则。  
> 核心母题：量化表面研究市场，实际研究人在不确定世界里的决策。

---

## 一、系列定位

本系列是**普通人决策方法论型财经专栏**，不是量化策略教程，不是投资荐股栏目，也不是数学科普课。

它要回答：

```text
普通人为什么总在投资、选择和判断上反复犯同样的错？
量化思维能不能帮助一个不懂数学、不写代码的人，少做几次错误决定？
```

核心叙述不是“量化很高级”，而是：

```text
人脑很擅长讲故事，却不擅长处理概率。
市场会放大人的恐惧、贪婪、侥幸和从众。
量化不是预测未来的水晶球，
而是一套把情绪、感觉和运气从决策里剥离出来的方法。
```

---

## 二、系列总气质

| 维度 | 要求 |
|---|---|
| 总体气质 | 清楚、克制、有判断、不端着 |
| 解释方式 | 用日常例子承载机制，用机制解释读者自己的决定 |
| 叙述视角 | 站在读者这一边，像一个比读者早想明白几年的朋友 |
| 情绪强度 | 可以有态度，但不煽动；可以有结论，但不控诉 |
| 现实连接 | 每篇都要让读者带走一个下周就能用上的判断 |
| 读者收获 | 读完获得一套“少亏几次钱、少做几次错决定”的心智模型 |

一句话原则：

```text
不写“你太笨”，写“什么机制让普通人很容易这样做”。
```

---

## 三、五层递进框架

全系列围绕“人如何面对不确定性”展开，按五层递进。

| 层级 | 核心问题 | 典型机制 |
|---|---|---|
| 人为什么总做错决定 | 为什么赚钱拿不住、亏钱扛到底、总买在高点 | 损失厌恶、从众效应、处置效应、确认偏误 |
| 量化到底在做什么 | 量化是否等于预测未来、机器人交易、AI 炒股 | 概率优势、胜率、盈亏比、回测、纪律执行 |
| 市场到底有没有规律 | 为什么策略会失效、为什么没人一直赢 | 有效市场、信息扩散、策略拥挤、过拟合 |
| 普通人怎么使用 | 定投、指数基金、风险控制为何也需要量化思维 | 长期样本、风险预算、最大回撤、低频决策 |
| 用量化思维看人生 | 努力、选择、试错、复利如何被概率解释 | 大数定律、样本数量、贝叶斯更新、反馈周期 |

每篇文章必须明确自己主要服务哪一层，不要一篇文章同时吃下五层。

---

## 四、写作总原则

### 4.1 单篇独立

每篇文章都必须独立成立。

读者不看前文，也能理解：

1. 本篇在问什么；
2. 本篇讲哪个机制；
3. 本篇结论是什么；
4. 本篇如何放回“量化思维理解世界”的暗线。

### 4.2 暗线统一

每篇文章都从不同角度回答：

```text
人在不确定世界里为什么容易被自己骗？
量化思维如何帮人降低被自己骗的概率？
```

但正文中不要机械重复“量化思维很重要”，要让读者从自己的经历里看到这个结论。

### 4.3 每篇只打一颗主钉

一篇文章只解决一个核心问题，交付一个核心机制。

禁止：

- 一篇文章同时讲损失厌恶、有效市场、回测、定投、人生复利；
- 为了显得完整，把文章写成术语大全；
- 在结尾突然拔高到人生哲学，导致正文承诺失焦。

### 4.4 不写策略大全

禁止把本系列写成量化入门教程或策略合集。

不默认展开：

- 双均线；
- 网格；
- 高频；
- CTA；
- Alpha 因子库；
- Python 代码；
- 券商软件教程。

如果具体策略出现，只能作为机制例子，不作为文章主体。

### 4.5 不写投资建议

本系列只解释思维方法，不提供买卖建议。

禁止：

- 推荐具体股票、基金、币种、平台；
- 承诺收益；
- 暗示“照做就能赚钱”；
- 把历史回测说成未来保证；
- 用“普通人唯一出路”这类绝对化表达制造焦虑。

---

## 五、优先内容类型

| 类型 | 用法 |
|---|---|
| 共鸣型 | 用读者自己的亏钱经历、追高经历、拿不住经历打开文章 |
| 机制型 | 用一个行为金融或量化机制解释现象 |
| 对比型 | 用“普通人凭感觉 vs 规则系统”形成反差 |
| 方法型 | 给读者一个能立刻使用的判断句或检查清单 |
| 迁移型 | 把市场机制迁移到职业、学习、选择和人生试错 |

最优先组合：

```text
共鸣型 × 机制型 × 方法型
```

## 六、表达口径

### 6.1 推荐表达

- “少被自己骗一次”
- “先看概率，再看故事”
- “单次结果不重要，长期结构才重要”
- “不是预测未来，而是管理不确定性”
- “规则不是为了显得冷冰冰，而是为了防止情绪变形”
- “好方法要经得起复盘”
- “长期胜率略高，比一次神预测更重要”
- “别只问能赚多少，也要问错了会怎样”

### 6.2 慎用表达

- “稳赚”
- “财富密码”
- “普通人逆袭”
- “唯一正确”
- “颠覆认知”
- “吊打基金经理”
- “AI 时代最后机会”
- “人性弱点决定一切”

慎用词只有在正文充分支撑时才能使用，并必须降级为机制解释。

### 6.3 禁止表达

- 投资承诺；
- 荐股荐基荐币；
- 嘲笑普通投资者；
- 贩卖焦虑；
- 过度鸡汤；
- 数学炫技；
- 神秘化量化；
- 把复杂问题归因给单一人性弱点。

---

## 七、结尾基调

结尾应该完成三件事：

1. 回收本篇机制；
2. 给读者一句能记住的判断；
3. 点出这个判断如何帮助普通人少做一次错误决定。

结尾不应：

- 突然推荐投资产品；
- 突然升格成宏大人生鸡汤；
- 写成口号堆叠；
- 用“你必须”“你一定要”压迫读者。

推荐结尾力度：

```text
克制地指出：量化思维不是让人没有情绪，而是让情绪不要直接接管决定。
```
