# 文风禁用清单

> 适用系列：用量化思维理解世界  
> 用途：供文风、大纲、草稿、审稿、修订、发布检查等环节排除不适合本系列的表达。  
> 核心原则：不装深、不带节奏、不荐股、不鸡汤。

---

## 一、绝对禁止的表达方向

### 1.1 投资承诺类

禁止：

- 稳赚不赔；
- 保证收益；
- 长期必胜；
- 普通人靠这个翻身；
- 学会这招再也不怕亏；
- 财富自由密码；
- 下一轮机会就在这里；
- 现在不上车就晚了。

替代表达：

```text
它不能保证你赚钱，
但能帮助你少做一些明显错误的决定。
```

### 1.2 荐股荐基荐币类

禁止：

- 建议买入；
- 可以布局；
- 适合上车；
- 逢低加仓；
- 现在是机会；
- 这类资产值得配置；
- 某某标的是普通人的好选择。

替代表达：

```text
本文不讨论具体买卖，
只讨论判断一套方法是否可靠时应该看什么。
```

### 1.3 嘲笑读者类

禁止：

- 散户就是韭菜；
- 普通人太贪；
- 你亏钱是活该；
- 没认知就别碰市场；
- 大多数人注定被收割；
- 这就是穷人思维。

替代表达：

```text
这个错误很常见，
不是因为人笨，
而是因为人的本能在市场里经常会变形。
```

### 1.4 神秘化量化类

禁止：

- 量化正在统治市场；
- 机器已经碾压人类；
- 散户在量化面前毫无机会；
- 真正赚钱的人都在用某种秘密模型；
- AI 量化时代，普通人已经没有选择。

替代表达：

```text
量化并不神秘。
它首先是一种把规则说清楚、把结果放进样本里检验的方法。
```

### 1.5 过度鸡汤类

禁止：

- 相信长期主义；
- 坚持就是胜利；
- 努力一定有回报；
- 人生没有白走的路；
- 越努力越幸运；
- 普通人逆袭靠认知。

替代表达：

```text
长期有意义，不是因为它听起来正确，
而是因为概率优势需要足够多的样本才有机会显现。
```

## 二、慎用词

以下词语不是绝对禁止，但需要有充分机制支撑。

| 慎用词 | 风险 | 建议替代 |
|---|---|---|
| 收割 | 容易变成阴谋论或情绪煽动 | 交易对手、成本、错误定价 |
| 韭菜 | 嘲笑读者 | 普通投资者、没有系统的人 |
| 财富密码 | 营销号口吻 | 判断框架、方法论 |
| 颠覆认知 | 标题党 | 换一个角度看 |
| 唯一 | 绝对化 | 重要、常见、值得注意 |
| 必然 | 过度确定 | 更容易、往往、可能 |
| 人性 | 容易空泛 | 具体写损失厌恶、从众、确认偏误 |
| 底层逻辑 | 容易套话 | 机制、规则、约束 |
| 认知差 | 容易优越感 | 信息差、方法差、执行差 |
| 逆袭 | 鸡汤化 | 改善、提高胜率、减少错误 |

## 三、标题禁用风格

禁止标题：

- 《学会量化，普通人也能财富自由》
- 《AI 量化正在淘汰所有散户》
- 《99% 的人不知道的赚钱底层逻辑》
- 《为什么你注定被市场收割》
- 《普通人最后一次翻身机会》
- 《看懂这篇，投资再也不亏》

推荐标题：

- 《为什么大多数人赚钱的时候拿不住？》
- 《为什么你总能买在高点？》
- 《量化到底在赚谁的钱？》
- 《为什么 90% 的投资建议都没法验证？》
- 《量化最怕的不是亏钱，而是规律消失》

## 四、开头禁用风格

禁止开头：

```text
在当今复杂多变的资本市场中，量化投资已经成为越来越重要的投资方式。
```

问题：太像报告，读者没有进入感。

禁止开头：

```text
如果你还不会量化，那么你注定会被市场淘汰。
```

问题：贩卖焦虑，且结论过度。

禁止开头：

```text
很多散户之所以亏钱，本质上是因为认知太低。
```

问题：羞辱读者，且解释粗糙。

推荐开头：

```text
很多人都有一个奇怪的习惯：
亏钱的时候能扛很久，
赚钱的时候反而三天就想跑。

这不只是胆小。
它背后有一个很稳定的心理机制。
```

## 五、术语禁用方式

禁止把术语当成权威压读者。

不推荐：

```text
根据行为金融学中的损失厌恶理论和前景理论，投资者会表现出非对称效用函数下的风险偏好变化。
```

推荐：

```text
损失厌恶说的是：
同样一块钱，亏掉带来的痛苦，
通常比赚到带来的快乐更强。
```

---

## 六、结尾禁用风格

禁止结尾：

- 所以赶紧学量化；
- 所以普通人必须拥抱 AI；
- 所以下一轮财富机会属于懂概率的人；
- 所以人生也是如此，只要坚持就会成功；
- 所以关注我，带你系统学习量化。

推荐结尾：

```text
量化思维的价值，
不是让你每一次都判断正确。

它更现实：
在你最容易被情绪推着走的时候，
先让规则替你挡一下。
```

## 七、审稿自检清单

每篇文章发布前检查：

1. 是否出现收益承诺；
2. 是否出现具体买卖建议；
3. 是否嘲笑普通投资者；
4. 是否把量化写得过度神秘；
5. 是否把复杂问题归因给单一人性弱点；
6. 是否使用营销号标题；
7. 是否出现没有解释的术语；
8. 是否把回测说成未来保证；
9. 是否把结尾写成鸡汤；
10. 是否缺少读者可带走的判断。

任一项不合格，必须退回修订。
