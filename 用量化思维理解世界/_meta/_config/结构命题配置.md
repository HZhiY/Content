# 结构命题配置

> 适用系列：用量化思维理解世界  
> 用途：供结构标准、结构分析、方向把控、大纲和审稿阶段判断文章的洞察组合、承诺链和证明链是否成立。  
> 核心原则：结构不是资料顺序，而是读者理解机制的顺序。

---

## 一、结构命题定位

本系列每篇文章都应围绕一个结构命题展开：

```text
某个常见的投资/决策错误，背后是什么行为机制或概率机制在起作用，
市场如何放大它，量化思维如何帮助绕开它。
```

结构命题必须能回答：

1. 文章从哪个读者经历进入；
2. 核心机制是什么；
3. 市场/环境如何放大这个弱点；
4. 量化思维如何处理它；
5. 这一步如何服务"用量化思维理解世界"的母题。

---

## 二、六类洞察分工

### 2.1 入口洞察

作用：把读者带进问题。

要求：

- 具体；
- 好懂；
- 有共鸣感；
- 不需要专业背景。

常见入口：

- 一个亏钱经历；
- 一个追高场景；
- 一个拿不住的动作；
- 一个"别人赚钱我错过"的焦虑；
- 一个反常识问题。

### 2.2 骨架命题

作用：支撑全文主线。

格式：

```text
因为 [行为/概率机制]，人在 [场景] 中容易做出 [错误动作]；
市场会放大这个弱点；量化思维通过 [方法] 来绕开它。
```

要求：

- 可被正文证明；
- 不过度抽象；
- 不超过事实边界；
- 能贯穿每个小节。

### 2.3 副洞察

作用：辅助主命题，解释某个环节。

要求：

- 不能抢主线；
- 不能引入另一篇文章的主题；
- 必须服务骨架命题。

### 2.4 新意洞察

作用：让文章区别于常见写法。

要求：

- 是解释角度的新意，不是事实猎奇；
- 必须被证据支撑；
- 不能为了新意牺牲准确。

### 2.5 反差洞察

作用：制造读者想读下去的张力。

常见反差：

- 表面是胆小，实际是损失厌恶在驱动；
- 表面是稳健，实际是情绪在替你做决定；
- 表面是保守，实际在破坏长期盈亏结构；
- 表面是理性，实际在用感觉代替概率；
- 表面是简单，实际是最难执行的。

反差必须能被正文兑现。

### 2.6 结尾升维洞察

作用：把本篇机制放回全系列暗线。

要求：

- 只升一层；
- 从正文自然推出；
- 不引入新事实；
- 不写成鸡汤。

---

## 三、承诺链

文章必须形成清楚的承诺链：

```text
标题承诺
→ 引言提出问题
→ 方向主承诺
→ 大纲小节证明
→ 草稿正文兑现
→ 结尾回收
```

任一环节断裂，都应退回对应阶段。

---

## 四、证明链

证明链应按"读者理解顺序"组织，而不是按资料出现顺序组织。

推荐链条：

1. 读者自己的错误经历；
2. 常见理解（胆小、没经验、运气差）；
3. 关键反转（不是性格问题，是机制问题）；
4. 核心机制解释；
5. 市场如何放大它；
6. 量化思维如何处理；
7. 普通人能带走什么；
8. 本篇在全系列中的位置。

---

## 五、结构评分维度

每个候选结构命题按 1-5 分评分。

| 维度 | 权重 | 说明 |
|---|---:|---|
| 主承诺清晰度 | 5 | 是否一句话说清文章要证明什么 |
| 证明链完整度 | 5 | 是否能从经历推到机制到方法 |
| 入口适配度 | 5 | 是否服务五层递进框架 |
| 读者理解顺序 | 4 | 是否按读者能理解的顺序推进 |
| 事实安全 | 5 | 是否不突破事实边界 |
| 反差有效性 | 4 | 是否有张力且能兑现 |
| 副洞察克制 | 4 | 是否不抢主线 |
| 结尾升维安全 | 4 | 是否自然回到系列暗线 |

事实安全低于 4 分，结构命题不得通过。

---

## 六、一票否决项

出现以下任一项，结构命题不通过：

1. 主承诺无法被事实核查清单支撑；
2. 文章试图同时证明多个主命题；
3. 结构只是资料顺序，不是论证顺序；
4. 入口洞察和骨架命题不一致；
5. 反差洞察正文无法兑现；
6. 结尾升维超出正文证明；
7. 副洞察变成另一篇文章；
8. 方向把控已放弃的内容被重新引入；
9. 需要读者读过前文才能理解；
10. 把复杂机制压成单一人性弱点。

## 七、按文章类型的结构建议

### 7.1 共鸣型 × 机制型

结构：

```text
读者经历 → 常见误解 → 机制反转 → 市场放大 → 方法 → 一句话带走
```

适合：行为金融篇（赚钱拿不住、追高、亏钱死扛）。

### 7.2 机制型 × 分析型

结构：

```text
现象 → 机制部件 → 传导链路 → 失效或转折 → 框架提炼
```

适合：量化本体篇（赚谁的钱、回测、过拟合）。

### 7.3 对比型 × 分析型

结构：

```text
凭感觉做 → 用规则做 → 差异点 → 概率优势 → 长期结果
```

适合：普通人 vs 系统、基金经理 vs 指数。

### 7.4 迁移型 × 方法型

结构：

```text
市场机制 → 生活类比 → 概率解释 → 普通人能带走什么
```

适合：人生迁移篇（大数定律、样本量、坚持对）。

### 7.5 反常识纠偏型

结构：

```text
读者常识 → 反常识判断 → 证据 → 机制 → 纠偏后的新框架
```

适合：有效市场、策略失效、幸存者偏差。

---

## 八、大纲检查问题

生成或审阅大纲时必须问：

```text
[ ] 本文主承诺是否一句话可说清？
[ ] 每节是否服务同一个骨架命题？
[ ] 是否有一节只是在堆资料？
[ ] 是否按读者理解顺序推进？
[ ] 是否过早使用抽象概念？
[ ] 是否把故事讲成了目的？
[ ] 是否有副洞察抢主线？
[ ] 结尾是否自然回到五层递进？
[ ] 标题、引言、大纲、结尾是否承诺一致？
```

---

## 九、方向把控输出要求

方向把控最终必须明确：

1. 方向主承诺；
2. 入口洞察；
3. 骨架命题；
4. 可用副洞察；
5. 应放弃洞察；
6. 标题承诺边界；
7. 大纲必须证明的链条；
8. 结尾允许升维到哪里。

不得只写"方向可行"这类空泛结论。
